# 🤖 Antigravity コマンド一覧

AIアシスタント（Antigravity）に「/コマンド名」で話しかけると、決められた手順を自動実行してくれます。

---

## 📋 コマンド一覧

| コマンド | 何をするのか | 使い方のヒント |
|---------|------------|---------------|
| `/sales-funnel` | セールスファネル（台本・LP・LINEシナリオ等）を一式制作する | ヒアリングシートを埋めて一緒に渡すとスムーズ |
| `/deploy` | HTMLページをsurge.shにデプロイし、デプロイ台帳を更新する | 「このHTMLをデプロイして」と一言添えるだけでOK |
| `/update-ritzpro` | 議事録をもとにリッツプロのダッシュボードを更新しデプロイする | 議事録テキストを貼り付けて使う |
| `/figma-to-html` | FigmaデザインをHTML/CSSに変換する（双方向連携） | Figma Channel IDが別途必要 |
| `/pdf-to-md` | PDFからテキストを抽出してMarkdownに変換する | PDFのパスを指定して使う |
| `/claude` | Claude Code（別AI）に高度なタスクを委譲する | 複雑なコーディングタスクを丸投げしたい時 |

## 💡 使い方の基本

```
/コマンド名 + 補足情報や素材を一緒に貼り付けて投げる

例：
  /sales-funnel ← ヒアリングシートをここに貼り付ける
  /deploy この sales-letter フォルダをデプロイして
  /pdf-to-md /Users/hiroshi/Desktop/資料.pdf
  /update-ritzpro ← 議事録テキストをここに貼り付ける
```
