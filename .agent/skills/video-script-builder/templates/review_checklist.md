# 台本レビューチェックリスト

## 全体構成

- [ ] 全体の心理導線が設計されているか（問題認識→教育→オファー）
- [ ] 各話の役割が明確か
- [ ] 話のつなぎ（次回予告→次話冒頭）が自然か
- [ ] トータル尺が適切か

## 第一話（導入＋全体像）

### フック
- [ ] 冒頭15秒で「何が手に入るか」を明言しているか
- [ ] 対象者を3カテゴリ以上明示しているか
- [ ] 到達可能な数字を3段階で提示しているか

### 動機づけ
- [ ] 視聴期限（緊急性）を設定しているか
- [ ] 最終話のプレゼントを予告しているか
- [ ] 回避できるリスクを3つ列挙しているか

### 信頼構築
- [ ] 自己紹介に外部権威（メディア等）を含めているか
- [ ] 挫折→覚醒ストーリーに「メソッドとの出会い」が含まれているか
- [ ] クライアント/受講生事例は3名以上あるか

### メッセージ
- [ ] 核心メッセージが1フレーズに凝縮されているか
- [ ] 売上の方程式で論理的に証明しているか
- [ ] 業界の常識を1つ以上否定しているか
- [ ] メソッドに固有名詞がついているか

### CTA
- [ ] 次回予告が「質問形式」で好奇心を煽っているか
- [ ] 感想ボタンCTAが明確か

## 第二話・第三話（教育パート）

- [ ] 前回の1行要約があるか
- [ ] 具体的なフレームワーク/手順を提示しているか
- [ ] 実例（Before→After）で解説しているか
- [ ] よくある間違いを指摘しているか
- [ ] 受講生/クライアントのインタビュー or 事例があるか
- [ ] 次話への好奇心を煽る予告があるか

## 第四話 / VSL（オファーパート）

### 価値の構築
- [ ] 理想の未来を5感で描写しているか
- [ ] 3つの未来パターンを提示しているか
- [ ] 最悪の未来（何もしなかった場合）を描いているか

### 反論処理
- [ ] 「自分にもできるか？」への回答があるか
- [ ] 「詐欺じゃないか？」への回答があるか
- [ ] 「お金がない」への回答があるか
- [ ] 「時間がない」への回答があるか
- [ ] 「自分は〇〇だから無理」への回答があるか（属性別）

### 社会的証明
- [ ] Before/After事例が感情の変化を含んでいるか
- [ ] アンケートデータ（数字）があるか
- [ ] インタビュー動画の挿入箇所が指定されているか

### オファー構造
- [ ] 商品の詳細が過不足なく説明されているか
- [ ] 価値の積み上げ（合計〇〇万円分）があるか
- [ ] 価格の葛藤ストーリーがあるか
- [ ] 日割り換算があるか
- [ ] 保証（返金保証等）が明記されているか
- [ ] 特典名にベネフィットが埋め込まれているか
- [ ] スクリーニング（合う人/合わない人）があるか

### クロージング
- [ ] 2択クロージングの構造になっているか
- [ ] CTAが具体的か（ボタンの場所等）
- [ ] 緊急性のリマインドがあるか
- [ ] ミッションステートメント（利他的な締め）があるか

## 品質チェック

- [ ] 📌マークで差し替え箇所が全て明示されているか
- [ ] 【】で演出指示が適切に入っているか
- [ ] 抽象的な表現を具体的な数字に置き換えているか
- [ ] 感情に訴えるシーン描写が含まれているか
- [ ] 間（ま）の指示が適切に入っているか
- [ ] 話し言葉として自然に読めるか
