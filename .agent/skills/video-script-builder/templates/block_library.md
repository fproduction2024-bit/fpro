# 台本ブロックライブラリ（Block Library）

> **用途**: ファネル動画の各ブロックを新規案件に差し込む際の再利用パーツ集
> **参照元**: e-Harbor（高単価セールス）、Skill Hacks（副業スキル）、COMPASS（フィットネスコーチ）

---

## A. 導入系ブロック

### A-1. フック（冒頭メリット提示）

```
「このセミナーでは、[ターゲット]の方が、
[到達目標①]、[到達目標②]、そして[到達目標③]を実現できるようになる方法を
オンライン完結でお伝えします。
最後まで見ていただければ、[最大の成果]が手に入ります」
```

**差し替え箇所（📌）**
- 📌 ターゲット（コンサル・コーチ・講師 etc）
- 📌 到達目標（3段階：現実的→高め→理想）
- 📌 最大の成果（最も刺さるベネフィット）

---

### A-2. 回避できるリスク列挙

```
「逆に言うと、この動画を最後まで見ることで、以下を回避できます」
1. [お金軸のリスク]：📌 来月の売上が不安、資金ショートの恐怖
2. [時間軸のリスク]：📌 時間の切り売りから抜けられないジレンマ
3. [精神軸のリスク]：📌 方向性が見えない焦り、やる気の消耗
```

**再現ポイント**: 3軸すべてを網羅することで「自分に当てはまる」が増える

---

### A-3. 実績チラ見せ

```
「実際に、[初心者向け実績]、また[中級者向け実績]という形で
結果を出していただいています」
（詳細はストーリーパートで後出し）
```

**差し替え箇所（📌）**
- 📌 初心者実績：「影響力0から○ヶ月で○万円」
- 📌 中級者実績：「年商○万→○億へ」

---

### A-4. 緊急性＋限定性

```
「この動画は[期限]間の限定配信です。
[期限]以上放置すると閲覧できなくなり、二度と見ることができません。
[対応不可の宣言]、本気の方だけにご覧いただきたいと思います」
```

**差し替え箇所（📌）**
- 📌 期限：「3日間」が黄金バランス
- 📌 対応不可の宣言：「問い合わせへの対応もできませんので」

---

### A-5. プレゼント予告

```
「最後まで見ていただいた方には、
[プレゼント名（ベネフィット埋め込み）]を
特別にご用意しています。
[投資額・開発費]から導き出した[価値]を、
今回限定でお届けします。
詳細は最終話でお伝えします」
```

**差し替え箇所（📌）**
- 📌 プレゼント名：「年商○○を仕組み化する 1on1オーダーメイド戦略診断」等
- 📌 投資額：「2,000万の事業投資」「5年の現場実績」等

## B. 権威構築系ブロック

### B-1. 自己紹介＋権威付け

```
「改めまして、[会社名]代表の[名前]と申します。
私たちは[専門領域]に特化した[事業形態]を運営しており、
これまでに[成約率]を実現するプロ集団です。

[外部権威]では[実績・受賞・掲載]もいただいており、
現在は[人数]名のプロフェッショナルチームで[提供価値]を
クライアントの皆様にお届けしています」
```

**差し替え箇所（📌）**
- 📌 外部権威：テレビ・新聞・雑誌・受賞・著書 等
- 📌 チーム体制：専門領域ごとに紹介すると信頼度UP

---

### B-2. 挫折→覚醒ストーリー

```
ブロック①【失敗の始まり】
「私も昔は[年齢]歳で[挑戦]しましたが、
[失敗の理由]により、[最悪の状況]になりました」

ブロック②【どん底の描写】
「[感情・心情の描写]。
[具体的な状況]で、本当に[感情]でした」

ブロック③【転換点との出会い】
「そんな時、[転換点（人・本・体験）]との出会いがありました」

ブロック④【覚醒の瞬間】
「[メソッド/台本/手法]を使ったところ、
初めて[具体的な数字と期間]という結果が出ました」

ブロック⑤【成長の軌跡】
「それから[期間]で[数字]、そして[期間]で[数字]へと
ステップアップすることができました」
```

**再現ポイント**
- 失敗は具体的（年齢・金額・感情を入れる）
- 転換点は「1つ」に絞る
- 覚醒は数字で証明する

## C. 教育系ブロック

### C-1. 核心メッセージ（1フレーズ）

```
「結論、[核心スキル/核心コンセプト]をマスターすることが全てです。
[核心スキル]がない状態で[目標]しようとするから、
[問題①][問題②][問題③]が生まれてしまうのです」
```

**キャッチーな1フレーズの作り方**
- 「○○は△△が9割」
- 「△△なくして○○なし」
- 「売れる必然を作る」
- 「○○力をマスターせよ」

---

### C-2. 独自フレームワーク提示

```
「本日お伝えするのは、[フレームワーク名]です。
これは[要素A] × [要素B] × [要素C]の3つが揃って初めて機能します。
多くの方はこのいずれかが欠けているか、ずれています」
```

**再現ポイント**
- フレームワークは3要素以内（認知負荷を抑える）
- 有名フレームワークを引用 or 独自名称をつける

---

### C-3. 信念の書き換え（Before→After）

```
「多くの方は[誤った信念]だと思っていますが、
実はそうではありません。
正しくは[新しい信念]です。

なぜなら、[誤った信念]だと[デメリット]になりますが、
[新しい信念]だと[メリット]が得られるからです」
```

**汎用的な信念書き換えパターン**
| Before（誤） | After（正） |
|-------------|------------|
| 集客が先 | 商品・セールスが先 |
| 安い商品の方が売りやすい | 高額の方が顧客の質が上がる |
| 教えることが商品 | 結果を得られる仕組みが商品 |
| 認知されるから売れる | 売れるから認知される |
| 口が上手い人が売れる | 台本がある人が売れる |

---

### C-4. 比喩で具体化

```
「わかりやすく言うと、[身近な業界/職業]の例で考えてみてください。
[A型（誤ったやり方）]の[職業]は[行動]をします。
一方、[B型（正しいやり方）]の[職業]は[行動]をします。
あなたがやるべきなのは後者です」
```

**汎用的な比喩リスト**
- 医者（診断→処方）vs 薬剤師（成分説明）
- スポーツトレーナー（結果にコミット）vs 情報提供者（方法を教えるだけ）
- 優秀な営業マン（ヒアリング後出し）vs 下手な営業（いきなりプレゼン）

---

### C-5. ステップ提示（「見せるが渡さない」）

```
「私は[テーマ]において[ステップ数]つのステップを使っています。
全体像はお見せしますが、詳細なテンプレートは
今回のプレゼント（診断参加特典）としてお渡しします」

Step 1: [概要のみ]
Step 2: [概要のみ]
Step 3: [概要のみ]
```

---

### C-6. 機会損失の数字化

```
「ちなみに、[成果ある人]と[成果ない人]の
[単位]あたりの差は[数字]。
これを年間に換算すると、実に[年間数字]もの差になります。
あなたは今、毎[単位][数字]を損しているかもしれません」
```

**再現ポイント**: 月次→年次換算でインパクトを最大化

## D. 事例系ブロック

### D-1. クライアント事例（テキスト）

```
「[肩書き・属性]の[名前orイニシャル]さんの場合、
受講前は[Before状況]という状態でした。
[メソッドで何をしたか（1行）]。
その結果、[After成果（数字）]を実現されました」
```

**属性の分散ポイント**
- 初心者〜上級者でレベルを分ける
- 男性・女性で分ける
- 業種・職種を分ける

---

### D-2. インタビュー動画の構成

```
1. 自己紹介（What）
   「簡単に自己紹介をお願いします」

2. Before（Before）
   「受講前、どんな状況/悩みでしたか？」

3. 転換点（Why）
   「何がきっかけで変わりましたか？」

4. After（After）
   「具体的にどんな成果が出ましたか？」（数字必須）

5. 印象的な一言（Insight）
   「一番印象に残った考え方を教えてください」

6. 差別化（Diff）
   「他と比べてどんな点が特徴的でしたか？」
```

## E. オファー系ブロック

### E-1. 理想の未来描写（最終話）

```
「一度、想像してみてください。
[シーン①：場所の自由]
[シーン②：時間の自由]
[シーン③：家族との時間]
[シーン④：お金の自由]
[シーン⑤：自己実現/貢献]
こんな状態になれたとしたら、あなたの人生はどう変わりますか？」
```

**5カテゴリから選ぶ**
1. 💼 場所の自由（どこでも働ける）
2. ⏱️ 時間の自由（好きな時に働ける）
3. 👨‍👩‍👧 家族との時間（子供の成長を見届けられる）
4. 💰 お金の自由（銀行残高が増え続ける）
5. 🌟 自己実現（社会に貢献できる）

---

### E-2. プレゼント提示

```
「動画を最後まで見てくださったあなたに、
[プレゼント正式名称（ベネフィット入り）]を
無料でご提供します。

通常、このサービスは[通常価格]で提供しているものですが、
今回に限り[理由]のためお代はいただきません。

私たちのプロコンサルタントと[時間]のZoom面談で
[具体的に得られること]をお約束します」
```

---

### E-3. 特典の構成設計

| 特典番号 | 役割 | 設計の意図 |
|---------|------|---------|
| 特典① | 外部権威 | テレビ取材映像、推薦書、受賞実績等 |
| 特典② | 知識集 | メソッドの深掘りコンテンツ |
| 特典③ | **本命特典（第三話で欲求を作ったもの）** | テンプレート・台本・ツール |
| 特典④ | 第四話教育の補強 | 広告ガイド、集客ツール等 |
| 特典⑤ | **バックエンドへのブリッジ** | 優待価格・売上保証付き参加権 |

以下に該当する方はご遠慮ください：

## G. チェックリスト（全話共通）

### 第一話チェックリスト
- [ ] 冒頭15秒で「何が手に入るか」を明言しているか
- [ ] 対象者を3カテゴリ以上明示しているか
- [ ] 視聴期限（緊急性）を設定しているか
- [ ] 最終話のプレゼントを予告しているか
- [ ] 挫折→覚醒ストーリーに「メソッドとの出会い」が含まれているか
- [ ] 核心メッセージが1フレーズに凝縮されているか
- [ ] クライアント事例は3名以上あるか（属性分散）
- [ ] 次回予告が「質問形式」で好奇心を煽っているか

### 第二話チェックリスト
- [ ] 前回の核心メッセージを冒頭でリマインドしているか
- [ ] 独自フレームワーク（3要素以内）を提示しているか
- [ ] 信念の書き換えが最低3つあるか
- [ ] リサーチ/顧客理解を「最優先」として位置づけているか
- [ ] インタビュー動画が1本以上あるか

### 第三話チェックリスト
- [ ] 機会損失を年間換算の数字で見せているか
- [ ] ❌型 vs ✅型の対比を教育しているか
- [ ] 比喩で概念を具体化しているか
- [ ] テンプレートの存在を見せて「特典で渡す」と告知しているか
- [ ] 差別化を「3つの否定→自社の強み」で表現しているか
- [ ] 最終話への最大フックを仕込んでいるか

### 第四話チェックリスト
- [ ] 理想の未来を5シーン以上描写しているか
- [ ] プレゼント名にベネフィットが埋め込まれているか
- [ ] 特典の中に前話で欲求を作ったものが含まれているか（伏線回収）
- [ ] スクリーニング（NG→OK）を明示しているか
- [ ] 2択クロージングを使っているか
- [ ] カウントダウン＋「全消滅」で緊急性を最大化しているか
- [ ] 申し込み手順が4ステップ以内か
- [ ] ミッションステートメントで利他的に締めているか
