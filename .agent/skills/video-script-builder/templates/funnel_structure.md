# ファネル動画 全体構成テンプレート（4話構成）

> **参照元**: e-Harbor「3ステップセールスメソッド」ファネル（全4話）
> **用途**: 高単価バックエンド商品（コンサル・スクール・セッション）への誘導ファネル

---

## ファネル全体の心理導線

```
第一話: 問題認識 → 権威構築 → メソッド全体像の提示 → 好奇心
第二話: 教育①（商品/方法論） → 「自分にもできそう」
第三話: 教育②（セールス/実践） → 「具体的なツールが欲しい」
第四話: 教育③（集客/自動化） → オファー → 緊急性 → 申込
```

---

## ファネル設計の前提

| 項目 | 設計指針 |
|------|---------|
| **配信形式** | LINE登録 → 感想ボタン（行動）で次話解放 |
| **緊急性演出** | 各動画は「3日間限定配信」で閲覧期限を設定 |
| **各話の尺** | 第一話25分、第二話20分、第三話25分、第四話40〜50分 |
| **商品構造** | フロントエンド（無料動画＋無料診断）→ バックエンド（有料プログラム） |
| **クロージング方法** | 第四話内で完結（動画内オファー＋申込手順まで） |

---

## 第一話：フック＋権威構築＋メソッド全体像

**役割**: 問題認識させ、話者を信頼させ、次話を見たくさせる

### 構成ブロック（順番厳守）

```
1.  フック：メリット提示＋対象者の明示         ← 離脱防止（冒頭15秒以内）
2.  回避できるリスクの列挙                      ← 痛みの喚起（お金・時間・精神の3軸）
3.  実績チラ見せ（数字）                        ← 信頼の種まき
4.  緊急性＋限定性の設定                        ← 視聴動機の強化（3日限定）
5.  プレゼント予告                              ← 最終話まで見る動機（体験型）
6.  自己紹介＋権威付け                          ← 話者の信頼構築（外部権威必須）
7.  挫折→覚醒ストーリー（最長ブロック）         ← 感情移入＋共感
8.  核心メッセージの提示                        ← 世界観のインストール（1フレーズ）
9.  売上の方程式（論理補強）                    ← 納得感（3変数以内の数式）
10. 常識の否定（パラダイムシフト）              ← 気づきの付与
11. 広告/詳細手法の前提条件                    ← 第四話への伏線
12. 3ステップメソッド紹介（ロードマップ）       ← 全体像の提示
13. 自社実験の証明                              ← 再現性の裏付け
14. クライアント事例（3〜4名）                  ← 社会的証明
15. 理想の未来描写                              ← 欲求の最大化
16. 次回予告＋感想ボタンCTA                     ← 行動誘導
```

### ❶ フック：メリット提示＋対象者明示

```
「このセミナーでは[目標成果]ができるようになる方法をお伝えします」
→ 対象者を3〜4カテゴリ具体的に列挙（自分ごと化）
→ 数字を3段階で提示（現実的→やや高め→理想的）
```

**再現ポイント**
- 冒頭15秒以内に「何が手に入るか」を明言する
- 対象者を具体的に挙げて「自分のことだ」と思わせる

---

### ❷ 回避できるリスクの列挙

```
「逆に言うと、この動画を最後まで見ることで〇〇を回避できます」
```

**3軸で網羅**
1. 💰 お金のリスク（来月の売上不安、資金難）
2. ⏰ 時間のリスク（時間の切り売り、労働集約）
3. 🧠 精神のリスク（不安、焦り、方向性のなさ）

---

### ❸ 実績チラ見せ

- 初心者向け実績：「ゼロから→○ヶ月で○○万」
- 中級者向け実績：「年商○○万→○億へ」
- **詳細はストーリーパートで展開（ここはあくまでチラ見せ）**

---

### ❹ 緊急性＋限定性

```
「このセミナー動画は3日間の限定配信。3日以上放置すると閲覧不可になります」
「本気の方だけに見てほしいため、問い合わせ対応はできません」
```

**再現ポイント**: 期限は「3日」が黄金バランス

---

### ❺ プレゼント予告

- プレゼント＝実質的なバックエンドへの導線（体験型：診断・セッション・面談）
- 「○○万円投資して導き出した」でアンカリング
- 詳細は最終話で公開（全話視聴の動機）

---

### ❻ 自己紹介＋権威付け

| 要素 | 内容 |
|------|------|
| 会社名・代表名 | 正式名称で |
| 専門分野 | 1行で言語化 |
| 実績（率＋額） | 「成約率○%」「年商○億」等 |
| 外部権威 | テレビ出演・メディア掲載・受賞歴 |
| チーム体制 | 人数＋各専門領域 |

---

### ❼ 挫折→覚醒ストーリー（最長ブロック）

```
1. 過去の失敗（共感ポイント）
   └ 年齢・金額・感情を具体的に
2. どん底の描写
   └ 最も辛かった瞬間を1シーンで
3. 転換点（メソッドとの出会い）
   └ 「1冊の本」「1人の師匠」「1つの気づき」に集約
4. 覚醒の瞬間
   └ 初めて数字が出た瞬間を数字で証明
5. 成長の軌跡
   └ 段階的に数字を積み上げる
```

**再現ポイント**: ストーリーの起点が「今教えているメソッドの原点」になっている

---

### ❽ 核心メッセージ

```
「結論、[コアスキル/コアコンセプト]をマスターすることです」
「[コアスキル]がない状態で[目標]しようとしているから、全ての悩みが生まれる」
```

**再現ポイント**: 核心メッセージは**1フレーズ**に凝縮する

---

### ❾ 売上の方程式

```
[変数A] × [変数B] × [変数C] = 売上
```

- 方程式は最大3変数に絞る
- 「たった○人集めるだけ」と心理的ハードルを下げる計算式を示す

---

### ❿ 常識の否定（パラダイムシフト）

```
「[業界の常識]と思っている方が多いですが、[正しい考え方]が正解です」
「正しい順序は [1→2→3] であり、[2→1→3] は逆です」
```

**再現ポイント**: 「AではなくB」という反転構文が記憶に残る

---

### ⓫ 次回予告＋感想ボタンCTA

```
「次回は[次話テーマを質問形式でティーザー]します」
「感想ボタンを送った方だけに個別で続きの動画をお送りします」
「3日間以内に必ずご覧ください」
```

## 第二話：教育①（理論・考え方）

**役割**: 正しい考え方を教育し、「自分にもできるかも」と思わせる

### 構成ブロック

```
1.  前回の振り返り（リマインド）                ← 文脈の再接続
2.  今回の約束（メリット提示）                  ← 視聴動機
3.  回避できるリスク（今話テーマに即した）      ← 痛みの維持
4.  信念の書き換え（常識の否定）                ← 前提のアップデート
5.  本編フレームワーク提示（3要素以内）          ← 本編開始
6.  フレームワーク詳細①                        ← 教育①
7.  フレームワーク詳細②（リサーチ/顧客理解）   ← 教育②（最重要）
8.  フレームワーク詳細③                        ← 教育③
9.  フレームワーク詳細④（スケーラブル運営）    ← 教育④
10. クライアント成功事例（数字のBefore→After） ← 社会的証明
11. インタビュー動画                            ← 感情的証明
12. 次回予告＋感想ボタンCTA                     ← 行動誘導
```

### 重要な教育テクニック：信念の書き換えパターン

| 既存の信念（Before） | 新しい信念（After） |
|---------------------|-------------------|
| [業界の誤った常識①] | [正しい考え方①] |
| [業界の誤った常識②] | [正しい考え方②] |
| [業界の誤った常識③] | [正しい考え方③] |

**再現ポイント**: 最低3つの信念書き換えを盛り込む

### インタビュー動画の構成（1本必須）

```
1. 自己紹介（何をしている人か）
2. Before（何に悩んでいたか）
3. 転換点（何がきっかけで変わったか）
4. After（具体的な成果・数字）
5. 印象に残った言葉/考え方
6. 他との違い（なぜこのプログラムを選んだか）
```

## 第三話：教育②（実践・テクニック）

**役割**: 具体的な方法論を教え、「ツールが欲しい」という欲求を最大化する

### 構成ブロック

```
1.  導入：問題の重要性（数字でインパクト）      ← 注意獲得
2.  苦手意識への共感                            ← 心理的バリア除去
3.  核心メッセージ（「○○は△△が9割」形式）    ← 世界観インストール
4.  推奨手法の提示                              ← 売り方の提示
5.  ❌型 vs ✅型の対比（最重要教育ブロック）    ← 常識の破壊
6.  ✅型の本質の深掘り                          ← 気づきの付与
7.  比喩で具体化（医者と薬等）                  ← 理解の促進
8.  実践ステップの提示（5ステップ以内）         ← メソッド提示
9.  応用テクニック（上級者向け）                ← 高度テクニック
10. 【特典告知】テンプレートの存在を示す        ← 欲求喚起（中身は渡さない）
11. インタビュー動画（今話テーマで成功した人）  ← 社会的証明
12. 自社の差別化（3つの否定→自社の強み）       ← 他社との違い
13. 次回予告＋感想ボタンCTA（最大級のフック）  ← 行動誘導
```

### 重要パターン：「見せるが渡さない」

| 見せるもの | 効果 | いつ渡すか |
|-----------|------|----------|
| フレームワークの全体像 | 知的好奇心を煽る | プログラム内 |
| テンプレートの存在 | 「欲しい」を作る | 特典で配布 |
| 具体的なツール名 | リアリティを出す | 最終話で |

### 差別化の表現パターン

```
❌ 「[競合パターン①]ではなく」
❌ 「[競合パターン②]でもなく」
❌ 「[競合パターン③]でもなく」
✅ 「[自社の本質的な強み]」
```

## 第四話（最終話）：教育③＋オファー

**役割**: 最後の教育 → 全体まとめ → オファー提示 → 申込

> ⚠️ **第四話は教育4割・オファー6割**。他の話と比率が逆転する。

### 構成ブロック

```
【教育パート（40%）】
1.  導入：今話の約束（3つの成果）＋後半プレゼント告知
2.  常識の否定①（集客の誤解を5つ以上列挙→全否定）
3.  正しい全体設計の概念（ファネル=線で見る）
4.  自社のリアルな動線フローの公開（5ステップ以内）
5.  投資/広告の教育（恐怖→最強の投資へのマインドセット転換）
6.  Before/After対比表でマインドセット転換
7.  インタビュー動画（自動化テーマに合った人）
8.  3ステップ総まとめ（タイムライン付き）

【オファーパート（60%）】
9.  理想の未来（再描写・集大成版、5シーン以上）
10. プレゼント提示（名称にベネフィット、通常価格→無料）
11. 診断/セッションの具体的内容（5項目以上）
12. 特典詳細（5つ前後、最後がバックエンドへの導線）
13. バックエンドプログラムの紹介（テンプレート一覧を具体的に）
14. 参加基準（NG基準→OK基準の順で）
15. 2択のクロージング（自力 vs プロ利用）
16. 緊急性＋カウントダウン（「1秒でも過ぎたら」+「全消滅」）
17. 申し込み手順（4ステップ以内）
18. ミッションステートメント（利他的に締める）
```

### オファー設計の「伏線回収」マップ

| 伏線を張った話 | 伏線の内容 | 回収される特典 |
|---------------|----------|--------------| 
| 第一話 | 「○○万投資のノウハウをプレゼント」 | バックエンドのテンプレート群 |
| 第二話/第三話 | 「リサーチシート/台本テンプレートがある」 | 特典②③ |
| 第三話 | 「○○通りにやるだけで成果が出る」 | 特典③（本命） |
| 第四話 | 「広告の考え方を教えた」 | 特典④ |
| 全話共通 | 「1on1診断で全て解決」 | 本体オファー |

### 2択クロージングのテンプレート

```
選択肢①: 自分一人で[メソッド]を構築する
→ 「遠回りしたり失敗することはあるかもしれませんが、できないとは言いません」

選択肢②: プロの脳と経験を利用する
→ 「テンプレートを活用するだけで、見たこともない[成果]を信じられないスピードで実現できる」
→ 「一人で3〜5年かかることが半年〜1年で」
```

### ミッションステートメントのテンプレート

```
「[素晴らしい商品/サービス]を持っているにもかかわらず苦労している方を見てきました」
「あなたの[商品/サービス]を求めている人は世の中に必ずいます」
「私たちのミッションは、[利他的なビジョン]を実現することです」
「本日は最後までご視聴いただきありがとうございました」
```


## 繰り返し使うキーフレーズのパターン

| パターン | 効果 | 例（e-Harbor） |
|---------|------|--------------|
| 「影響力0、知名度0でも○ヶ月で○万」 | ハードル除去 | 3ヶ月で100万 |
| 「10人に話したら○人に売れる」 | 成約率のイメージ | 8人 |

| 「3日間限定」「二度と見れない」 | 緊急性 | 全話で繰り返す |
| 「感想ボタンを送った方だけ」 | エンゲージメント＋次話導線 | 全話で繰り返す |
| 「[メソッド名]」 | ブランディング | 3ステップセールスメソッド |

## オファー構造テンプレート

### フロントエンド（無料）
- 4本の動画セミナー
- 1on1診断/セッション（通常○万円→無料）
- 5大特典（テンプレ、ガイド等）

### バックエンド（有料）
- コンサル/スクール/プログラム
- 売上・成果の保証
- 優待価格（診断参加者限定）
- 少人数制・審査あり

### マネタイズフロー

```
LINE登録（無料）
  → 動画4本で教育
    → 1on1診断（無料・申込フォーム→担当者が電話）
      → 診断（Zoom）でバックエンドを提案
        → 有料プログラム参加
```
