# 動画台本スキル（Video Script Builder）

## 概要

このスキルは、**ファネル動画（ステップ動画）** や **VSL（Video Sales Letter）** の台本を、実績のある構造パターンに基づいて設計・執筆するためのものです。

### 対応する動画タイプ
- **ファネル動画**（3〜4話構成のステップ配信）
- **VSL**（1本完結のセールス動画）
- **セミナー動画**（ウェビナー / 録画セミナー）

---

## 使い方

### Step 1: ヒアリング

台本制作の前に、以下の情報を必ず確認する。不足している場合はユーザーに質問する。

| 項目 | 質問例 |
|------|--------|
| **商品/サービス** | 何を売るのか？価格帯は？ |
| **ターゲット** | 誰に売るのか？ペルソナは？ |
| **話者** | 誰が話すのか？実績は？ |
| **構成** | 何話構成？各話の役割は？ |
| **CTA** | 最終的に何をさせたいか？ |
| **配信方法** | LINE? メール? LP埋め込み? |
| **既存素材** | 既存の台本・書き起こし・分析があるか？ |

### Step 2: 構成設計

テンプレートを使って全体設計を行う。

- **ファネル動画の場合** → `templates/funnel_structure.md` を参照
- **VSLの場合** → `templates/vsl_structure.md` を参照

### Step 3: 台本執筆

各ブロックごとに台本を執筆する。

- 各ブロックの **テンプレート要素** と **再現ポイント** を参照
- ユーザーの商品・ターゲットに合わせてカスタマイズ
- 📌マークでデータ差し替えが必要な箇所を明示

### Step 4: レビュー

完成した台本を以下のチェックリストで検証する。

- `templates/review_checklist.md` を参照

---

## テンプレートファイル

| ファイル | 用途 |
|---------|------|
| `templates/funnel_structure.md` | ファネル動画（3〜4話）の全体構成テンプレート |
| `templates/vsl_structure.md` | VSL（セールス動画）の構成テンプレート |
| `templates/block_library.md` | 台本ブロックの再利用パーツ集 |
| `templates/review_checklist.md` | 台本レビュー用チェックリスト |
| `templates/hearing_sheet.md` | 台本制作前のヒアリングシート |

## 重要な設計原則

### 1. 心理導線を意識する
各話は独立したコンテンツではなく、心理的な旅路の一部。

```
第一話: 問題認識 → 権威構築 → 全体像 → 好奇心
第二話: 教育①（方法論） → 「自分にもできそう」
第三話: 教育②（具体策） → 「もっと知りたい」
第四話: 教育③ → オファー → 緊急性 → 申込
```

### 2. 感情の起伏を設計する
フラットな説明にしない。各話の中に必ず感情の山と谷を作る。

### 3. 数字で証明する
抽象的なメリットではなく、具体的な数字で語る。
- ❌「多くの方が成果を出しています」
- ✅「3ヶ月で月商100万円を達成された方が4名以上います」

### 4. 📌マークで差し替え箇所を明示する
台本内の実例・数字で、実際のデータに差し替えが必要な箇所は📌で明示する。

### 5. 演出指示は【】で記載する
スライド切替・演出メモは【】内に記載し、読み上げないことを明示する。
