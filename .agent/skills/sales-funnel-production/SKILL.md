# セールスファネル一式制作（Sales Funnel Production）

## 概要

LINE × 動画ファネルのセールス一式を制作するスキル。以下の成果物を一貫して制作する。

```
┌─────────────────────────────────────────────────────────┐
│  リード獲得（LINE登録）                                   │
│       ↓                                                 │
│  第一話 コンテンツ配信（問題提起 → 権威構築）              │
│       ↓                                                 │
│  第二話 コンテンツ配信（方法論 → 「自分にもできそう」）     │
│       ↓                                                 │
│  第三話 コンテンツ配信（具体策 → 「もっと知りたい」）       │
│       ↓                                                 │
│  第四話 / VSL（教育③ → オファー → 緊急性 → 申込）        │
│       ↓                                                 │
│  セールスレター（テキストで訴求 → 決済誘導）               │
│       ↓                                                 │
│  特典配布（購入者向け / 無料視聴者向け）                   │
└─────────────────────────────────────────────────────────┘
```

## 制作フロー

### Step 1: ヒアリング

以下の情報を確認する。不足している場合はユーザーに質問する。

| 項目 | 質問例 |
|------|--------|
| **商品/サービス** | 何を売るのか？価格帯は？ |
| **ターゲット** | 誰に売るのか？年齢・職業・悩みは？ |
| **話者** | 誰が話すのか？実績・権威性は？ |
| **構成** | 何話構成？（推奨: 3話＋VSL） |
| **価格** | 販売価格は？分割対応は？ |
| **保証** | 返金保証の有無・条件は？ |
| **特典** | 購入特典・無料特典は何か？ |
| **競合** | 同ジャンルの競合サービスは？価格帯は？ |
| **配信方法** | LINE（プロライン）/ メール / LP埋め込み？ |
| **既存素材** | 台本・書き起こし・LP・分析データがあるか？ |
| **参考スタイル** | 参考にしたいLPやセールスレターのURLは？ |

### Step 2: 全体構成設計

`roadmap.md` を作成し、ファネル全体の設計を行う。

- 各話の役割と感情曲線
- CTAの設計（各話のゴール）
- 特典の設計
- 価格戦略

### Step 3: 台本制作

[動画台本スキル](file:///Users/hiroshi/cursor/.agent/skills/video-script-builder/SKILL.md) を使って台本を作成する。

### Step 4: コンテンツページ制作

各話のコンテンツページをHTMLで作成する。

**コンテンツページの必須要素:**
- ヘッダー（話数＋タイトル）
- 動画埋め込みエリア
- 動画の要約テキスト（3〜5ポイント）
- 次話の予告（最終話以外）
- 感想フォーム or CTA
- フッター

**コンテンツページのテキスト要件:**
- 台本のタイトルとページのタイトルを必ず一致させる
- 動画を見なくても概要が分かるサマリーを入れる
- 次話への期待を煽るフックを入れる

### Step 5: セールスレター制作

VSL台本をベースに、テキスト訴求のセールスレターを制作する。

**スタイルの選択:**

| スタイル | 特徴 | 使い分け |
|---------|------|---------|
| **Brainコミット型** | テキスト主体、ブログ記事風、短い段落、黄色マーカー、`>>参加する` リンク | 個人ブランド強め / 読み物として |
| **LP型** | ビジュアル重視、カード・バッジ・ボタン、KPIグリッド | 法人向け / 数字訴求 |

**Brainコミット型の文章パターン（実績済み）：**

| パターン | 用途 | 例 |
|---------|------|-----|
| 「……あれ？」型 | 劇的な間＋気づき | 「……あれ？80万って高すぎません？」 |
| 「正直に言うと」 | 自己開示で信頼構築 | 「正直に言えば、教材売れるだけなら儲かります」 |
| 「…それでも、やりたい。」 | 三点リーダーで感情の溜め | 止められた→でもやる、のパターン |
| 「ただそれだけ。」 | 一行で結論を断言 | 3つ列挙した後の締め |
| （笑）挿入 | カジュアルな括弧で親近感 | 「ノウハウコレクターの方が儲かるまであります…（笑）」 |
| 残り時間カウント | 時間の制約で進行感を出す | 「5分だけ」→「あと4分」→「残り3分」→「あと1分」 |
| 「頭おかしいと思われますが、ガチです。」 | 型破りな提案への自覚 | 2倍返金保証・破格の価格設定の後 |
| drop-then-lift | 一旦落として持ち上げる | 「諦めていました。でも、いたのです。」 |

**CTA分割版の出力:**
- プロラインに貼り付ける場合、CTA箇所で分割して出力する
- 各CTA箇所は `【★ここにCTA○を挿入★】` で明示
- CSSは別途まとめて提供

### Step 6: LINEシナリオ制作

「フェーズ5: LINEシナリオ制作」の構成表（5-1〜5-4）と「実績リファレンス（Skill Hacks）」を基準に作成する（専用ワークフロー line-scenario.md は未作成）。

### Step 7: 特典制作

無料特典を制作し、配布ページをHTMLで作成する。

### Step 8: デプロイ・統合

[デプロイワークフロー](file:///Users/hiroshi/cursor/.agent/workflows/deploy.md) を使ってsurge.shにデプロイする。
