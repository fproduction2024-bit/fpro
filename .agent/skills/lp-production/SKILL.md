## LP 9セクション構成テンプレート

### ① Hero — 数字インパクト（ファーストビュー）
**目的**: 3秒で「自分ごと」にさせる

必須要素:
- **ターゲティングラベル**: 「○○をお探しの△△の皆様」
- **バッジ**: 参入障壁の低さを示す（「未経験でも」「資格不要」等）
- **メイン数字**: 最も強いKPIを72px級で大きく表示（例: 年間純利益542万円）
- **キャッチコピー**: 黄色下線マーカーで強調（例: 「たった1人で、手間なく実現」）
- **KPIボックス3つ**: 投資回収・利益率・参入ハードルの低さ
- **ブランド名表示**

**コピー原則**:
- 数字は必ず具体的に（「高利益」→「利益率35.6%」）
- 「あなたが現場に出ることなく」のような二人称で語りかけ

### ② ペイン提起 — 共感
**目的**: 読者の悩みを言語化して「自分のことだ」と思わせる

必須要素:
- 見出し: 「こんなお悩みありませんか？」
- 5つ前後の具体的な悩みをリスト形式で
- 感情絵文字やアイコンを添える

**コピー原則**:
- 「〜したいけど、〜で不安…」のパターン
- ターゲットが日常的に感じている具体的な不安を書く
- 曖昧な悩みではなく、行動を阻害している具体的な壁を書く

### ③ 解決策 — ソリューション提示
**目的**: すべての悩みを解決する手段として自社サービスを提示

必須要素:
- 見出し: 「○○なら その全ての悩みを解決できます」
- カード形式で3〜5つの強みを提示
- 各カードにアイコン＋タイトル＋説明文＋強調テキスト（赤）

**コピー原則**:
- ペインセクションの悩みと1対1で対応させる
- 「構造的に〜が起きない」のような仕組みの説明を入れる

### ④ 実績データ — 信頼構築
**目的**: 数字で裏付けて信頼を獲得

必須要素:
- 4つのKPIを2×2グリッドで表示
- 各KPIに: ラベル / 大きな数字 / 補足テキスト
- 中間CTA挿入

**主要KPI例**:
- 年間純利益 / 利益率 / 投資回収期間 / リピート率（or 店舗数/継続率）

### ⑤ 収益シミュレーション — 夢を膨らませる
**目的**: 具体的な数字で「自分もこうなれる」とイメージさせる

必須要素:
- 1店舗の収支テーブル（売上/原価率/利益率/累計利益）
- 複数店舗の計算式（1店舗×3＝年収○万円）
- ダークカラー背景のボックスで強調

**コピー原則**:
- 計算式を大きなフォントで見せる
- 「手堅く実現可能」で締める

### ⑥ 比較表 — 優位性の可視化
**目的**: 競合との比較で自社の圧倒的優位性を示す

必須要素:
- 自社列をゴールド/ハイライトカラーで強調
- 比較軸: 初期投資/技術・資格/必要人員/原価率/投資回収/副業可否

### ⑦ お客様の声・オーナーの声 — 社会的証明
**目的**: 第三者の声で安心感を与える

必須要素:
- 3件以上のテスティモニアル
- 各カードに: 見出し / 本文 / 属性タグ（元会社員・未経験等）
- 太字で最も刺さるフレーズを強調

### ⑧ FAQ — 不安の最終解消
**目的**: 最後の疑問を払拭してCTAへ誘導

必須要素:
- Q&A形式で4〜6問
- Q = 緑丸、A = 金丸でビジュアル区別
- よくある質問を先に、価格系を後に配置

### ⑨ 最終CTA — クロージング
**目的**: 今すぐ行動させる

必須要素:
- ダークカラー背景（ブランドカラー）
- 見出し: 「まずは○○で全ての数字を確認してください」
- CTA: 「今すぐ ○○に申し込む」（緑グラデーション）
- マイクロコピー: 「※ 勧誘は一切ありません」

## デザインルール

### 配色
| 用途 | ルール |
|------|--------|
| ブランドカラー | 案件のメインカラーを使用 |
| 数字強調 | 赤系（`#D63031`等）で大きく表示 |
| コピー強調 | 黄色マーカー下線（`linear-gradient(transparent 60%, #FFE66D 60%)`） |
| CTAボタン | 緑グラデーション（ブランドカラーと補色関係が理想） |
| 背景切り替え | 白→クリーム→ライトグリーン→白 で単調さを防ぐ |

### CTA設計
- **フローティングCTA**: スクロール500px以降で画面下部に追従表示
- **挿入頻度**: 2〜3セクションごとにインラインCTAを挿入
- **ボタン上ラベル**: 「○○募集中」を赤テキストで表示
- **「今すぐ」バッジ**: 黄色背景のバッジをボタン内に配置

### タイポグラフィ
- フォント: `Noto Sans JP` + `Inter`（数字用）
- メイン数字: `Inter` 48〜72px / font-weight: 900
- 見出し: 22px / font-weight: 900
- 本文: 14〜15px / line-height: 1.8
- レスポンシブ: max-width: 800px でモバイルファースト

### アニメーション
- Intersection Observer でスクロール連動フェードイン（`.reveal`クラス）
- CTAボタン: hover時に `translateY(-2px)` + box-shadow拡大
- 過度なアニメーションは避ける（3要素以上の同時アニメ禁止）
