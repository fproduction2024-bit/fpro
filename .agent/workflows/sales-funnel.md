# セールスファネル制作ワークフロー（Skill Hacks型）

// turbo-all

「セールスファネル一式制作（Sales Funnel Production）」スキル（Skill Hacks実績ベース）を用いて、新規商材のセールスファネルを自動構築する手順。

## 前提事項

実行前に、以下のヒアリング事項が明確になっているかユーザーと確認する。
- 商材内容・商品名
- ターゲット（ペルソナ）と抱える悩み
- 価格・保証・特典内容
- ファネルの話数構成（標準は3話 ＋ VSL）

## 実行手順

以下の工程を順に Antigravity（AI）が実行・提案していく。

### 1. プロジェクトディレクトリ作成

新しくファネルを作るディレクトリ群を以下のシェルコマンドで一括作成する。

```bash
# ※ 実行前に <プロジェクトパス> を実際のパス（例: docs/古橋の会社ナレッジ/Brain/新商品/）に置き換える
PROJECT_DIR="<プロジェクトパス>"
mkdir -p "${PROJECT_DIR}"/{台本,content-pages,sales-letter,LINEシナリオ,プレゼント}
```

### 2. 全体構成設計の合意

ファネルの全体設計（ロードマップ、感情曲線、CTA設計）をマークダウン形式で作成し、`${PROJECT_DIR}/ファネル構成案.md` に保存。ユーザーのレビュー・合意を得る。

### 3. 台本制作（Phase 2）

動画台本スキルを利用し、各話の目的に合わせた台本を順次作成する。
- `第一話_台本.md`（問題提起・権威構築）
- `第二話_台本.md`（方法論）
- `第三話_台本.md`（具体策）
- `第四話_VSL_台本.md`（オファー・保証・CTA）

### 4. コンテンツページHTML制作（Phase 3）

台本を元に、各話の視聴用コンテンツページ（HTML）を作成する。
- モバイルレスポンシブなビュー
- 動画視聴部分（プレースホルダー）、要約テキスト、次話予告
- `content-pages/` ディレクトリに保存

### 5. セールスレター制作（Phase 4）

VSL台本の内容をもとに、Brainコミット基準（テキスト主体、黄色マーカー等）のセールスレターHTMLを作成。
- `sales-letter/index.html` に保存。

### 6. LINEシナリオ作成（Phase 5）

ユーザーに動画を視聴させるためのLINEメッセージのシナリオ（第零話〜第四話＋セールス案内）を執筆する。
- `LINEシナリオ/` 配下にテキストファイル・Markdownとして配置。

### 7. レビュー＆修正

作成した一式のファイル（台本・HTML・シナリオ）をユーザーが確認し、ブラッシュアップ作業（反復）を行う。

### 8. デプロイ（Phase 7）

`/deploy` ワークフローを用いて、完成した `content-pages` や `sales-letter` などの表示確認用URL（surge.sh）を発行し、ダッシュボードに登録する。
