## 02-26 会議: 事業承継ファンド設立戦略・売上拡大型モデル・LP向けストーリー再構成

## 1. 事業承継ファンドの設立目標・基本戦略と未決課題
### 結論
- 2029年1月の事業承継ファンド設立方針は維持。ファンドは「交渉・財務・法務の基本戦術」と「売上成長シナリオ（シナジー創出・販路/ネットワーク活用・ロールアップ等）」の両輪で戦い、基本に忠実な運営を軸に攻めのポートフォリオで高リターン（例：4年で20倍）を狙う。
- 設立要件（資金規模、LP条件、投資方針、ターゲット件数/KPI、運用スタイル）が不明確である点を重大課題として認識。単なる効率化（経費削減）だけでは投資家説得力が弱く、売上成長フェーズに資金を投じるストーリーが必須。
- 運用スタイル（出資比率、ハンズオン度、転売/保有戦略）と「独自の勝ち筋（売上拡大パターン）」の確立が必要。再現可能なパターン化により案件ごとの思考負荷を下げる。
### 計画
- [ ] 設立要件定義（資金目標、LP条件、投資テーマ、売り手/買い手パイプライン、KPI）と運用スタイル（投資/支援モデル、取得比率、リターン設計）の骨子作成と意思決定会議設定
- [ ] LP向けピッチ再構成（売上起点の成長フェーズへの投資、BS/CFは補助）とケーススタディ（チャネル活用/新規事業での売上伸長例）
- [ ] 2029年1月到達状態からの逆算ロードマップ策定（約35ヶ月）。初期3.5ヶ月で戦略アセット整備・運用スタイル定義・勝ち筋パターン化を完了、5月までに対外的に示せる戦略的アセット（資金調達目安、LP候補、ネットワーク）を揃える
### 議論の要点
- 設立条件が煮詰まっておらず、目標の具体（資金額、確保社数等）が欠如。法人設立だけの目標は視座が低い。
- 投資家は「売上伸長→稼ぐ力付与」フェーズへの投資を志向。効率化偏重は下り局面の打ち手に見え、資金が集まりにくい。
- ポートフォリオの顔を明確化（B2B/B2C特化や横断型）し、シナジーで伸ばす設計が重要。
## 2. 2年間のトラクション計画：EBITDA56%成長・15社創出の再設計
### 結論
- 「向こう2年でEBITDA合計56%成長を15社で創出」のKPIは維持。ただし、達成方法は経費削減依存から売上成長（チャネル拡張、新規事業、計画準拠）を中核へ修正。純資産積み上げ/マルチプル拡大の視点も併走。
- 成長の質（成功比率、ソーシング粒度、再現性）をLP向けに明記し、単なる労働集約型拡大に依存しない売上拡大型の実行計画を提示する。
### 計画
- [ ] 売上成長中心の達成シナリオ再設計（年次フェーズ、KPIツリー、新規事業含む）
- [ ] 56%以外のLP説得ロジック（純資産積み上げ、マルチプル拡張、FCF改善のガバナンス付き見せ方）作成
- [ ] 15社パイプライン要件（業種、規模、改善余地、チャネル適合性）定義と候補抽出、ソーシング基準の絞り込み
### 議論の要点
- 役員報酬引下げ等の経費削減でも数値は作れるが、投資家受けは悪い。未来計画に沿った売上伸長で「上げ方」を示すべき。
- 成長率だけでは大口資金は集まりにくく、強み（チャネル構築力、オペ改善力）の証憑が必要。
## 3. 支援ドメイン再定義とオペ標準化
### 結論
- 支援の二本柱は「バックオフィス/財務改革」と「売上成長（販路・チャネル）」。採用は補助的ドライバーとして必要に応じて最適化/削減。
- CFO代行の属人性を解消し、パッケージ化（導入テンプレ、KPI）で再現性を高める。担当者スキルに依存しない成果を出すため導線設計の標準化とノウハウの組織化が必須。
### 計画
- [ ] バックオフィス/財務の標準パッケージ化（診断テンプレ、改善ロードマップ、KPI）
- [ ] 売上成長施策の設計（チャネル連携、販売力強化、価格戦略、プロダクト改良、ロールアップ）
- [ ] 採用施策の再評価（売上弾性が高いケースに限定、コスト最適化・撤退基準設定）
- [ ] 導線（バックエンド）設計の標準テンプレ作成・テスト、運用ノウハウの体系化と短期ブートキャンプによる人材育成
### 議論の要点
- 採用起点の売上拡大は遅く変数が多い。低利益率業種（運送等）では投資効率が悪い。
- 標準オペ構築により社長/キーパーソン依存を解消し、弱い担当者でも達成できる数値設計を目指す。
## 4. 業種フォーカスとポートフォリオの「顔」づくり
### 結論
- 運送/建設中心の人材調達依存ビジネス集中は一理あるが、LPから「下火業種偏重」に見えるリスク。成長性・魅力度の高い業種（メーカー等）も組み込み、流通チャネル拡張（地域→全国→海外）で伸ばすモデルを併走。
- 非上場企業を3〜5倍で取得後、上場企業傘下化で10〜15倍のPRを得る「マルチプル・アービトラージ」を活用し、ブランド/タイアップ/ストーリーでプレミアム付与。
### 計画
- [ ] 業種ポートフォリオ方針策定（比率案含む）と各業種のLP向け投資ストーリー作成
- [ ] メーカー等の対象選定と国内→海外展開シナリオ（展示会出展、海外百貨店卸KPI）設計
- [ ] 上場傘下化の適用条件・デューデリ基準と事業計画の整合資料作成
### 議論の要点
- SNS依存採用は中長期で厳しく、海外コンテンツ競争・人口構造変化によりボーナスは終焉傾向。販路・ネットワーク起点のシナジーで短期成長を優先すべき。
## 5. 投資家向けストーリーテリングと財務/FCFの見せ方
### 結論
- 「効率化フェーズ投資」の印象を避け、売上→投資→販売力強化→成長の循環を計画ベースで提示。FCF改善（運転資本コントロール等）は事業成長と接続できる範囲で活用し、短期的な見せ方偏重に依存しないバランスを取る。
### 計画
- [ ] LP向けピッチの再構成（売上成長起点、成長フェーズ投資、BS/CFの補助説明）
- [ ] ケーススタディ（チャネル活用/新規事業での売上伸長、FCF改善と実態改善の接続）作成
- [ ] 運転資本オプティマイゼーションのガバナンス指針（倫理・説明方針・実態改善指標）定義
### 議論の要点
- 投資家は事実ベースの売上成長実績と筋の通った計画を評価。大規模実績がなくても動線の明確さが重要。
## 6. 売上拡大型「独自モデル」の研究・設計
### 結論
- 採用起点ではなく「販路・ネットワーク起点」で短期成長する独自モデル（海外/国内販路ネットワーク、プラットフォーム連携、ロールアップによる販路統合）を1〜2年で研究・設計し、2029年設立時点までにネットワークと仕組みを揃える。
### 計画
- [ ] 他ファンドの売上拡大手法の体系的リサーチ（IR精読、事例収集、経験者ヒアリング）
- [ ] 業務提携/販路ネットワーク候補の開拓（国内外プラットフォーム）
- [ ] ロールアップ構想素案作成とPoC設計（販路・ネットワーク起点の短期成長検証）
- [ ] 自社メディア群/強いパイプの構築（特化メディア多数のポータル構想、広告×採用のクロス設計）
### 議論の要点
- ポートフォリオを交渉で柔軟に組み、スポンサー型/財務型など複数スキームでレバレッジ可能。債券発行等の資金調達オプションも検討。
## 7. 採用モデルの位置づけと検証
### 結論
- SNS単独の採用支援は再現性・即効性に疑義。求人媒体ハック（インディード/エンゲージ等）、広告運用、業界メディア運用を組み合わせたポートフォリオ型採用が有望。採用は主要ドライバーでなく補助的に位置づけ、固い再現性のある施策を標準化。
### 計画
- [ ] SNS×広告×業界メディア流入の採用パッケージの実証（KPI: 応募率、面接率、採用単価、離職率、売上寄与）
- [ ] 割引スキームの調査・組み込み（インディード等の長期継続性・コンプラ確認）
- [ ] 既存SNS支援会社/求人媒体運用会社との買収・連携検証、後工程の導線設計見直し・標準化
### 議論の要点
- 労働集約領域では人が集まれば売上が伸びるため、採用パッケージのトラックレコード（70〜80%達成）でファイナンス容易化。担当者品質に依存しない仕組み化が肝要。
## 8. 組織内役割・提案駆動体制と人材育成
### 結論
