# LP Builder - アップロードガイド

このガイドでは、作成したLPをXサーバーにアップロードする手順を説明します。

## 必要なもの

- **FTPクライアント**: FileZilla（推奨）または Cyberduck
- **Xサーバーのログイン情報**:
  - FTPホスト名
  - FTPユーザー名
  - FTPパスワード

## アップロード手順

### 1. HTMLファイルのエクスポート

1. LP Builderでエクスポートしたいを開く
2. 「エクスポート」ボタンをクリック
3. HTMLファイルがダウンロードされます

### 2. FileZillaのインストール（初回のみ）

1. [FileZilla公式サイト](https://filezilla-project.org/)からダウンロード
2. インストーラーを実行してインストール

### 3. Xサーバーへの接続

1. FileZillaを起動
2. 上部のクイック接続バーに以下を入力:
   - **ホスト**: `ftp.example.com`（Xサーバーから提供されたFTPホスト名）
   - **ユーザー名**: FTPユーザー名
   - **パスワード**: FTPパスワード
   - **ポート**: `21`
3. 「クイック接続」ボタンをクリック

### 4. ファイルのアップロード

1. 左側（ローカル）でダウンロードしたHTMLファイルを探す
2. 右側（リモート）で目的のディレクトリに移動
   - 例: `/public_html/clp/present19/`
3. HTMLファイルを左から右にドラッグ&ドロップ
4. アップロード完了を確認

### 5. 動作確認

1. ブラウザで `https://yourdomain.com/clp/present19/` にアクセス
2. LPが正しく表示されることを確認

## トラブルシューティング

### 接続できない場合

- FTPホスト名、ユーザー名、パスワードが正しいか確認
- Xサーバーのコントロールパネルでアカウント情報を再確認
- ファイアウォールやセキュリティソフトがFTP接続をブロックしていないか確認

### ファイルが表示されない場合

- ファイル名が `index.html` になっているか確認
- パーミッション（権限）が正しく設定されているか確認（644推奨）
- ブラウザのキャッシュをクリアして再読み込み
