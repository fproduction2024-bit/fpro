# Obsidian 使い方ガイド

## Obsidianとは？

Obsidianは、ローカルのMarkdownファイルを使用する強力なナレッジベース・ノート管理アプリケーションです。ファイルはすべてあなたのコンピュータに保存され、プレーンテキストのMarkdown形式なので、将来的にも安全です。

### 主な特徴

- **リンクベースの思考**: ノート間を自由にリンクして、知識のネットワークを構築
- **グラフビュー**: ノート間の関係を視覚的に表示
- **完全オフライン**: インターネット接続不要で動作
- **カスタマイズ可能**: プラグインとテーマで機能を拡張
- **Markdown対応**: 標準的なMarkdown記法をサポート

## 基本的な使い方

### 1. Vaultの作成・開き方

1. Obsidianを起動
2. 「Open folder as vault」を選択
3. `/Users/hiroshi/cursor` フォルダを選択

### 2. ノート間のリンク

Obsidianの最も強力な機能の一つが、ノート間のリンクです。

**内部リンクの作り方:**
```markdown
[[ファイル名]]
[[フォルダ/ファイル名]]
[[ファイル名|表示テキスト]]
```

**例:**
```markdown
[[ゼンタングル事業概要_MVV]]
[[タングルシード/2026年実施施策]]
[[企業提携戦略|提携戦略について]]
```

### 3. タグの使い方

タグを使ってノートを分類・整理できます。

**タグの付け方:**
```markdown
#タグ名
#タングルシード
#戦略/2026年
```

**YAMLフロントマターでのタグ:**
```yaml
---
tags:
  - タングルシード
  - 戦略
  - 2026年
---
```

### 4. YAMLフロントマター

ファイルの先頭にメタデータを追加できます。

```yaml
---
title: ドキュメントのタイトル
date: 2026-01-14
tags:
  - タグ1
  - タグ2
category: カテゴリ名
status: 進行中
---
```

### 5. グラフビュー

- 左サイドバーの「グラフビュー」アイコンをクリック
- ノート間のリンク関係が視覚的に表示されます
- ノードをクリックすると、そのノートを開けます

### 6. 検索機能

**基本検索:**
- `Cmd + Shift + F` で検索パネルを開く
- テキストを入力して検索

**タグ検索:**
```
tag:#タングルシード
tag:#戦略
```

**複数条件:**
```
tag:#タングルシード tag:#2026年
```

## おすすめのプラグイン

### コアプラグイン（標準搭載）

1. **バックリンク**: ノートへのリンクを自動表示
2. **タグパネル**: すべてのタグを一覧表示
3. **アウトライン**: 現在のノートの見出し構造を表示
4. **検索**: 強力な検索機能
5. **グラフビュー**: ノート間の関係を可視化

### コミュニティプラグイン（おすすめ）

1. **Obsidian Git**: Gitと自動同期（既に設定済み）
2. **Dataview**: ノートをデータベースのように扱う
3. **Calendar**: カレンダービューでノートを管理
4. **Kanban**: カンバンボードでタスク管理
5. **Templater**: 高度なテンプレート機能

## ワークフローの例

### 1. 新しいプロジェクトを始める

1. 適切なフォルダに新しいMarkdownファイルを作成
2. YAMLフロントマターでメタデータを追加
3. 関連するノートへのリンクを追加
4. 適切なタグを付ける

### 2. 既存の情報を探す

1. `Cmd + O` でクイックスイッチャーを開く
2. ファイル名を入力して検索
3. または、タグパネルからタグをクリック
4. グラフビューで関連ノートを探す

### 3. 定期レビュー

1. タグ検索で `tag:#進行中` を検索
2. 各ノートの状態を確認
3. 完了したものは `#完了` に変更
4. 新しいアイデアは `#アイデア` でタグ付け

## ベストプラクティス

### ファイル名

- **わかりやすい名前**: `企業提携戦略` ✓ / `doc1` ✗
- **日本語OK**: Obsidianは日本語ファイル名に完全対応
- **スペース使用可**: `2026年 実施施策` でもOK

### リンクの活用

- 関連するノートは積極的にリンク
- リンクを作ることで、後でグラフビューで関係が見える
- 「このノートは何と関連しているか？」を常に考える

### タグの使い方

- **階層タグ**: `#戦略/2026年/Q1` のように階層化できる
- **一貫性**: タグ名は統一する（`#タングルシード` と `#tangleseed` を混在させない）
- **適度に**: タグが多すぎると管理が大変

### メタデータの活用

```yaml
---
title: ドキュメント名
date: 2026-01-14
updated: 2026-01-14
tags:
  - タングルシード
  - 戦略
category: 事業戦略
status: 進行中
author: 古橋
---
```

## トラブルシューティング

### リンクが機能しない

- ファイル名が正確か確認
- 相対パスが正しいか確認
- ファイルが存在するか確認

### 同期の問題

- Obsidian Gitプラグインの設定を確認
- GitHubとの接続状態を確認
- 手動で `Cmd + P` → "Obsidian Git: Commit and push" を実行

### 検索結果が出ない

- 検索対象のフォルダが除外されていないか確認
- 設定 → ファイルとリンク → 除外ファイル を確認
