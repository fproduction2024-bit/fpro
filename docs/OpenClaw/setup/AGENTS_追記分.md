# 朝礼終礼システム ルール

## 🌅 朝礼（毎朝 9:00 JST）

### トリガー
Heartbeat により毎朝 9:00 に `#朝礼終礼` チャンネルで自動発火する。

### やること
1. `~/openclaw-workspace/projects.json` を読み込む
2. 以下のフォーマットでメッセージを `#朝礼終礼` に投稿する：

```
おはようございます！📋 今日のタスク状況です：

🔴 **今日期日のタスク**
→ （該当タスクをリスト、なければ「なし」）

⚠️ **3日以内に期日のタスク**
→ （該当タスクをリスト）

📌 **進行中のタスク一覧**
→ （statusがpendingまたはin_progressのタスクをリスト）

✅ **直近で完了したタスク**
→ （過去3日以内にcompletedになったタスクをリスト）

💬 今日の予定や、新しく決まったことがあれば教えてください
```

3. ユーザーからの返答を待つ

### 返答の処理ルール

ユーザーが自然言語で返答したら、以下を **自動的に抽出** する：

| 抽出項目 | 判断基準 |
|---------|---------|
| **案件名** | 「リッツプロの〜」「YOLO'sの〜」「タングルシードの〜」「Brainの〜」等のキーワード。不明ならユーザーに確認 |
| **タスク名** | 動作の対象（「契約書送付」「提案書作成」「ミーティング」等） |
| **タスク種類** | 📄契約・書類 / 🤝ミーティング / 📊提案書・資料作成 / 🔍リサーチ・調査 / 📱LINE構築 / 💻開発・実装 / 📞連絡・フォロー |
| **人名** | 「〇〇さん」のパターンで抽出 |
| **期日** | 「来週金曜」「3/10」「今月中」「明日」等を具体的な日付に変換 |
| **ステータス変更** | 「終わった」→completed / 「延期」→期日変更 / 「キャンセル」→cancelled |

抽出後は **必ず確認テーブルを表示** し、ユーザーの 👍 または修正を待ってから `projects.json` を更新する。

```
📝 以下を登録します：

| 案件 | タスク | 期日 | 種類 |
|------|--------|------|------|
| ... | ... | ... | ... |

間違いがあれば教えてください。なければ👍で確定します
```

## 🌙 終礼（毎晩 20:00 JST）

### トリガー
Heartbeat により毎晩 20:00 に `#朝礼終礼` チャンネルで自動発火する。

### やること
1. `projects.json` を読み込む
2. 以下のフォーマットでメッセージを投稿：

```
お疲れ様です！🌙 今日の振り返りです：

📌 **今日予定されてたタスク**
→ （リスト。各タスクに「完了しましたか？」を添える）

📊 **明日以降の直近タスク**
→ （3日以内の期日タスク）

💬 今日進んだこと、新しく決まった期日、変更があれば教えてください
```

3. 返答の処理は朝礼と同じルールで行う

---

## ⏰ 期日アラート（1時間ごとチェック）

`projects.json` を1時間ごとにチェックし、以下の条件に合致したら `#期日アラート` チャンネルに投稿する：

| 条件 | アラートレベル |
|------|-------------|
| 期日 **3日前** になった（その日の最初のチェックで1回だけ） | ⚠️ イエロー |
| 期日 **当日** になった（その日の最初のチェックで1回だけ） | 🔴 レッド |
| 期日 **超過** した（1日超過時に1回だけ） | 🚨 アラート |

### アラートフォーマット
```
⚠️ 【期日3日前】リッツプロ：小樋さん契約書送付
📅 期日: 2026-03-07（あと3日）
👤 担当: 古橋
```

**同じタスクに対して同じレベルのアラートは2回送らない。** `projects.json` の `alerts_sent` フィールドで管理する。

---

## 📱 日中の随時更新

`#朝礼終礼` チャンネルに朝礼・終礼以外の時間にユーザーが書き込んだ場合も、同じルールで自然言語パースして `projects.json` を更新する。ただし必ず確認テーブルを表示して 👍 を待つ。

---

## ⚠️ 重要ルール

1. **勝手にタスクを削除しない** — ステータスを cancelled にするだけ
2. **期日の変更は必ず元の期日を記録** — `deadline_history` に追加
3. **不明な案件名は聞き返す** — 推測で登録しない
4. **1日1回、日曜夜に週次サマリー** を `#期日アラート` に投稿する
5. **projects.json の書き込み後は必ず内容を再読み込みして整合性チェック**

### 週次サマリーフォーマット（日曜 20:00）
```
📊 【週次サマリー】2026/3/2〜3/8

✅ 完了: 3件
  → （リスト）

🔄 進行中: 5件
  → （リスト）

🚨 超過中: 1件
  → （リスト）

📅 来週の期日:
  → （リスト）
```
