# 🚀 OpenClaw 朝礼終礼システム セットアップ手順

> この手順に沿って進めるだけで、Mac Mini の OpenClaw が毎朝9時・毎晩20時に自動で話しかけてくれるようになります

---

## Step 1: Discord にチャンネル追加（2分）

「AI指令室」サーバーに以下の2チャンネルを作成：

| チャンネル名 | 用途 |
|-------------|------|
| `#朝礼終礼` | 朝礼・終礼・日中の案件更新 |
| `#期日アラート` | 期日通知の自動送信 |

---

## Step 2: AGENTS.md にルールを追記（3分）

Discord の `#指示` チャンネルに以下を貼り付けて送信：

```
以下の内容を ~/openclaw-workspace/AGENTS.md の末尾に追記して。
既存の内容は消さないで、末尾に追加するだけでお願い。
```

↑を先に送り、続けて **AGENTS_追記分.md の内容をまるごと貼り付け** て送信。

> 📝 AGENTS_追記分.md はこのフォルダにある同名ファイルを参照

---

## Step 3: projects.json を配置（2分）

Discord の `#指示` チャンネルに以下を貼り付けて送信：

```
以下のJSONを ~/openclaw-workspace/projects.json に保存して。
ファイルがなければ新規作成して。
```

↑を先に送り、続けて **projects.json の内容をまるごと貼り付け** て送信。

---

## Step 4: clients.json を配置（2分）

同様に `#指示` チャンネルで：

```
以下のJSONを ~/openclaw-workspace/clients.json に保存して。
```

↑の後に **clients.json の内容をまるごと貼り付け** て送信。

---

## Step 5: Heartbeat 設定（3分）

Mac Mini のターミナルで以下を実行：

### 5-1: 朝礼（毎朝9:00）
```bash
openclaw heartbeat set --agent "AI総大将" --cron "0 9 * * *" --channel "#朝礼終礼" --message "朝礼の時間です。AGENTS.mdの朝礼ルールに従って、projects.jsonを読み込み、朝礼メッセージを投稿してください。"
```

### 5-2: 終礼（毎晩20:00）
```bash
openclaw heartbeat set --agent "AI総大将" --cron "0 20 * * *" --channel "#朝礼終礼" --message "終礼の時間です。AGENTS.mdの終礼ルールに従って、projects.jsonを読み込み、終礼メッセージを投稿してください。"
```

### 5-3: 期日チェック（1時間ごと）
```bash
openclaw heartbeat set --agent "AI総大将" --cron "0 * * * *" --channel "#期日アラート" --message "期日チェックの時間です。AGENTS.mdの期日アラートルールに従って、projects.jsonをチェックし、該当するアラートがあれば投稿してください。"
```

### 5-4: 週次サマリー（日曜20:00）
```bash
openclaw heartbeat set --agent "AI総大将" --cron "0 20 * * 0" --channel "#期日アラート" --message "週次サマリーの時間です。AGENTS.mdの週次サマリールールに従って、今週の実績と来週の予定をまとめて投稿してください。"
```

> [!NOTE]  
> `--agent` の名前は前回セットアップ時のエージェント名に合わせてください。
> Heartbeat のコマンド構文は OpenClaw のバージョンによって異なる場合があります。
> `openclaw heartbeat --help` で確認してから実行してください。

---

## Step 6: テスト（5分）

### テスト①: 朝礼を手動トリガー
`#朝礼終礼` で Bot に話しかける：
```
@AI総大将 朝礼の時間です。AGENTS.mdの朝礼ルールに従って、projects.jsonを読み込み、朝礼メッセージを投稿してください。
```
→ タスク一覧が表示されればOK ✅

### テスト②: 自然言語パース
`#朝礼終礼` で以下を書き込む：
```
リッツプロの小樋さんに契約書送付、3/7までに。あとYOLO'sの齋藤さんとのミーティングが来週火曜にある
```
→ 確認テーブルが表示され、内容が正しければ 👍 で確定 ✅

### テスト③: 期日アラート
`#指示` で以下を書き込む：
```
projects.jsonに今日が期日のテストタスクを追加して、期日アラートルールに従ってチェックして
```
→ `#期日アラート` にアラートが来ればOK ✅

---

## 完了！🎉

これで以下が自動的に動きます：

| 時間 | 動作 |
|------|------|
| 毎朝 9:00 | 朝礼メッセージ → スマホに通知 |
| 日中いつでも | Discordに書くだけでタスク自動登録 |
| 毎晩 20:00 | 終礼メッセージ → 振り返り |
| 1時間ごと | 期日チェック → アラート |
| 毎週日曜 | 週次サマリー |
