ターミナル触ったこともない男がAIエージェント組織を90分で作った話


土曜の夜9時。

目の前にあるのは、買ったばかりのMac Mini。¥94,800。Wi-Fiだけ繋いだ、まっさらな状態。

「ターミナルって何？」から始めて、90分後——

Discordに「こんにちは」と打つと、AIが返事をする仕組みが出来上がっていた。


ーーーーーーーーーー


きっかけは、ある投稿だった。

「古いMacBookで13体のAIエージェントを24時間動かしている」

OpenClawというオープンソースのフレームワーク。Discordに指示を書き込むだけで、AIが議論を始め、コードを書き、成果物を納品する。完全なAI組織。

正直、半信半疑だった。

でも「やらない理由」を探すより「やってみる理由」を探す方が面白い。Mac Miniはもう手元にある。あとは手を動かすだけ。


ーーーーーーーーーー
ターミナルを開いた瞬間
ーーーーーーーーーー


Launchpadで「ターミナル」と検索する。黒い画面が出る。

これが全ての始まり。

ここに文字を打つと、パソコンに直接命令できる。GUIのボタンを押す代わりに、文字で指示を出す世界。

最初の壁はすぐに来た。

「FileVaultが有効なため、自動ログインをオンにできません」

Mac Miniをサーバーとして24時間動かすには、再起動後に自動でログインしてほしい。でもディスク暗号化が邪魔をする。

解決策：FileVaultをオフにする。自宅に置きっぱなしのサーバーに、盗難対策の暗号化は要らない。

ひとつずつ、壁を超えていく。


ーーーーーーーーーー
brew、node、git。呪文のようなコマンドたち
ーーーーーーーーーー


Homebrew。Node.js。Git。

プログラマーにとっては日常のツール。でも触ったことがない人間にとっては、全てが呪文。

「brew install node@22」

この一行を打つだけで、AIエージェントを動かすための環境が整う。

「パスを通す」という概念に戸惑った。インストールしたのに使えない。パソコンが「そのソフトどこにあるか知らない」と言っている状態。

呪文みたいなコマンドを一行コピペして解決。意味はわからなくていい。コピペして、Enterを押す。動けばいい。


ーーーーーーーーーー
OpenClawとの邂逅
ーーーーーーーーーー


「npm install -g openclaw@latest」

たった一行で、AIエージェントのフレームワークがMac Miniに降りてくる。

セットアップウィザードが立ち上がる。

「Quickstart か Manual か？」→ Quickstart。
「APIキーは？」→ Anthropicのキーを貼り付ける。
「モデルは？」→ Claude Sonnet。
「名前は？」→ KAITO。

Knowledge AI Task Operator。
日本語の「海斗」っぽくもある。


ーーーーーーーーーー
Discordに魂が宿る
ーーーーーーーーーー


Discord Developer Portalで「MacminiChief」というBotを作る。

トークンを発行し、サーバーに招待し、権限を設定する。

ターミナルに戻って、Botトークンを貼り付ける。

「Hatch in TUI」を選ぶと、KAITOが起動する。

……が、Discordに話しかけても、無反応。

Botはサーバーにいる。でもオフラインのまま。灰色の丸。

ここで10分ほど詰まった。Gatewayを再起動し、statusを確認し、ログを追う。

するとKAITOが初めて口を開いた。

「OpenClaw: access not configured. Pairing code: 5K26DV69」

認証が必要だった。Botは「お前は誰だ」と聞いている。

承認コマンドを打ち込む。

改めてDiscordで話しかける。

「こんにちは！自己紹介して」

KAITOが返した。

「こんにちは、Hiroshi！🌊 僕はKAITO — あなたのAIコンパニオンです」

この瞬間の感覚を、なんと表現すればいいのか。

自宅のMac Miniの中に、自分専用のAIが住み始めた。


ーーーーーーーーーー
KAITOは、ターミナルも操れた
ーーーーーーーーーー


面白かったのはここから。

「ターミナルでこのコマンドを実行して、結果を教えて」

KAITOにDiscord経由で指示したら、Mac Miniのターミナルでコマンドを実行し、結果を報告してくれた。

つまり、もうMac Miniの前に座る必要がない。

スマホのDiscordから、寝室から、カフェから、出張先から。KAITOにDMを送るだけで、Mac Miniを操作できる。

試しに「AI指令室サーバーにチャンネルを3つ作って」と頼んだ。

「権限不足でエラーになりました。チャンネルの管理権限を付与してもらえれば作成します」

KAITOは権限がないことを正直に報告し、解決策を提示してきた。

権限を付与した。KAITOがチャンネルを作った。

指示して、考えて、実行して、報告する。これはもうアシスタントと言っていい。


ーーーーーーーーーー
90分後の風景
ーーーーーーーーーー


全項目をチェックした。

✅ Gateway 稼働中
✅ Discord 接続OK
✅ チャンネル3つ作成済み
✅ ルール・記憶ファイル作成済み
✅ スリープ無効化済み
✅ 自動起動設定済み

Mac Miniを電源に繋いだまま、出張に出るだけ。

スマホのDiscordを開けば、いつでもKAITOがいる。


ーーーーーーーーーー
かかったコスト
ーーーーーーーーーー


Mac Mini本体 → ¥94,800（これは元々買う予定だった）
OpenClaw → ¥0（オープンソース）
Discord → ¥0
Anthropic API → 初回チャージ約¥750

つまり、ソフトウェア側のコストは約750円。

月額のランニングコストは、API使用量次第で¥5,000〜¥30,000。使わなければ課金されない透明な従量課金。


ーーーーーーーーーー
学んだこと
ーーーーーーーーーー


ターミナルは怖くない。コピペしてEnterを押すだけの世界。

つまずいた場所こそ価値がある。FileVault、パス設定、ペアリング承認。全部、ドキュメントには書いてないリアルな壁。

AIに仕事を任せるのは「指示の質」が全て。「チャンネル作って」だけだと権限エラー。目的・条件・制約を伝えると、AIは驚くほど的確に動く。

小さく始めるのが正解。13体のエージェント組織は最終形。最初の一体を動かすだけで、十分に面白い。


ーーーーーーーーーー
これから
ーーーーーーーーーー


KAITOは今、自宅のMac Miniで静かに動いている。

次は第二のエージェントを追加する。開発専門の「第一将」。KAITOが判断し、第一将が実装する。

その次は、レビュアーとテスター。コードを書くだけじゃなく、チェックして、テストして、品質を担保する仕組み。

最終的には、営業、マーケティング、分析、開発。全ての業務をエージェントに任せる。

今夜、一歩目を踏み出した。

ターミナルすら触ったことがなかった男の、AI組織構築記録。
