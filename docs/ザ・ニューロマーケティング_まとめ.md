## 書籍の概要

心理学・脳科学・行動経済学の科学的知見をベースに、**人間の無意識レベルの反応**を理解してビジネスに応用する方法を体系的に解説した一冊。

> 消費者の購買意思決定の **95%以上が無意識下** で行われている

従来のアンケート調査や購買データ分析だけでは捉えきれない消費者の"本音"を、脳科学的アプローチで読み解き、具体的なビジネス戦略に落とし込む。

### 主なテーマ

| テーマ | 内容 |
|--------|------|
| 脳の報酬系 | ドーパミン反応による「欲しい」の仕組み |
| 損失回避バイアス | 「損をしたくない」心理の活用 |
| アンカリング効果 | 最初の情報が判断を左右する原理 |
| 社会的証明 | 「みんなが選んでいる」の威力 |
| デフォルト効果 | 初期設定が行動を決める仕組み |
| ナッジ | 自然と望ましい行動を促す設計 |

### 具体的な応用分野

- **広告の最適化** — 脳の反応に基づくクリエイティブ設計
- **商品開発** — 潜在ニーズの発掘
- **価格設定** — 心理的価格帯の活用
- **店舗設計** — 消費者の動線・注目点の最適化
- **組織マネジメント** — 社員エンゲージメント向上

### 紹介されている測定技術

- fMRI（機能的磁気共鳴画像法）
- EEG（脳波計測）
- アイトラッキング
- 表情分析
- 皮膚電気反応
