## 📝 ドキュメント作成ガイドライン

新しいドキュメントを作成する際は、以下のテンプレートを使用してください:

```yaml
---
title: ドキュメントのタイトル
date: YYYY-MM-DD
tags:
  - カテゴリタグ
  - ステータスタグ
  - 年度タグ
category: カテゴリ名
status: ステータス
---

# ドキュメントのタイトル

## 概要

## 詳細

## 関連ドキュメント

- [[関連ファイル1]]
- [[関連ファイル2]]
```
