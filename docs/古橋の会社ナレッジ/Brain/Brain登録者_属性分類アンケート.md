# Brain新規登録者 属性分類アンケート

## 概要

Brain新規登録者に対して15問の簡単なアンケートを実施し、以下の4属性に分類する。

| 属性 | ターゲット像 | レコメンド商品 |
|------|------------|-------------|
| **A: コンテンツホルダー** | 既に専門知識・スキルがあり、それをBrainで販売したい人 | Brainアカデミー |
| **B: 0→1（初心者）** | まだ稼いだことがなく、何かを学んで最初の収益を得たい人 | スキルハックス |
| **C: 売上あり経営者** | すでに事業で売上があるが、スケールに壁を感じている人 | Brainコミット |
| **D: アフィリエイター** | 他人の商品を紹介して報酬を得たい人 | 迫さんのX攻略講座 |

---

## スコアリングロジック

各質問の回答にA〜Dのポイントを割り当て、全15問の合計で最もスコアが高い属性をその人のタイプとする。

## 判定ロジック

### 合計スコア計算

```
A（コンテンツホルダー）: Q1①+Q2①+Q3④+Q4①+...の合計
B（0→1 初心者）:         Q1②+Q2②+Q3①+...の合計
C（売上あり経営者）:      Q1③+Q2③+Q3⑤+...の合計
D（アフィリエイター）:    Q1④+Q2④+Q3②+...の合計
```

### 判定ルール

| 条件 | 結果 |
|------|------|
| **Aが最高スコア** | → **Brainアカデミー** をレコメンド |
| **Bが最高スコア** | → **スキルハックス** をレコメンド |
| **Cが最高スコア** | → **Brainコミット** をレコメンド |
| **Dが最高スコア** | → **迫さんのX攻略講座** をレコメンド |

### 同点の場合の優先順位

1. **C > A > D > B** の順で優先（LTV・購買力が高い順）
2. または、サブ属性として2番目に高いスコアの商品も「こちらもおすすめ」として表示

## 実装メモ

### 配信タイミング
- **Brain新規登録直後**（ウェルカムメッセージと一緒に配信）
- 所要時間：**約2〜3分**で完了する設計

### アンケート形式
- 全問**選択式**（記述なし）→ 離脱率を最小化
- **プログレスバー表示**で残り質問数を可視化

### 回答後のアクション
1. 判定結果を表示（「あなたは○○タイプです！」）
2. 該当商品のLPまたはファネル入り口へ誘導
3. LINEシナリオの分岐条件として活用（属性別ステップ配信）
