# Brain ブースターパッケージ LINE配信企画書

> **目的**: プロライン構築の専門家へ共有し、シナリオ構成・設定方法を確認するための資料
> **作成日**: 2026年2月15日

---

## 1. 企画概要

| 項目 | 内容 |
|------|------|
| **企画名** | Brain ブースターパッケージ（10大特典） |
| **目的** | Brain LINE登録者を**村上さんセールスチームとの無料面談予約**に繋ぐ |
| **ゴール** | 面談に着座 → セールスチームが提案（コミット/ハックス/その他商材） |
| **プレゼント** | 面談参加者全員に10大特典（専用会員サイトアクセス権）を付与 |
| **KPI** | 1面談あたりの単価 3万〜5万円 |

### ポイント
- プレゼントは**面談参加後にのみ**渡す（面談予約のインセンティブ）
- LINE登録〜面談予約までの接続導線がゼロだったので、それを構築する
- 村上さんは**セールス特化**（Zoomに来てもらえれば仕上げるスタンス）

---

## 2. 登録者の4属性

Brain登録者はアンケートにより4つの属性に分類される。プレゼントは全属性に刺さる内容を混ぜている。

| 属性 | ターゲット像 |
|------|------------|
| **A: コンテンツホルダー** | 専門知識を持ちBrainで販売したい人 |
| **B: 0→1（初心者）** | まだ稼いだことがなく最初の収益を得たい人 |
| **C: 売上あり経営者** | すでに売上はあるがスケールに壁がある人 |
| **D: アフィリエイター** | 他人の商品を紹介して報酬を得たい人 |

## 4. シナリオ詳細

### シナリオ① プレゼント紹介（2日締切＋先頭に戻す）

> **トリガー**: LINE登録直後
> **締切**: 2日間（明後日24時）
> **ボタン押下で**: シナリオ②へ移動

## 7. プロライン構築で確認したい事項

### シナリオ設定について

1. **シナリオ遷移**: シナリオ①のボタン押下でシナリオ②に移動する設定は「シナリオ移動」アクションで実装可能か？
2. **先頭に戻す**: 締切後に「先頭に戻す」で再度ステップ1からやり直す設定方法は？（延長ボタン押下時）
3. **配信タイミング**: 各ステップの配信間隔（例: 登録直後→数時間後→翌日AM…）はステップ配信の「待機時間」で設定？

### ボタン・アクション設定

4. **ボタンの実装方法**: `[プレゼントを受け取りたい]` 等のCTAは「リッチメッセージ」「カルーセル」「テキスト+ボタン」のどれが最適か？
5. **画像添付**: 各ステップでヘッダー画像やバナーを添付する場合、リッチメッセージとFlex Messageのどちらを推奨？
6. **面談予約リンク**: 面談予約URLの埋め込み方法。外部カレンダー（Calendly等）か、プロラインの予約機能か？

### 面談後のプレゼント送付

7. **面談完了トリガー**: 面談が完了した人にだけプレゼントURLを自動送信する方法はあるか？（手動送信 vs タグ付与+自動送信）
8. **プレゼントURL管理**: surge.shの公開URLを直接送る予定だが、URL流出対策（ワンタイムURL等）は必要か？

### 全体構成

9. **シナリオの本数**: 提案では2シナリオ構成だが、プロラインの推奨構成はあるか？
10. **タグ管理**: 「興味あり」「面談予約済」「面談完了」等のタグ設計はどうすべきか？
11. **未反応者への対応**: 先頭に戻すを3回やっても反応がない人への次のアクション（別シナリオ移動？リスト保持のみ？）
