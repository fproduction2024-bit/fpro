**by 迫 佑樹（Brain代表）**

---

> フォロワー0から1万人まで、僕は3ヶ月だった。
> 才能じゃない。「型」があるかどうかの問題だ。

---

## はじめに

X（旧Twitter）は、**最も手軽に「影響力」を手に入れられるプラットフォーム**だ。

- 初期費用ゼロ
- 顔出し不要
- 文章だけで勝負できる
- フォロワーがそのまま「見込み客」になる

ただし、闇雲に投稿しても一生伸びない。

このテンプレートでは、**再現性のある「X運用の型」**をお渡しします。

---

## PART 1：アカウント設計

### プロフィール設計テンプレート

```
【名前】
〇〇｜肩書き or 実績

例）迫佑樹｜Brain代表 / 20歳で年商10億

【自己紹介文のフレームワーク】
・何者か（1行で端的に）
・実績（数字で語る）
・何を発信しているか
・フォローするメリット
・CTA（LINE登録やnoteへの誘導）
```

### 自己紹介文テンプレート

```
〇〇を専門にしている△△です。
□□の実績：(数字を入れる)
このアカウントでは「〇〇で稼ぐ方法」を毎日発信しています。
フォローすると〇〇が身につきます。
▼ 無料プレゼントはこちら
（リンク）
```

### プロフィール画像のポイント

| 要素 | 推奨 | NG |
|------|------|-----|
| **アイコン** | プロ感のある顔写真 or 認識しやすいイラスト | 風景写真・デフォルト画像 |
| **ヘッダー** | 実績や提供価値が一目で分かるデザイン | 何も設定しない |
| **固定ツイート** | 最も反応が良かった投稿 or 自己紹介スレッド | 日常投稿を固定 |

## PART 2：投稿の「型」7選

### 型①：ノウハウ共有型（伸びやすさ：★★★★★）

```
〇〇で月△△万円稼いだ方法を公開します。

① ＿＿＿＿＿
② ＿＿＿＿＿
③ ＿＿＿＿＿
④ ＿＿＿＿＿
⑤ ＿＿＿＿＿

特に③が重要。これだけで結果が変わりました。
```

### 型②：ビフォーアフター型（伸びやすさ：★★★★★）

```
【3ヶ月前】〇〇だった
【今】△△になった

やったことはたった3つ。

① ＿＿＿＿＿
② ＿＿＿＿＿
③ ＿＿＿＿＿

一番効果があったのは②です。
```

### 型③：常識破壊型（伸びやすさ：★★★★☆）

```
「〇〇すべき」は嘘です。

実際に結果を出している人は△△をやっています。

理由はシンプルで＿＿＿＿＿。

僕も〇〇をやめてから、□□になりました。
```

### 型④：失敗談共有型（伸びやすさ：★★★★☆）

```
正直に告白します。

〇〇で□□万円損しました。

原因は△△だったんですが、
同じミスをしている人をめちゃくちゃ見かけるので共有します。

① やってしまったこと
② なぜダメだったか
③ 今ならこうする
```

### 型⑤：数字インパクト型（伸びやすさ：★★★★☆）

```
〇〇を始めて△△日。

・フォロワー：□□人→□□人
・売上：□□万円
・問い合わせ：□□件

やったことは毎日この3つだけ。
```

### 型⑥：まとめ・リスト型（伸びやすさ：★★★☆☆）

```
〇〇したい人が絶対に読むべきアカウント10選

① @＿＿＿：理由
② @＿＿＿：理由
③ @＿＿＿：理由
...

全員フォローしておいて損はないです。
```

### 型⑦：スレッド型（伸びやすさ：★★★★★）

```
【1投目】インパクトのある結論
「〇〇するだけで月△△万円増えた方法を全部公開します🧵」

【2〜8投目】具体的なステップを1つずつ解説

【最終投目】まとめ + CTA
「参考になったらRT & いいねお願いします。
さらに詳しい内容はこちら →（リンク）」
```

## PART 3：1週間の投稿スケジュール

### 毎日の投稿ルーティン

| 時間帯 | 投稿内容 | 目的 |
|--------|---------|------|
| **7:00〜8:00** | おはようツイート + 今日の学び | エンゲージメント獲得 |
| **12:00〜13:00** | ノウハウ系 or 数字インパクト型 | インプレッション狙い |
| **19:00〜21:00** | スレッド or 失敗談 | 深い共感・拡散狙い |
| **随時** | リプライ・引用RT | コミュニティ形成 |

### 1週間スケジュール

| 曜日 | 投稿テーマ | 投稿数 |
|------|----------|--------|
| **月** | 週の目標共有 + ノウハウ | 3〜4 |
| **火** | 失敗談 + 学び | 3〜4 |
| **水** | スレッド投稿（渾身の1本） | 1（スレッド）+ 2 |
| **木** | ビフォーアフター + 数字報告 | 3〜4 |
| **金** | 常識破壊型 + まとめ | 3〜4 |
| **土** | 1週間の振り返り | 2〜3 |
| **日** | 来週の予告 + 軽めの投稿 | 2〜3 |

## PART 4：フォロワー伸長の5つの加速器

### 加速器①：毎日30人にリプライする

```
ターゲット：自分と同じジャンルで自分よりフォロワーが多い人
リプライの型：「共感 + 自分の体験 + 質問」
効果：相手のフォロワーに自分の存在を認知させる
```

### 加速器②：企画を月1回やる

```
企画例：
「フォロー＆RTしてくれた方のアカウント、全員見に行って1人ずつ感想を返します」
「〇〇に関する質問、何でも答えます（24時間限定）」
```

### 加速器③：伸びたツイートを分析する

```
チェック項目：
・いいね数がフォロワー数の5%以上 → 「型」を分析して再利用
・RT数がいいね数の20%以上 → 拡散される要素を特定
・プロフィールクリック率が高い → フック（冒頭文）が強い
```

### 加速器④：他プラットフォームとの連携

```
X → note（詳しい解説記事へ誘導）
X → LINE（リストとして獲得）
X → YouTube（長尺コンテンツでファン化）
```

### 加速器⑤：コラボ企画

```
同じフォロワー規模の人とスペース（音声配信）をやる
お互いのフォロワーに露出 → 相互にフォロワーが増える
```
