| 区分 | 画像枚数 |

締切・残枠・最終日などの緊急性を演出するバナー画像。テキストのみをボールドに表示するシンプルなデザイン。

| # | 画像名 | テキスト | 使用箇所 |

| D-1 | **残枠わずかバナー** | 「⚠️ 今週の面談枠 残り3枠」 | シナリオ② ステップ6（あと3日） |

## デザインガイドライン

### カラーパレット（Web UIと統一）

| 用途 | カラー |
|------|--------|
| 背景（メイン） | `#0a0a1a`（ダークネイビー） |
| アクセント | `#7c3aed` → `#a855f7`（パープルグラデーション） |
| CTAボタン | `#8b5cf6`（パープル） / `#22c55e`（グリーン） / `#f97316`（オレンジ） |
| テキスト | `#ffffff`（白） / `#a1a1aa`（サブテキスト） |
| カード背景 | `rgba(255,255,255,0.05)` + ボーダーグロー |

### フォント
- 日本語：**Noto Sans JP**（Bold / Medium）
- 英数字：**Inter**（Bold）

### デザインの方向性
- Web UI（brain-booster-pkg.surge.sh）と**トーン&マナーを統一**
- LINEの画面幅（約375px表示）で**文字が読めるサイズ**を確保
- パープルの光彩（グロー）エフェクトを控えめに使用
- 無駄な装飾は省き、テキストが主役のクリーンなデザイン

## 制作の優先順位

| 優先度 | 画像 | 理由 |
|--------|------|------|
| 🔴 最優先 | A-1（プレゼント一覧）、B-1（受取ボタン）、B-2（面談予約ボタン） | 最初に目にする画像＆全ステップで頻出 |
| 🔴 最優先 | A-2（面談案内ヘッダー） | シナリオ②の起点 |
| 🟡 次に | B-3, B-4, B-5（再チャンス・延長・プレゼント閲覧ボタン） | 先頭に戻すフェーズで必須 |
| 🟡 次に | D-1, D-2, D-3（緊急性バナー3種） | 締切感を視覚的に演出 |
| 🟢 後で | A-3, A-4（チラ見せ・お客様の声） | あると効果的だがテキストでも代替可 |
| 🟢 後で | C-1, C-2, C-3（フロー図・メリット図解） | チャリティ画像 |
