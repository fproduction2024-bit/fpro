# Brain販売で月50万円を達成するロードマップ

**by 迫 佑樹（Brain代表）**

---

> 「知識をお金に変える」——これは特別な才能じゃなく、正しい"順番"を知っているかどうかの話です。

---

## はじめに

僕がBrainを立ち上げた理由は1つだけ。

**「知識を持っている人が、正当に報われる世界を作りたい」**

あなたがもし何かの分野で人より詳しいこと、経験から得た知見、仕事で積み上げたスキルがあるなら、それは間違いなく"売れる"。

ただし、正しい手順を踏まなければ1円にもならない。

このロードマップでは、僕が数千人のBrain出品者を見てきた中で分かった**「月50万円を最短で達成する人の共通パターン」**をお伝えします。

---

## Phase 0：自分の"売り物"を特定する（Day 1〜3）

### やるべきこと

1. **過去3年間で人に教えたこと**を全部書き出す
2. **「ありがとう」と言われた経験**をリストアップする
3. **自分が"当たり前"だと思っているが他人は知らないこと**を洗い出す

### 売れるテーマの3条件

| 条件 | チェック |
|------|---------|
| ① その知識で**誰かの悩みが解決する** | □ |
| ② ネットで**検索している人がいる**（需要がある） | □ |
| ③ あなたが**実体験に基づいて語れる** | □ |

**❌ 初心者がやりがちなNGテーマ設定**
- 「誰でもスマホポチポチで月100万（実績なし）」→ 信用ゼロ・規約違反リスク高
- 「絶対に失敗しない人生の歩み方」→ テーマが広すぎて誰も買わない
- 「私が〇〇大学に合格した日記」→ 悩みの解決策（ノウハウ）になっていない

> 💡 **迫のワンポイント**: 「自分が稼いだ金額」よりも「自分が解決した問題」で商品を考えること。月収5万円でも「副業の始め方」は売れる。月収1億でも「なんとなく成功した話」は売れない。

## Phase 1：最小単位でコンテンツを作る（Day 4〜10）

### ❌ やりがちなミス

- 100ページのPDFを作ろうとする
- 30本の動画講座を企画する
- 完璧になるまで出品しない

### ✅ 正しいやり方

**「1つの問題を、1つの方法で解決するコンテンツ」を作る。**

| 要素 | 具体例 |
|------|--------|
| **タイトル** | 【初心者向け】Instagramリール動画で月1万フォロワーを獲得した全手法 |
| **構成** | 5,000〜10,000字 or 動画3〜5本 |
| **制作期間** | 3〜7日 |

### コンテンツのフレームワーク

```
1. 読者のビフォー（今こんな状態ですよね）
2. アフター提示（こうなれます）
3. なぜそうなれるのか（根拠・実績）
4. 具体的な手順（ステップ1〜5）
5. よくある失敗と対策
6. まとめ＋次のアクション
```

**📊 【実データ】文字数ごとの平均販売価格と満足度の相関**
- **3,000字未満**: 満足度低下のリスク大（薄いと感じられやすい）
- **5,000〜10,000字**: 1,000円〜4,980円帯で最も読了率・満足度が高い黄金比
- **20,000字以上**: 高単価（9,800円〜）で正当化されやすいが、動画解説がないと挫折率が上がる

> 💡 **迫のワンポイント**: 最初のコンテンツに100点は要らない。70点で出して、レビューを見て改善する。これが最速。

## Phase 2：価格と販売戦略を決める（Day 11〜14）

### 価格設定の公式

```
初回価格 ＝ 本来価格の30〜50%（アンカー効果を使う）
```

| 戦略 | 具体例 |
|------|--------|
| **ローンチ価格** | 4,980円（最初の50部限定） |
| **通常価格** | 9,800円 |
| **部数連動値上げ** | 50部→100部→200部で段階的に値上げ |

### 販売前にやるべき3つの仕込み

1. **Xで「作ってます宣言」をする**（制作過程を投稿）
2. **無料部分で"価値の証明"をする**（冒頭を無料公開）
3. **レビュー依頼リストを作る**（最初の5人に無料配布してレビューをもらう）

## Phase 3：初速を作る（Day 15〜21）

### Brainの売上が伸びる仕組み

```
レビュー数 × レビュー質 × アフィリエイト報酬率 ＝ 拡散力
```

### 初速のための施策

| 施策 | 目的 |
|------|------|
| **アフィリエイト報酬率を50%に設定** | 紹介者のインセンティブを最大化 |
| **レビューキャンペーン** | 購入者にレビュー依頼→追加特典プレゼント |
| **Xでのカウントダウン投稿** | 「あと10部で値上げ」で緊急性を演出 |
| **購入者限定の追加コンテンツ** | 「買った人だけ見れる裏話」でレビュー促進 |

**🎯 レビュー獲得率を3倍にする「特典の渡し方」**
単に「レビューしてね」はNG。
1. コンテンツの最後に「**実践用スプレッドシート（または秘匿プロンプト）**」の存在を明かす
2. 「本気で実践したい方だけに渡したいので、レビューを書いてくれた方限定でお渡しします」と理由を添える
3. LINE公式アカウント等に誘導し、レビューのスクショを送ってもらう

> 💡 **迫のワンポイント**: Brainのランキングは「直近の売上本数」で決まる。だから短期間に集中して売ることが重要。ダラダラ売るより、3日間で一気に売る方が結果的に総売上も伸びる。

## Phase 4：月50万円の安定収益を作る（Day 22〜90）

### 2つの収益エンジン

#### エンジン①：商品ラインナップの拡充

```
1商品 × 平均単価9,800円 × 月50本 ＝ 月49万円

→ 達成のためにはコンテンツ数を3〜5本に増やす
→ 1本あたり月10〜15本売れればOK
```

| 商品# | テーマ例 | 価格帯 |
|-------|---------|--------|
| 商品1 | 入門編（初心者向け） | 4,980円 |
| 商品2 | 実践編（中級者向け） | 9,800円 |
| 商品3 | テンプレート集 | 14,800円 |
| 商品4 | 個別添削付きパッケージ | 29,800円 |
| 商品5 | コンサル付きプレミアム | 49,800円 |

#### エンジン②：アフィリエイト収益

- 自分の商品を買ってくれた人が次のアフィリエイターになる
- つまり「良い商品を出す→レビューが増える→紹介される→さらに売れる」の循環

### 月50万円達成者の時間配分

| 活動 | 週あたりの時間 |
|------|--------------|
| 新コンテンツ制作 | 10時間 |
| 既存コンテンツ改善 | 3時間 |
| X/SNS発信 | 5時間 |
| レビュー対応・コミュニティ運営 | 2時間 |

### 🛑 突破口コラム：売上が止まった時に見直す3つの数字
売上が月5万〜10万で停滞した時、才能を疑う前に以下の「数字」を見直してください。

1. **PV（閲覧数）が足りない** → SNSからの流入導線が弱い。無料プレゼント企画でインプを稼ぐ。
2. **CTR（アフィリンクのクリック率）が低い** → 訴求文が弱い。ベネフィット（読者がどう変わるか）を再定義する。
3. **CVR（成約率）が低い（3%未満）** → セールスレター（無料部分）の質が低い、または値段と価値が釣り合っていない。無料部分で「ノウハウの強力さ」を出し惜しみしない。
