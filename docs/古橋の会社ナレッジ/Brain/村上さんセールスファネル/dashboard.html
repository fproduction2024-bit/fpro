再案内

🔔 コンテンツ再送

流れ共有

📋 受取までのSTEP説明

明日終了

最終日

🔴 締切当日＋お客様の声

受取方法の再説明。面談参加者の成功事例を紹介。

⏰ 残り4h → 2h → 1h

先頭に戻す

具体化
