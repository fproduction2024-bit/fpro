## 3. スキルハックス卒業後の3つの未来

### パターン①: 副業で月5万〜10万プラス

本業でもやりがいを持って働きながら、「俺には副業のスキルがあるしな」っていう心の余裕を持ちながら本業と副業ライフを楽しんでいく。

例えば月収20万円で生活費15万円、実質自由に使えるお金は5万円。そこに副業で5万〜10万稼げたら、自由に使えるお金が2倍〜3倍に。

### パターン②: フリーランスとして独立（月50万〜100万）

評判いいフリーランスにはどんどん仕事が流れてきます。会社員として働くってのは会社が利益を中抜きしてる状態。スキルを身につけてクライアントに直接価値提供すれば、月50万〜100万はすぐ行ったりする。

### パターン③: 事業を作る側へ（月300万〜年商1億超）

フリーランスとして実力がついたらチームを作って仕事を振っていく。法人設立して社長になってる人もたくさん。月の利益で300万、500万、年商1億ベースに乗ってる人まで。

## 4. よくある質問（前半）

### Q1. 本当に自分にもできるの？

テレビで出ている有名な経営者もSNSで活躍してるインフルエンサーも、ぶっちゃけ能力はあんまり変わらないです。僕もめちゃくちゃ頑張ってブログ記事を100記事書いたにも関わらず出た収益はたったの273円だった。今では売上規模で10億とかの会社をやってますけども、正しいタイミングで正しい知識を正しい環境で学べたかどうかだけなんです。

### Q2. 情報商材ってぶっちゃけ詐欺じゃないの？

ビジネスってのはお客さんがいてそこに対して価値提供をすることができて初めて「ありがとう」って言われてお金がもらえる──こんな仕組みなんですよね。「楽して誰でもコピペだけで稼げる」はこの原理原則に反している。

ちなみにうちの会社って会社作って2年目の時点で**銀行から2億円の資金調達**してるんですよ。銀行さんはSNSも全部チェックされるし、受講生の実績とかも見られるし、決算書も全部開示した上で信頼された。

### Q3. 周りで成功してる人なんかいないんだけど

うまくいってない人の周りにはうまくいってない人しかいません。うまくいってる人の周りにはうまくいってる人がたくさんいます。だからこそのコミュニティ。

**シングルマザーの事例**: 2歳・3歳の子供を1人で見ながら副業。コミュニティで同じ境遇のシングルマザーの先輩からアドバイスをもらい「子供が寝た後にベッドの中で提案文を書いて送ってください」──結果、**月10万円の副業収入を達成**。

### Q4. お金がもったいない／今お金がない

分割払いの場合は**1日コーヒー1杯分ぐらい**。大学の学費って1年間で100万、4年で400万。正直その400万よりは圧倒的に人生変わるきっかけに。

### Q5. 時間がない

時間がないってのは実は幻想です。うちのスタッフが「マジで時間ないんです」っていう人とZoomでスケジューリングしてあげたら、**1週間後には案件取れちゃった**みたいな事例がある。

## 13. 2倍返金保証の条件（詳細）

**条件はシンプルに3つ:**

1. **運営が伝えた課題を期限通りやる**（個別ヒアリングした上で合意した無理のないスケジュール）
2. **日報を毎日提出する**（今日何やったか、明日何やるかの箇条書き）
3. **月の収益報告をする**（コミュニティやSNSで発信）

この3つをやっていて、なお2年間で受講料すらペイできなかったら→ **未回収分の2倍を返金**。

例：
- 20万しか稼げなかった → 差額19.8万の2倍 = 39.6万円返金
- 1円も稼げなかった → 39.8万の2倍 = 79.6万円返金（**完全に赤字**）
