## 1. 全体概要

### 商品スペック

| 項目 | 内容 |
|---|---|
| **商品名** | スキルハックス（Skill Hacks） |
| **価格** | 398,000円（税込） |
| **分割** | 最大24回（1日あたり約450円） |
| **保証** | 2倍返金保証（未回収分の2倍を返金） |
| **ターゲット** | 副業ゼロイチ層（未経験〜初収益を目指す人） |
| **提供内容** | 全講座学び放題＋伴走支援＋コミュニティ＋特典 |

### ファネルのゴール

LINE登録者を**動画教育（4本）**で温め、スキルハックスへの**申込み＋決済**まで完結させる。

## 4. タグ・セグメント設計

### 推奨タグ一覧

| タグ名 | 付与タイミング | 用途 |

| `未反応_第X話` | 先頭戻し最終ステップ後 | リスト保持・再アプローチ判定 |

### セグメント

| セグメント名 | 条件 | 用途 |
|---|---|---|
| **温まったリード** | VSL視聴完了 & 未購入 | セールスシナリオ対象 |

| **購入者** | 決済完了タグあり | 会員コンテンツ配信 |
