**あなたの特徴**: 論理的に物事を考えるのが得意。仕組みを作ることに喜びを感じるタイプ。

| 項目 | 内容 |
|------|------|
| おすすめ講座 | **ProgrammingHacks** |
| 主な案件 | LP制作・サイト修正・WordPress構築 |
| 市場の案件数 | ★★★★☆（非常に多い） |
| 初案件までの目安 | 2〜4週間 |

#### 📖 受講生リアルストーリー

> プログラミング学習を通じて、論理的思考力やクライアント対応、情報発信力といった「ソフトスキル」を磨いたことで、未経験からでも圧倒的に評価されるようになった方が多数います。技術だけじゃない。**人間力 × スキル**が最強の組み合わせです。

## 同点の場合

2つのスキルが同点の場合は、以下の基準で決めましょう：

1. **「やってみたい」と直感で思える方** → 楽しさが継続の原動力になる
2. **案件単価が高い方** → 同じ時間で稼げる金額が変わる
3. **案件数が多い方** → 最初の1件を取りやすい

### 🔀 ハイブリッド戦略：同点タイプを活かす

同点は「弱点」ではなく「強み」です。2つのスキルを掛け合わせることで、単一スキルの人よりも**高単価で差別化**できます。

| 同点パターン | ハイブリッド戦略 | 目指せる単価 |
|-------------|----------------|-------------|
| A＋C（プログラミング×デザイン）| デザインからコーディングまでワンストップ | 10〜50万円/件 |
| B＋C（動画編集×デザイン）| YouTube編集＋サムネをセット提案 | 1〜3万円/本 |
| A＋D（プログラミング×ライティング）| SEOに強いWebサイト制作 | 10〜30万円/件 |
| B＋D（動画編集×ライティング）| 台本作成から編集まで一括対応 | 1〜5万円/本 |
| C＋D（デザイン×ライティング）| LPのコピー＋デザインをセット | 10〜30万円/件 |
| A＋B（プログラミング×動画編集）| Webアプリ紹介動画やSaaSのPR映像 | 5〜20万円/件 |

> **掛け合わせのコツ**: まず1つ目のスキルで案件を取れるレベルになってから、2つ目を追加する。2つ同時に学ぶのは効率が悪い。順番が大事！

> **迷ったら？** まず1つ始めてみましょう。合わなかったら途中で変えても大丈夫です。
