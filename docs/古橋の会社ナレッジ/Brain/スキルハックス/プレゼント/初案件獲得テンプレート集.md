## 1. クラウドソーシング プロフィール文

### プログラミング（コーディング）

```
はじめまして、【名前】と申します。
プロフィールをご覧いただきありがとうございます。

■ 対応可能な業務
・LP（ランディングページ）コーディング
・コーポレートサイト制作・修正
・WordPressカスタマイズ
・レスポンシブ対応（スマホ・タブレット）

■ 使用ツール・言語
HTML / CSS / JavaScript / jQuery / WordPress

■ 制作実績
【ポートフォリオURLを記載】

■ 納期について
・LP1ページ：最短3営業日〜
・サイト修正：最短1営業日〜
※案件内容によりご相談させてください

■ 稼働時間
平日【○時〜○時】、土日【○時〜○時】
連絡は24時間以内に返信いたします。

■ 心がけていること
・レスポンスの早さ
・デザインカンプに忠実なコーディング
・納期厳守

まずはお気軽にご相談ください。
丁寧な対応を心がけます。よろしくお願いいたします。
```

> ⚠️ **注意**: 「なんでもできます」は逆効果。対応業務は**自分が実際にできること**だけに絞りましょう。具体的に書くほどクライアントは安心します。

#### ❌ NG例：こんなプロフィールは選ばれない

```
プログラミング勉強中です。まだ実績はありませんが
頑張りますのでよろしくお願いします。
いろいろなことに挑戦してみたいです。
```

**何がダメか**：
- 「勉強中」→ 仕事を任せる不安しかない
- 「実績はありません」→ サンプル・ポートフォリオは作れる
- 「いろいろ」→ 何ができるのか分からない
- 心がけ・稼働時間・納期の情報がゼロ

## 2. 案件応募（提案文）テンプレート

### 基本テンプレート（全スキル共通）

```
【クライアント名 or 会社名】様

はじめまして、【名前】と申します。
今回の案件に興味を持ち、ご応募いたしました。

■ 応募理由
【案件の内容に触れて、なぜ自分が適任か1〜2文で記載】

■ 対応可能な内容
【案件の要件に合わせて、自分ができることを箇条書き】

■ 制作実績
【サンプルURL or ポートフォリオURL】

■ 納期
ご依頼から【○】営業日以内に納品可能です。

■ 稼働時間
平日【○時〜○時】で対応可能です。
チャットでのご連絡は24時間以内に返信いたします。

■ 料金
ご予算【○○円】の範囲で対応可能です。
※ご予算に応じてご相談させてください。

ご検討のほどよろしくお願いいたします。
```

### 差別化ポイント追加版

```
【上記テンプレートに加えて、以下のいずれかを追記】

① 具体的な提案を添える
「お送りいただいた参考動画を拝見しました。テロップの
 フォントは○○系、BGMは○○の雰囲気が合うと考えています。」

② 相手のチャンネル/サイトを分析する
「○○様のチャンネルを拝見しました。○○な世界観が
 素敵だと感じました。その雰囲気を崩さない編集を心がけます。」

③ テスト納品を提案する
「まず1本、テスト的にお受けすることも可能です。
 品質をご確認いただいた上で、継続をご判断ください。」
```

> 💡 **ワンポイント**: ①が最も効果的。「ちゃんと案件内容を見ている」と伝わるだけで、返信率が**2〜3倍**になります。コピペ感のある提案文は見てもらえません。

---

### 📊 データで見る「応募のリアル」

応募する前に、数字の現実を知っておきましょう。

| 指標 | 初心者の目安 | 3ヶ月後の目安 |
|------|-------------|--------------|
| 応募数 / 日 | 3〜5件 | 1〜2件（質重視） |
| 提案文の返信率 | 10〜15% | 25〜40% |
| 返信から受注の確率 | 30〜50% | 60〜80% |
| 初案件獲得まで | 10〜30件の応募 | - |

**つまり**：初案件を取るには、最低10件は応募が必要。30件応募しても取れないこともある。でもそれは**普通**のこと。

> スキルハックスの受講生の中には、300件応募してようやく初案件を取り、その後月50万稼ぐ動画編集者になった人もいます。500件応募しても取れなかった人が、コツを掴んでから100万フォロワーのインフルエンサーになった事例もあります。
>
> 不器用でも、数を打てば当たる。当たった後は急成長する。これがリアルです。

## 3. 価格設定ガイドライン

### 初心者が設定すべき価格の目安

| スキル | 案件例 | 初心者相場 | 実績3件後の相場 | 実績10件後の相場 |
|-------|--------|-----------|---------------|----------------|
| プログラミング | LP1ページ | 3〜5万円 | 5〜10万円 | 10〜30万円 |
| プログラミング | サイト修正 | 5,000〜1万円 | 1〜3万円 | 3〜5万円 |
| 動画編集 | YouTube 10分 | 3,000〜5,000円 | 5,000〜1万円 | 1〜2万円 |
| 動画編集 | ショート動画 | 1,000〜3,000円 | 3,000〜5,000円 | 5,000〜1万円 |
| デザイン | バナー1枚 | 3,000〜5,000円 | 5,000〜1万円 | 1〜3万円 |
| デザイン | サムネイル1枚 | 1,000〜3,000円 | 3,000〜5,000円 | 5,000〜1万円 |
| ライティング | 3,000字記事 | 文字単価1円 | 文字単価2〜3円 | 文字単価3〜5円 |
| ライティング | 5,000字記事 | 文字単価1円 | 文字単価2〜3円 | 文字単価3〜5円 |

> **ポイント**: 最初の3件は「実績を作ること」が目的。相場より少し安めに設定して、★5のレビューを集めましょう。実績が3件以上たまったら、段階的に単価を上げていきます。

### 💡 値段設定のやってはいけない

- ❌ **いきなり高額**: 実績ゼロで相場以上の価格をつけると応募しても選ばれない
- ❌ **「いくらでもいいです」**: 自信がないように見える。必ず具体的な金額を提示する
- ✅ **最適解**: 相場の70〜80%で提示し、「実績づくりのため特別価格です」と添える

> 迫さんも最初はこう営業しました──「大学生なんで今回特別にお安くさせていただきます。予算2〜5万円のところ、僕は18,000円でいいです。1割お値引きしますので僕に任せていただけませんか」。結果、**1件目の営業で即成約**。

## 4. クライアントへのメッセージテンプレート

### 案件受注直後

```
【クライアント名】様

この度はご依頼いただき、誠にありがとうございます。
精一杯取り組ませていただきます。

つきまして、以下の点を確認させてください。

1. 【確認事項①】
2. 【確認事項②】
3. 納期は【○月○日】でよろしいでしょうか？

ご確認のほどよろしくお願いいたします。
```

> 💡 確認事項の例：素材の受け渡し方法 / 参考イメージ / 修正回数の上限 / 納品ファイル形式

### 進捗報告

```
【クライアント名】様

お世話になっております、【名前】です。
進捗のご報告です。

■ 現在の進捗
【具体的な進捗状況を記載】

■ 完了予定
【○月○日】までに初稿をお送りする予定です。

何かご要望や変更点がございましたら、
お気軽にお知らせください。

引き続きよろしくお願いいたします。
```

> 💡 作業の50%時点で1回、納品前に1回──最低2回は進捗報告を入れると信頼度が爆上がり

### 納品時

```
【クライアント名】様

お世話になっております、【名前】です。
納品物が完成いたしましたので、お送りいたします。

■ 納品ファイル
【ファイル名 / URL】

■ 補足事項
【修正回数の残り、注意点など】

ご確認いただき、修正点がございましたらお知らせください。
【○回】まで修正対応いたします。

今後ともよろしくお願いいたします。
```

### 修正依頼への返信

```
【クライアント名】様

ご確認いただきありがとうございます。
修正点、承知いたしました。

以下の内容で修正いたします。
・【修正内容①】
・【修正内容②】

【○月○日】までに修正版をお送りいたします。
よろしくお願いいたします。
```

> 💡 修正依頼が来ても焦らない。「承知いたしました」の一言で冷静にプロ対応。修正は「あなたの成長チャンス」でもある

### リピート（継続案件）のお願い

```
【クライアント名】様

この度はご依頼いただき、ありがとうございました。
ご一緒にお仕事ができ、大変勉強になりました。

もし今後も同様のお仕事がございましたら、
ぜひお声がけいただけますと幸いです。

継続的にご依頼いただける場合、
通常よりお得な料金でご提案することも可能です。

今後ともよろしくお願いいたします。
```

> 💡 この一言を送るだけで、リピート率は**3倍以上**になるというデータもあります。「わざわざ言わなくても…」と思うかもしれませんが、言わないと「もう次はないのかな」と思われて終わり

## 5. 🤖 AI活用Tips── テンプレートをもっと使いこなす

ChatGPTやClaude等のAIツールを使えば、テンプレートのカスタマイズが格段に楽になります。

### プロフィール文のAIカスタマイズ

```
以下のプロフィール文テンプレートを、私の情報に合わせて
カスタマイズしてください。

【テンプレートをコピペ】

■ 私の情報
・名前：○○
・スキル：動画編集（Premiere Pro）
・稼働可能時間：平日21時〜24時、土日10時〜18時
・強み：前職の営業経験でクライアント対応が得意
・ポートフォリオURL：○○
```

### 提案文のAIカスタマイズ

```
以下の案件に応募する提案文を作ってください。

■ 案件名：【コピペ】
■ 案件の詳細：【コピペ】
■ 私のスキル：○○
■ ポートフォリオ：○○

以下のテンプレートをベースに、この案件に特化した
提案文にカスタマイズしてください。
特に「応募理由」は案件内容に具体的に触れること。

【テンプレートをコピペ】
```

### ⚠️ AI活用の注意点

- **そのままコピペしない**: AIが生成した文章はそのまま使わず、必ず自分の言葉で微調整する
- **嘘を書かない**: AIは実績を「盛る」ことがある。嘘の実績は絶対にNG
- **毎回変える**: 同じ提案文を複数の案件に使い回すと、コピペ感が出てバレる
- **最終チェックは自分で**: 誤字脱字・不自然な表現がないか、送信前に必ず音読する

> AIは「書き出しの壁」を超えるためのツール。最終的な仕上げは、あなた自身の言葉で。

---

> **このテンプレート集の使い方**
> 1. テンプレートをそのままコピーして使う
> 2. 【 】内を自分の情報に書き換える
> 3. 慣れてきたら、自分の言葉で少しずつアレンジする
> 4. AIを使って案件ごとにカスタマイズする
>
> 最初は「型通り」で十分です。案件を重ねるうちに、自然と自分のスタイルが出来上がります。
