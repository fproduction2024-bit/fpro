## Phase 1：スキル選定・環境準備・学習開始（Day 1〜7）

### 目標
「何をやるか」を決めて、スキルの基礎学習を開始できる状態にする。

### Day 1〜2：自分に合うスキルを選ぶ

| アクション | 詳細 |
|-----------|------|
| 診断シートを使う | 「副業スキルマッチング診断シート」で自分のタイプを確認 |
| 市場調査をする | クラウドワークスで各スキルの案件数・相場を確認 |
| 1つに決める | 迷ったら直感で選ぶ。合わなければ途中で変えてもOK |

### Day 3〜5：環境を整える

| アクション | 詳細 |
|-----------|------|
| ツールを準備 | 必要なソフトをインストール（Premiere Pro / Photoshop 等） |
| アカウント登録 | クラウドワークス・ランサーズに登録 |
| 学習環境 | 毎日の学習時間と場所を決める（例：21時〜23時） |
| 学習開始 | 選んだスキルの基礎学習に着手 |

### Day 6〜7：学習を継続する

| アクション | 詳細 |
|-----------|------|
| 学習継続 | 基礎スキルの習得を続ける（1日2〜3時間） |
| 手を動かす | 見るだけでなく、必ず自分で再現する |
| 学習記録 | 毎日の学習内容と気づきをメモ |

### ⚠️ Phase 1の落とし穴 & 対策

| 落とし穴 | 典型パターン | 対策 |
|---------|------------|------|
| **スキル選びで迷い続ける** | 3日経ってもまだ調べてる | 迷ったら「案件数が多い × 直感でやりたい方」。合わなければ後から変更OK |
| **ツール選びに凝りすぎる** | どのPC？どのソフト？で1週間溶ける | 今あるPCで始める。道具にこだわるのは稼いでから |
| **「もう少し調べてから」症候群** | 情報収集が目的化。実際に手を動かさない | 調査は2日まで。3日目には必ず学習動画を再生する |

### Phase 1 チェックリスト
- [ ] 取り組むスキルを1つ決めた
- [ ] 必要なツール・ソフトをインストールした
- [ ] クラウドワークスに登録した
- [ ] 毎日の学習スケジュールを決めた
- [ ] 基礎学習を開始した

## Phase 2：ポートフォリオ・提案文準備（Day 8〜14）

### 目標
サンプル作品を作り、営業を始められる状態を整える。

### Day 8〜11：サンプル作品を作る

| アクション | 詳細 |
|-----------|------|
| サンプル制作 | 実際の案件を想定した作品を制作 |
| 数の目安 | 動画編集：1本 / デザイン：バナー3枚 / プログラミング：LP1ページ / ライティング：記事2本 |
| フィードバック | 身近な人や同じ目標を持つ仲間に意見をもらう |

**スキル別の「基礎完了」ライン:**

| スキル | ここまでやればOK |
|-------|----------------|
| 動画編集 | テロップ・カット・BGM・SE・画像挿入の5つが一人でできる |
| デザイン | Photoshopでバナーを1枚作れる |
| プログラミング | HTML/CSSで簡単なページを1枚コーディングできる |
| ライティング | SEOを意識した3,000字の記事を1本書ける |

### Day 12〜14：ポートフォリオ・提案文を整える

| アクション | 詳細 |
|-----------|------|
| まとめる | サンプルをGoogleドライブ / Notionにまとめる |
| URLを発行 | 共有リンクを作成（提案文に貼れるように） |
| プロフィール完成 | クラウドワークスのプロフィール文を完成させる |
| 提案文を準備 | テンプレート集を使って提案文のベースを用意する |

### ⚠️ Phase 2の落とし穴 & 対策

| 落とし穴 | 典型パターン | 対策 |
|---------|------------|------|
| **完璧主義の罠** | 「もう少し上手くなってから…」で永遠に次に進まない | 70%でOK。技術が成熟するのを待っていたら一生案件は取れない |
| **枝葉のスキルに逃げる** | 要らないスキルに時間を使う | 「その技術がないと案件を納品できないか？」を自問。答えがNoならやらない |
| **サンプルに凝りすぎる** | 1つの作品に1週間かけてしまう | サンプルは「70点を3つ」が「100点を1つ」より100倍価値がある |

### Phase 2 チェックリスト
- [ ] サンプル作品を規定数制作した
- [ ] ポートフォリオURLを用意した
- [ ] クラウドワークスのプロフィールが100%完成した
- [ ] 提案文のベースを用意した

## Phase 3：営業開始（Day 15〜21）

### 目標
案件に応募して、初受注を目指す。

### Day 15〜17：集中応募期間

| アクション | 詳細 |
|-----------|------|
| 案件を探す | 「新着順」で自分のスキルに合う案件を毎日チェック |
| 1日3件以上応募 | 返信率は10〜20%なので数が重要 |
| 差別化する | 相手のチャンネル/サイトを分析して提案文に反映 |
| テスト提案 | 「まず1本テストで」を積極的に提案 |

### 📬 応募テクニック集

**① ゴールデンタイムを狙う**
- 朝9〜10時、昼12〜13時、夜20〜22時に新着案件が多い
- 夜に提案文を下書き保存 → 翌朝8〜9時に送信が最も効果的

**② 「初心者歓迎」案件の見分け方**
- ✅ 選ぶべき：「初心者歓迎」「未経験OK」「丁寧に教えます」
- ✅ 選ぶべき：予算が明記されている、クライアントの評価★4以上
- ❌ 避ける：予算が異常に安い（搾取案件）、依頼内容が曖昧

**③ 提案文の差別化テクニック**
- **「御社の○○を拝見しました」**の一言が最強の差別化（コピペ感がゼロになる）
- ポートフォリオのURLだけでなく、1作品のスクショを提案文内に貼ると見てもらえる確率UP

### Day 18〜21：初案件の獲得へ

| アクション | 詳細 |
|-----------|------|
| 返信対応 | 返信が来たら即レス（24時間以内、できれば数時間以内） |
| 条件確認 | 納期・修正回数・納品形式を事前に合意 |
| 受注 | 初案件は「稼ぐ」より「実績を作る」ことが目的 |

### Phase 3 チェックリスト
- [ ] 10件以上の案件に応募した
- [ ] 1件以上の案件を受注した

## Phase 4：初案件獲得・安定受注（Day 22〜60）

### 目標
月3〜5万円を安定的に稼ぐ。

### Day 22〜30：初案件の納品

| アクション | 詳細 |
|-----------|------|
| 50%報告 | 作業の中間段階でクライアントに進捗共有 |
| 納品 | 丁寧なメッセージと共に納品物を提出 |
| 評価獲得 | ★5 の評価をもらうことを意識 |

> **ポイント**: 初案件は「稼ぐ」よりも「実績を作る」ことが目的。相場より少し安くても、丁寧に取り組んで★5評価を取る。

### Day 31〜60：実績を積む・単価を上げる

| アクション | 詳細 |
|-----------|------|
| 継続応募 | 毎日1〜2件は新規案件に応募を続ける |
| リピート打診 | 納品後に「今後もお仕事があればぜひ」と一言添える |
| 実績3件突破 | ★5評価を3件以上集める → 信頼度が大幅UP |
| 相場通りの価格に戻す | 初期の割引価格から通常価格に戻す |
| 2つ目のスキル学習開始 | スキルの掛け合わせで単価UPを目指す |

### ⚠️ Phase 4の落とし穴 & 対策

| 落とし穴 | 典型パターン | 対策 |
|---------|------------|------|
| **安い案件から抜け出せない** | 値上げが怖い | 実績3件超えたら値上げ。品質が良ければクライアントは離れない |
| **キャパオーバー** | 受けすぎて品質が下がる | 同時に抱える案件は3件まで |
| **学習をやめてしまう** | 案件に追われて成長が止まる | 週2時間だけでも新しいスキルのインプット時間を確保する |

### Phase 4 チェックリスト
- [ ] 実績が3件以上になった
- [ ] 単価を初期から20%以上UPした
- [ ] リピートクライアントが1名以上いる
- [ ] 月3万円以上の副業収入を達成した
- [ ] 2つ目のスキルの学習を開始した

## Phase 5：月10万円達成・仕組み化（Day 61〜90）

### 目標
月10万円の副業収入を達成し、継続的に稼げる仕組みを作る。

### Day 61〜70：収入源を複数化

| アクション | 詳細 |
|-----------|------|
| 複数プラットフォーム | クラウドワークス + ランサーズ + ココナラ の3つで案件を回す |
| 直接取引 | 信頼関係のあるクライアントとプラットフォーム外で直接契約（手数料削減） |
| パッケージ化 | 「動画編集 + サムネ5枚セット ○○円」のようなセット商品を作る |

### Day 71〜90：効率化・月10万円突破

| アクション | 詳細 |
|-----------|------|
| テンプレ化 | よく使うテロップスタイル / バナーテンプレ / 記事構成を型にする |
| 月額契約 | 「月○本の動画編集で月額○万円」の継続契約を目指す |
| 単価交渉 | 全クライアントに単価見直しを相談 |
| 発信を始める | X（Twitter）で学びや実績を発信 → 直接依頼の導線を作る |

**月10万円の達成パターン例:**

| パターン | 内訳 | 合計 |
|---------|------|------|
| 動画編集 | 8,000円/本 × 13本 | 104,000円 |
| デザイン | バナー5,000円 × 10枚 + LP 50,000円 × 1件 | 100,000円 |
| プログラミング | LP 50,000円 × 2件 | 100,000円 |
| ライティング | 文字単価2円 × 5,000字 × 10本 | 100,000円 |
