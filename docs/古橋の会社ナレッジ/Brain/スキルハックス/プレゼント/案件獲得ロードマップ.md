# 案件獲得ロードマップ

> ゼロから初案件を獲得するまでの完全ステップガイド。
>
> スキルハックス 全話視聴者限定特典

---

## このロードマップの使い方

1. **STEP 1〜7を順番に進めてください**（飛ばさない）
2. 各STEPの「完了条件」を満たしたら次に進む
3. 迷ったら動画のコメント欄や同じ目標を持つ仲間に相談する
4. **目安期間：2週間〜1ヶ月で初案件獲得**

---

## 全体マップ

```
STEP 1（1日目）    → スキルを選ぶ
STEP 2（2〜7日目）  → コアスキルだけ学ぶ
STEP 3（5〜7日目）  → サンプルを作る
STEP 4（7〜8日目）  → プロフィールを整える
STEP 5（8〜10日目） → 案件に応募する
STEP 6（10〜14日目）→ 初案件を納品する
STEP 7（14日目〜）  → リピートと単価アップ
```

---

## STEP 1：スキルを選ぶ（1日目）

### やること
自分が取り組むスキルを1つ決める。

### 選び方のポイント

| 判断基準 | 質問 |
|---------|------|
| 興味 | どの作業が「やってみたい」と思えるか？ |
| 適性 | 細かい作業が好き？ 文章を書くのが好き？ |
| 市場 | クラウドワークスでどのくらい案件が出ているか？ |
| 速さ | 最短で案件が取れるのはどれか？ |

### 各スキルの特徴

| スキル | こんな人向け | 初案件までの目安 | 初期の案件単価 |
|-------|------------|----------------|-------------|
| 動画編集 | コツコツ作業が好き | 1〜2週間 | 3,000〜5,000円/本 |
| Webデザイン | ビジュアルにこだわりたい | 2〜3週間 | 3,000〜5,000円/枚 |
| プログラミング | 論理的思考が得意 | 2〜4週間 | 3〜5万円/ページ |
| ライティング | 文章を書くのが好き | 1〜2週間 | 文字単価1円〜 |

> **迷ったら？** まず1つ選んで動いてみましょう。合わなかったら途中で変えても大丈夫です。

> 💡 **ワンポイントアドバイス**: 「迷ってる時間が一番もったいない。直感で1つ選んで、合わなかったら変えればいい」

### 完了条件
- [ ] 取り組むスキルを1つ決めた

## STEP 2：コアスキルだけ学ぶ（2〜7日目）

### やること
選んだスキルのカリキュラムで、**案件獲得に必要な最低限の部分だけ**を学ぶ。

### 学習のルール

1. **全部やろうとしない** — 基礎編だけでOK
2. **手を動かしながら学ぶ** — 見るだけでなく、必ず自分で操作する
3. **分からないところは即質問** — Q&Aや調査で解決する
4. **1日の学習時間を決める** — 最低1時間、できれば2〜3時間

### 各スキルの「最低限ここまで」ライン

**動画編集の場合:**
- テロップ挿入 → カット編集 → BGM挿入 → SE挿入 → 画像挿入
- この5つができればYouTube編集案件は受けられる

**Webデザインの場合:**
- Photoshopの基本操作 → バナー制作 → SNS画像制作
- バナーが作れれば案件に応募できる

**プログラミングの場合:**
- HTML/CSS → レスポンシブ対応 → 簡単なJavaScript
- LP1ページをコーディングできれば案件に応募できる

**ライティングの場合:**
- SEOの基礎 → 記事構成の作り方 → PREP法での執筆
- 3,000字の記事を書ければ案件に応募できる

> 💡 **ワンポイントアドバイス**: 「枝葉のスキルに逃げないで。案件を取るのに必要な"最低限"だけを最速で身につけて」

### 完了条件
- [ ] 基礎スキルを一通り習得した
- [ ] 基本的な操作を自分一人でできるようになった

## STEP 3：サンプルを作る（5〜7日目）

### やること
案件応募用のサンプル作品（ポートフォリオ）を作る。

### サンプルの作り方

| スキル | 作るもの | 参考にするもの |
|-------|---------|-------------|
| 動画編集 | YouTube動画の編集サンプル1本 | 人気YouTuberの動画をお手本に |
| デザイン | バナー3枚 + サムネイル2枚 | 実際の広告やYouTubeサムネを参考に |
| プログラミング | 架空のLP1ページ | 実在するLPを模写 |
| ライティング | SEO記事2本（各3,000字） | 検索上位の記事を分析して書く |

### サンプル制作のコツ

1. **実在する案件を想定して作る** — 架空クライアントの依頼だと思って取り組む
2. **完璧じゃなくていい** — 70%の完成度でOK。案件を回しながら上達する
3. **見せ方を工夫する** — GoogleドライブやNotionにまとめてURLで共有できるようにする
4. **制作意図を書く** — 「このバナーは○○をイメージして、○○を意図して作りました」と1行添えると、クライアントが制作力を判断しやすい

> 💡 **ワンポイントアドバイス**: 「"自分で作ったサンプルです"と言えること自体が武器。実績ゼロでもサンプルは作れる。作れるのに作らないのは、自ら武器を捨てているのと同じ」

### 完了条件
- [ ] サンプル作品を規定数作成した
- [ ] ポートフォリオURLとしてまとめた（Googleドライブ / Notion / サイト等）

## STEP 4：プロフィールを整える（7〜8日目）

### やること
クラウドソーシングサイトに登録し、プロフィールを完成させる。

### 登録先
1. **クラウドワークス**（案件数が最も多い）
2. **ランサーズ**（高単価案件が多い傾向）
3. **ココナラ**（自分からサービスを出品できる）

> 最初はクラウドワークスだけでOK。慣れてきたら他も登録。

### プロフィール完成チェックリスト
- [ ] プロフィール写真を設定した（顔写真 or プロっぽいアイコン）
- [ ] 自己紹介文を記入した（このテンプレート集を活用）
- [ ] スキル・経歴を記入した
- [ ] ポートフォリオURLを掲載した
- [ ] 本人確認（身分証提出）を完了した
- [ ] NDA（秘密保持契約）に同意した

> 💡 **ワンポイントアドバイス**: 「プロフィール写真は絶対に設定して。写真なし＝信頼ゼロ。顔写真がベストだけど、無理ならプロっぽいアイコンでもOK」

### 完了条件
- [ ] クラウドワークスのプロフィールが100%完成している
- [ ] ポートフォリオURLがプロフィールに掲載されている

## STEP 5：案件に応募する（8〜10日目）

### やること
実際に案件を探して応募する。**最低10件に応募**する。

### 案件の探し方

1. クラウドワークスで自分のスキルに合うカテゴリを開く
2. 「新着順」でソートする
3. 以下の条件で絞り込む：
   - 予算が明記されている
   - 「初心者歓迎」「未経験OK」と書いてある
   - 依頼内容が具体的（曖昧な案件は避ける）
   - クライアントの評価が★4以上

### 応募のルール

| ルール | 理由 |
|-------|------|
| 1日3件以上応募する | 返信率は10〜20%。数を打つのが大事 |
| テンプレートをベースに毎回カスタマイズ | コピペ感が出ると見てもらえない |
| 相手の案件内容に必ず触れる | 「ちゃんと読んでいる」と伝わる |
| テスト納品を提案する | クライアントのリスクを下げる |
| 最初の3件は安くてもOK | 実績（★5レビュー）を作ることが最優先 |

### 📬 応募の科学 ── データで見る案件獲得の真実

応募してからの流れを数字で把握しておくと、心が折れにくくなります。

**返信率のリアルデータ（受講生平均）：**

| 応募方法 | 返信率 | 受注率（返信→受注） |
|---------|--------|-------------------|
| コピペ提案文 | 5〜8% | 10〜20% |
| カスタマイズ提案文 | 15〜25% | 30〜50% |
| 作品分析＋提案文 | 25〜40% | 50〜70% |

**つまり**：
- コピペ提案文で100件応募 → 返信5〜8件 → 受注1件以下
- カスタマイズ提案文で30件応募 → 返信5〜8件 → 受注2〜4件
- **手間をかけた方が、結果的に少ない応募数で案件が取れる**

**時間帯別の応募効果：**

| 時間帯 | 効果 | 理由 |
|-------|------|------|
| **朝 8〜10時** | ★★★★★ | クライアントが出勤後にチェック。一番見てもらえる |
| **昼 12〜13時** | ★★★★☆ | 昼休みにチェックするクライアントが多い |
| **夜 20〜22時** | ★★★☆☆ | ライバルが多い時間帯。でも案件も多い |
| **深夜 0〜6時** | ★★☆☆☆ | 朝一で目に入るかもしれないが、埋もれやすい |

> 💡 **ワンポイントアドバイス**: 夜に提案文を「下書き保存」→ 翌朝8〜9時に送信。これが最も返信率が高いパターン。

### 応募後にやること

- **返信が来たら即レス**（24時間以内、できれば数時間以内）
- **質問されたら丁寧に具体的に答える**
- **条件が折り合えば、すぐに着手する旨を伝える**

> 💡 **ワンポイントアドバイス**: 「明らかな搾取案件以外は、まず経験を積むことを優先して」

### 完了条件
- [ ] 10件以上の案件に応募した
- [ ] 1件以上の案件を受注した

## STEP 6：初案件を納品する（10〜14日目）

### やること
受注した案件を納品する。**ここが一番大事なSTEP。**

### 案件進行の流れ

```
1. 受注確定 → 条件・納期を確認
2. 不明点を質問 → 作業開始前に疑問をゼロにする
3. 作業開始 → 途中経過を共有（50%時点で一度確認）
4. 初稿提出 → 修正依頼を受ける
5. 修正対応 → 最終確認
6. 納品完了 → 評価をもらう
```

### 初案件で意識すべき3つのこと

1. **レスポンスの速さ** — メッセージは即返信。これだけで信頼度が段違い
2. **納期厳守** — 余裕を持ったスケジュールを提示し、前倒しで納品する
3. **丁寧なコミュニケーション** — 進捗報告をこまめにする

### 💼 初案件あるある失敗談と対処法

実際によくある「初案件のやらかし」とその対処法です。事前に知っておくだけで、同じミスを避けられます。

**① 「思ったより難しい…」パニック**
- 状況：受注したけど、想定より技術的に難しくて手が止まる
- 対処法：諦めずに調べ、どうしても解決しない場合はクライアントに正直に伝える
- 最悪の場合：「今回お金は受け取りませんので、最後まで納品だけさせてください」で誠意を見せる。大きなトラブルにはならない

**② 修正が3回以上来て心が折れる**
- 状況：「ここ変えて」「ここも変えて」「やっぱり最初の方が…」のループ
- 対処法：受注時に「修正は2回まで」と明記しておく（テンプレート集のメッセージ参照）。修正回数は事前合意が鉄則
- マインド：修正は「ダメ出し」ではなく「クライアントの好みを学ぶチャンス」

**③ 納期ギリギリになって焦る**
- 状況：作業量を見誤って、締め切り前日に徹夜コース
- 対処法：提示する納期は「自分が思う必要日数 × 1.5倍」にする。余裕があれば前倒し納品 → クライアント大喜び
- 鉄則：「間に合わないかも」と思った瞬間にすぐ連絡。ギリギリまで黙っているのが最悪のパターン

**④ 単価が安すぎて時給100円になる**
- 状況：1本3,000円で受けたのに、作業に20時間かかった…
- 対処法：初案件は「実績づくり」と割り切る。2件目からは作業時間を記録して、時給を計算してから受注可否を判断する

### トラブル対応

| トラブル | 対応 |
|---------|------|
| 作業が予想より難しい | 一人で抱え込まず、調べるか正直に伝える |
| 納期に間に合わなそう | 分かった時点ですぐクライアントに連絡。代替案を提示 |
| 修正が多すぎる | 「修正は○回まで」を事前に合意しておく |
| クライアントの返信が遅い | 2営業日返信がなければ丁寧にリマインド |

> 💡 **ワンポイントアドバイス**: 「初案件で完璧な仕事ができる人はいません。大事なのは"誠実に向き合ったかどうか"。クライアントが見ているのは、スキルより姿勢です」

### 完了条件
- [ ] 初案件を無事に納品した
- [ ] クライアントから★4以上の評価をもらった

## STEP 7：リピートと単価アップ（14日目〜）

### やること
初案件の実績を武器に、継続案件と単価アップを目指す。

### 📈 単価推移のリアル── 実績と単価の関係

```
実績   0件 ▓░░░░░░░░░ 相場の70%（実績づくり価格）
実績   3件 ▓▓▓░░░░░░░ 相場通り
実績  10件 ▓▓▓▓▓░░░░░ 相場の110〜120%
実績  30件 ▓▓▓▓▓▓▓░░░ 相場の150%+（指名依頼も来始める）
実績  50件 ▓▓▓▓▓▓▓▓▓░ 相場の200%+（直接契約・月額契約）
実績 100件 ▓▓▓▓▓▓▓▓▓▓ ディレクター・外注化フェーズへ
```

> **ポイント**: 最初の3件を超えるまでが一番辛い。3件超えると「実績あり」として信頼されるようになり、受注がラクになる。10件超えると「選ぶ側」に変わる。

### やるべきこと

1. **納品後にリピートを提案する**（テンプレート集の「リピートのお願い」を活用）
2. **プロフィールに実績を追加する**（「○件の実績・平均★4.8」等）
3. **提案文に実績を入れる**（「類似案件の経験があります」）
4. **スキルの掛け合わせを始める**（動画編集 × サムネデザイン → ワンストップ提案）
5. **直接取引（継続契約）を目指す**（クラウドソーシングの手数料をカットできる）

### スキルの掛け合わせ例

| 掛け合わせ | できる案件 | 単価の目安 |
|-----------|-----------|-----------| 
| 動画編集 × デザイン | YouTube運営代行（編集+サムネ） | 1万〜3万円/本 |
| ライティング × デザイン | LP制作（コピー+デザイン） | 10〜30万円/件 |
| プログラミング × デザイン | Webサイト制作（デザイン+コーディング） | 10〜50万円/件 |
| 動画編集 × マーケティング | YouTubeチャンネル運営 | 月額5〜20万円 |
| ライティング × SNS運用 | SNS運用代行 | 月額3〜10万円 |

> 💡 **ワンポイントアドバイス**: 「リピートのお願いを"わざわざ"送る人は実はかなり少ない。だからこそ、テンプレ通りでもいいから送るだけで差別化になる。特に"継続だと割引します"の一言が効く」

### 完了条件
- [ ] 継続案件またはリピート案件を獲得した
- [ ] 初案件より高い単価で受注できた

## 🧠 メンタルブロック5選と突破法

案件獲得を阻む最大の敵は、スキル不足ではなく**メンタルブロック**です。以下は最もよくハマる5つの壁と、突破した人たちのリアルな声です。

### ブロック①「まだスキルが足りない気がする…」

**突破法**：最初のプログラミング案件は「クイズアプリを作れる」程度の技術しかなかった受講生が、学習塾のアプリ開発案件を取り、18,000円で1件目を即成約させた事例があります。技術が成熟してからなんて待てない。最低限できれば、飛び込んでいい。

> 「最悪、本当に謝って"今回お金受け取らないんでただ最後までやらせてください"って言ったら大きなトラブルになることなんかない」── 迫 佑樹

---

### ブロック②「応募しても返信が来ない…向いてないのかも」

**突破法**：返信率10〜15%が普通。10件送って1件返事が来ればいい方。300件応募してやっと初案件を取り、今は月50万稼いでいる受講生がいる。500件応募してもダメだった人が、最終的に100万フォロワーのインフルエンサーになった事例も。**「数が足りてるか？」がまず最初のチェックポイント**。

---

### ブロック③「お金をもらっていいレベルじゃない…」

**突破法**：これは「完璧主義の罠」。先を行っている先輩がいる環境にいると「完璧じゃなくてもいける」と気づける。基準値が上がると「自分もやっていいんだ」と思える。

> 「完璧じゃないとお金なんかもらっちゃいけないっていうメンタルブロック…これは先を行ってる先輩がいるからこそ脱却できる」── 迫 佑樹

---

### ブロック④「一人でやってると不安で続かない…」

**突破法**：独学で挫折した方の第1の理由が「相談できる環境が欲しかった」。同じ目標を持つ仲間と繋がると、一人では絶対超えられなかった壁を超えられる。

> 「環境を整えてください。私の性格と能力では多分1人ではできなかったと思います」── 受講生インタビューより

---

### ブロック⑤「副業バレが怖い…会社に知られたくない」

**突破法**：
- 確定申告で「住民税を普通徴収（自分で納付）」にチェックすれば、会社には通知されない
- クラウドソーシングのプロフィールにはニックネーム＋本名なしでも活動可能
- 顔出しなしでも案件は取れる（ポートフォリオで判断されるため）
