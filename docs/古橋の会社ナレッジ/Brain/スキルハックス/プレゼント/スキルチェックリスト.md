## 🎬 動画編集

### 基礎スキル（必須5項目）
- [ ] テロップの挿入・装飾ができる
  → *視聴者の目を引く最重要要素。フォント選び＋色使い＋位置の3つを押さえる*
- [ ] カット編集（不要部分の削除・繋ぎ）ができる
  → *「えーっと」「あのー」を消すだけで動画のクオリティが段違いに上がる*
- [ ] BGMの挿入・音量調整ができる
  → *BGMは「聞こえるか聞こえないか」の音量がベスト。大きすぎは素人の証*
- [ ] 効果音（SE）の挿入ができる
  → *テロップ出現時の「ポン」「シュッ」で視聴維持率が平均12%向上するデータあり*
- [ ] 画像・図解の挿入ができる
  → *トーク系動画では画像挿入があるだけで「プロっぽい」と感じてもらえる*

### 実務スキル
- [ ] 編集ソフト（Premiere Pro またはDaVinci Resolve）の基本操作を理解している
  → *案件の8割がPremiere Pro指定。DaVinci Resolveは無料で練習に最適*
- [ ] テンプレートを使って10分の動画を2時間以内に編集できる
  → *時給換算で2,500円以上を確保するための最低ライン*
- [ ] サムネイル画像の作成ができる（Canva or Photoshop）
  → *「編集＋サムネセット」で提案すると単価が1.5〜2倍になる*
- [ ] 書き出し設定（解像度・ビットレート）を理解している
  → *YouTube推奨設定を知っているだけでOK。間違えるとクレームの元*

### 案件獲得の最低ライン
- [ ] YouTube動画の編集サンプルを1本以上作成した
  → *好きなYouTuberの動画を「勝手に編集」して練習作品にするのが王道*
- [ ] ポートフォリオ（サンプル動画のリンク集）を用意している
  → *Googleドライブで限定公開リンクを作り、提案文に貼るだけ*

> 🎯 **最短で身につける流れ**:
> 1. テロップ・カット・BGM・SE・画像挿入の基礎5項目を習得する（1週間）
> 2. 好きなYouTuberの動画を1本「勝手に編集」してサンプルを作る
> 3. クラウドソーシングで「動画編集」案件に1日3件ペースで応募開始

## ✍️ ライティング

### 基礎スキル
- [ ] SEOライティングの基本（キーワード選定・見出し構成）を理解している
  → *検索結果の1ページ目に表示される記事の多くが適切なキーワード設計をしている*
- [ ] PREP法（結論→理由→具体例→結論）で文章を書ける
  → *ビジネス文章の基本型。これだけで「読みやすい」と言われる記事になる*
- [ ] 論理的な文章構成（導入→本文→まとめ）ができる
  → *読者は3秒で「読むか読まないか」を判断する。導入での掴みが命*
- [ ] 誤字脱字なく3,000文字以上の記事を書ける
  → *誤字脱字は一番目立つミス。納品前にWordやGoogleドキュメントのスペルチェック必須*

### 実務スキル
- [ ] WordPressへの入稿作業（画像挿入・装飾含む）ができる
  → *「入稿までお願いします」と言われた時にできるかどうかで単価が変わる*
- [ ] キーワード調査ツール（ラッコキーワード等）を使える
  → *無料ツールだけで十分。有料ツールは実績3件超えてからでOK*
- [ ] 競合記事のリサーチ・分析ができる
  → *上位10記事の見出し構成を分析 → 網羅性で上回る記事を書くのが王道SEO*
- [ ] 取材記事・インタビュー記事の執筆ができる
  → *取材記事は文字単価3〜5円の高単価ゾーン。社会人経験がそのまま武器になる*

### 案件獲得の最低ライン
- [ ] SEO記事のサンプルを2本以上作成した
  → *「自分が詳しいジャンル」で書くと質が高くなり、ポートフォリオ映えする*
- [ ] ポートフォリオ（記事サンプルのリンク集）を用意している
  → *note.comに公開するだけでもOK。「URLがある」ことが重要*

> 🎯 **最短で身につける流れ**:
> 1. SEOライティングの基礎を学ぶ（キーワード選定・見出し設計）
> 2. PREP法を習得して、実際に自分で3,000字の記事を2〜3本書いてみる
> 3. 書いた記事をnote等に公開してポートフォリオにし、営業を開始する

## 🎨 デザイン

### 基礎スキル
- [ ] 画像編集ソフト（Photoshop等）の基本操作（レイヤー・マスク・切り抜き）ができる

  → *ロゴやアイコン系はIllustrator必須。最低限「テキストを図形と組み合わせる」ができればOK*

  → *「なんかダサい」の原因の多くは配色。Adobe Colorで解決できる*

  → *ゴシック体＝信頼、明朝体＝高級感。この使い分けだけで印象が激変*

### 実務スキル
- [ ] バナー広告を制作できる（サイズ展開含む）
  → *1枚のデザインを複数サイズに展開できると「セット受注」で単価2倍*
- [ ] SNS用画像（Instagram投稿・YouTubeサムネ等）を制作できる
  → *SNS運用代行とセットで月額案件に発展しやすい*

  → *印刷入稿の知識（解像度350dpi、カラーモードCMYK）があると差別化に*

### 案件獲得の最低ライン
- [ ] バナー3種類以上のサンプルを作成した
  → *「実在する商品のバナーを作ってみた」が最強のサンプル。架空より説得力がある*
- [ ] ポートフォリオ（制作実績まとめ）を用意している
  → *Behance、Dribbble、Notion──どれでもOK。「作品を見せられる状態」が大事*

> 🎯 **最短で身につける流れ**:
> 1. Photoshopの基礎（レイヤー・マスク・切り抜き）を3日で学ぶ
> 2. 実在する商品のバナーを模写で3枚制作する（5日）

## 📊 チェック達成率別 ── 次にやるべきこと

あなたのチェック率に応じて、最適なアクションが変わります。

### 0〜30%（スタートライン）
まだ学習の初期段階。焦る必要はありません。
- **やること**: 選んだスキルの基礎から集中。1日2〜3時間、1〜2週間で基礎スキルの項目を埋める
- **気をつけること**: 完璧を目指さない。70%の理解で次に進む

### 30〜60%（基礎完了間近）
基本的な操作はできるようになってきた段階。
- **やること**: サンプル作品の制作に着手。実際の案件を想定した作品を1〜3つ作る
- **気をつけること**: 「完璧な作品」を作ろうとしない。「70点の作品を3つ」が「100点の作品を0個」より100倍価値がある

### 60〜90%（案件応募準備OK）
ポートフォリオが整い始めている段階。もう案件に応募できます。
- **やること**: プロフィール完成 → テンプレートを使って提案文を準備 → 1日3件以上応募
- **気をつけること**: 「もう少し勉強してから…」は禁句。技術が成熟してから案件を取ろうとすると、いつまでも取れない。

### 90〜100%（即戦力）
全項目が埋まった、もしくはほぼ埋まった状態。おめでとうございます！
- **やること**: 案件を回しながら2つ目のスキルの学習を開始。スキルの掛け合わせで単価を2倍にする
- **気をつけること**: 埋まらない最後の数項目は、案件をこなしながら自然に身につく
