## ① HERO セクション

> **方針メモ**：ターゲットは「ノウハウコレクター」になっていて収益が出ていない人。
> 機能訴求（もらえるもの）はここに出さない。ペイン共感 → 差別化で引き込む。
> 以下に**複数案**を用意しています。どれか1つを選ぶか、組み合わせてください。


### EPISODE 01

**タイトル**
```
なぜ「勉強熱心な人」ほど
副業で1円も稼げないのか
```

**尺・ジャンル**
`📹 約10分 ／ 導入・コアメッセージ`

**この動画で分かること**
- 「ノウハウを知ること」に価値がない理由。**インプット習慣がなぜ成果を妨げるのか**を解説
- 1年毎日ブログを書いて**273円しか稼げなかった僕**が、年商10億になれた「たった1つの気づき」
- 成果が出る人と出ない人の**決定的な違い**。才能ではない、やり方だ
- スキル副業が「物販やアフィリエイト」より**リスクが低く再現性が高い**理由
- 動画編集で案件獲得に必要なのは**たった5つのスキルだけ**（残りは全部不要）

**ティーザーコメント**
```
「本を読んで、YouTube見て、note買って……それでも1円も稼げない。
僕もそうでした、1年間ずっと。でも今日、その理由が完全に分かります。」
```
