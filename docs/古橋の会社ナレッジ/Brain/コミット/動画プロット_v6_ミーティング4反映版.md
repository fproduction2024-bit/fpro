## ── ミーティング4で出た最重要アップデート ──

### ミーティング4以前の問題点
- 動画の枠組みに整合性はあるが「本当に俺でもやれそう」が足りない
- 木村の話が自分から遠く感じられ、オファーが他人事に聞こえる
- ロードマップ（現状→ゴール）の具体的な道筋が見えていない

### ミーティング4で出た新アイデア

```
① 「1億円ロードマップ」を中心ビジュアルに使う
   → ゼロ〜1000万〜3000万〜1億〜10億 各ステージの「何が変わるか」

② ピラミッド構造（基準値・マインド → スキル → 行動）を明示
   → 底辺（基準値）を大きくすることで、上層（行動）が自動的にデカくなる

③ 影響範囲×時間軸の「コンフォートゾーン軸」
   → 1000万：自分・今月 / 1億：顧客・半年〜1年 / 3億：社会の目・1〜3年 / 10億：業界・3〜5年
   → ここが「膨張（自分のためだけ）か拡大（責任感の拡張）か」を決める

④ 身近な事例として「剣心くん」型を入れる
   → 大した学歴でも特別なノウハウでもない人が、基準値が違うだけで結果が全然違う

⑤ みんな「機能戦略」しか見ていない（全社→事業→機能の階層問題）
   → 売り方を変える前に、なぜそれをやっているのかの定義が必要

⑥ 「膨張vs拡大」の言語化
   → 膨張：自分のためだけに売り上げが膨らむ状態 → 爆発寸前の風船
   → 拡大：責任範囲が広がり、周りと相互作用しながら伸びる状態
```

> これがシンプルな真実です。

### 【ブロック②】 影響範囲×時間軸「コンフォートゾーン軸」（6:00〜14:00）

**語り（木村）**：
> 「売上のステージで、見ている世界が全然違います。
>
> 1000万ぐらいの人は、自分の生活のために動いている。時間軸は今月。
> 1億ぐらいになると、お客さんのことを考えるようになる。時間軸は半年〜1年。
> 3億ぐらいになると、社会からの見られ方が気になってくる。時間軸は1〜3年。
> 10億ぐらいになると、業界のことを考えるようになる。時間軸は3〜5年。
>
> これ、能力の違いじゃないんです。
> 自分がコンフォートに感じる影響範囲と時間軸のこと。
> この2つの軸の大きさが、売上のステージを決めている。
>
> 才能がある人が大きい事業を作っているんじゃない。
> コンフォートゾーンが大きい人が、大きい事業を作っている。
>
> で、これ一人でいると、なかなか広がらないんです。
> 同じ会話をして、同じ思考範囲で動いていると、コンフォートゾーンは変わらない。
> 10億の人と話す機会が増えると、自分の判断基準が変わってくる。
> 環境が基準値を変えるんです。」
