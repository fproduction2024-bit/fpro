## 2. ある1日のリアル

### 6:30 ── 起床（目覚ましより先にスマホ）

布団の中でスマホを開く。Slackに社員からの質問が3件。LINEにクライアントから「あの件どうなりました？」。まだ目が覚めてないのに、すでに**3つの問題が自分を待っている**。

トイレに行きながら返信する。朝食はコンビニのおにぎりか、食べないか。妻（彼女）はまだ寝てる。今日も会話なしで家を出る。

### 9:00 ── 出社（オフィス or 自宅の作業部屋）

社員が来る。「おはようございます」の後に、すぐ質問される。

- 「〇〇の案件、どう進めたらいいですか？」
- 「△△さんから修正依頼来てるんですけど、追加料金取りますか？」
- 「□□さん、今月で辞めたいって言ってます」

**全部自分が判断しないと何も進まない。** 社員は指示を待っているだけ。自分がいないと現場が止まる。

### 10:00 ── クライアントとのZoom

新規案件の打ち合わせ。自分が出ないと取れない。社員に任せた案件は成約率が半分以下に落ちる。**営業ができるのは自分だけ。**

打ち合わせの裏で、別のクライアントから「納品いつですか？」のメッセージ。社員に確認する。「え、まだ終わってないの？」心の中で舌打ちするけど、怒る時間がもったいない。自分でやった方が早い。

### 12:00 ── 昼食（デスクで食べる）

コンビニ弁当をデスクで食べながら、今月の数字を確認する。

```
今月の売上: 185万円
固定費・人件費: 148万円
手残り: 37万円
```

**年商1500万。でも手元に残るのは年間400万前後。** 会社員時代の年収とほとんど変わらない。いや、ストレスと責任の分だけ割に合ってない。

去年より売上は200万伸びた。でも社員を1人増やしたから、利益はむしろ減っている。**売上が増えても、利益が増えない。このループに出口が見えない。**

### 13:00 ── 作業（自分しかできないタスク）

提案書を作る。見積もりを作る。企画書を直す。全部自分でやる。社員に振りたいけど、クオリティが落ちるのが怖い。自分でやった方が3倍速い。

でも、それをやっている間に**新しい案件を取る時間がない。** 「売上を上げる仕事」と「売上を維持する仕事」が同時に押し寄せて、どっちも中途半端になる。

### 15:00 ── 突発トラブル

社員がミスした。クライアントに謝罪メールを自分が書く。修正も自分がやる。**「なんで俺がこんなことやってるんだ」**と思うけど、社員を責めても辞められると困る。

採用にかけた時間と金を思い出す。求人広告10万円、面接に5時間、研修に2ヶ月。それでも半年で辞められた前科がある。いま残ってる社員に辞められたら、全部自分に戻ってくる。

### 17:00 ── 今月の売上を考える

来月の案件がまだ2件しか確定していない。あと3件は取らないと人件費が払えない。

営業メールを5通送る。SNSで投稿する。でも**「この作業を毎月やり続けるのか？」**という虚無感が襲ってくる。仕組み化したい。でも仕組み化する時間がない。仕組み化を教えてくれる人もいない。

### 19:00 ── 退社

社員は18時に帰った。自分はまだ残ってる。帰る前にSlackを確認。また質問が来てる。明日の朝でいいか…でも気になるから返す。

### 20:00 ── 帰宅

妻が「今日も遅いね」と言う。「うん、ちょっと忙しくて」。この会話が3年間変わっていない。

夕食を食べながら、スマホでTwitterを開く。

### 20:30 ── SNSで心が折れる

タイムラインに同世代の起業家の投稿が流れてくる。

- 「月商1000万達成！チームに感謝！」
- 「今日は社員と沖縄でワーケーション🌴」
- 「新規事業の準備が着々と。来月リリースします」

**俺だってこんなに頑張ってるのに。** こいつらは何が違うんだ。才能か？運か？人脈か？

いや、分かってる。**何かが根本的に違う。** でも、それが何なのかが分からない。

### 22:00 ── 風呂

湯船に浸かりながら考える。このままあと10年やったらどうなる？

年商は2000万くらいにはなるかもしれない。でも人件費も増えて、利益はたぶん今と変わらない。50歳になったとき、まだ自分が営業してる。まだ自分がトラブル対応してる。**まだ自分が全部やってる。**

ゾッとする。

### 23:30 ── 就寝（できない）

ベッドに入るけど、頭が止まらない。

- 来月の売上どうしよう
- あの社員ちゃんと育つかな
- あの案件の見積もり安すぎたかな
- もっと単価上げるべきなのか
- でも単価上げたら競合に負けるかも
- いっそ全部一人に戻した方が楽なのか…

**誰にも相談できない。** 社員に言ったら不安がらせる。妻に言ったら心配させる。起業仲間はいるけど、全員自分より上か下で、同じ悩みを共有できる相手がいない。

**0:30にようやく眠りにつく。6時間後にまた同じ一日が始まる。**

## 3. この人が抱える「5つの地獄」

### 地獄① ── 売上は自分にしか作れない

社員はタスクを実行するだけ。「今月あと100万どうやって作る？」を考えられるのは社内で自分だけ。営業も企画も提案も、**売上に直結する仕事は全て属人化**している。

自分が病気で1週間倒れたら、文字通り会社が止まる。有給なんか取ったことない。旅行に行っても結局PCを開いてる。**自分が商品であり、自分がボトルネックである**という矛盾から抜け出せない。

### 地獄② ── 売上が増えても残らない

年商は順調に伸びている。でも人を雇い、ツールを入れ、オフィスを借り、**コストが売上と同じスピードで膨らんでいく。**

```
年商  800万（1人） → 手残り 500万 😊
年商 1200万（2人） → 手残り 400万 😐
年商 1500万（3人） → 手残り 350万 😰
年商 2000万（4人） → 手残り 380万 😤
```

**規模を大きくしたのに、自分の生活は楽になっていない。** むしろ責任とストレスだけが増えた。「独立した意味ってなんだっけ？」と自問する深夜。

### 地獄③ ── 人の問題が終わらない

- 半年かけて育てた社員に「他にやりたいことができたので」と辞められる
- 面接では良いことを言っていたのに、入社3日で「思ってたのと違いました」
- 残ってくれている社員のモチベーション管理まで自分の仕事になっている
- 「採用」という名の博打に毎回10〜30万円が消えていく

**人を雇うのが正解なのか、一人に戻すのが正解なのか、もう分からない。** でも今更一人に戻したら、抱えてるクライアントを捌けない。

### 地獄④ ── 経営者としての孤独

この苦しみを**誰にも話せない。**

- **社員には言えない**: 「来月の売上ヤバい」と言ったら、辞められる。
- **妻（家族）には言えない**: 心配させたくない。「大丈夫だよ」と嘘をつく。
- **友達には言えない**: 会社員の友達に「年商1500万なのに苦しい」と言っても、「贅沢言うな」と思われるだけ。
- **起業仲間には言えない**: プライドがある。弱みを見せたくない。

経営者の悩みを本当に理解できるのは、**同じステージを経験した経営者だけ。** でもそんな人間は周りにいない。孤独死しそうなほど、一人で抱えている。

### 地獄⑤ ── 比較と焦り

SNSを開くたびに、自分より上の人間が目に入る。

- 同い年で年商3億の会社を経営している奴
- 自分より2年遅く始めて、もう月商1000万の奴
- バリ島に住みながらリモートで年商5000万の奴

**「俺の方が長くやってるのに、なんでこいつらに追い抜かれるんだ」**

この焦燥感は、努力で埋められない。なぜなら、自分もすでに死ぬほど努力しているから。**努力の量ではなく、何か根本的なものが違う。** でも、それが何なのかが言語化できない。

## 4. この人が「喉から手が出るほど欲しいもの」

### ① 「お前の事業、こうすればいい」と名指しで教えてくれる人

一般論のセミナーはもう要らない。本も十分読んだ。**「俺の場合」を見て、「これをやれ、これは捨てろ」と具体的に指示してくれる人間。** しかもその人自身が年商1億以上を達成していて、言葉に重みがある人。

### ② 「毎月の売上を自分以外が考えてくれる」状態

自分が営業しなくても売上が立つ仕組み。自分がいなくても回る組織設計。**「売上のことは俺に任せろ」と言ってくれる右腕か、そうなるための具体的な設計図。**

### ③ 本音を吐ける、同じ苦しみを知っている仲間

「来月の売上がヤバい」「社員が辞めそう」「正直もう疲れた」── これを**バカにされず、心配されず、ただ「分かる」と言ってくれる同じステージの経営者**。

### ④ 「なぜ自分は伸びないのか」の明確な答え

努力は足りてる。知識もある。でも結果がスケールしない。**この「見えない天井」の正体を、ハッキリ言葉にして突きつけてくれる人。** それが怖くても、聞きたい。

### ⑤ 「このやり方で続けてれば大丈夫だ」という確信

毎晩眠れない理由は、**自分がやっていることが正しいのかどうか分からない**から。誰かに「その方向で合ってる。あとはこれだけやれ」と言ってほしい。判断の重圧から、一瞬でも解放されたい。

### ⑥ 「あの世界の住人」に近づきたい

これが最も根源的な欲求かもしれない。

## 4.5. 最深層の欲求：「距離への渇望」

### あの世界は、見えてるのに届かない

この人はYouTubeで迫佑樹を見ている。令和の虎を見ている。Twitterで年商10億超えの起業家を見ている。

**見えてはいる。** でも、画面の向こう側だ。

迫さんがBrain社でどんな判断をしているか。木村さんが朝6時にどういう基準で1日を設計しているか。令和の虎に出ていた起業家たちがどんな人脈でどんな話をしているか。

**その「空気」を知りたい。** 情報じゃなくて、空気を。

### 「圏内」に入りたい

年商1500万の世界には、年商1500万レベルの人間しかいない。飲みに行く相手も、情報交換する相手も、全員同じステージ。だから視座が上がらない。発想が広がらない。

**もし、迫さんの「圏内」に入れたら？**

- 迫さんに直接「お前の事業、ここが問題だ」と言ってもらえる
- 木村さんに毎日の行動を管理されて、あの人の基準値が自分に染み込む
- Brain社のリソースや人脈にアクセスできる可能性が開ける
- 令和の虎に出ていたような起業家たちと「同じ環境」にいられる

これは教材では絶対に手に入らない。セミナーでも手に入らない。**「距離をゼロにする」こと自体が、最大の価値。**

### なぜ「距離」がこれほど強力なのか

人間は、近くにいる人間のレベルに同期する生き物だ。

年商1500万の仲間に囲まれていれば、年商1500万が「普通」になる。自分の天井はそこで固定される。

でも、**年商10億の人間の隣に立ったとき、「年商1500万の自分」が恥ずかしくなる。** 怖くなる。でも同時に、「この人は別の惑星にいるわけじゃない。同じ人間だ」と分かる。

**あの人にできて、俺にできない理由はない。** ──その確信は、本を読んでも得られない。動画を見ても得られない。**隣にいるからこそ、初めて自分の骨に刻まれる。**

### この人のスマホの中の「距離」

夜、ベッドの中でInstagramを開く。迫さんのストーリーが流れてくる。

事業ミーティングの様子。新しいプロジェクトの発表。一緒に仕事してる仲間たちとの食事。

**「俺もあの輪の中に入りたい」**

この気持ちは、論理じゃない。理屈で説明できるものでもない。でも、夜のベッドの中で、スマホを握りしめながら感じるこの気持ちが──

**一番正直な欲求。**

「近くにいたい」。「あの人たちの"普通"を、自分の"普通"にしたい」。「そうすれば、自分もあのレベルに近づいていけるはずだ」。

### 月額11万円の意味が変わる

この欲求を理解すると、月額11万円の意味が完全に変わる。

- ❌ 「教育サービスの月謝」→ 高い
- ❌ 「自己啓発の投資」→ 効果が見えない
- ✅ **「迫佑樹・木村の"圏内"に入る入場料」→ 安すぎる**

年商10億の人間の隣に毎日いられる。その人の基準値が自分に伝染する。その人の人脈や視座に触れられる。

**月11万円で「あの世界」への距離がゼロになるなら、年間132万円は投資として破格。**

この人が今まで買ってきた教材の合計金額（おそらく200〜500万円）と比べても、「距離がゼロになる体験」の方が圧倒的にROIが高いことは、本人が一番よく分かっている。

### 【最重要】「距離」は売るな。感じさせろ。

> **「近くにいれますよ」と直接言った瞬間に、安っぽくなる。**

この欲求は、対談の中身そのものによって「感じさせる」もの。言葉で説明するのではなく、**動画全体を通じて「この世界のレベル」を証明する**ことで、視聴者が勝手に「この人たちの近くにいたら、自分も変われる」と思う状態を作る。

#### 具体的に「感じさせる」方法

**① 対談の思考レベルで示す**

迫氏と木村氏が話している内容の「次元」が、視聴者の日常と明らかに違うことを自然に見せる。

- 迫氏が事業判断を語るとき、「年商10億の人間は、こういう基準で考えてるんだ」と視聴者が気づく
- 木村氏が行動管理を語るとき、「この人の"普通"は、自分の"限界"よりはるか上だ」と感じる
- 2人の会話のテンポ、判断の速さ、切り口の鋭さ自体が「このレベルの世界」を体現する

**② 「当たり前」のギャップで感じさせる**

2人が「当たり前のこと」として話す基準が、視聴者にとっては「信じられないレベル」であるとき、距離への渇望が自然に生まれる。

例：
- 迫氏「朝の1時間で事業戦略の方向性を3つ潰して1つに絞る。毎日やってる」→ 視聴者は「月に1回もやってない…」
- 木村氏「報告が1日でも途切れたら即連絡する。例外はない」→ 視聴者は「自分にこの基準を適用してくれる人がいたら…」
- 迫氏「うちのメンバーは全員、週次で数字をレビューしてる。当たり前だけど」→ 視聴者は「うちの社員は月次すらやってない…」

**③ 「この世界に入れる可能性」を匂わせるだけ**

直接「入れますよ」とは言わない。代わりに：

- 迫氏が「こういう基準で動ける人間と一緒にやりたいんだよね」と**理想の仲間像**を語る → 視聴者は「自分もそうなりたい」
- 木村氏が「実際にこの基準に適応した人は、3ヶ月で見違えるように変わる」と**変化の事実**を語る → 視聴者は「自分もあの環境にいれば変われるんじゃないか」
- 対談の最後に「この世界を一緒に作っていく仲間を探してる」と**共創の文脈**で語る → 「売る」のではなく「招く」ニュアンス

**④ 絶対にやってはいけないこと**

| NG | なぜダメか |
|----|----------|
| 「迫さんの近くに来れますよ」 | 芸能人の握手券みたいで安っぽい |
| 「このコミュニティに入れば人脈が広がります」 | 異業種交流会の営業トーク |
| 「年商10億の世界を覗けます」 | 覗き見感が出て、対等な関係ではなくなる |
| 「令和の虎の出演者と繋がれます」 | 他人の権威を借りている印象。迫さん自身の価値が下がる |

**正解は：動画の中身そのもので「この人たちの世界」を見せること。視聴者に「この距離を縮めたい」と自発的に思わせること。**

## 6. この人に刺さる言葉 / 刺さらない言葉

### 刺さる言葉

| フレーズ | なぜ刺さるか |
|---------|-------------|
| 「売上のこと、一人で考えてませんか？」 | 一番の孤独に直接触れている |
| 「年商1500万なのに、なぜか楽にならないですよね」 | 外から見えない苦しみを言い当てている |
| 「頑張ってないわけじゃない。頑張り方が間違ってるだけ」 | 努力は認めつつ、原因を提示している |
| 「自分がいないと回らない会社は、会社じゃなくて自営業です」 | グサッと来るが、本質 |
| 「5年後も同じ1日を繰り返しますか？」 | 最大の恐怖を直接突く |

### 刺さらない言葉

| フレーズ | なぜ刺さらないか |
|---------|-----------------|
| 「年商10億を目指しましょう！」 | 現実感がなさすぎる。今年の売上で精一杯 |
| 「マインドセットが大事です」 | 抽象的すぎる。明日の売上にどう繋がるか分からない |
| 「自由な人生を手に入れよう」 | もう「自由」が嘘だと分かっている。独立したのに不自由だから |
| 「可能性を広げましょう」 | ふわっとしすぎ。具体性ゼロ |
| 「基準値を上げれば全て変わる」 | 概念としては分かるが、明日の請求書は概念じゃ払えない |
| 「成功者のマインドを学ぼう」 | 「学ぶ」んじゃなくて「近くにいたい」んだ。情報じゃなくて距離 |

## 7. 誰に来てほしいか / 誰に来てほしくないか

### 来てほしい人

| 条件 | 理由 |
|------|------|
| **年商1000万〜5000万を自力で作った経験がある** | 「稼ぐ力」は既に証明済み。足りないのはスケールの基準値と環境。ゼロイチは教えるフェーズではない |
| **現状に「このままじゃダメだ」と本気で危機感を持っている** | 危機感がない人間は、木村がどれだけ管理しても動かない。苦しい自覚がある人だけが変われる |
| **指示されたことを素直に実行できる** | プライドが高くても、「自分のやり方を一度全部捨てる」覚悟がある人。木村の管理に従えない人は3日で脱落する |
| **月額11万円を「痛いけど払える」レベル** | 生活が崩壊する金額ではダメ。でも「余裕でしょ」でもダメ。痛みがあるから本気になれる |
| **孤独を抱えている** | 社員にも妻にも友達にも言えない悩みを持っている人ほど、この環境に入ったときの変化が大きい |
| **「迫・木村の近くにいたい」と感じている** | この感覚がある人は、動画を見た時点で「入りたい」と思っている。理屈ではなく直感で決められる人 |
| **情報じゃなくて「環境」を求めている** | 教材もセミナーも十分やってきた。もう「学ぶ」フェーズは終わっていると自分で分かっている人 |

### 来てほしくない人

| 条件 | 理由 |
|------|------|
| **年商1000万未満（まだ食えていない人）** | 基準値以前の問題。まずスキルで稼ぐフェーズにいるので、スキルハックスが正解 |
| **「迫さんと友達になりたい」が動機の人** | ファンクラブではない。迫の時間とリソースを事業成長に使う場。人脈目的の人は環境を汚染する |
| **ノウハウコレクター** | また新しい教材を買う感覚で申し込む人。行動しないのに「知識」だけ溜め込む人は、25枠の1つを無駄にする |
| **「楽して稼ぎたい」人** | 木村の管理は「楽」の対極。毎日の行動報告、朝のルーティン、週次レビュー。覚悟がない人には地獄でしかない |
| **言い訳が先に出る人** | 「忙しくて…」「今月は無理で…」が口癖の人。木村はその言い訳を全部潰すので、それに耐えられない人は来ないでほしい |
| **他人の意見に流される意思決定ができない人** | 「妻に相談してから…」「パートナーに聞いてみないと…」── 経営の意思決定を自分一人でできない人は、事業のスケールもできない |
| **月額11万を「高い」と感じる人** | このサービスの価値が「教育」だと思っている証拠。距離と環境の価値を理解していない。価格で迷う人はそもそもターゲットではない |
| **すでに年商1億以上で順調に伸びている人** | ステージが違う。Brainコミットは「1000万→1億の壁」を越えるための場。すでに超えている人には物足りない |

### スクリーニングの役割

スクリーニングは**ただの選別ではなく、願望増幅装置**でもある。

> 「この人たちは誰でも受け入れるわけじゃない」
> → 「選ばれた人だけが入れる」
> → 「自分は選ばれる側になりたい」

動画ファネルの中で「来てほしくない人」を明確に示すことは、**来てほしい人の欲求を加速させる。**

- 「俺はノウハウコレクターじゃない。本気だ」→ 自己証明欲求が刺激される
- 「言い訳が先に出る人はお断り」→ 「俺は違う」と思いたくなる
- 「25名限定」→ 「その25名に入りたい」

### 動画内でのスクリーニングの出し方

| 出し方 | 効果 |
|--------|------|
| **木村氏がハッキリ言う** | 「覚悟がない人は来ないでください。僕はあなたの言い訳を聞く人間じゃないので」→ 厳しさが本物感を生む |
| **迫氏がフォローする** | 「木村さんは本気でぶつかってくる。だからこそ変われる人が出る」→ 厳しさに理由と愛がある |
| **参加者の声で語る** | 「最初は正直ビビりました。でも3ヶ月後、あの厳しさがなかったら何も変わってなかった」→ 第三者の証言が最強 |
| **条件を「逆説的に」出す** | 「もし今の生活に満足してるなら、絶対に来ないでください。ここは現状を壊す場所です」→ 満足してない人の心に刺さる |
