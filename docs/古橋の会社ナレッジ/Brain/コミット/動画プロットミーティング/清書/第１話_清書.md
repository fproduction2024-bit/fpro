## ■ セクション構成

### 1-1｜導入（前回の振り返りと本動画の目的）

**前回（第０話）のおさらい**  
- 佐古さんと木村が、この4年間で「ちゃんと成長した人」と「消えていった人」を見てきた  
- その共通点と違いを、この動画シリーズ全体でお伝えすると予告した

**今回の動画の目的**  
- 特に「年商1億を当たり前に達成している人」と「頑張っても1,000万〜3,000万で止まってしまい、利益も出ない人」の違いが**具体的に何なのか**を解説する

**視聴後に得られるもの**  
- 3万人以上の受講生の中で、爆発的な成果を出す人と普通の成果の人の「根本的な違い」が分かる  
- どんな事業でも年商1億は当たり前に作れる、という基準値になる  
- 同じノウハウ・同じリソースを持っていても、圧倒的な成果を出せるようになる

---

### 1-2｜問題提起（頑張っているのに稼げない3つの原因）

> ※ この3つを提示し、後の章で1つずつ回収する構成

**① フォーカスする領域が間違っている**  
- 1,000万〜3,000万で止まっている人の多くは「行動」にフォーカスしている  
- 行動＝今月どんな仕事を受注したか・今月何を完了させたか  
- 例：動画編集者なら「案件をどう取るか」「今の仕事の効率化」ばかりに集中  
- 週7で頑張って月300万になっても、2〜3ヵ月先まで仕事がパンパンで限界、という状態に

**② 戦略の違い（必要な知識が足りていない）**  
- ビジネスを作る上で考えるべき「4つの戦略の階層」を知らない  
- ノウハウはどの業界でも均一化しているが、この戦略の知識は全事業の土台  
- この知識格差が結果の差として現れている

**③ 正しい投資ができていない**  
- ずっと自己投資を続けているが、事業を大きくするフェーズの投資に移れていない  
- 拡大している人は「自己投資ではない投資」をちゃんとやっている  
- どのフェーズでどんな投資が必要なのか、が分かっていない

---

### 1-3｜解決策①｜フォーカスポイントの違い（意識のピラミッド）

**図の説明：意識のピラミッド**

```
[ マインド・基準値 ]  ← 伸びる人はここにフォーカス
[    スキル・知識   ]
[    行動・タスク   ]  ← 伸び悩む人はここにフォーカス
```

**伸び悩む人の状態**  
- ピラミッドの「行動」部分に意識が集中している  
- 目の前の案件を効率化しても、行動の天井に到達すると詰まってしまう

**伸びる人の状態**  
- ピラミッドの「土台（マインド・基準値）」にフォーカスしている  
- マインドが変わると基準値が変わる  
- 例：「自分で動画編集する」→「スクールにしよう」「自社で雇用して伸ばそう」という発想に自然になる  
- その結果、スキルが広がり、行動が変わり、事業の規模が変わる

**重要なポイント**  
- ノウハウ自体はいくらでも教えられる  
- でも「このマインドと基準値を持っていないと」ノウハウを聞いたところで行動に落とし込めない  
- 目の前の行動にフォーカスが当たっているか、これから作るものにフォーカスが当たっているか、これが全ての差

---

### 1-4｜解決策②｜4つの戦略の違い（経営の4層ピラミッド）

**図の説明：4つの戦略の階層（上が土台）**

```
[ 全社戦略 ]　会社の存在意義・ビジョン・ミッション
[ 事業戦略 ]　何の事業をやるか
[ 機能戦略 ]　マーケティング・採用・教育（ノウハウはここ）
[ 財務戦略 ]　資金調達・再投資の方法
```

**重要な原則**  
- 企業家は「上から順に」考える（MBAは下から考えるが、企業家は逆）  
- 上の階層の問題は、下の階層では解決できない  

**各層の解説**

| 層 | 内容 |
|----|------|
| **全社戦略** | 会社が何のために存在するか（ビジョン・ミッション・バリュー） |
| **事業戦略** | 全社戦略を実現するための事業選択（ビジョンが変われば事業が変わる） |
| **機能戦略** | 事業を成立させるマーケティング・採用・教育戦略。「ノウハウ」はすべてここ |
| **財務戦略** | 機能を動かすための人・資金・物の調達方法 |

**具体例（動画編集ビジネス）**  
- 「クライアントのために良い動画を納品する」が全社戦略 → 動画編集屋さんになる  
- 「動画編集を通して多くの人の人生を変える」が全社戦略 → 動画編集スクールになる  
- **全社戦略が違うだけで、事業の形が根本的に変わる**

**なぜ機能戦略（ノウハウ）だけ学んでも伸びないか**  
- 全社戦略・事業戦略がなければ、機能戦略に何を当てはめるかが決まらない  
- 財務戦略も、目の前の稼ぎのために調達するのではなく、この4層の設計があって初めて外部調達ができる  
- この4層を質問の内容から見るだけで、その人の売上規模がわかってしまうほど、フォーカスの位置と結果は連動している

---

### 1-5｜解決策③｜正しい投資の段階（1億円コンフォートゾーンマトリックス）

**図の説明：売上フェーズと必要な投資の対応表**

| フェーズ | 状態 | 必要な投資 |
|---------|------|-----------|
| 〜1,000万 | 自己投資型。自分の食い口のために頑張るだけで到達できる。案件は毎月リセット | **自己投資** |
| 1,000〜3,000万 | 自分＋社員・提携先リソースを活用。事業計画・予算管理が必要になる。案件単価アップ（B2B:300万/B2C:100万近く） | **人的投資** |
| 3,000万〜1億 | 人間が稼働するマックスの壁。「工場の生産ライン」を作るフェーズ。教材・マニュアル・外注管理の仕組みで人に依存しない富の再生産を構築。スクール・SNS運用会社など「同じものを何個も売る」モデルへ移行 | **設備投資（仕組みへの先行投資）** |
| 1億〜 | 知らない人・ファンでない人にも届くフェーズ。商品力・全社戦略の力がないと炎上リスク。設備投資が済んで「いい価値を安く提供できる」状態になっていないと広告は組めない | **広告・認知投資** |
| さらに上 | 業界全体の手本・お手本モデルになる。自社リソースを見つめ直し、完全に新しい活用法を発明するフェーズ | **ビジネスモデル開発投資（ピボット）** |

**重要なポイント**  
- 「自己投資→人的投資→設備投資→広告投資→ビジネスモデル開発」の順に移行しないと、順番を誤ると詰まる  
- 設備投資（仕組み）が済んでいないのに広告認知を取ると、クレーム・炎上リスクが高まる  
- 「ずっとコンサルを買い続けているだけの人は伸びない」── 自己投資の次のフェーズの投資に移れていないため
