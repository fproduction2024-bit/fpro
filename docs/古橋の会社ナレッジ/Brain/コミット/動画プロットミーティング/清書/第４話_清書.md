## ■ セクション構成

### 4-1｜導入（シリーズ全体の総まとめ）

**動画シリーズ全4話を通じてお伝えしてきたこと**

> ※ 木村の顔横に「第１話・第２話・第３話」のサムネorタイトルを並べてビジュアル表示

**第１話のおさらい**  
- 年商1,000万で止まる人と1億いく人は「フォーカスする場所」が違う  
- 止まる人は「今月の受注・来月の受注」という行動レベルにフォーカスしている  
- 伸びる人は「自分の仕事の基準値・どこまでを自分ごととして見るか」にフォーカスしている  
- その結果、メンバーが増え、お客様に応援される状況が作られていく  
- 会社の4つの戦略（全社→事業→機能→財務）の順番で設計することの重要性

**第２話のおさらい**  
- 5年前に有名だった人が今いなくなる / 当時から今でも生き残り続けている人の違い  
- 目先の売上だけを追うのか、価値が届く仕組みを作って同じお客様から売上が上がり続ける良いビジネスを作れているのか  
- これが会社が存続するかどうかの最大の分岐点

**第３話のおさらい**  
- 木村と佐古が最初の1,000万〜3,000万を稼いでいた頃、どんなバランス感覚で「現場」と「経営」を両立していたか  
- どんな時間の使い方をして、誰と会っていたか（環境設計）  
- これを再現すれば、あなたも同じ壁を突破できる

### 4-2｜今回の動画の目的（コミット紹介前の前置き）

**この動画の目的**  
- 「コミット」というプログラムの内容をご案内する前に、まず「なぜこれを作ったのか」という想いをお伝えしたい  
- 思いが同じ人が集まっていない環境は、参考にならない先輩になってしまう  
- 自分が本当に一緒に頑張っていきたいのは、同じ方向を向いている人たち  
- だからまず、自分の考え方をお伝えさせてほしい

---

### 4-3｜木村のビジョン（なぜコミットを作ったか）

**木村が目指している未来**  
- 自分が影響している50人が、全員「自分一人の幸せだけでなく、周りの人や社会のために頑張れる人」になっていること  
- 業界を変えるようなナンバーワン企業を、自分の周りから輩出していくこと

**その未来が実現したら何が起きているか**  
- 「自分の生存」にフォーカスが当たらなくなる  
- 関わっている人がどうなるのか、先人たちが作ってきた会社・インフラをどう継承・進化させていくのか、という大きな視点で動ける  
- 経営の原則が分かっていると、どんな業種でも社会にフィットしながら価値を生み出し続けられる

**それが実現できた人の状態**  
- 無限に富にアクセスできる  
- 敷地を超えた基準値を持っている人には、人・機会・資金がすべて集まってくる  
- みんなに感謝されながら、個人としてやりたいこともすべて叶えられる  
- フォーカスが「生存」ではなく「成長」と「仲間への応援」に向いた人生になる

**木村自身の現在**  
- 今、自分の人生はまさにその状態になってきている  
- だからこそ、これをさらに加速できる仲間を集めたいと思って、「コミット」という環境を用意した

### 4-4｜リアリティの提示（なぜ木村だから言えるのか）

**「佐古さんや木村さんだからできたんじゃないか」という疑問への回答**  
- 木村が美咲先生に多額を払って学んでいた頃の話  
- 村上さんにコンサルを受けていた頃の状況  
- 「上の人と繋がれたのは、どんなマインドを持っていたから」という話  

**木村がコンサルしている業種の幅**  
- 無形〜有形、さまざまな業種を扱っている  
- どの業種でも「原則は一緒」と言えるような普遍的な思想から学び、それを各現場に落としている  

**「あなたと一流の世界の狭間にいるのは木村だけ」という提示**  
- 一定以上の成功をしている人しかいなくなった世界と、今これを見ているあなたの世界の間に木村がいる  
- 時間とお金の投資教育：木村自身がこれほどの金額・時間を師匠に投資してきたから今がある  
- だから木村と同じ環境に身を置くことが、あなたにとっての最短ルートになる

### 4-5｜商品説明（コミットとは何か）

> ※「ここから先はコミットというプログラムの具体的な説明になりますので、興味のある方だけ聞いてください」と前置き

**コミットのコンセプト**  
- 木村の経営視点・アドバイスを受けられる「総合環境型プログラム」  
- あなたがプレイヤーとして仕事をしている間、木村と話す時間だけは経営者目線で事業を俯瞰できる  
- ミクロ（日々の実務）とマクロ（事業設計・投資判断）を同時に見るのは一人では難しい → 木村の目を借りること

**コミットの機能一覧**

| 機能 | 内容 |
|------|------|
| **チャット相談** | 日常的な壁打ち・判断サポート |
| **コラム・コンテンツ** | 木村の経営観・ノウハウのインプット |
| **佐古のマインドセットメール** | 佐古からのマインドコンテンツ |
| **コミット会（オフライン）** | 月1回・各地方で開催。直接会って同じ時間・空間を共有する。**This is the CORE.** |

**コミット会について（特に強調）**  
- 振り返っても「先輩と同じ時間・空間を共有したこと」が最も大切だった  
- だからこそオフラインで直接会う機会が、この商品の最も重要な核  
- 参加者全員がこの場に来ることを、強くコミットしてほしい

**成果事例**  
- 木村と壁打ちしながらこの頻度で関わっている人は、このような結果を出している  
  → 複数の受講生事例を提示（売上数字・事業の変化など）

### 4-6｜価格と正当性

**本来の価値換算**  
- チャット・Zoom・オフライン会で年間これだけの時間を共有するとなると、経営コンサルの市場価格では年間500万円相当  
- 木村自身も、このレベルの師匠に2ヶ月で500万円規模の投資をしてきた

**今回の価格設定**  
- **月額11万円（年額132万円）**  
- 基本は年額132万円の契約を前提とする（一括払い推奨）  
- 分割24回払いの相談も可

**この価格を設定した理由**  
- 年商1,000万〜3,000万がボリュームゾーンの対象者に、年間500万円はストレッチが大きすぎる  
- 木村が気合を入れて乗り越えてきた金額と同様の負荷を、誰にでもかけるよりも「一緒に価値を創出していける仲間」を育てたい  
- だからこそ現実的な月額11万円（年132万円）に設定している

**来てほしくない人（ここは動画で明言する）**  
- この132万円が気になって、経営の判断が鈍ってしまうような人には今は向かない  
- 活動予算が気になって本質的な動きができなくなるなら、今は自分一人で頑張ることをお勧めする  
- 一括払い以外の選択肢を取ることで経営が危なくなるような状態の人も、今じゃない  
- → **来るかどうかギクッとなるなら、申し込みはしないでください**

**来てほしい人**  
- 貯金・事業のキャッシュフローに余裕があり、132万円を気合の投資として出せる人  
- 長期的な視点で「この1年で突き抜ける」と本気で決めた人  
- 木村と一緒に、お互いの価値を高め合える関係性を作っていける人

### 4-7｜申し込みの流れとリスクリバーサル

**限定人数**  
- 50名限定（満員の場合は申し込みページが閉まっている場合あり）  
- 木村が直接関わる形式のため、それ以上は受けられない

**申し込み〜スタートの流れ**  
1. 感想フォームから感想を送る → ご案内ページへ誘導  
2. 申し込みページから決済  
3. **2週間以内に初回面談**（木村との1on1）  
4. 初回面談で「相互に合わない」と判断した場合 → **全額返金対応**  

**リスクリバーサルの設計**  
- 2週間以内の初回面談が実質的なトライアル期間  
- 木村が「この人には難しいと判断した場合」も返金  
- 申し込んだ側が「やっぱり違う」と感じた場合も返金  
- → **決済後2週間は、どちらかが判断すれば無条件で全額返金可能**

> ※ 「もしかしたらすでに満員で閉まっている可能性もあります。早めにお申し込みください」と緊急性を添えて伝える

### 4-8｜最終クロージング（木村の人間性を見せる）

**木村個人の話**  
- 経営がつらかった時期もあった  
- 支えてくれた人・目標としていた人に「証明していこう」と思って今の状態がある  
- だからこそ、同じ思いを持つ仲間を作り続けることが自分のミッションになっている

**視聴者へのメッセージ**
