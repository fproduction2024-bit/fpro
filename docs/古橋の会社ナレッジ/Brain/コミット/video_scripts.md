## 📽 Vol.1：共鳴とアイデンティティ（基準値の衝撃）

**【コンセプト】**
視聴者が抱える「なぜ結果が出ないのか」という疑問に終止符を打ち、迫氏の教育者としての覚悟と、本プロジェクトの存在意義を伝える。

| 構成案 | 映像イメージ | 脚本（ナレーション/セリフ） |
| :--- | :--- | :--- |
| **0. オープニング** | 迫氏のアップ、または洗練されたオフィス背景。真剣な表情。 | **（迫）**「単刀直入に聞きます。なぜ、同じ教材を買っているのに、年商10億を超える人と、1円も稼げない人に分かれるのでしょうか？」 |
| **1. 問題提起** | テロップ：才能？ 運？ 裏技？（すべてに×印） | 「それは才能の差でも、運の良さでも、隠れた裏技を知っているわけでもありません。答えはたった一つ。**『基準値（ベンチマーク）』**が違うからです。」 |
| **2. 共鳴（痛みの開示）** | 過去のセミナーや指導風景のインサート。少し声を落として語る。 | 「僕は情報発信の業界に10年以上いて、3万人以上の受講生を見てきました。そこで一つの残酷な事実に直面したんです。…最強の知識を渡しても、やり切れないノウハウコレクターを量産してしまっている。」 |
| **3. 教育者の覚悟** | 画面を真っ直ぐに見据える。 | 「正直に言えば、教材を売り続ける方が会社は儲かります。でも、それは僕がやりたかったことじゃない。知識を渡すだけで終わるなら、教育者失格だと思っています。」 |
| **4. 木村氏との共闘** | 木村氏との2ショット、または木村氏の活動風景。 | 「だからこそ、基準値を直接叩き込み、強制的に引き上げる環境を作ろうと決めました。そのパートナーが、僕が7年間信頼し続けてきた木村さんです。彼ほどの基準値を持ち、人の人生に本気で向き合える人は他にいません。」 |
| **5. コンセプト提示** | ロゴ：Brainコミット | 「これは単なる講座ではありません。あなたのマインドと習慣を根本から改造し、強制的に超人へ生まれ変わらせる『限界突破プログラム』。それがBrainコミットです。」 |
| **6. クロージング** | 希望を感じさせる明るいライティング。 | 「あなたは今日から、単に『学ぶ人』を卒業してください。基準値を壊し、人生の景色を変える。その旅を、僕らと一緒に始めましょう。次の動画では、実際に基準値が書き換わる体験をしてもらいます。」 |

## 📽 Vol.2：自己効力感の着火（基準値を壊す体験）

**【コンセプト】**
成功はセンスではなく「手順」であることを証明し、その場で小さな成功体験（Small Win）を積ませる。

| 構成案 | 映像イメージ | 脚本（ナレーション/セリフ） |
| :--- | :--- | :--- |
| **1. 導入** | テロップ：成功は手順である。 | **（迫）**「『自分にできるだろうか』という不安。それは基準値が低い世界の見え方です。成功者がやっていることは、実は驚くほどシンプルなんです。」 |
| **2. ステップの因数分解** | ホワイトボードや図解：1.マインド 2.方向性 3.知識 4.実践 5.継続 | 「成功までの5つのステップを因数分解しました。1：マインドを叩き込む、2：方向性を決めてもらう、3：必要な知識だけを学ぶ、4：超人基準で実践する、5：監視されながら継続する。これ、手順通りにやれば誰でも同じ結果が出ると思いませんか？」 |
| **3. 公開ワーク（マイクロアクション）** | 時計のタイマーなどが画面の端に出現。 | 「今から10分間だけ、僕と同じ基準値で動いてみましょう。感情を一切入れず、目の前のタスク1つを完遂してください。スマホも、SNSも、雑念もすべて遮断します。」 |
| **4. 実践と肯定** | 10分後の迫氏。笑顔で。 | 「お疲れ様でした。今この10分間、あなたは年商10億の経営者と同じ基準値で動きました。どうですか？案外、できたはずです。その『できた』という感覚が、あなたの世界を広げる種になります。」 |
| **5. 次回の予告** | | 「でも、一人だとこの基準値は明日には下がります。次回の動画では、この高まった基準値を下げない『環境の秘密』についてお話しします。」 |

## 📽 Vol.3：深層価値の体験（環境の魔力）

**【コンセプト】**
機能（価格、回数）ではなく、環境に身を置くことで得られる「感情的ベネフィット（フロー状態、迷いの消失）」にフォーカスする。

| 構成案 | 映像イメージ | 脚本（ナレーション/セリフ） |
| :--- | :--- | :--- |
| **1. 共振** | 迫氏と木村氏、そして受講生が熱量高く議論している背景映像。 | **（迫）**「基準値は一人でいると必ず下がります。人は放っておくと、楽な方に、緩い方に流れてしまう生き物だからです。」 |
| **2. フロー体験の説明** | 抽象的だが美しいイメージ映像（光の筋、静かな集中状態）。 | 「想像してみてください。周り全員が当たり前のように年商1億を狙い、淡々とタスクをこなしている場所。そこでは『頑張る』必要はありません。それが普通だからです。この環境に入った瞬間、あなたの迷いは消え、深い没頭状態――フローに入ることができます。」 |
| **3. 深層価値の提示** | テロップ：迷いのない人生 | 「Brainコミットが売っているのは教材ではありません。あなたが一生、迷わずに走り続けられる『高い基準値という一生モノの資産』です。」 |
| **4. ビジョン提示** | 将来の受講生が成功を報告しているイメージ。 | 「1年後、あなたは今の自分を思い出して驚くはずです。『あんな小さなことで悩んでいたのか』と。視座が上がり、人生の解像度が一気に高まる。その瞬間を共有したいと思っています。」 |

## 📽 Vol.4：社会性と実用性の提示（日常への実装）

**【コンセプト】**
基準値の向上が具体的にどう収益を上げ、周囲を幸せにするのか、実務レベルのコンテキスト（背景）を提示する。

| 構成案 | 映像イメージ | 脚本（ナレーション/セリフ） |
| :--- | :--- | :--- |
| **1. 実務への接続** | 具体的なビジネス例（フリーランス、店舗、サラリーマン）。 | **（迫）**「基準値が上がると、具体的に何が起きるか。例えばクライアントワーク。単価10万の案件を恐る恐る受けていた人が、『僕なら100万の価値を出せる』と確信を持って提案できるようになります。なぜなら、自分をサポートする超人たちの背中を知っているからです。」 |
| **2. 貢献の輪** | 「お裾分け（貢献）」をイメージした図解。 | 「私たちが定義する超人は、利己的な人ではありません。自分が高い基準値で勝つ習慣を身につければ、今度はあなたの周りの人を引き上げ、救えるようになります。自立し、他者に貢献できる。それこそが最高にカッコいい生き方だと思いませんか？」 |
| **3. ハードルの低下** | リラックスした姿勢で。 | 「毎日完璧である必要はありません。でも、このコミュニティに繋がっていること。それだけで、あなたは平均的な日本人を遥かに凌駕する速度で成長し続けます。」 |
| **4. 次回（最終回）への端渡し** | 手を差し出すアクション。 | 「さて、いよいよ最後です。この超人の世界に入るための、具体的な扉の開け方をお話しします。僕らが赤字覚悟で用意した『ある挑戦』について、聞いてください。」 |

## 📽 Vol.5：確信とクロージング（超人への招待）

**【コンセプト】**
圧倒的なオファーの正当性と「2つ先からお金をもらう」哲学を伝え、参加を促す。

| 構成案 | 映像イメージ | 脚本（ナレーション/セリフ） |
| :--- | :--- | :--- |
| **1. 圧倒的オファー** | テロップ：月額500円 / 月額10万円 | **（迫）**「Brainコミットには2つの扉を用意しました。月額500円の実践コースと、月額10万円の超人コースです。」 |
| **2. 報酬哲学の説明** | 図解：1つ先（受講料）ではなく、2つ先（その後の成功）でお金をもらう。 | 「月額500円を見て、頭がおかしいと思ったかもしれません。当然です。でも、僕らの哲学は**『2つ先からお金をもらう』**こと。まずはあなたに徹底的に勝ってもらう。その先の未来で生まれる大きなビジネスチャンスや、揺るぎない信頼関係こそが、僕らの本当の報酬です。」 |
| **3. 超人コースの熱量** | 木村氏も登場、または木村氏のメッセージ映像。 | 「本気で人生を最短で改造したいなら、限定25名の超人コースに来てください。僕と木村が、あなたの魂を直接叩き直します。一切の言い訳も妥協も許しません。一生に一度、死ぬほどやり切る体験。それを約束します。」 |
| **4. 最後のメッセージ** | 迫氏の真剣な表情、最後は笑顔。 | 「時代は今、人類史上最も面白いフェーズにあります。チャンスは誰にでも広がっている。でも、それをつかむのは基準値を変えた人だけです。一生に一度くらい、人生の景色が変わるほど仕事をしてみませんか？ お待ちしています。」 |
| **5. CTA** | 特設ページのURL、ボタンの案内。 | 「詳細は下のボタンから。超面白い世界を、一緒に作りましょう。」 |
