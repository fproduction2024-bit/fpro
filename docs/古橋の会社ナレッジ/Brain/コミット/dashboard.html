第０話 · 対談 · 迫が木村をTアップ
シリーズ全体の文脈設定・対象者定義
話者：迫メイン 序章
0-1｜コアメッセージ（動画シリーズ全体で何を得られるか）
コンセプト
あなたと全くスタートラインが同じだった人が、4年前から今にかけて「圧倒的な差」を出している。
「なぜここまで差がついたのか」をすべて言語化する動画シリーズです。
革新的メッセージの軸
・足りなかったのはノウハウではなかった
・ノウハウはすでに均一化されている
・差がつくのは「誰とやるか」「基準値の環境」
0-2｜対象者の定義（こんな人に見てほしい）
状態① — 器用貧乏
・頑張っているのに「手残り」がない
・忙しいが売上が停滞している
・自信を持って利益が出る商品を提供できていない
・年間1,000万円の顧問プランがあっても公表できないような「心理的な線引き」がある
状態② — 踏み込めない感
・次の一手の答えが分からず、身動きが取れない
定量的な定義
・年商1,000万〜5,000万のレンジ
・利益が「余っていなくもないが、余ってもいない」人
0-3｜自己紹介（迫 → 木村へのTアップ対談）
📹 撮影形式：2人が並んで話す対談形式。迫がメインで進行し、木村をTアップする。
① 迫の自己紹介（迫が話す）
1. 業界最大級の知識共有プラットフォーム「Brain」を運営している
2. ユーザー数は急増し、年間流通額は10億円超
3. 教育事業を多数展開し、複数の会社経営も行っている
4. ビジネス仲間として、おさるさん（デジタルマーケティング系・実業）など多数の方と活動している
→ 淡々と事実を話す。「おさるさんとも一緒にやってます」という実績だけ出して次へ
② 木村の紹介（迫がTアップ → 木村が補足）
・「パートナーの木村さんです」
・オフラインでのセミナー・授業を実施している
・Brain上でのコンテンツ展開も行っている
・コンサルティングも多数手がけている
→ 木村本人が補足。フォーマット：「実際にやってきたこと」「今の活動」の2点を端的に
③ 共通の権威づけ（迫が代表して話す）
1. 「僕も木村さんも、5〜6年前は本当にゼロからのスタートでした」
2. 実際にクライアントワークをしていて、皆さんと同じ時代を過ごしていた
3. 「消えなかった2人の共通点」をお伝えしたいと思っています

視聴者の疑念（先出しして潰す）
→「Brainというプラットフォームがあるから強いんでしょ」
→「オフラインで借り入れできる資本があるからできるんでしょ」

切り返しセリフ（迫）
→「Brainができる前の僕は、あなたたちと一緒でした」
→「資本を借りてトラックをやる前の木村さんも、あなたたちと一緒でした」
→「では、なぜそういうことができるようになったのか。それをお伝えするのが今日の動画です」
④ 権威づけまとめ（迫がしめる）
・「僕らがコンサルしてきた領域はとても広い。無形・有形、地方・都市、あらゆる業種」
・「その中で、生き残った人・消えていった人を、長い時間軸の中で見てきました」
・「そこには共通点がありました。本には書かれていない、生々しい情報をこの動画でお伝えします」
0-4｜このシリーズで手に入るもの（3本の動画で解説すること）
① 第１話で手に入ること
同じ時間・同じリソースなのに、3,000万で止まる人と1億にノンストップで拡大する人の差。「考え方と時間の使い方」の違いを完全に理解できる。
② 第２話で手に入ること
1億まで行ったのになぜか突然消えてしまった人と、2億・3億と伸び続けた人の差。キーワード：膨張 vs 拡大。
1億をゴールにして1億を手本にすると「短距離走」になり、消えてしまうビジネスを作ってしまう。本当に構造的優位なビジネスであれば10億まで行くはず、という視点で事業設計を見直す。
③ 第３話で手に入ること
第１話・第２話で得た考え方を「机上の空論」で終わらせず、実地で継続できる状態にする方法。勢力（引力）が働き続ける環境に身を置くことの重要性。甲子園に行く学校は「だいたいみんなうまい」── 同じ基準値を持つ仲間と近くにいるから再現性が生まれる。コミットとは関係なく、まず一般論として「正しい引力の中に身を置くこと」が答えだと提示する。

第１話 · 木村ソロ
同じノウハウ・同じリソースから始めて４年で100倍の差がついた３つの理由
キーワード：フォーカスポイント・4つの戦略・1億円コンフォートゾーン
木村ソロ
特典：解説レポートPDF
1-1｜導入（前回の振り返りと本動画の目的）
前回（第０話）のおさらい
迫さんと木村が、この4年間で「ちゃんと成長した人」と「消えていった人」を見てきた。その共通点と違いを、この動画シリーズ全体でお伝えすると予告した。
今回の動画の目的
特に「年商1億を当たり前に達成している人」と「頑張っても1,000万〜3,000万で止まってしまい、利益も出ない人」の違いが具体的に何なのかを解説する。
視聴後に得られるもの
・3万人以上の受講生の中で、爆発的な成果を出す人と普通の成果の人の「根本的な違い」が分かる
・どんな事業でも年商1億は当たり前に作れる、という基準値になる
・同じノウハウ・同じリソースを持っていても、圧倒的な成果を出せるようになる
1-2｜問題提起（頑張っているのに稼げない3つの原因）
① フォーカスする領域が間違っている
1,000万〜3,000万で止まっている人の多くは「行動」にフォーカスしている。行動＝今月どんな仕事を受注したか・今月何を完了させたか。例：動画編集者なら「案件をどう取るか」「今の仕事の効率化」ばかりに集中。週7で頑張って月300万になっても、2〜3ヵ月先まで仕事がパンパンで限界、という状態に。
② 戦略の違い（必要な知識が足りていない）
ビジネスを作る上で考えるべき「4つの戦略の階層」を知らない。ノウハウはどの業界でも均一化しているが、この戦略の知識は全事業の土台。この知識格差が結果の差として現れている。
③ 正しい投資ができていない
ずっと自己投資を続けているが、事業を大きくするフェーズの投資に移れていない。拡大している人は「自己投資ではない投資」をちゃんとやっている。どのフェーズでどんな投資が必要なのか、が分かっていない。
1-3｜解決策①｜フォーカスポイントの違い（意識のピラミッド）
[ マインド・基準値 ] ← 伸びる人はここにフォーカス
[　　スキル・知識　]
[　　行動・タスク　] ← 伸び悩む人はここにフォーカス
伸び悩む人の状態
ピラミッドの「行動」部分に意識が集中している。目の前の案件を効率化しても、行動の天井に到達すると詰まってしまう。
伸びる人の状態

多くの人が感じていること

2-3｜問題提起（消えていく人の2パターン）
パターン特徴原因
①低空飛行のまま消えるずっと小さい売上のまま撤退基準値が低い・ノウハウが間違っている・お手本が間違っている
②打ち上げて消える一時的に大きな売上を出したが突然消える実態を伴わない売上（膨張）を作っていた
特に危険なのは「①がお手本にしているのが②」という構造
一発当てて消えた人は「勝ち続けた人」の10倍以上いる。その消えた人をお手本にすると、歪んだ売上の作り方を真似することになり、同じように消える。

消えていく共通のメカニズム
フォーカスが「お金の流れ（売上数字）」に当たっている。「価値の流れ（誰の人生をどう変えたか・お客様に本当に価値が届いているか）」が見えていない。例：FC本部が「何件FC契約を取れたか」だけに注目している → 1店舗1店舗のお客様への価値提供から設計されていない。
2-4｜解決策①｜「価値の流れ」を中心に置く
「価値の総量」と「売上の総量」の関係
価値の総量 ＞ 売上の総量 → 長く生き残る
売上の総量 ＞ 価値の総量 → 信用がなくなって消える
価値の流れを中心に置くとは
・無形商品：誰の人生をどんな風に変えたか
・クライアントワーク：この制作物でクライアントの売上がどれだけ上がったか
・EC・店舗：来てくれたお客様にどのように価値を届けているか
これを「注目するべき数字」として事業の中心に置いている人は長生きしている。
新規顧客獲得コストの罠（負のスパイラル）
CSに投資せず価値提供の質が下がる → リピートが発生しない → 毎月新規顧客を取り続けなければならない → 新規を取れば取るほどCSが追いつかなくなりクオリティが下がる →新規コスト↑ × リピート率↓ × 品質↓ の「負のスパイラル」が起こる
2-5｜解決策②｜正しいお金の回し方（分配率の設計）
膨張している人がやりがちなお金の回し方
・売上のほぼ全てをマーケティング・営業コストに再投資する
・CS（顧客対応・品質）への投資が極端に薄い（例：営業10人・CS2人）
・設備投資（仕組み・マニュアル化）をしないまま売上規模を拡大しようとする
・規模が大きくなるほど社内コミュニケーションコストが増し、1人あたりの仕事量が増え、クオリティが下がる
長く生き残る人がやっていること
1. まず「今いるお客さんへの価値提供」を気合で上げる
2. リピートしてもらえる体制を作る → LTV（顧客生涯価値）を高める
3. 残った利益でCSをマニュアル化・仕組み化（設備投資）する
4. 低コストで高い価値を届けられる土台を作る
5. 稼働率が80%程度になってから、人的投資・店舗拡大・次の売上へ

結果：時間が経つほど売上と利益が自然に上がる構造になる
遊んでいるように見えて生き残っている人の本質
遊んでいる部分だけが切り取られているが、裏側では「仕組み」が常に動いている。仕組みが完成しているから、遊びに使う適切な分配率が算出できている。仕組みが完成していないのに目先のお金で遊ぶと、CSへの再投資ができなくなり苦しくなる。
2-6｜コンフォートゾーンマトリックスとの接続
順番を間違えると膨張する。例：自己投資・人的投資フェーズ（〜3,000万クラス）なのに、いきなり広告・認知投資に踏み込む。社内の仕組みが整っていないのに外へ大量認知を取ると、クレーム・炎上・品質劣化が起きる。業種・業態によって売上の数字に差はあるが、「この土台をクリアした上で次の投資へ」という順番は変わらない。
