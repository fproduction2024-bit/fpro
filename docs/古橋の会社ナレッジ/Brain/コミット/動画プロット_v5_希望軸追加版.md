# Brainコミット 動画プロット v5
## 「恐怖→希望→仲間」の3話構造に再設計

作成日：2026-04-15  
前バージョン：v4（恐怖軸が強すぎた）  
改善方針：**恐怖で立ち止まらせ、希望で動かし、仲間で決断させる**

---

## ── 設計思想の変更 ──

### v4の問題点
第一話・第二話ともに「消える、死ぬ、詰む」という恐怖軸に偏りすぎた。  
視聴者が「やばい」と感じても、「だからどうすればいいのか」の出口が見えなかった。

### v5の設計原則

```
第一話：「恐怖」── 現実を直視させる
第二話：「希望」── 突破した人の具体的な中身を見せる
第三話：「再現性」── なぜ50人が集まると再現できるのかを証明する
VSL：「決断」── 今ここで選ぶ必要がある理由
```

---

## 全体構成

```
第一話（対談）：「5年後、あなたの会社は存在していますか」
                   ↓ 恐怖×希望の同時提示
第二話（木村ソロ）：「100億の社長が、呼吸するようにやっていること」
                   ↓ 具体的希望の提示
第三話（木村ソロ）：「なぜ50人の超人チームで、100億が複製できるのか」
                   ↓ 再現性の証明
VSL（木村ソロ）：「同じ基準値で走る50人を探している」
```
