## 📽 Vol.1：選別とアイデンティティ（基準値の衝撃）

**【コンセプト】**

| 構成案 | 映像イメージ | 脚本（ナレーション/セリフ） |
| :--- | :--- | :--- |
| **0. 先制のフィルタリング** | 迫氏の真剣な表情。BGMなし。 | **（迫）**「最初に断っておきます。今からお話しするのは、『これから副業を始めたい』という初心者の方や、『誰かに稼がせてもらいたい』という受動的な方のための話ではありません。時間の無駄になるので、ここで動画を閉じてください。」 |
| **1. ターゲットへの問い** | テロップ：年商500万〜5000万の壁 | 「すでにご自身で事業を持ち、年商500万、あるいは1500万という成果を出している。でも、そこから先の景色が見えない。なぜか？ それは、あなたの『基準値』が、まだ年商10億のステージに届いていないからです。」 |
| **2. 共鳴（教育者の絶望）** | 書斎で深く考え込む演出。 | 「僕は3万人の受講生を見てきて絶望しました。最強のノウハウを渡しても、結局は自分の『ぬるい基準値』の枠内でしか行動できない。僕の会社は教材を売れば儲かります。でも、そんな『知識の切り売り』で終わる自分に、僕は耐えられなくなりました。」 |

## 📽 Vol.2：自己効力感の着火（超人モードの疑似体験）

**【コンセプト】**
高単価（月額11万円）の正当性を、感情論ではなく「成功の手順」への確信によって証明する。

| 構成案 | 映像イメージ | 脚本（ナレーション/セリフ） |
| :--- | :--- | :--- |
| **1. 成功のアルゴリズム** | 図解：マインド・方向性・実践・継続への監視。 | **（迫）**「月額11万円という価格。これを高いと感じるなら、まだあなたは『労働対価』で考えています。僕が提供するのは、年商を桁一つ変えるための『アルゴリズム』そのものです。」 |
| **2. マイクロアクション（強制モード）** | 10分間のカウントダウン。迫氏も一緒に作業する様子。 | 「今から10分間、一切の言い訳を捨ててください。感情を殺し、機械のように目の前の重いタスク1つを完遂する。これが、僕ら年商10億超えの人間が毎日、呼吸するようにやっている『超人モード』の入り口です。さあ、始めましょう。」 |
| **3. 体験後のフィードバック** | | 「10分で世界は変わりましたか？ 変わったのはあなたではなく、あなたの『当たり前』です。この極限状態を、僕らが24時間、強制的に維持させます。」 |

## 📽 Vol.3：深層価値の体験（基準値という資産）

**【コンセプト】**
「頑張る」ことが不要になる「仕事への評価＝QOL」という上位価値観への書き換え。

| 構成案 | 映像イメージ | 脚本（ナレーション/セリフ） |
| :--- | :--- | :--- |
| **1. 頑張るのをやめる** | 落ち着いたトーン、ゆったりとした音楽。 | **（迫）**「一人で頑張るのを、もうやめませんか？ 高い基準値の集団に身を置けば、努力は『当たり前』に昇華されます。そこではもう、迷うエネルギーすら節約できる。」 |
| **2. QOLの再定義** | 木村氏との対談風景を回想。 | 「よくQOL（生活の質）のために仕事を抑えると言いますが、逆です。仕事への圧倒的な需要と評価、それ自体が人生のQOLそのものになる世界がある。私たちは、そんな『勝ち続ける側』の人間とだけ、付き合いたいと思っています。」 |
| **3. ビジョンの共有** | | 「年商を1500万から3000万、1億へと引き上げるのは、スキルの差ではありません。環境がもたらす『視座の差』です。」 |
