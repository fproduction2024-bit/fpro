【第1部：衝撃の導入（スライド2〜8）】

スライド2：時代背景
「"SaaS is Dead" ── 今、何が起きているのか」
- これまで：やりたいこと1個につきSaaS1個
  - HP作りたい → WordPress（月額＋テーマ代＋プラグイン）
  - LP作りたい → ペライチ / STUDIO
  - メール配信 → マイスピー / プロライン
  - 記事書きたい → SEOツール＋ライター外注
  - 文字起こし → 専用ツール＋別の要約サービス
- 各SaaSを契約し、使い方を覚え、個別に操作する…
→ この構造自体が崩れ始めている

スライド3：新しい世界線
「AIエージェント1つが全部やる時代」
- 「HP作って」→ 作る（WordPressなし）
- 「LP作って」→ 作る（ペライチなし）
- 「シナリオ書いて」→ 書く（外注なし）
- 「文字起こしして」→ する（専用ツールなし）
→ 非エンジニアがWordPressを使わずにHPを作れる。この世界線がもう来ている。

スライド4：問いかけ
「あなたはAIをまだ"相談相手"として使っていませんか？」
→ ChatGPTでテキストを生成するだけの使い方との比較を示唆

スライド5：ビフォーアフター
「従来のやり方 vs AIエージェント」
左右比較レイアウト：
- 左：LP制作→外注で30万/2週間、台本→ライターに依頼で1本5万、SEO記事→1本3万×30本
- 右：全部AIエージェントが実行→コスト激減、スピード10倍

スライド6：「これ全部、コードを1行も書かずに作りました」
実績リスト（箇条書き）：
- プロ品質のWebサイト（タングルシード公式HP）
- プロジェクト管理ダッシュボード（自動生成→即公開）
- 動画ファネル台本5本＋セールス台本
- LINE配信シナリオ6本
- SEO記事30本
- 企業提携戦略資料（8業態分析）
- ペルソナ設計書（26,000字）
- 録音データの自動文字起こし＆要約

スライド7：実際の成果物スクリーンショット（プレースホルダー）
「※ここにタングルシードHP、ダッシュボード等のスクリーンショットを差し込み」

スライド8：キーコンセプト
「AIに"仕事場"を持たせると何が変わるのか？」
→ 次の第2部への橋渡し

【第2部：ChatGPTとは次元が違う5つの能力（スライド7〜16）】

スライド7：セクションタイトル
「ChatGPTとの決定的な違い」

スライド8：比較表
| | ChatGPT | Antigravity（Cursor内） |
|---|---|---|
| テキスト生成 | ○ | ○ |
| ファイル作成・編集 | × | ○ PCのファイルを直接操作 |
| フォルダ構造を把握 | × | ○ ビジネス資料全体を理解 |
| コマンド実行 | × | ○ デプロイ・自動化 |
| Web検索・閲覧 | 制限あり | ○ 自由にリサーチ |
| 文脈の継続性 | 薄い | ○ ワークスペース全体が記憶 |

スライド9：能力① ナレッジ管理
「ファイル操作 × ナレッジ管理」
- 会社のドキュメントを構造化・INDEX自動生成
- フォルダ整理、情報の検索と横断的な分析
→ 実例：タングルシード全ドキュメント管理

スライド10：能力② Webサイト・LP制作
「デザイン込みのサイトをゼロから構築」
- HTML/CSS/JSを自動生成
- SEO対策済み、レスポンシブ対応
→ 実例：タングルシード公式HP、FC募集プレゼン資料

スライド11：能力③ コンテンツ量産
「構造分析→パターン抽出→再現」のフロー
- 成功事例の台本を食わせて構造を抽出
- その構造で自社版を一気に生成
→ 実例：スキルハックス台本5本、LINEシナリオ6本、SEO記事30本

スライド12：能力④ リサーチ＆戦略立案
「市場調査・競合分析・ペルソナ設計を対話で深堀り」
- Webリサーチと自社データの掛け合わせ
- 1つのテーマを何万字レベルで掘り下げ
→ 実例：ペルソナ設計26,000字、企業提携戦略8業態

スライド13：能力⑤ 自動化＆ワークフロー
「繰り返し作業をワークフロー化して一発実行」
- 一度作ったフローは次回から1コマンドで再現
- 録音→文字起こし→要約の完全自動化
→ 実例：Plaud連携、surge.shデプロイ自動化

スライド14：重要な気づき
「実はここまでの作業に"プログラミング"は一切不要」
→ Cursorは"コードエディタ"だが、自分は"AIのコックピット"として使っている

スライド15：概念図
「Cursorの本当の役割」
図解：
Cursor = AIエージェントの操作環境
├── ファイルシステム → 資料の作成・編集・整理
├── ターミナル → デプロイ・自動化スクリプト
├── ブラウザ → Webリサーチ・サイト確認
└── Antigravity → ↑これら全部を"考えて"操作するAI頭脳

スライド16：もう1つの重要ポイント
「"特化ツールとの使い分け"もAI活用の鍵」
- スライド制作 → GenSpark（特化ツール）
- 台本・戦略設計 → Antigravity（万能エージェント）
- デザイン → Canva、Figma
→ 全部AIにやらせるのではなく、AIが得意な領域を見極める

- ファネル設計：外注30-50万 → AI: 0円
