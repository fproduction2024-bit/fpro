# Antigravity × ビジネス活用セミナー 構成案

> **AIの「使える人」と「使えない人」の差は、ここで決まる**

---

## セミナーのゴール

参加者が「Antigravity（AI×コード環境）を使えば、自分のビジネスのこの部分が劇的に変わる」と具体的にイメージできる状態にする。

---

## ターゲット

- 情報発信・コンテンツビジネスをしている起業家
- ファネル構築やLPを外注している経営者
- AIに興味はあるが、ChatGPTの域を出ていない人

---

## 全体構成（約90分想定）

### 🔴 第1部：衝撃の導入（10分）
**「AIでここまでできる時代になった」**

- **ビフォーアフター提示**: 従来の外注フロー vs Antigravityの実作業デモ
- 実際に作ったもののスクリーンショットや成果物をスライドで見せる
  - タングルシードHP（プロ品質のWebサイト）
  - スキルハックスダッシュボード（プロジェクト管理サイト）
  - 30記事のSEOブログ（自動生成）
- **キーメッセージ**: 「これ全部、僕がコードを1行も書かずに作りました」

---

### 🟡 第2部：Antigravityで何ができるのか（20分）
**「ChatGPTとは次元が違う5つの能力」**

#### 能力① ファイル操作 × ナレッジ管理
- Obsidianと連携して会社のナレッジを構造化・整理
- 実例：タングルシード全ドキュメントのINDEX自動生成、フォルダ自動整理

#### 能力② Webサイト・LP制作
- デザイン込みの本格的なサイトをゼロから構築
- 実例：タングルシードHP（SEO対策済み）、FC募集プレゼン（HTML）

#### 能力③ コンテンツ量産マシン
- 台本・シナリオ・記事を「構造分析→再現」のフローで量産
- 実例：スキルハックス台本5本、LINEシナリオ6本、SEO記事30本

#### 能力④ リサーチ & 戦略立案
- 市場調査、競合分析、ペルソナ設計を対話形式で深堀り
- 実例：ターゲットペルソナ26,000字、企業提携戦略8業態分析

#### 能力⑤ 自動化 & ワークフロー構築
- 繰り返し作業をワークフロー化して一発実行
- 実例：Plaud録音→文字起こし→要約の自動化、surge.shデプロイ自動化

---

### 🟢 第3部：ライブデモ（25分）
**「実際の画面を見せます」**

以下から2〜3個をライブで実演:

1. **ファネル台本リバースエンジニアリング**
   - 既存の成功事例の台本を食わせて → 構造分析 → 自社版台本を一気に生成
   - e-Harbor/COMPASSファネルの実例を使って見せる

2. **SEO記事の一括生成**
   - キーワードリサーチ → 記事構成 → 本文生成 → HTMLに変換
   - ゼンタングルの記事生成の実例

3. **LINEシナリオ設計**
   - ステップ配信のシナリオをまるごと設計・ライティング
   - `/line-scenario` ワークフローの実演

4. **ダッシュボード生成→即デプロイ**
   - プロジェクトの進捗管理サイトを生成して即公開
   - `/deploy` ワークフローの実演

---

### 🔵 第4部：ビジネスモデルへの組み込み方（20分）
**「どうやって自分のビジネスに取り入れるか」**

#### パターンA：コンテンツビジネス加速
```
Plaud録音 → 自動文字起こし → コンテンツ企画
→ 台本生成 → LINE配信文生成 → LP制作 → デプロイ
```
- 1つのミーティング音声から、ファネル丸ごと作れる未来

#### パターンB：既存事業のDX
```
業務ナレッジ → Obsidian整理 → INDEX自動生成
→ マニュアル化 → 社員教育資料化
```
- FC本部のマニュアル構築など、属人化の解消に直結

#### パターンC：新規事業のプロトタイプ
```
アイデア → 市場リサーチ → ペルソナ設計
→ MVP制作（LP + ファネル） → テストマーケティング
```
- NFT構想、書店提携プレゼンなど、アイデアを即形にする

---

### 🟣 第5部：始め方 & 個別相談への導線（15分）
**「今日から始める3ステップ」**

1. **環境構築**（5分で完了）
   - Cursor + Antigravityのインストール
   - ワークスペースの設定

2. **最初にやるべきこと**
   - 自分のビジネス資料をフォルダに入れる
   - 「これを分析して」からスタート

3. **個別コンサルのご案内**
   - 「あなたのビジネスだと、どこにAIを入れるのが最も効果的か」
   - 1on1で一緒に設計するセッション

## 差別化ポイント

> [!IMPORTANT]
> このセミナーの最大の差別化は **「全部自分でやった実績ベースで語れる」** こと。
> よくあるAIセミナーは「こんなことができます」の一般論。
> 古橋さんの場合は「実際にこれを作って、この成果が出ました」と言える。

### 他のAIセミナーとの違い
| よくあるAIセミナー | このセミナー |
|---|---|
| ChatGPTのプロンプト集 | 実業務での成果物ベース |
| テキスト生成の話だけ | Webサイト・LP・ダッシュボードまで |
| 個人の生産性向上 | ビジネスモデルへの組み込み |
| 理論・一般論 | ライブデモで証明 |
