📌 STEP1: リード獲得

広告運用: Meta広告（Facebook/Instagram）。RIDE社が運用、リッツプロがディレクション。月次レポートをクライアント共有。

  1. UTAGEの管理画面で新規リードを確認
  2. 自動返信メールの送信を確認
  3. GoogleスプレッドシートのリードリストにID追加を確認
  4. LINE友だち追加が入った場合 → あいさつメッセージの自動送信 + ステップ配信スケジュールを確認

📌 STEP3: 個別面談・クロージング

面談前の準備: ①お客様カルテの確認 ②提案書を準備 ③収支シミュレーション準備

時間 内容 ポイント
0-10分 アイスブレイク セミナーの感想を聞く
10-25分 ヒアリング 動機・資金・時期・エリア
25-40分 提案 収支モデルをカスタマイズ
40-50分 質疑応答 不安要素を1つずつ解消
50-60分 ネクストステップ 契約意思の確認

クロージングの要点:

  • 「今だけの条件」を明示（0次募集は加盟金100万円、通常200万円）
  • 投資回収期間を具体的に（14ヶ月）
  • 他のオーナーの声を共有
  • 即決できない場合は次の具体日程を必ず確保

📌 STEP4: 契約・オンボーディング → CSへトスアップ

  1. 契約手続き: クラウドサインで契約書送付 → 入金確認（加盟金+初期費用） → 領収書発行
  2. キックオフMTG: ダッシュボードURL共有 → ガントチャートで全体スケジュール説明 → 初回ヒアリング（お客様カルテ記入）
  3. CS引継ぎ: お客様カルテ・契約情報・商談録画をCS担当に共有。以降の進行管理はCSが主導

⚠️ 迷惑メール回避の3原則 着席率UP

  1. リンクは1つだけ（複数リンク = 迷惑メール判定されやすい）
  2. 短縮URL使用（bitly等で短縮。生URLは文字数超過 + 迷惑メール判定リスク）
  3. 過度な記号を避ける（【】★※の多用は迷惑メールフィルターに引っかかりやすい）
