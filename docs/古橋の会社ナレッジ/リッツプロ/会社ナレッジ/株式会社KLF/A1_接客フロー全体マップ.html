💬 アイスブレイク・来院理由のヒアリング
5〜10分
最初の信頼構築フェーズ。来院経路・症状・説明の希望レベルを確認する。
✓
来院経路（Google／ホットペッパー／知人紹介）を確認
✓
症状・悩みを一言でヒアリング（腰痛？産後？むくみ？）
🔑
受け取り方の確認：「詳しく知りたい派」vs「とりあえずやってほしい派」を聞く
🔑
パターン確認（産後の場合）：産む前から決めてきた？症状が出てから来た？
スクリプト例

「なるべく詳しく知りたいか、とりあえずやってほしいか、どっちが近いですか？
あと甘口・中口・辛口でレベル感を教えてもらえると話しやすいです」

必須 信頼構築
2
📊 インボディ計測結果の説明
10〜15分
数値を使って「体の現状」を客観的に示す。感情ではなくデータで納得感を作る。
✓
3本棒グラフ：体重・筋肉・体脂肪のバランスを確認（C型チェック）
✓
体脂肪率：28%超えで「隠れ肥満」であることを伝える
✓
部位別体脂肪（Vバー）：体幹に集中しがちであることを確認
🔑
細胞外水分比（0.380基準）：むくみ・筋肉質の判定。0.380以下は優秀と伝える
⚠
数値を責めるのではなく「原因と対策が見えてよかった」という方向で伝える
必須 データ説明
3
🧠 体のメカニズム教育トーク
15〜20分
「なぜ今の状態になったのか」を仕組みで説明し、治療の必要性に自然と気づいてもらう。
✓
骨:筋肉 = 10:10 バランスの基本から説明
✓
20歳以降の筋肉低下：年1%ずつ落ちる。出産で3〜5%下がる
🔑
☆ビーフジャーキー理論：筋肉が細く・硬くなった状態。古い輪ゴムのたとえで伝える
🔑
☆サーロインステーキ現象：筋肉に脂肪が入り込んで太くなる。それでも支えられなくなり歪みへ
✓
（エステの場合）脂肪細胞は3歳で数が確定→膨らむだけ→温めて小さくできる
ビーフジャーキー説明のスクリプト

「新品の輪ゴムって引っ張ると伸びますよね？古くてカラカラになった輪ゴムを引っ張ると…そう、切れそうでしょ？
それが運動会で肉離れするおじさんの状態なんですよ」

必須 ☆核心コンテンツ
4
🦴 歪みチェック（実技）
5分
実際に患者の体を目で見て確認。理論から実感へ移行させるポイント。
✓
患者に前を向いて正座させ、膝の高さ（突出具合）を上から見る
✓
足の長さ差を患者自身に実感してもらう（手を置いて高さを比較）
🔑
連鎖の説明：足の長さ差→骨盤の傾き→肩の高さ差→荷物のかけ方のクセ まで一連で説明
🔑
WHYロジック：歪み+ビーフジャーキー→血流悪化→怪我しやすい→治りにくい の流れで危機感を作る
⚠
エステ目的の場合はSTEP4を省略 or 軽くに留める
必須（骨盤矯正） 体験→納得
5
🎯 治療方針・ゴール設定の提示
10分
患者自身がゴールを決める。「来させられてる感」をなくし自発的な継続につなげる。
🔑
3つのゴール方向：A:筋肉増強 / B:脂肪減少 / C:両方（どれを目指すか患者が選ぶ）
✓
継続パターン：短期卒業（再発しやすい）/ 中長期（再発しにくい）/ メンテナンス継続
✓
仕分けを明示：「自分でできること」vs「院でしかできないこと」を整理して伝える
⚠
こちらがゴールを押し付けないこと。患者が選んだゴールへのアドバイスをする立場
ゴール設定トークのスクリプト

「今城さんがここを目指してるのに、僕らがこっちにしてたら『来させられてる』って感じますよね。
逆に目指してるのにもういいよって言ったら『えじゃあどうすれば？』ってなっちゃう。
だから本人がどこまで行きたいか決めてもらって、それに合わせてアドバイスする形にしています」

必須 ☆継続率に直結 患者主体で

💴 料金・プランの説明
10〜15分
料金の透明性を保ちながら、会員プランへの誘導とオプションの体験を促す。
✓
基本料金の説明：初回5,600円（初診4,500円＋検査1,100円）。2回目以降は下がる
✓
会員プラン：1ヶ月18,000円 / 3ヶ月13,000円 / 1年11,000円の3択を比較して提案
🔑
当日入会割引：入会費8,000円 → 当日入会なら5,500円（本日限り）
✓
オプション（肋骨矯正・産後骨盤・EMS・Pulse）を状況に合わせて提案
⚠
保育士など職業要因がある場合は労災利用を提案（治療費がゼロになる期間がある）
必須 成約フェーズ 当日入会割引
7
🗓️ 次回予約・クロージング
5分
施術後の説明と来院頻度の目安を伝え、次回予約を確定させる。
🔑
施術後説明：「〇〇年間の人生の歴史の体が、正しい位置に戻ろうとしている」で違和感を説明
✓
来院頻度の目安：悪い時は週2〜3回→週1回→2週に1回→月1回とフェードアウト
✓
次回の日程を当日中に決める。「次回は来週の何曜日頃が合いそうですか？」と聞く
⚠
「翌日・2日後に体が少し重くなる場合がある」と先に伝えておく（不安を未然に防ぐ）
必須 継続率確保
