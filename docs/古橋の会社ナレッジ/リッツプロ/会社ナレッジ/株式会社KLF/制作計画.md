## 🔍 文字起こし分析メモ（素材整理）

### 接客の流れ（全ケース共通パターン）

```
① アイスブレイク・来院理由ヒアリング
   └ 来院経路（Google/ホットペッパー等）の確認
   └ 今日の症状・目的をヒアリング
   └ 説明の受け取り方を聞く（詳しく知りたい？vs とりあえずやってほしい？）

② インボディ計測結果の説明
   └ 筋肉・体重・体脂肪のバランス（3本の棒グラフ）
   └ C型／逆矢印型タイプの説明
   └ 細胞外水分比（0.380基準）＝むくみ・筋肉質の指標
   └ 部位別体脂肪（体幹が多い傾向）

③ 体のメカニズム説明（教育トーク）
   └ 骨:筋肉 = 10:10 バランスの話
   └ 20歳以降の筋肉低下（年1%、出産で3〜5%）
   └ ビーフジャーキー理論（筋肉が細く硬くなる）
   └ サーロインステーキ現象（筋肉に脂肪が入り込む）
   └ 脂肪細胞の仕組み（3歳で数が確定、膨らむだけ）
   └ 怪我した時のNGアドバイス（3日間は温めない・揉まない）

④ 歪みチェック（実技）
   └ 膝の高さ・足の長さチェック
   └ 骨盤が傾く→肩が上がる→痛みの連鎖を説明

⑤ 治療方針の提示
   └ 3つの方向性：筋肉をつける / 脂肪を減らす / 両方
   └ 「自分でできること」と「院でしかできないこと」の分類
   └ ゴール設定（短期卒業 / 中長期 / メンテナンス継続）

⑥ 料金・プランの説明
   └ 本日の費用の説明（初回：5,600円など）
   └ 会員プランの案内（1ヶ月/3ヶ月/1年）
   └ オプション（肋骨矯正、産後骨盤矯正、EMS、Pulse）の紹介

⑦ 次回予約・クロージング
   └ 来院頻度の目安を伝える（週1〜2回 → 隔週 → 月1）
   └ 労災・保険活用のアドバイス（保育士など職業別）
```

### KLFの強力な"言語化された比喩・フレーズ"

| フレーズ | 意味・用途 |
|---------|-----------|
| ビーフジャーキー理論 | 筋肉が細く・硬くなった状態の説明 |
| サーロインステーキ現象 | 細くなった筋肉に脂肪が入り込んだ状態 |
| 輪ゴム（新品 vs 古いもの） | 筋肉の伸縮性を例える（肉離れの説明） |
| 運動会でこける中年おじさん | 筋肉の怪我しやすさのイメージ |
| 体重56 vs 体重14 の棒グラフ | インボディのC型（逆矢印）を視覚的に説明 |
| 人生の歴史 | 患者の体の歴史を尊重する言い方（施術後説明） |
| ガソリンのない車 | タンパク質不足で筋トレしても無駄な状態 |
| 風船が膨らむ | 脂肪細胞が数は増えず膨らむ仕組みの比喩 |
| 血流を"悪く"してね | 怪我後3日間は温めず冷やす（逆説的な表現） |

## 💡 制作における注意事項

1. **文字化けについて**：文字起こしは自動生成のため固有名詞や数字に誤りあり。内容の文脈から補正して作成する
2. **話し言葉の整理**：実際のトークは関西弁ベース。スクリプト化では標準語ベースで整理するが、「味のある言い回し」は残す
3. **図解の重要性**：「絵に描いて説明」が多いため、HTMLにはSVG/CSS図解を積極活用する
4. **患者ごとのカスタマイズ**：インボディの数値は毎回変わるため、スクリプトは「型」として作成（穴埋め形式）
5. **追加録音が揃ってから**：最終精度向上は5件分揃ってから実施（現状3件分分析済み）
