### 【体のメカニズム説明】教育トーク（共通）

**骨と筋肉の基本バランス**

```
基本的に人の体って骨と筋肉で分かれてるんですね。
骨に重さの負担があれば歪みっていうものは出ない。
筋肉に重さの負担があれば、太くて柔らかいっていう状態になる。

これが健康な体なんですけど...
```

**20歳以降の筋肉低下**

```
20歳を過ぎたら、みんな疲れたの基準が「肉体疲労」から「脳疲労」に切り替わっていくんです。
子育てとか仕事とかって、どれだけ疲れても体は動かさないじゃないですか。

結果、筋肉は1年で1%ずつ落ちると言われていて、
出産すると3〜5%下がるって言われてるんですよ。
```

**ビーフジャーキー理論（☆核心コンテンツ）**

```
筋肉が落ちてくると、太かったものが細くなって、
柔らかかったものが硬くなっちゃうんです。

これを僕たちはビーフジャーキーって呼んでるんですよ。

イメージで言うと、新品の輪ゴムって引っ張ると伸びるでしょ？
古くて落ちてるような輪ゴムって引っ張るとどうなりますか？
（患者：切れそう）

そう！それが運動会で肉離れするおっちゃんみたいな状態なんです。
頭の中でははしれるイメージがあるのに、実際走ったら切れちゃうみたいな。
```

**サーロインステーキ現象（☆核心コンテンツ）**

```
筋肉が落ちて体重は増えた、ってなると、何で増えてるかわかります？
（患者：脂肪）

そう。筋肉と体脂肪で体を支えられなくなるから、
脂肪で太くしようとするんですね。
ビーフジャーキーに脂肪を足した状態を「サーロインステーキ現象」って言うんですよ。

霜降り肉みたいに、中にサシが入って太くなってる状態。
でも結局体は支えられないから、次は骨に負担がかかり始めるんです。
それが歪みなんですよ。
```

### 【治療方針の説明】WHYを使ったロジック

```
先生：この歪みがあって、筋肉がビーフジャーキー化してる状態って、
血液の流れ良さそう・悪そう、どっちだと思います？
（患者：悪そう）

じゃあこの状態でパーソナルトレーニング頑張ったら、怪我しそうですか？
（患者：しそう）

怪我した時に治りが良さそうですか？
（患者：悪そう）

だから、まず筋肉をつける前に、足の長さを揃えましょうってことが骨盤矯正です。
```

**回復の4ステップ**

```
①  歪みを取る（骨盤矯正）
②  硬くなった筋肉を柔らかくする
③  細くなった筋肉を太くする（筋肉増強）
④  維持する
```

**ゴール設定の3方向**

```
先生：治療の方向性は3つに分かれます。

A：筋肉をつける方向
   → 歪みを取って → 柔らかくして → 太くして → 維持

B：脂肪を減らす方向（ダイエット）
   → 歪みを取って → 脂肪を落として → 維持

C：両方同時に
   → 歪みを取りながら筋肉をつけつつ脂肪も減らして維持

どれを目指すかは本人が決めてください。
僕らがゴールを決めると「来させられてる感」になっちゃうので。
```

### ▶ 接客の基本7ステップ

```
STEP 1：アイスブレイク・来院経路確認
  └ Google／ホットペッパー／知人紹介など
  └ 今日の症状・悩みを一言でヒアリング

STEP 2：説明の受け取り方を確認
  └「詳しく知りたい派」vs「とりあえずやってほしい派」
  └ 甘口・中口・辛口でレベル感を合わせる

STEP 3：インボディ計測結果の解説
  └ 3本棒グラフ（C型チェック）
  └ 体脂肪率（28%基準）→ 隠れ肥満かどうか
  └ 部位別体脂肪（体幹に集中しがち）
  └ 細胞外水分比（0.380基準）→ むくみ・筋肉質の判定

STEP 4：体のメカニズム教育トーク
  └ 骨:筋肉 = 10:10 バランス
  └ 20歳以降の筋肉低下メカニズム
  └ ビーフジャーキー理論
  └ サーロインステーキ現象
  └（エステの場合）脂肪細胞の仕組み

STEP 5：歪みチェック（実技）
  └ 膝の高さで足の長さ確認
  └ 骨盤傾き→肩の高さの変化を説明
  └ 怪我しやすさ・治りにくさのWHY説明

STEP 6：治療方針とゴール設定
  └ A：筋肉増強 / B：脂肪減少 / C：両方
  └ 短期卒業 / 中長期 / メンテナンス継続
  └ 自分でできること／院でしかできないことの仕分け

STEP 7：料金・プラン案内＋次回予約
  └ 本日の費用説明（初診5,600円など）
  └ 会員プランの案内（1ヶ月/3ヶ月/1年）
  └ オプションの提案
  └ 来院頻度の目安（週2→週1→隔週→月1）
```

### 🔑 インボディを活用したFC向け完全接客トーク（小林先生実演・2026/4/22）

#### STEP 1：インボディの数値を見ながら体の状態を説明する

```
先生：インボディというデータが出るんですね。
体重・筋肉・体脂肪という3つがキロ計算で出るんです。

棒グラフを見た時に、筋肉量が一番短い棒グラフになってるじゃないですか。
→ ということは、この筋肉でこの体重と体脂肪を支えないといけないんですね。
→ 筋肉からすると100%以上の力を常に発揮してる状態なんで、
   痛みが出て当たり前なんです。

痛みが出てないなら、筋肉以上に骨に負担がかかってるから痛みが出てる人が多い。
→ 今現状、治療は必要な体というのがこのグラフでわかるんですけど...

治療して楽になっても、結局このバランスのままだとすぐ痛くなる。
治療というのはマイナスをゼロに戻すイメージなんですね。
ゼロをプラスにしたいなら、この筋肉を増やすか脂肪を減らすかが必要。
```

#### STEP 2：一般論への展開（ビーフジャーキー〜サーロインへの接続）

```
先生：人の体って基本的に骨と筋肉で分かれてるんです。
骨が10、筋肉が10の割合で支え合ってるのが基本。

20歳を過ぎると、脳疲労に切り替わる人が多くなって...
→ よく年1%ずつ筋肉が落ちると言われてます
→ 出産した人は3〜5%落ちると言われてます

筋肉が落ちてくると細く硬くなる。これが「ビーフジャーキー」。

輪ゴムの例：
新品の輪ゴム → 伸び縮みする
古くなった輪ゴム → 引っ張るとちぎれる
＝  運動会でこけるおっちゃんが肉離れするのはこの状態

○○さん、20歳と比べて体重どうですか？
（増えてる） → 筋肉が落ちてるのに体重が増えてる
→ 何が増えてるかわかりますか？脂肪ですよね。

ビーフジャーキーに脂肪がまとわりつくと「サーロインステーキ現象」
→ 筋肉の質が悪くなってる状態
→ この体重を支えきれなくなって骨に負担 → 歪みが出てくる
```

#### STEP 3：数値から「あなたの体」への接続

```
先生：この体脂肪の量が18.3kgあって、体重が58.3kgなんですけど、
→ 18.3 ÷ 58.3 = 31.3% → 28%超えると女性は「肥満」扱いになる
→ 体重は標準なのに体脂肪率が超えてる → 「隠れ肥満」

部位別脂肪でどこについてるかが見れる：
→ 体幹が**282%**ついてる
→ 重りを減らすなら体幹から減らす方が効率的
→ ここが興味あればダイエットの話もしますね、という流れで展開
```

#### STEP 4：治療ゴールを「患者が選ぶ」形に持っていく

```
先生：悩みが永続するのを防ぐには、
 A：筋肉を増やす方向
 B：脂肪を減らす方向（ダイエット）
のどちらかをしないといけない。どっちが良さそうですか？という形で方向性を決めてもらう。

次に「自分でできること」と「僕らがすること」を分類する：

歪みを取る → 自分じゃできない → 任せてください
柔らかくする → ストレッチ・お風呂・水分 → でもここは院でもできる
筋肉をつける → 筋トレ → EMS機器もある
栄養 → タンパク質 → DNA検査・プロテインも提案

→「早く終わりたかったら短期プランで卒業できる。
   ただ再発しやすい。
   再発したくないなら中長期でしっかりやっていく。
   どちらか自分で決めてください」という形で選択を渡す
```

└──────────────┴────────────┴──────────────────────┘
