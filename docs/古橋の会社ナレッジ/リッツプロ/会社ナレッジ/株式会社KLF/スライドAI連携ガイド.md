```
目的：
  スタッフが小林先生と同じ成約率（目標80%）を出せるようにするための
  「接客説明図スライド」を作成する

  - 新人スタッフのオンボーディング

  - KLFの施術スタッフ（新人・既存）
  - 将来のFC加盟店スタッフ

スライド枚数の目安：
  30〜35枚（6章 × 各4〜6枚）
```

## ■ 全体構成（6章の流れ）

```
第1章：骨と筋肉のバランス崩壊の仕組み（5枚）
  - 理想の10:10バランス
  - 10:4への変化と痛みの原因
  - InBodyのC型パターン
  - 手書きで描く方法のポイント
  - 接客トリガーのセリフ例

第2章：筋肉劣化の3段階（5枚）
  - 健康な状態（太く・柔らかい）
  - ビーフジャーキー化（細く・硬い）
  - サーロインステーキ現象（脂肪まとわりつき）
  - 輪ゴムの比喩でわかりやすく
  - 劣化連鎖を患者に説明する3ステップ

第3章：年齢・出産による筋肉低下（4枚）
  - 20歳の壁（肉体疲労→脳疲労への移行）
  - 年1%の低下・出産3〜5%の数値
  - 患者の共感を引き出す確認トーク
  - InBodyの数値と紐づける方法

第4章：回復の4ステップ（6枚）
  - ①歪みを取る / ②柔らかくする / ③太くする / ④維持
  - ゴール3方向（A:筋肉 / B:脂肪 / C:両方）
  - 「患者が選ぶ」ゴール設計のセリフ
  - +¥3,300 産後骨盤矯正の追加提案

第5章：自分でできること vs 院でしかできないこと（5枚）
  - 4項目の分類表（歪み・柔らかく・太く・栄養）
  - 「歪みは自分じゃできない」のセリフ
  - ゴールのすり替え戦略（継続率の秘密）
  - 頻度を落としながら継続させる設計

第6章：怪我の豆知識（4枚）
  - 急性期のNG3つ（温める・お酒・確認行動）
  - 院に来てからの流れ
  - InBody270 FC必須機器の説明
  - まとめ・次のアクション
```

## ■ デザイン指定（必ず守ること）

```
カラーパレット：
  メイン    : ティール   #0B6E4F（信頼・健康のイメージ）
  アクセント : アンバー   #D97706（行動・注意喚起）
  警告      : レッド     #DC2626（NG・危険・悪化）
  ベース    : ライトグレー #F1F5F2
  テキスト  : ダークネイビー #1E293B

フォント：
  日本語   : Noto Sans JP（Bold / Regular）
  数字・英語: Inter（Black / Bold）

スライドサイズ：
  16:9（ワイドスクリーン）Canva標準

デザインルール：
  - 比較・対比を多用する（良い状態 vs 悪い状態）
  - 数字は大きくドン！と見せる（体脂肪率・年1%など）
  - 絵・図解を中心に、テキストは補足として小さく
  - 「手書き風」のアイコンや丸・矢印を活用
  - スライド1枚に情報を詰め込まない
  - 「スタッフが接客中に思い出せる」シンプルさを優先
  - 各章の最後に「接客トリガー（セリフ例）」を1枚入れる
  - 背景色はほぼホワイト・薄いミント系（清潔感）
```

## ■ スライドAIへの依頼文テンプレート

```
以下の情報をもとに、KLFスタッフ向け接客マニュアルのスライドを作成してください。

【目的】
スタッフが小林先生（成約率90%）のトークを再現できる研修スライドを作る。
InBodyを使った体の説明から、ゴール提案・プラン設計まで一貫した接客フローを
スライド化する。

【必読ファイル】
1. スライドAI連携ガイド.md（デザイン指定・数値・セリフ一覧）
2. A0_接客図解マップ.html（6章の全コンテンツ・図解・接客トリガー）
3. 営業データベース.md（詳細な営業ロジック・患者タイプ別対応）

【デザイン指定】
- カラー：ティール #0B6E4F × アンバー #D97706 × ホワイト
- フォント：Noto Sans JP / Inter
- サイズ：16:9（Canvaワイドスクリーン）
- スライド総数：30〜35枚（6章構成）

【重要なポイント】
- 「ビーフジャーキー」「サーロインステーキ」「輪ゴム」の比喩を必ずビジュアル化
- 各章の最後に「接客トリガー（セリフ例）」のスライドを入れる
- 図解は手書き風・シンプルに（患者に描いて見せる図のデジタル版）
- 良い状態（緑）vs 悪い状態（赤）の対比を徹底する
- スタッフが「このスライドを見れば接客できる」レベルを目指す
```
