# Valoom FC事業 — オファー内容変更まとめ

**作成日**: 2026年3月19日

---

## 変更の全体像

従来モデル（加盟金300万円） → スタートアップ支援型（2月3日〜） → 価格緩和（3月4日〜）

---

## 1. 従来モデル（〜2月2日）

| 項目 | 内容 |
|------|------|
| 加盟金 | 300万円 |
| ロイヤリティ | シャンプー台1台あたりの固定費 |
| 運営 | 加盟店が自主運営 |
| 契約形態 | 通常FC加盟 |

【課題】
セミナーに人は集まるが成約しない。「集客できるか」「求人できるか」「収益化できるか」という未知のリスクを過大評価されていた。

---

## 2. スタートアップ支援型モデル（2月3日〜）

浦郷さん主導で提案された最大の転換点。コンセプトが「FC加盟」→「協業パートナーシップ」へ変更。

### 変更点サマリ

| 項目 | 従来 | 変更後 |
|------|------|--------|
| 運営主体 | 加盟店 | 本部が1年間運営（HQ主導） |
| 契約形態 | FC加盟 | 協業モデル（共同経営） |
| 加盟金 | 300万円 | 300万円（うち保証金150〜300万円） |
| ロイヤリティ | 固定費/台 | 売上の%（1年目13%→4年目10%） |
| オーナー配分 | 全売上 | 使用期間中は売上の10% |
| 撤退条件 | なし | 稼働率10%未満が4ヶ月連続で双方撤退 |
| 引き継ぎ条件 | - | 稼働率40%達成で事業引き継ぎ |

### 保証金モデル（リッツプロ提案 → 2/4合意）

| パターン | 加盟金 | 保証金 | 失敗時の最終収支 |
|----------|--------|--------|-----------------|
| A（当初案） | 300万円 | 150万円 | -85〜138万円（赤字） |
| B（推奨案） | 300万円 | 300万円（全額） | +12〜65万円（黒字） |

→ パターンBなら「どっちに転んでもオーナーは黒字」。「やるかやらないか」→「いつやるか」の提案に変わる。

### ロイヤリティ変更（固定費→売上連動）

| 年次 | 料率 | 年間売上800万の場合 |
|------|------|-------------------|
| 1年目 | 13% | 104万円 |
| 2年目 | 12% | 96万円 |
| 3年目 | 11% | 88万円 |
| 4年目〜 | 10% | 80万円 |

長く継続するほど引かれる額が少なくなる設計。3年更新契約なので2期目継続のインセンティブにもなっている。

### セミナーフローの変更

| 従来 | 変更後 |
|------|--------|
| 一括説明 → 全員にQ&A | セミナー途中で関心のない方を離脱させる |
| 情報収集層とガチ層が混在 | 本気度の高い人だけに特別プランを提示 |
| 検討期限なし | 3週間以内の決断を条件 |

## 3. 価格緩和（3月4日〜）

既存リードの成約率を上げるため、加盟金自体を引き下げる方針に変更。

### 加盟金の段階設定

| ステージ | 加盟金 | 適用条件 |
|----------|--------|----------|
| 0次募集 | 100万円 | 最初の5店舗まで（実績構築フェーズ） |
| 1件目 | 150万円〜 | 資金面で悩む場合の最低ライン |
| 特別価格 | 200万円 | 3週間以内の契約限定 |
| 通常価格 | 300万円 | 実績確立後の標準価格 |

【背景】
- 美容室オーナーの利益率は3〜5%で、300万円一括は心理的ハードル大
- まず1件目の契約獲得を最優先し、実績を作る戦略
- 夜間帯だけで年間約300万円の固定利益が見込める → やらないデメリットの方が大きいことを数値で伝える

## オーナー視点の収支比較（現行オファー）

### 成功ケース（稼働率40%以上）

| 項目 | 0次（100万） | 特別（200万） | 通常（300万） |
|------|-------------|-------------|-------------|
| 加盟金 | -100万 | -200万 | -300万 |
| 初期費用 | -15万 | -15万 | -15万 |
| 使用期間中配分 | +80万 | +80万 | +80万 |
| 1年目実質支出 | -35万 | -135万 | -235万 |
| 2年目以降月次利益 | 30〜40万 | 30〜40万 | 30〜40万 |
| 黒字転換 | 2ヶ月目 | 5ヶ月目 | 9ヶ月目 |

### 失敗ケース（保証金全額返金の場合）

| 項目 | 保証金100万 | 保証金200万 | 保証金300万 |
|------|-----------|-----------|-----------|
| 加盟金 | -100万 | -200万 | -300万 |
| 配分（1年） | +80万 | +80万 | +80万 |
| 保証金返金 | +100万 | +200万 | +300万 |
| 最終収支 | +80万 | +80万 | +80万 |

→ 保証金全額返金モデルなら、どの価格帯でもオーナーは黒字で終われる。

## セミナーでの伝え方ポイント

【従来の訴求】
「300万円で加盟してください。成功すれば年間300万円の利益です」

【現在の訴求】
「私たちが1年間すべて運営します。うまくいけばそのまま引き継ぎ。万が一うまくいかなければ保証金は全額お返しします。どちらに転んでもあなたは損しません」

【キーメッセージ】
1. 値引きではなく、リスクの所在を変えた — オーナーのリスクを本部が肩代わり
2. テスト期間である — いきなり本契約ではなく、1年間の使用期間
3. 本部が自信を持っている証拠 — 全額返金できるのは勝てる自信があるから
4. やらないことのデメリット — 夜間帯の機会損失は年間300万円
