# ミーティング議事録

**日時：** 2026年3月4日  
**参加者：** 浦郷様（株式会社マインド）、古橋、髙柳  
**議題：** Valoom事業 3月度進捗共有・営業戦略の見直し

---

## 1. 営業進捗の共有

### 見込み顧客：北村様
- 技術面での確認を希望しており、**一度施術を体験した上でスタッフと共に導入判断したい**という意向
- 体験には2枠必要だが調整が難しいため、**1名ずつ時間をずらして対応**する方向で再提案する
- 日程調整の結果、体験は**4月にずれ込む可能性**あり → 前後の空き時間で調整を試みる

## 2. 広告の状況

- 現在、広告は**一時停止中**
  - セミナー予約が入らない状態が続いていた
  - 残りの広告消化金額は**約20万円**
- ターゲティング・キャンペーンを立て直してから再開予定
- 広告費が尽きた段階で改めて相談し、**30〜50万円程度の予算**を契約金から補填して再投下する方針

## 3. セミナー・提案内容の改善状況

### 改善後の変化（髙柳より報告）
- 提案内容の変更後、以前の課題（集客・採用面のネガティブ反応）は**ほぼ解消**
- 現在は**より現実的な質問・課題**が中心になっている
  - 営業時間の調整
  - 利益面の懸念
  - 実績不足への不安

### 残課題：セミナー参加者の温度差
- 「モデルを知りたいだけ」の情報収集層と「本気で導入したい」層のギャップが大きい
- ネガティブな質問がセミナー内で共感を呼び、全体の温度感が下がるケースがある

### 浦郷様からの提案
- セミナー途中で**関心のない方を離脱させるフロー**を設け、本気度の高い人だけに提案を続ける構成にする
- ビジネスモデル調査目的の質問と、加盟前提の真剣な質問は**種類が違う** → 分けて対応すべき

## 4. よくある質問・懸念への対応策

セミナーで頻出する質問トップ3（髙柳共有）：

| # | 質問内容 | 対応方針（浦郷様回答） |
|---|---------|-------------------|
| 1 | **トラブル時の対応**（鍵・お湯・シャンプー台の設備不具合など） | 協業モデル＝共同経営なので、オーナー側にも当事者意識を持ってもらう |
| 2 | **時間の問題**（カラーが遅れて18:30に間に合わない等） | 厳密に線引きはできないが、最初の15分程度の被りは許容。シャンプー台移動後は照明・音楽を切り替え、Valoom側の空間に完全移行 |
| 3 | **営業日の柔軟性**（休みの設定など） | サロンの定休日に合わせて提供日を設定。営業時間の後ろ倒しもOKだが、稼働率低下＝加盟店の利益減となるだけで本部リスクはない |

### 本部での実例共有（浦郷様より）
- 火曜日に夜間スタッフの**無断欠勤トラブル**が発生 → 該当スタッフは解雇済み
- 対策として**4月から火曜は定休日に変更**し、昼間にサロン営業がある日のみ夜間を提供する体制へ
- **基本は3回転のビジネスモデル**であり、連日2回転では利益率が低すぎる

## 5. 加盟金・条件の緩和について

### 浦郷様提案の特別オファー
- **3週間以内に契約まで進む方限定で、加盟金を大幅に引き下げ**
- 通常300万円 → **200万円で提案**、資金が理由で悩む場合は**最低150万円まで交渉可**
- まず**1件目は150万円でも契約を優先**し、2件目以降は200万円で通す方針

### 背景
- 美容室オーナーの利益率は3〜5%程度で、300万円の一括投資はハードルが高い
- 夜間帯だけで**年間約300万円の固定利益**が見込めるため、やらないデメリットの方が大きいことを数値で伝える
- 夜間帯の売上実態を知らないオーナーが多い → 「実際に数字で比較してください」という教育が必要

## 6. 具体的アクションプラン

### 既存リードへの再アプローチ
| 対象 | 状況 | アクション |
|------|------|-----------|
| **北村様** | 体験希望、日程調整中 | 1名ずつの体験枠で再提案、できれば3月中に実施 |
| **横浜の複数店舗サロン**（共同経営2名） | 前向きだが実績不安・資金面がネック | 加盟金引き下げ（200万→150万）で再提案 |
| **資金NG済みサロン** | 300万円で断念 | 新条件（200万/150万）でショートメッセージにて再アプローチ |
| **過去に意欲はあったが調整不可だったサロン** | スタッフが業務委託で営業時間を削れなかった | 直営モデルなら柔軟に対応可能と再提案 |
| **髙柳の元MTGメーカー時代の繋がりのサロン** | ReFa導入済み、関係構築済み | 新条件で提案予定 |

### セールスフローの改善
1. **セミナー（加盟説明会）** を実施
2. 関心のある方のみ残し、**3週間以内の決断を条件**として次の提案へ
3. 加盟金を引き下げた**特別プラン**を提示
4. **体験日をその場で決定**（ホットペッパービューティーで空き枠を確認）
5. 体験 → 申込 → 審査 → 契約

### LP改修
- 現在のLPは FC（フランチャイズ）モデル訴求のまま → **直営モデルの強みやリスクゼロ訴求**を反映した改修が必要
- 「黒字で追われるフランチャイズの始め方」等のフックを検討
