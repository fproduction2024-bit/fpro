# 本部運営収益モデル分析
## 使用期間中の店舗運営で本部はいくら儲けるか

**作成日**: 2026年2月3日  
**視点**: 店舗運営ビジネスとしての本部収益性分析

---

## 💡 ビジネスモデルの本質

このスタートアップ支援型FCモデルは、実質的に：

> **「本部が1年間、加盟店の場所を借りて店舗運営する代行ビジネス」**

- 加盟店から場所を借りる対価：売上の10%
- 本部の取り分：売上の90%
- 広告費・人件費・採用費等は本部負担
- リスクも本部が背負う代わりに、**利益の大部分も本部が取る**

## 📊 1店舗あたりの運営収支（1年間）

### 収益構造

| 項目 | 金額 | 備考 |
|------|------|------|
| **年間売上** | 800万円 | シャンプー台2台、稼働率55-60% |
| オーナーへの配分（10%） | -80万円 | 場所代的な意味合い |
| **本部の粗利** | **720万円** | 売上の90% |

### コスト構造

| 項目 | 金額 | 備考 |
|------|------|------|
| 人件費（スタッフ2名） | 360万円 | 月15万×2名×12ヶ月 |
| 広告費（集客） | 120万円 | 月10万×12ヶ月 |
| 材料費・消耗品 | 80万円 | 売上の10% |
| 研修・管理費 | 40万円 | 初期研修含む |
| その他運営費 | 40万円 | 予備費等 |
| **総コスト** | **640万円** |  |

### 1店舗の運営純利益

```
粗利 720万円 - コスト 640万円 = 純利益 80万円/年
```

**月あたり純利益**: 約6.7万円/店舗

## 💡 運営収益最大化の戦略的ポイント

### 1. 早期フル稼働が重要

10店舗フル稼働時の月次運営収益：**67万円**

- 1ヶ月早くフル稼働 → +67万円
- 3.5ヶ月早くフル稼働 → **+235万円**

→ パターンBの成約率向上が直接的に運営収益増に貢献

### 2. 運営効率の向上

10店舗同時運営により：
- スタッフの掛け持ち配置が可能
- 広告費の効率化（エリア集中）
- 研修の一括実施

→ **実際のコストは想定より10-15%削減可能**

### 3. スケールメリット

| 運営店舗数 | 月次純利益 | 改善率 |
|-----------|-----------|--------|
| 1-3店舗 | 5万円/店 | - |
| 4-7店舗 | 6万円/店 | +20% |
| 8-10店舗 | **7万円/店** | **+40%** |

→ 早期に10店舗達成することで、運営効率が向上

## ✅ 結論：運営収益の視点から

### 🏆 パターンBが圧倒的に有利

**運営収益面での優位性:**

1. ✅ **運営期間中の収益が+80万円多い**
2. ✅ **10店舗フル稼働が3.5ヶ月早い**
3. ✅ **早期キャッシュフロー確保**（3ヶ月で+1,100万円）
4. ✅ **総純利益が+350万円多い**

### 運営ビジネスとしての本質

このモデルは：
- **FC加盟金ビジネス**（一時的収益）
- **店舗運営ビジネス**（継続的収益）
- **ロイヤリティビジネス**（引継後の継続収益）

の**三層構造**

パターンBは三層すべてで優位性があり、特に：
- 運営期間が長く取れる → 運営収益↑
- 早期に実績を作れる → 次の加盟店獲得が加速
- キャッシュフローが早期に確保できる → 再投資可能
