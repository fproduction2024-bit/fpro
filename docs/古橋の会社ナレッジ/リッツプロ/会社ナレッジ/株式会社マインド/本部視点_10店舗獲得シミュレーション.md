# 本部視点：10店舗獲得シミュレーション

**作成日**: 2026年2月3日  
**目的**: 保証金50%（150万円）vs 100%（300万円）モデルでの本部収益比較

---

## 📊 前提条件と仮定

### 共通条件
- **目標**: 10店舗の契約獲得
- **運営期間**: 1年間（使用期間）
- **本部の運営コスト**: 1店舗あたり約150万円（広告費・人件費・採用費等）
- **成功時の本部収益**: 加盟金300万 + 研修費60万 = 360万円
- **失敗時の本部損失**: 運営コストから売上配分を差し引いた額

### 成約率の仮定

会議の文字起こしから推測される成約率：

| モデル | 成約率 | 根拠 |
|--------|--------|------|
| **パターンA（150万保証）** | **20%** | リスクが残るため心理的ハードルあり |
| **パターンB（300万保証）** | **50%** | 「やらない理由がない」状態になる |

### 成功率の仮定

フルハシ氏の分析「返金リスクはほぼゼロ」を考慮：

- **稼働率40%達成（成功）**: 90%
- **稼働率40%未達（失敗・返金）**: 10%

|------|------|

| 保証金返金 | 0円（条件達成） |
| 運営コスト | -150万円 × 9店舗 = -1,350万円 |
| **小計** | **1,890万円** |

**失敗ケース（1店舗 = 10%）**

| 項目 | 金額 |
|------|------|
| 加盟金収入 | 300万円 × 1店舗 = 300万円 |
| 保証金返金 | -150万円 × 1店舗 = -150万円 |
| 売上配分（1年分） | 80万円 × 1店舗 = 80万円 |
| 運営コスト | -150万円 × 1店舗 = -150万円 |
| **小計** | **80万円** |

### パターンA 総収益

| 項目 | 金額 |
|------|------|
| 成功9店舗の収益 | 1,890万円 |

## 💡 重要な洞察

### 1. 広告費削減効果が圧倒的

成約率が2.5倍になることで：
- 必要な説明会参加者が **167名 → 67名（-60%）**
- 広告費が **500万円 → 200万円（-60%）**
- その他営業コストも削減（高柳氏の稼働削減）

### 2. 返金リスクは実質的に小さい

- 失敗1店舗での返金差額は **150万円**
- しかし広告費削減効果は **300万円**
- **返金リスクの2倍の広告費削減効果**

### 3. 投資効率（ROI）が劇的に向上

- パターンA: 181%
- パターンB: **550%（+369%）**

少ない投資で大きなリターンを得られる

### 4. 達成スピードが向上

- パターンA: 50件の個別相談が必要 → 約**6ヶ月**
- パターンB: 20件の個別相談で達成 → 約**2.5ヶ月** ⚡

**早期に実績を作れる** → ブランディング効果でさらに成約率UP

## ✅ 結論と推奨

### 🏆 パターンB（300万円全額保証）を強く推奨

**理由:**

1. ✅ **純利益が270万円多い**（+21%）
2. ✅ **ROI が3倍以上**（181% → 550%）
3. ✅ **広告費が300万円削減**
4. ✅ **達成スピードが2倍以上速い**（6ヶ月 → 2.5ヶ月）
5. ✅ **営業チームの負荷が大幅軽減**
6. ✅ **最悪シナリオでもパターンAと同等以上**

### 返金リスクについて

- 返金リスクの増加（150万円/店）より
- 広告費削減効果（300万円）の方が**2倍大きい**
- フルハシ氏の分析通り、実際の返金確率は極めて低い

### ブランディング効果（定性的メリット）

- 「絶対的な自信」を示せる
- 口コミ・紹介が発生しやすくなる
- 2巡目以降はさらに成約率向上が期待できる
