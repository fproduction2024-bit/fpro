伴走型FC事業支援
プロデュース業務委託契約書

株式会社リッツ・PRO（以下、甲とする）と、株式会社三十九（以下、乙とする）とは、乙のFC事業及びM&A支援を目的として経営、本部構築、加盟店開発に関する指導・助言及びマーケティング活動全般における業務委託契約を締結する。

第１条（契約の内容）

  1. 甲は、乙のFC事業及びM&A支援を目的としてプロデュース業務を請け負う。
  2. 本契約は成果を保証するものではないことを相互に確認する。

第２条（業務内容）

  1. 甲は乙へ必要に応じて以下の業務を行う。
    1. フランチャイズシステムの構築と管理
    2. ブランド開発と管理
    3. 経営支援と指導及び助言
    4. ターゲット市場の調査と分析
    5. FC市場調査と競合分析
    6. フランチャイズパッケージの作成
    7. PR活動（プレスリリース、メディア取材等）の支援及び実行
    8. フランチャイズ募集人員、及び本部人員の編成の代行、指導及び助言
    9. 活動全般における状況分析と改善
    10. マニュアル作成の支援
    11. ブランディング戦略の立案及び実行
    12. フランチャイジー募集用資料の作成及び制作
    13. 株式売却戦略の立案及び支援
  2. 乙は甲の業務遂行にあたり必要な以下の業務を行う。
    1. 商品提供、及び作成
    2. マニュアル作成を含むFC本部構築のために必要なヒアリングの協力
    3. 本件業務の進捗状況その他甲が定める事項の報告
    4. セミナー及び加盟説明会の実施
    5. フランチャイズ本部の運営
    6. 品質管理を含むフランチャイジーのモニタリング業務
    7. フランチャイジーへのサポート業務

第３条（支払い）

  1. 甲と乙は、成果報酬型により、報酬を分け合うこととする。
  2. 甲と乙の成果報酬の利益配分の計算は、甲によって実施されたマーケティング活動によって発生した売上から経費を除いた分を甲と乙とで、甲が７０％、乙が３０％の比率で分け合うものとする。なお、本契約における経費の定義は別途甲乙間で協議のもと決定する。
  3. 報酬の支払は、売上が着金した月を起算点として、翌月１５日までに乙が甲の指定する口座に振込を行う。
  4. 乙は本業務の契約金２００万円（税別）を甲の指定した口座に支払うものとする。
  5. 契約金の支払いは、以下のとおり２回に分割して行うものとする。
    1. 第１回：２０２６年３月５日までに１００万円（税別）
    2. 第２回：２０２６年４月５日までに１００万円（税別）
  6. 支払い済みの契約金に関しては甲の都合によって契約が履行できない状況が発生した場合には速やかに全額を返金することとする。

第４条（経費計上）

  1. 甲乙協議の上、甲が立替て支払った経費に関して、本契約において発生した利益分より立替精算を行うものとする。
  2. 甲の立替経費については、毎月月末締め翌月末精算を行う。
  3. 甲の立替精算は、請求書および領収書の写しを証憑とする。

第５条（著作権・利用権・パートナー関係の保護）

甲が、本業務の提供の一環として、作成又は乙に提供する資料、報告書、マーケティングノウハウ、マーケティングファネルを含む全ての情報データ・物理的化体物に関する著作権、著作隣接権その他一切の知的財産権（著作権法第２７条及び第２８条に関する権利も含む。）は、甲に帰属する。

第６条（再委託）

  1. 甲は、本件業務の履行上必要な場合は、本件業務の全部または一部を第三者に再委託することができるものとする。
  2. 甲は、前項の再委託をする場合、甲の責任において再委託先に対し本契約の定めを遵守させるものとする。

第７条（秘密保持）

  1. 甲及び乙は、互いに本契約に基づき知り得た相手方が秘密と指定する情報、ならびに本件に関する情報の秘密保持を徹底しなければならない。ただしこの情報が次の各号の一に該当するものは、秘密保持義務の対象から除外する。
    1. 開示または提供された当事者が秘密保持義務を負うことなく開示時点で既に保有している情報。
    2. 開示または提供された当事者が秘密保持義務を負ってはいない第三者から合法的に入手した情報。
    3. 開示または提供された当事者が独自に制作した情報。
    4. 開示または提供された当事者が本契約の秘密保持義務に違反することなく入手した情報。
    5. 開示または提供された当事者の責任に帰することなく公知となった情報。
    6. 開示または提供された当事者から秘密保持義務を負うことなく開示または提供された情報。
    7. 法律の定めにより、開示を要求された情報。
  2. 甲及び乙は本契約における秘密情報を、本契約に関係する人員にのみ開示が可能であり、それ以外への開示は一切行わない。
  3. 本契約における秘密事項は、甲の提供するノウハウ、情報、その他甲の行う全てのマーケティング業務がそれにあたる。
  4. 本契約における秘密保持は、本契約終了後も当然に存続することに同意する。

第８条（契約解除）

甲及び乙は、次の事由があった場合は、一方当事者が他方当事者に催告したのち、10日を経過しても是正されなかった場合には本契約を解除することができる。なお、この解除は損害賠償の請求を妨げない。

  1. 本契約に違反したとき。
  2. 手形、小切手を不渡にする等支払停止の状態に陥ったとき。
  3. 仮差押え、差押え、仮処分、競売等の申立てを受けたとき。
  4. 破産、民事再生、会社更生、特別清算等の手続き申立てを受けたとき、または自ら申立てをしたとき。
  5. 公租公課の滞納処分を受けたとき。
  6. その他各号に類する不信用な事実があるとき。

第９条（契約期間）

本契約の有効期間は、本契約締結の日から２４ヶ月間とする。また、本契約期間終了の４ヶ月前までに甲乙いずれから書面による廃棄の通告がない時は、本契約と同一条件で自動的に更新し、以後も同様とする。

第１０条（損害賠償・免責）

  1. 甲及び乙は、本契約を忠実に遂行し、本契約の違反が発覚した場合、推定される年間の営業利益（想定される売上から３０％の広告換算費用を差し引いた金額）を損害賠償金額として相手方に速やかに支払う。
  2. 本業務は甲が乙のマーケティング活動を支援する目的で履行されるものであり、甲は商品提供、商品販売、及びその他生じた損害責任はいかなる場合も負わないこととする。
  3. 甲及び乙は、本契約に基づく支払いを遅滞した場合、遅滞金額に対し年間１４.６％の遅延損害金を支払うものとする。

第１１条（不可抗力）

  1. 本契約上の義務が、以下に定める不可抗力に起因して遅滞もしくは不履行となったときは、甲乙双方本契約の違反とせず、その責を追わないものとする。
    1. 自然災害
    2. 戦争、内乱、暴動、革命および国家の分裂
    3. ストライキおよび労働紛議
    4. 火災および爆発
    5. 伝染病
    6. 政府機関による法改正
    7. その他前各号に準ずる非常事態
  2. 前項の事態が発生したときは、被害に遭った当事者は、相手方にただちに不可抗力の発生の旨を伝え、予想される継続期間を通知しなければならない。
  3. 不可抗力が90日以上継続した場合は、甲および乙は、相手方に対する書面による通知にて本契約を解除することができる。

第１２条（反社会的勢力の排除）

  1. 本契約において、「反社会的勢力」とは、以下のいずれかに該当する者をいう。
    1. 暴力団、暴力団員又は暴力団員でなくなったときから5年を経過しないもの
    2. 暴力団準構成員
    3. 暴力団関係企業
    4. 総会屋
    5. 社会運動標ぼうゴロ
    6. 政治活動標ぼうゴロ
    7. 特殊知能暴力集団
    8. その他前各号に準じる、暴力的な要求行為、法的な責任を超えた不当な要求行為を行う勢力
  2. 甲及び乙は、現在又は将来にわたって、自らが反社会的勢力に該当せず、かつ、反社会的勢力と次の各号のいずれにも該当する関係がないことを相互に表明し、保証する。
    1. その代表者、役員、支配人その他重要な従業者又は経営を実質的に支配する者が反社会的勢力又はその構成員に該当しないこと
    2. 反社会的勢力が経営を支配しているか実質的に関与していると認められる関係
    3. 自己、自社若しくは第三者の不正の利益を図る目的又は第三者に損害を加える目的をもってするなど、不当に反社会的勢力を利用していると認められる関係
    4. 反社会的勢力に対して資金等を提供し、又は便宜を供与するなどの関与をしていると認められる関係
    5. 反社会的勢力との社会的に非難されるべき関係
  3. 甲及び乙は、現在又は将来にわたって、次の各号に該当する行為を自ら行わず、かつ、第三者に行わさせないこととする。
    1. 暴力的な要求行為
    2. 法的な責任を超えた不当な要求行為
    3. 取引に関して、脅迫的な言動をし、又は暴力を用いる行為
    4. 風説を流布し、偽計若しくは威力を用いて相手方の信用を毀損し、又は相手方の業務を妨害する行為
    5. その他前各号に準ずる行為
  4. 甲及び乙は、相手方が第2項又は前項に違反したとき、何らの催告を要することなく直ちに本契約を解除することができる。この場合、契約を解除した当事者は、相手方に対し、何らの損害を賠償する責を負わず、また、相手方は、契約を解除した当事者が被った一切の損害（合理的な弁護士費用を含むがこれに限られない。）を賠償しなければならない。
  5. 甲又は乙は、自己の取引先等が、反社会的勢力又は第2項各号のいずれかに該当することが判明した場合は、契約の解除その他の必要な措置をとらなければならない。

第１３条（利反行為の禁止）

  1. 甲は、誠実に本業務を遂行し、乙は、本契約の目的または本契約に基づく当事者の義務に反する行為（以下、「利反行為」）を行ってはならないものとします。
  2. 具体的な禁止行為
    利反行為には、但これに限らず、以下のような行為が含まれます。
    1. 当事者の一方が、他方の事業活動を不当に妨害する行為
    2. 当事者の一方が、他方に対する義務を怠り、それによって他方の利益を損なう行為
    3. 当事者の一方が、第三者との不正な取引によって他方の利益を損なう行為
  3. 本条に違反した場合、違反した当事者は、違反によって他方に生じた全ての損害に対して責任を負い、利反行為が確認された場合、被害を受けた当事者は、何らの通知や催告を要せずに、即時に本契約を終了することができるものとします。

第１４条（競業避止の同意）

甲は、乙の利益を最大化させる目的で本業務を請け負い、乙は、本契約中、及び本契約終了後、２年間は本業務と競合する事業に従事すること、または甲と競合する第三者と協力することをしないことに同意する。ただし、甲の契約違反によって本契約が解除された場合、乙は当然に競業避止義務を負わない。

第１５条（準拠法）

本契約は日本法を準拠法とし、これに従い解釈されるものとする。

第１６条（協議及び合意管轄）

本契約に定めなき事項または本契約の解釈に関し疑義ある事項に関しては、甲及び乙は誠意をもって協議のうえ解決する。本契約に関する一切の紛争については、大阪地方裁判所を第一審の専属的合意管轄裁判所とする。

第１７条（個人による契約引継ぎ保証）

  1. 甲の代表取締役である古橋寛（以下、「丙」という。）は、甲が破産手続開始決定、特別清算開始命令、民事再生手続開始決定、会社更生手続開始決定その他法的倒産手続（以下、「倒産手続等」という。）の対象となったことにより、甲が本契約に基づく業務を履行することが不可能又は著しく困難となった場合、丙が個人として本契約に基づく甲の義務を引き継ぎ、乙に対して誠実に履行する責任を負うものとする。
  2. 前項における引継ぎの範囲は、本契約の第２条に定める業務内容の全部とし、丙は甲と同一の条件にて業務を遂行するものとする。
  3. 丙は、甲に倒産手続等の申立てがなされた事実を知った場合、速やかに乙に対して書面にて通知を行い、業務の引継ぎに必要な手続を遅滞なく開始するものとする。
  4. 丙が本条に基づき業務を引き継いだ場合、本契約における甲の権利及び義務は、丙に承継されるものとし、本契約の他の条項は引き続き有効に存続するものとする。ただし、成果報酬その他の金銭的条件については、丙と乙の間で別途協議の上、合理的な範囲で変更することができるものとする。
  5. 丙は、本条に基づく義務を履行するために必要な能力、知識及び経験を有していることを乙に対して表明し、保証する。
