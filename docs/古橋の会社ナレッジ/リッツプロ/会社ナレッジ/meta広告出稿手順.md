# Meta広告をゼロから出稿する手順

## 1. 事前準備

### アカウント作成
1. **Facebookビジネスマネージャ**にアクセス → [business.facebook.com](https://business.facebook.com)
2. 「アカウントを作成」→ ビジネス名・名前・メールアドレスを入力
3. メール認証を完了

### 広告アカウントの設定
1. ビジネスマネージャ左メニュー →「ビジネス設定」
2. 「アカウント」→「広告アカウント」→「追加」→「新しい広告アカウントを作成」
3. **支払い方法**を設定（クレジットカード推奨）
4. タイムゾーン：**Asia/Tokyo**、通貨：**JPY** を選択

### Metaピクセルの設置（重要）

> ピクセル＝Metaが「誰がサイトに来たか」「何をしたか」を追跡する計測タグ。
> これがないと広告の効果測定・最適化ができないので、**最優先で設置する**。

#### Step 1: ピクセルを作成する
1. [ビジネスマネージャ](https://business.facebook.com) にログイン
2. 左メニュー「**ビジネス設定**」をクリック
3. 左サイドバー →「**データソース**」→「**ピクセル**」
4. 「**追加**」ボタンをクリック
5. ピクセル名を入力（例：`リサ広告ピクセル`）→「作成」
6. **ピクセルIDが発行される**（16桁の数字） → メモしておく

#### Step 2: ピクセルコードを取得する
1. 作成したピクセルを選択 →「**設定を続行**」
2. インストール方法を聞かれるので「**コードを手動でインストール**」を選択
3. 以下のようなコードが表示される：

```html

<script>
```

4. 「**コードをコピー**」をクリック

#### Step 3: LP/サイトにコードを貼り付ける

**貼る場所：`<head>` タグの中（`</head>` の直前が推奨）**

| サイトの種類 | 貼り方 |
|---|---|
| **WordPress** | 「設定」→「ヘッダーコード挿入」またはプラグイン「Insert Headers and Footers」を使用 |
| **ペライチ** | ページ設定 →「タグ埋め込み」→ headタグ内に貼付 |
| **自作HTML** | `index.html` の `<head>〜</head>` 内に直接貼付 |
| **Wix** | マーケティング統合 → Facebook Pixel を選択してID入力 |
| **LP作成ツール全般** | 「カスタムコード」「トラッキングコード」等のメニューから設置 |

> ⚠️ **全ページに設置する**のが基本。LPが1枚だけならそのページだけでOK

#### Step 4: ピクセルの動作を確認する

**方法①: Meta Pixel Helper（Chrome拡張）**
1. Chromeウェブストアで「**Meta Pixel Helper**」を検索 → インストール
2. ピクセルを設置したページにアクセス
3. ブラウザ右上の Pixel Helper アイコンをクリック
4. ✅ 緑色で「**PageView**」と表示されれば正常に動作中
5. ❌ 赤やエラーが出ている場合 → コードの貼り付け位置を確認

**方法②: イベントマネージャで確認**
1. [イベントマネージャ](https://business.facebook.com/events_manager) にアクセス
2. 作成したピクセルを選択
3. 「概要」タブでイベントの受信状況を確認
4. 「**テストイベント**」タブ → ブラウザのURLを入力 → テスト送信で確認

> 💡 ピクセルのデータ反映には**最大20分ほどかかる**場合がある

#### Step 5: コンバージョンイベントを設定する

コンバージョンイベント＝「広告の成果として何をカウントするか」の定義

**標準イベント一覧（よく使うもの）**

| イベント名 | 用途 | コード |
|---|---|---|
| **Lead** | LINE登録・資料請求 | `fbq('track', 'Lead');` |
| **Purchase** | 商品購入 | `fbq('track', 'Purchase', {value: 金額, currency: 'JPY'});` |
| **CompleteRegistration** | 会員登録完了 | `fbq('track', 'CompleteRegistration');` |
| **Contact** | お問い合わせ | `fbq('track', 'Contact');` |
| **ViewContent** | 特定ページ閲覧 | `fbq('track', 'ViewContent');` |

**設置方法（例：LINE登録をコンバージョンとして計測）**

1. LINE登録後のサンクスページ（リダイレクト先）のHTMLに以下を追加：
```html
<script>
  fbq('track', 'Lead');
</script>
```
2. これをピクセルの基本コード**の後に**配置する
3. イベントマネージャでイベントが受信されているか確認

**コードが触れない場合（ノーコードで設定）**
1. イベントマネージャ →「**イベント設定ツール**」を開く
2. サイトURLを入力 → サイトが表示される
3. 計測したいボタンやリンクをクリックで選択
4. 「新しいボタンをトラッキング」→ イベントを割り当て（Lead等）
5. 保存して完了

## 2. キャンペーン作成

### キャンペーン目的の選択
広告マネージャ →「＋作成」をクリック

| 目的 | 使うケース |
|---|---|
| **リード獲得** | LINE登録・資料請求など |
| **トラフィック** | LPへの誘導 |
| **コンバージョン** | 購入・申込み |
| **認知度** | ブランド認知拡大 |

> **おすすめ**: リスト獲得が目的なら「**リード獲得**」、LPに飛ばすなら「**トラフィック**」or「**コンバージョン**」

### キャンペーン設定
- キャンペーン名を分かりやすく命名（例：`【リード】よもぎ蒸しFC_2026年2月`）
- **キャンペーン予算の最適化（CBO）**: オンにすると、Metaが自動で最適な広告セットに予算配分
- 日予算 or 通算予算を設定

---

## 3. 広告セット作成

### ターゲティング設定
1. **カスタムオーディエンス**: 既存リスト・サイト訪問者がいれば活用
2. **地域**: 日本全国 or 特定エリア
3. **年齢・性別**: ターゲットに合わせて設定
4. **詳細ターゲティング**: 興味関心・行動で絞り込み
   - 例: 「起業」「フランチャイズ」「美容サロン経営」など
5. **Advantage+ オーディエンス**: AIに任せる場合はオンに

### 配置（プレースメント）
- **Advantage+ 配置（推奨）**: Metaが自動で最適な場所に配信
- 手動の場合: Facebook フィード、Instagram フィード、ストーリーズ、リールなど選択

### 予算とスケジュール
- **日予算**: テスト段階は **¥1,000〜3,000/日** から開始
- **開始日・終了日**: 設定 or 継続配信を選択
- **入札戦略**: 最初は「最小コスト（自動入札）」推奨

---

## 4. 広告クリエイティブ作成

### 広告フォーマット
| フォーマット | 特徴 |
|---|---|
| **シングル画像** | シンプル・作りやすい |
| **動画** | 高エンゲージメント・おすすめ |
| **カルーセル** | 複数訴求ができる |

### クリエイティブのポイント
1. **画像/動画**: 
   - サイズ: 1080×1080px（正方形）or 1080×1920px（縦型）
   - テキスト量は画像面積の20%以下が理想
   - 最初の3秒で注意を引く（動画の場合）
2. **メインテキスト（本文）**: 最初の3行で興味を引く。125文字以内推奨
3. **見出し**: 明確なベネフィット（27文字以内推奨）
4. **CTA（行動喚起ボタン）**: 「詳しくはこちら」「申し込む」「登録する」など
5. **リンク先URL**: LP or LINE登録ページなど

### A/Bテスト
- 最低 **3〜5パターン** のクリエイティブを用意
- 画像違い・コピー違い・ターゲット違いなどでテスト

## 5. 公開前チェックリスト

- [ ] ピクセルが正しく発火しているか確認
- [ ] リンク先URLが正しいか確認（実際にクリック）
- [ ] クリエイティブに誤字脱字がないか
- [ ] ターゲティングが適切か（広すぎ・狭すぎないか）
- [ ] 予算設定が正しいか（桁間違いに注意！）
- [ ] 支払い方法が有効か

---

## 6. 出稿・公開

1. すべて設定完了後 →「**公開する**」ボタンをクリック
2. Metaの広告審査（通常 **24時間以内**、早ければ数時間）
3. 審査通過後、自動的に配信開始

---

## 7. 出稿後の運用

### 最初の3日間
- **触らない**。Metaの学習フェーズ（データ蓄積期間）なので、設定変更しない
- 最低50件のコンバージョンが貯まるまでが学習期間

### 1週間後〜
| 確認指標 | 目安 |
|---|---|
| **CTR（クリック率）** | 1%以上なら合格 |
| **CPC（クリック単価）** | 業界平均と比較 |
| **CPL（リード単価）** | 目標CPA以内か |
| **フリクエンシー** | 3以上になったらクリエイティブ差替え |

### 改善サイクル
1. 成果の悪い広告を**オフ**
2. 成果の良い広告の予算を**増額**（20%ずつ段階的に）
3. 新しいクリエイティブを追加投入
4. 2週間ごとにクリエイティブをリフレッシュ
