## 第3部：ONのビジネスモデル（約25分）

> **このパートが最重要。「自分にもできる」と確信させるのがゴール。**

### 3-1. 「技術不要」のオペレーション（7分）

**施術の流れ（実演想定で説明）：**
```
1. お客様がハーブメニュー（7種）から選ぶ
2. スタッフがハーブを壺にセット
3. お客様が着替えて黄土椅子に着座
4. フットバス＋ボタニカルティーを提供
5. タイマーセット（40分）→ ここからスタッフの手が空く
6. カルテ入力（使用ハーブ・会話内容）
7. ホットタオル → スキンケア → お見送り
```

> **営業キラーフレーズ：**
> 「エステや美容院は"職人の技術"が売上を左右します。ONは違います。**誰がやっても同じクオリティ**。だから未経験者が即日現場に立てるんです」

**他業態との比較表（スライドで大きく見せる）：**

| 技術・資格 | **不要** | 調理経験推奨 | 技術研修必須 |

| 副業対応 | **可能** | 困難 | 困難 |

### 3-2. ONの圧倒的な差別化（8分）

#### ① 韓国ファンジン正規代理店（日本わずか10社）
- 無形文化財の伝統技術 × 最高級五色黄土
- 椅子の品質で効果が**数十倍**変わる → 偽物との違いを明確に

#### ② 希少ハーブ「モリンガ」の取り扱い
- 奇跡のハーブ：90種の栄養素 × 300個の薬用効果
- **関東でほとんど取り扱い店舗がない**希少体験

#### ③ 全品無農薬 × 自社開発ハーブ
- 一般社団法人にて自社開発 → **仕入れ原価を極限まで抑制**
- 原価率8〜15%（1回あたり約500円）を実現している秘密

#### ④ 空間デザインへのこだわり
- **日本一の部屋の広さ**を誇るよもぎ蒸し専門店
- デザイナー監修 × 高級スキンケア（トリロジー・AESOP）設置
- 安売りしない**価値型集客**

### 3-3. サブスクモデルの威力（5分）
> **「サブスクが積み上がれば、新規に依存しない安定経営が実現できます」**

| プラン | 月額 | 1回あたり |
|--------|------|----------|
| 月2回 | 7,600円 | 3,800円 |
| 月4回 | 14,800円 | 3,700円 |
| 月8回 | 28,400円 | 3,550円 |
| 通い放題 | 43,500円 | — |

- 月2回・4回が最も人気 → **リピート率65%**
- サブスク会員80〜100名で月100万円超が安定
- 会員が積み上がる = **新規集客のプレッシャーが減る** = オーナーの精神的余裕

### 3-4. 集客はHPBだけで完結（5分）

| 項目 | 実績 |
|------|------|
| 蔵前 新規数 | 繁忙期 80〜100名 / 閑散期 30〜50名 |
| 蔵前 月間PV | 繁忙期 約10,000PV |
| 市川 月間PV | 約5,000〜8,000PV |

> 「ホットペッパービューティーだけで成立する店舗を作る。それが**最も再現性が高いFC**です。集客予測が立つから、オーナーも本部も安心できる」

- 出店前にHPBの**検索数・PV・競合数**をリサーチ → 数字に基づく出店判断
- サブスク積み上げ後は新規依存が低減 → 季節変動に強い
