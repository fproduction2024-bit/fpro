## 4. ライティング方針（BUPURAベース）

### 基本構造の踏襲
- **BUPURAのLP構成をベーステンプレートとして使用する**
- FV以外のボディ構成（ペイン→ソリューション→実績→比較→CTA）は共通フォーマット

### FV（ファーストビュー）の方針
- 案件ごと・時流に合わせてカスタマイズ（毎回変える部分）
- ONサロンの現行FVキーワード：「累計2万人」「542万円（年間純利益）」「技術不要×1名運営×500万円〜」「1ヶ月目から黒字」

### コピーの軸
| 訴求軸 | 具体的なフレーズ |
|--------|----------------|
| 収益訴求 | 4台で年間純利益542万円。直営12ヶ月の実績データ全公開 |
| 未経験OK | 技術不要・資格不要。翌日から現場に立てる |
| リスク訴求 | 原価率8〜15%・投資回収14ヶ月・1ヶ月目から黒字 |
| サブスク安定 | リピート率65%。新規依存しないストックビジネス |
| 希少感 | 0次募集 残りわずか（加盟金100万円→次回300万円に引き上げ予定） |

## 9. 今後の運用方針（覚書）

- BUPURAのLP構成を**リッツCS全案件のベーステンプレ**として使う
- **FVのみ**案件ごとにカスタマイズ（時流・訴求軸で変える）
- ボディ以降は構成を共通化 → 毎回ゼロから作らない
- ライティングはAntigravityで対応（外注コスト削減）
- デザイン・HTML化は外注（予算目安：15万円/案件）
- 広告反応を見てCVR改善が必要な場合：月2万円 × 3ヶ月のオプション
