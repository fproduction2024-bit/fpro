### 🟠 Phase 2：ランディングページ（LP）

| # | 制作物 | 仕様 | 状態 | 備考 |
|---|--------|------|------|------|
| 2-1 | **FC募集LP（メインページ）** | HTML（レスポンシブ） | ❌ 未着手 | 広告からの受け皿。セミナー申込がゴール |
| 2-2 | **Metaピクセル設置** | ピクセルコード埋め込み | ❌ 未着手 | LP + サンクスページに設置 |
| 2-3 | **サンクスページ** | HTML | ❌ 未着手 | 申込完了後のリダイレクト先。CV計測用 |

#### LP構成案：
1. **ファーストビュー** — キャッチコピー + 嶋岡さん/サロン写真 + CTA
2. **こんなお悩みありませんか？** — ターゲットペルソナの課題
3. **ONサロンとは** — ブランド紹介・差別化5つのポイント
4. **ビジネスモデル** — 4台モデル/1名運営/原価率10〜15%
5. **収益シミュレーション** — 月次実績・3年計画の図表
6. **オーナーの声** — 加盟オーナーインタビュー
7. **他業態との比較表** — 飲食FC/エステFCとの優位性
8. **FC条件・費用** — 加盟金100万円・ロイヤリティ11万円
9. **サポート体制** — 研修・集客支援・仕入れ支援
10. **セミナー申込CTA** — フォーム or LINE登録

## 優先度と着手順序

```
【STEP 1】最小構成で広告開始（最低限必要なもの）
  → LP (2-1) + ピクセル (2-2) + サンクスページ (2-3) 
  → 静止画バナー3枚 (1-1) + 広告コピー3本 (1-4)
  → 申込フォーム (3-1) + 確認メール (3-3)
  → Meta広告設定 (6-1〜6-3)

【STEP 2】セミナー体制の構築
  → セミナースライド制作 (4-2)
  → セミナー案内ページ (4-4)
  → LINE設定 (3-2)

【STEP 3】コンバージョン率の改善
  → 動画広告 (1-3) + カルーセル (1-5)
  → 個別面談用提案書 (5-1)
  → A/Bテスト本格運用 (6-5)

【STEP 4】契約体制の整備
  → 契約書 (5-2) + 加盟申込書 (5-3)
  → 事業計画書テンプレート (5-4)
```

## 備考

- **テスト予算の目安**: ¥1,000〜3,000/日 からスタート（`meta広告出稿手順.md` 参照）
- **クリエイティブは最低3パターン**用意してA/Bテスト
- **学習期間（最初の3日間）は設定を変更しない**こと
- 嶋岡さんの**写真・動画素材**の撮影が必要（サロン内観・施術風景・本人出演）
