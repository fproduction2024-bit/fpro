### 1. 本格よもぎ蒸しサロン aUN ⚠️ 最大の注意対象

| 項目 | 内容 |
|------|------|
| 運営 | **フランチャイズビジネスインキュベーション株式会社** |
| 背景 | **「鰻の成瀬」を手掛ける会社**（381店舗/2025年10月時点）が美容業界に新規参入 |

## ONの戦略的ポジション分析

### ✅ ONが勝てるポイント
1. **累計来店数2万人超** × **直営4年の運営実績** → 数字で語れる信頼性
2. **韓国ファンジン正規代理店**（日本わずか10社） → 正規品の権威
3. **モリンガ蒸し**が体験できる → 関東でほぼ唯一の希少性
4. **自社開発ハーブ** → 仕入れ原価を極限まで抑制（原価率8〜15%）
5. **直営店の月次データ12ヶ月分 + 3年計画**がある → 説得力のある収益シミュレーション
6. **空間デザインの品質** →「安売りしない価値型集客」のブランドポジション

### ⚠️ ONが注意すべきポイント
1. **aUNのスピード** → 鰻の成瀬の運営会社が資金力とFC展開ノウハウで急拡大する可能性
2. **夢みるよもぎ蒸しのロイヤリティ0円** → 加盟者の比較検討時に不利になる可能性
3. **セルフ/無人モデルの台頭** → 「人がいなくてもいい」という訴求が広がると、1名運営のメリットが薄まる
4. **パートナー制度の存在** → 夢みるよもぎ蒸しの3.3万円導入は、ON加盟100万円との価格差が大きい

### 💡 セミナーでの差別化メッセージ案
> 「よもぎ蒸しのFCは確かに増えています。でも、**セルフ・無人型**と**本格派**は全くの別物です。セルフ型は月10〜20万の副業モデル。ONは**月50万円の利益を狙える本格事業**です」

> 「大事なのは**リピート率65%**という数字です。セルフサロンではこの数字は出ません。お客様が"習慣"にしてくれるのは、**空間の質・ハーブの質・接客の質**が揃って初めて成立する。ONはその全てを仕組み化しています」
