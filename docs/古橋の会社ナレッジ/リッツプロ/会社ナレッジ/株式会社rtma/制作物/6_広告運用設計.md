### 4週間運用スケジュール

| 週 | やること | 注意点 |
|----|----------|--------|
| Week 1 | 配信開始。全広告セット・全クリエイティブを同時配信 | **触らない**。学習フェーズ |

| Week 3 | 勝ちクリエイティブに予算集中（+20%）。新規クリエイティブ追加 | 急な大幅予算変更は避ける |
| Week 4 | 月次レポート作成。翌月のクリエイティブ・予算計画 | フリクエンシーチェック |

## 6-5. A/Bテスト計画

### テストロードマップ（4週間）

```
Week 1-2：テスト1（訴求軸テスト）
  → 勝者を特定

Week 2-3：テスト2（クリエイティブ形式テスト）
  → 勝者の訴求軸 × 最適フォーマットを特定

Week 3-4：テスト3（ターゲティングテスト）
  → 最適なオーディエンスを特定

Week 4〜：テスト4（LP最適化テスト）
  → CVRの改善
```

### テスト1：訴求軸テスト（最優先）

| | バリエーションA | バリエーションB | バリエーションC |
|---|---|---|---|
| 訴求 | 収益訴求 | 未経験訴求 | 低投資訴求 |
| コピー | 「年間純利益542万円」 | 「技術不要・2ヶ月で黒字化」 | 「500万円〜、14ヶ月で回収」 |
| 画像 | **同一** | **同一** | **同一** |
| ターゲット | **同一** | **同一** | **同一** |
| 最低サンプル | 各50クリック or 7日 |
| 判定指標 | CTR → CPL |
| 勝敗判定 | CPLが最も低いものが勝ち |

### テスト2：クリエイティブ形式テスト

| | バリエーションA | バリエーションB | バリエーションC |
|---|---|---|---|
| 形式 | 静止画（正方形） | 動画（15秒） | カルーセル（5枚） |
| コピー | **テスト1勝者** | **テスト1勝者** | **テスト1勝者** |
| ターゲット | **同一** | **同一** | **同一** |
| 最低サンプル | 各50クリック or 7日 |
| 判定指標 | CTR → CPL |

### テスト3：ターゲティングテスト

| | バリエーションA | バリエーションB | バリエーションC |
|---|---|---|---|
| ターゲット | 起業・副業関心層 | 美容・健康関心層 | 投資・資産形成関心層 |
| クリエイティブ | **テスト1+2勝者** | **テスト1+2勝者** | **テスト1+2勝者** |
| 最低サンプル | 各30リード or 14日 |
| 判定指標 | CPL → セミナー参加率 |

### テスト4：LP最適化テスト

| | バリエーションA | バリエーションB | バリエーションC |
|---|---|---|---|
| FVコピー | 「年間純利益542万円のサロンビジネス」 | 「技術不要。1名で経営できるサロンFC」 | 「2ヶ月で黒字化した、新しい独立の形」 |
| 判定指標 | フォーム完了率（CVR） |
| 実施方法 | パラメータ付きURL or LP duplicate |

### 意思決定フロー

```
テスト期間終了
    ↓
統計的有意差あり？（p < 0.05 or 実務判断）
    ├─ YES → 勝者を本番採用。次のテストへ
    └─ NO → テスト期間延長（最大14日）
              ↓
          再判定しても有意差なし？
              ├─ YES → CPLが低い方を採用（実務判断）
              └─ NO → 勝者採用
```
