# ONサロン FC募集 — カルーセル広告構成（2パターン）

---

## パターンA：ビジネスモデル紹介型

### スライド1（フック）
- **見出し：** 年間純利益542万円のサロンビジネス
- **説明：** 黄土よもぎ蒸し専門店ONのFCモデル
- **ビジュアル：** サロン内観の美しい写真 + 数字オーバーレイ「¥5,420,000」
- **デザイン：** ティール背景 + 白文字。数字はInter太字で大きく

### スライド2（オペレーション）
- **見出し：** 技術不要。たった1人で運営できます
- **説明：** ハーブを選んでもらい、お茶を出すだけ。高度な施術技術は一切不要
- **ビジュアル：** 施術フロー図（アイコン3〜4ステップのイラスト）
- **デザイン：** 白背景 + ティールアクセント。チェックマークアイコン

### スライド3（収益モデル）
- **見出し：** 原価率8〜15%。サブスクで安定収益
- **説明：** リピート率65%。サブスク会員が積み上がり、新規に依存しない経営モデル
- **ビジュアル：** サブスク会員数の右肩上がりグラフ（95名→123名）
- **デザイン：** グリーンのグラフ + 白背景

### スライド4（社会的証明）
- **見出し：** 2ヶ月で黒字化した実際のオーナーの声
- **説明：** 「技術なしで始められて、数字が作りやすく、長く続けやすい」
- **ビジュアル：** 引用符デザイン + オーナーのシルエット or 写真枠
- **デザイン：** オレンジ背景（薄め）+ 白テキスト

### スライド5（CTA）
- **見出し：** まずは無料セミナーへ
- **説明：** 直営12ヶ月分の実績データを全て公開します
- **ビジュアル：** セミナーイメージ + 申込ボタンデザイン
- **デザイン：** ティール背景 + オレンジCTAボタン
- **CTA：** 「詳しくはこちら」

## パターンB：他業態比較型

### スライド1（問題提起）
- **見出し：** FCビジネス、どれを選ぶ？
- **説明：** 初期投資・技術・リスク…比べてみてください
- **ビジュアル：** 3つの扉のイラスト（飲食/エステ/よもぎ蒸し）
- **デザイン：** ダーク背景 + 白テキスト。クエスチョンマーク

### スライド2（飲食FC）
- **見出し：** 飲食FC
- **説明：** 初期投資1,000万円〜 / 技術必要 / 3名以上必要 / 原価率30〜35% / 回収1.5〜3年
- **ビジュアル：** 赤い×マークが各項目について
- **デザイン：** グレー背景。項目ごとにネガティブカラー（赤）

### スライド3（エステFC）
- **見出し：** エステFC
- **説明：** 初期500万〜 / 技術研修必須 / 2名必要 / クレームリスク中〜高 / 回収1〜2年
- **ビジュアル：** 黄色の△マークが各項目について
- **デザイン：** グレー背景。注意カラー（黄色）

### スライド4（ONサロン）
- **見出し：** よもぎ蒸し ON
- **説明：** 500万円〜 / 技術不要 / 1名完結 / クレームほぼゼロ / 回収14ヶ月 / 副業OK
- **ビジュアル：** 緑の◎マークが各項目について + サロン写真
- **デザイン：** 白背景。ポジティブカラー（グリーン/ティール）で圧倒的に明るく

### スライド5（CTA）
- **見出し：** 無料セミナーで詳しく解説します
- **説明：** 嶋岡みのり（代表）が直営データを全て公開。質疑応答あり
- **ビジュアル：** 嶋岡さん写真 + セミナー概要
- **デザイン：** ティール背景 + オレンジCTA
- **CTA：** 「申し込む」
