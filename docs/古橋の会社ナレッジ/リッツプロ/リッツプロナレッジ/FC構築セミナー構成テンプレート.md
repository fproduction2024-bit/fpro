> クライアントの業種・規模に応じて各パートの内容を差し替えて使用する。

## 第1部：導入・信頼構築（約15分）

### 1-1. オープニング・自己紹介
- セミナーの目的と進め方の説明
- 登壇者のプロフィール・実績紹介
- メディア実績があれば提示（テレビ出演、講演、出版等）

### 1-2. 成功の定義を共有
> **ポイント：「成功」の基準をまず揃える**
- 店舗数＝成功ではない
- **いつでもM&Aできる状態＝成功** と定義
- 参加者の認識をリセットし、セミナーの方向性を明確にする

### 1-3. 参加者の現在地・目標の確認（インタラクション）
- チャットで「目指している状態」を書いてもらう
  - 例：○年後に○店舗、○億円でM&A、年商○億円
- 参加者のゴールを把握し、以降の説明に反映させる

## 第2部：FC × M&A の基本理解（約20分）

### 2-1. なぜFC × M&Aなのか
- FCと M&Aのシナジー（代表が抜けても回る再現性の証明）
- 買い手が最も重視するポイント：**人ではなく仕組みに価値があるか**

### 2-2. 売却時期の考え方
- **Sカーブ理論**：2〜3年で成長→成熟→衰退のサイクル
- 成長期のピークで売却するのが最も高値

### 2-3. M&A金額の算出方法
| 方法 | 計算式 | 対象 |
|------|--------|------|
| マルチプル法 | 将来の営業利益 × 5〜7倍 | 中小企業 |
| DCF法 | 将来キャッシュフローの現在価値 | 上場企業 |

### 2-4. 会社の出口5パターン
1. 倒産  2. 清算  3. 承継  4. 上場（IPO）  5. **M&A**

### 2-5. 売却のメリット3つ
1. **巨額資金の獲得**（税率20%で手取り効率が圧倒的に高い）
2. **リスクからの解放**（天災・経済変動・業界トレンド）
3. **次の事業への投資原資**

### 2-6. 具体的な数値例（納得感を作る）
- 手取り1億円を得るには：
  - 役員報酬ルート → 年商25億円の会社が必要
  - M&Aルート → **月200万円の営業利益**で到達可能

## 第3部：スケールアップ戦略（約30分）

### 3-1. 最短成功の必須条件
- **利益至上主義**（現金重視）＋ **最短至上主義**（速度重視）
- 財務の基本（PL=過去 / BS=現在 / CF=未来）

### 3-2. スケールアップ8ステップ（概要）

| Step | 内容 | キーワード |
|------|------|-----------|
| 1 | 明確なゴール設定 | 出口戦略 |
| 2 | 市場調査・ニーズ把握 | 全社戦略 |
| 3 | 戦略設計 | 事業戦略→機能戦略→財務戦略 |
| 4 | パッケージ化 | 売り物を作る |
| **5** | **業務のシンプル化** | **⚠️ここを飛ばすと衰退** |
| 6 | マーケティング実施 | 0次→1次→2次募集 |
| 7 | 回収＆投資 | ROAS / CPA |
| 8 | 持続的スケールアップ | — |

### 3-3. ステップ5の深掘り：業務シンプル化
> セミナーの最重要パート。ここに最も時間をかける。

- **教育期間の圧縮**事例（業界平均→短縮後の日数）
- **品質許容の考え方**
  - 職人品質 vs スケール品質のトレードオフ
  - 事例：回転寿司チェーン、シーシャバー、コカコーラ
- **ターゲットの再設定**
  - 品質を変えたらターゲットも変わる
  - コカコーラの変遷：「喉が乾いたら」→「リフレッシュ」→「いつでもどこでも」

### 3-4. 段階別拡大戦略

| 段階 | 最重要KPI | 解説 |
|------|-----------|------|
| 〜10店舗 | **再現性** | 本部でしかできない施策は入れない |
| 〜20店舗 | **エンゲージメント** | オーナーとリアルで会う仕組みを作る |
| 〜50店舗 | **マーケティング絞り込み** | 自社に合う5〜7手法に集中 |
| 〜100店舗 | **オーナー出店数** | 既存オーナーの複数店舗出店率 |

## 第4部：本部構築の核心（約20分）

### 4-1. 本部構築の3要素

```
① 社会性（共感） ── MVV・ESG・SDGs・寄付活動
② 専門性（差別化）── 何専門か？を尖らせる
③ 拡大性（スケール）── ニーズ×品質許容×多店舗適性
```

> **契約に至らない原因の大半は、収益性ではなく専門性・社会性の不足**

### 4-2. 社会性の作り方
- ESG（投資家向け）と SDGs（消費者向け）の違い
- 自社の社会テーマの設定方法
- ライトに始めるなら**寄付活動（年間10万円〜）**→ 活動報告をPRに活用

### 4-3. 専門性の尖らせ方
- **がん専門医の原理**：課題が深いほど単価が高い
- 業界事例で「何を本当に売っているか」を解説
  - ライザップ → 努力せずに痩せたい人
  - スターバックス → サードプレイス（居場所）
  - くら寿司 → ファミリー層（ガチャガチャ戦略）

### 4-4. レッドオーシャン×ブルーオーシャン戦略
> **レッドオーシャンの業界で、ブルーオーシャンの土地に出す＝最強の勝ち方**

- 競合調査の具体的方法（ホットペッパー等のプラットフォーム分析）
- エリアマーケティングのデータ活用

### 4-5. マニュアル構成の概要
（※FC本部マニュアル構築戦略より）

| 章 | 内容 |
|----|------|
| 第1章 | 目的と範囲 |
| 第2章 | 業務フロー（来店〜退店の全体フロー） |
| 第3章 | 役割と責任 |
| 第4章 | 手順とプロセス |
| 第5章 | テンプレートとフォーム |
| 第6章 | チェックリスト |
| 第7章 | 品質管理 |
| 第8章 | 教育とトレーニング |
| 第9章 | 更新履歴 |
| 第10章 | 付録（用語集・緊急連絡先） |

## 第6部：サービス紹介・CTA（約15分）

### 6-1. 退室案内
> 「サービス紹介になりますので、ご予定のない方はご退室いただいても大丈夫です」
> → 押し売り感を排除し、残った人の温度感を上げる

### 6-2. サービスの3つの注意事項（安心材料）
1. **成果報酬制**：広告費・LP制作費は支援側が負担
2. **報酬対象は加盟金のみ**：ロイヤリティ・仕入れからは取らない
3. **月間支援先は1社限定**＋**社内審査あり**

### 6-3. 推奨ロイヤリティ設計
- **固定型＋仕入利益**（パーセント型は計算が煩雑）

### 6-4. 収益シミュレーション
- 月間新規加盟数ごとの収益予測表を提示
- 3年契約換算での資産価値を算出

### 6-5. 契約の流れ
1. 初回ミーティング（ニーズ・目標把握）
2. 2回目ミーティング（成果報酬部分の決定・サービス明確化）
3. 契約書の読み合わせと締結
4. ご入金・プロジェクト開始
5. キックオフミーティング（スコープ・スケジュール・役割確認）
6. スタート

### 6-6. クロージング
- 限定性・緊急性の提示（月1社限定、○月枠は埋まっている等）
- 次のアクション（個別相談の申込み方法）
- アーカイブ動画の送付案内
