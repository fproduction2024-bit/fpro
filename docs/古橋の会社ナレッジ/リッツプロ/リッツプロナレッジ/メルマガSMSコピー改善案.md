# メルマガ・SMSコピー 改善案

> リッツ・PRO CS改善施策 — 2026年3月
> 対象: FC加盟店募集向けのメルマガ・SMS配信

---

## 1. 改善方針

### 現状の課題（推定）
- メールの開封率が業界平均以下の可能性
- CTAが不明確、クリック率が低い
- SMS活用が限定的
- メールとLINEの連携が弱い

### 改善の3原則
1. **件名で惹きつける**（数字・具体性・緊急性）
2. **本文は短く、1CTA**（行動を1つに絞る）
3. **SMS→LINE・メール連携**（マルチチャネル）

## 3. SMSコピー改善案

### SMS 基本ルール
- **70文字以内**（1通あたりのコスト最適化）
- **URL短縮必須**（bitly等）
- **パーソナライズ**（名前を入れる）
- **送信時間**: 平日10:00-12:00 or 18:00-20:00

### パターン1: セミナー告知SMS

**【Before（想定）】**
```
FC説明会を開催します。詳しくはこちら→URL
```

**【After】**
```
{名前}様、技術不要で年利益542万のよもぎ蒸しFC。無料説明会→{短縮URL}残席わずか
```
（68文字）

### パターン2: リマインドSMS

```
{名前}様、明日のFC説明会リマインドです。Zoom→{URL}  10時開始/5分前入室をお願いします
```
（65文字）

### パターン3: 不参加フォローSMS

```
{名前}様、先日のセミナー録画をお送りします。期間限定→{URL}  ご都合よい時にどうぞ
```
（62文字）

### パターン4: 掘り起こしSMS

```
{名前}様、よもぎ蒸しFC「ON」0次募集の残枠わずか。特別条件で加盟可→{URL}
```
（56文字）

## 4. メール×SMS×LINE クロスチャネル設計

### 配信スケジュール

```
申込当日
  ├── メール: 申込確認メール（自動）
  └── SMS: 「ありがとうございます。LINEも追加→URL」

申込翌日
  └── LINE: 特典資料配信

セミナー3日前
  └── LINE: 事前質問募集

セミナー前日
  ├── メール: リマインド + Zoom URL
  ├── SMS: リマインド（Zoom URL）
  └── LINE: リマインド

セミナー当日AM
  └── LINE: 「本日です！」

セミナー翌日
  ├── メール: お礼 + アーカイブ
  └── LINE: 個別面談案内

セミナー3日後
  └── SMS: 「まだ間に合います→URL」

セミナー7日後
  └── LINE: ラストチャンス

以降（月1回）
  └── メール: 事例紹介・実績報告
```

| 指標 | 現状（推定） | 目標 |
|-----|-----------|------|
| メール開封率 | 15-20% | 30%以上 |
