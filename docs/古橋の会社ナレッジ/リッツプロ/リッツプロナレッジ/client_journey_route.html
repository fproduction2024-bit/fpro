📞 初回ミーティング

ニーズ・目標・現状の把握。「いつまでに・いくらで・何店舗」のゴールイメージを共有する。

🟠 クライアントがやること
  • 自社の事業概要・強みを説明する
  • 現在の店舗数・直営実績を共有する
  • FC化の目的・3年後のゴールを伝える
🟢 リッツプロがやること
  • 現状ヒアリング・課題の特定
  • 出口戦略（M&A）の提案
  • 成功の定義の共有

🔍 2回目ミーティング（社内審査）

質問事項の確認、FC化の適性診断。社会性・専門性・拡大性の3軸で評価する。

🟠 クライアントがやること
  • 追加資料の提出（PL/BS/メニュー等）
  • 直営店の実績データ提供
  • 質問への回答
🟢 リッツプロがやること
  • FC化適性の社内審査
  • 社会性・専門性・拡大性の評価
  • 支援範囲・成果報酬の提示

📝 契約締結

契約書の読み合わせと電子契約書での締結。契約金の入金。

🟠 クライアントがやること
  • 契約内容の確認・承諾
  • 電子契約書へのサイン
  • 契約金200万円（税別）の入金
🟢 リッツプロがやること
  • 契約書の作成・読み合わせ
  • プロジェクトチームの編成
📦 この段階の成果物
  • 業務委託契約書
  • プロジェクト計画書

🚀 キックオフミーティング

プロジェクト開始。目的・スコープ・スケジュール・役割分担を全関係者で再確認。

🟠 クライアントがやること
  • 社内の関係者を集める
  • 既存マニュアル・資料の共有
  • プロジェクトの優先事項を伝える
🟢 リッツプロがやること
  • プロジェクト全体のロードマップ提示
  • スケジュール・マイルストーンの設定
  • 市場調査の開始

🎯 ゴール設計 ＆ 戦略設計

「いつまでに・何店舗・いくらで売却」を明確にし、逆算で戦略を組む。

🟠 クライアントがやること
  • 出口（M&A）の目標時期・金額を決める
  • 自社のMVV（ミッション・ビジョン・バリュー）を策定
  • 社会的意義の明確化（ESG/SDGs的な要素）
🟢 リッツプロがやること
  • 市場調査・ニーズ分析
  • 競合調査・ポジショニング設計
  • M&A売却額シミュレーション（マルチプル法）
  • 経営戦略の4層設計

📦 FCパッケージ化

接客・集客・商品提供・CS・経営会計を体系化し、加盟店に渡せるパッケージにする。

🟠 クライアントがやること
  • 直営店のオペレーションを洗い出す
  • 施術・サービスの手順を共有
  • 仕入先・原価・利益構造の開示
  • 写真・動画素材の撮影協力
🟢 リッツプロがやること
  • FCパッケージの設計・体系化
  • 業務のシンプル化・効率化（⚠️最重要）
  • 教育期間の圧縮設計
  • 品質許容ラインの設定

📚 マニュアル構築

加盟店が再現できるマニュアル・研修プログラムを作成する。

🟠 クライアントがやること
  • マニュアル内容の監修・確認
  • 研修プログラムの実演・撮影
  • トラブル事例の共有
🟢 リッツプロがやること
  • オペレーションマニュアル作成
  • 研修カリキュラム設計
  • チェックリスト・テンプレート整備
  • 品質管理KPI策定
📦 この段階の成果物
  • FCオペレーションマニュアル
  • 研修プログラム
  • チェックリスト
  • 品質管理基準書
  • トラブル対応マニュアル

⚖️ 法務・契約整備

FC加盟契約書・ロイヤリティ設計・コンプライアンス体制を整備する。

🟠 クライアントがやること
  • 加盟金額・ロイヤリティ金額を決定
  • 弁護士・法務との連携
  • 商標登録の確認
🟢 リッツプロがやること
  • FC契約書の雛形作成支援
  • ロイヤリティ設計（固定型推奨）
  • 法務アドバイス・コンプライアンス支援

🧪 0次募集（テストマーケティング）

3〜10店舗を割安条件で募集。マニュアル改善パートナーとして加盟してもらう。

🟠 クライアントがやること
  • セミナーに登壇する（オンライン90〜100分）
  • 個別面談に参加して直接クロージング
  • 加盟候補者の最終判断
🟢 リッツプロがやること
  • Meta広告の運用（リッツプロ負担）
  • セミナー集客・運営サポート
  • 個別面談の段取り
  • CPA・契約率の分析・改善

  • プレオープンの立ち会い

  • SVサポート体制の構築支援

スケールアップ
10店舗→50店舗→100店舗へ拡大する｜6ヶ月〜2年目

📈 1次募集（本格展開）

0次で検証したマーケティングを本格稼働。月5件ペースで加盟店を増やす。

🟠 クライアントがやること
  • セミナー登壇を継続（月2〜4回）
  • 個別面談・契約を実行
  • 加盟オーナーとのエンゲージメント維持
  • 既存加盟店への2ヶ月に1回のリアル訪問
🟢 リッツプロがやること
  • 広告の最適化・ROAS管理
  • 新クリエイティブのテスト
  • YouTube広告の追加
  • ブランド構築支援（メディア・出版）

🔄 回収＆投資（ROAS管理）

売上と利益を出しつつ、資金を回収してさらに投資するサイクルを回す。

🟠 クライアントがやること
  • 月次のPL/BS/CFの管理
  • ロイヤリティ・仕入利益の管理
  • 既存オーナーの複数店舗出店を促進
🟢 リッツプロがやること
  • 費用対効果の分析・レポーティング
  • マーケティング手法の追加・調整
  • 経営支援・アドバイス

🌟 2次募集 ＆ 持続的拡大

50店舗超からは既存オーナーの複数出店率が最重要KPI。

🟠 クライアントがやること
  • カスタマーサクセス体制の強化
  • 新商品・サービスの開発
  • エリア戦略の推進
  • ブランディング活動への参加
🟢 リッツプロがやること
  • マーケティングチャネルの拡充
  • 展示会・プラットフォーム出展
  • メディア戦略（テレビ・出版）
  • M&A準備のための企業価値向上支援

📊 M&A準備

デューデリジェンス（DD）に耐える体制を整え、企業価値を最大化する。

🟠 クライアントがやること
  • 財務諸表の整備（PL/BS/CF）
  • 法務・コンプライアンスの最終確認
  • 加盟店との契約内容の再確認
🟢 リッツプロがやること
  • DD対応支援
  • 企業価値の算出（マルチプル法）
  • 売却額が上がる構造の最終調整

🤝 売却交渉・クロージング

営業利益 × 5〜7倍のマルチプル法で売却。税率20%で現金化。

🟠 クライアントがやること
  • 買い手候補との面談
  • 条件交渉への参加
  • 最終合意・契約締結
🟢 リッツプロがやること
  • M&Aアドバイザーとの連携
  • 売却プロセスの伴走
  • ポストM&A移行支援
売却額の目安
営業利益 × 5〜7倍
月利200万 → 年間2,400万 → 売却額 1.2〜1.7億円（税率20%）
