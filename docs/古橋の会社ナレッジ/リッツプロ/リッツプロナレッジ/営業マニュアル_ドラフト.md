## 1. はじめに

### このマニュアルの目的
本マニュアルは、リッツプロのFC加盟店開発営業を**誰でも再現可能**にするための手順書です。
新規の営業メンバーが、このマニュアルだけで一通りの業務を回せることを目指しています。

### 対象読者
- 新規参画の営業メンバー
- CS（カスタマーサクセス）担当者
- 業務委託パートナー

### 用語について
専門用語は本文中に※マークで注記しています。詳細は末尾の[用語集](#9-用語集)を参照してください。

## 3. STEP1: リード獲得

### 3-1. 広告運用の基本
- **媒体**: Meta広告（Facebook / Instagram）
- **予算**: クライアントのデポジットから運用
- **運用者**: RIDE社（広告代理店）→ リッツプロがディレクション
- **レポート**: 月次で広告レポートをクライアントに共有

### 3-2. フォーム申込が入ったら
1. UTAGEの管理画面で新規リードを確認
2. 自動返信メールが送信されていることを確認
3. GoogleスプレッドシートのリードリストにIDが追加されていることを確認

### 3-3. LINE友だち追加が入ったら
1. LINE Official Account Managerでの通知を確認
2. あいさつメッセージが自動送信されていることを確認
3. ステップ配信のスケジュールを確認

## 4. STEP2: セミナー運営

### 4-1. セミナー前の準備（開催7日前〜）

| タスク | 担当 | 期限 |
|-------|------|------|
| Zoom URLの発行 | 営業 | 7日前 |
| セミナースライドの最終確認 | 営業 | 3日前 |
| リマインド配信設定の確認 | CS | 3日前 |
| 申込者リストの確認 | 営業 | 1日前 |

### 4-2. セミナー当日の運営

#### 開始前（30分前〜）
1. Zoom開室、画面共有テスト
2. スライド資料を開いておく
3. 録画開始ボタンの確認

#### セミナー中（約90〜100分）
| 時間 | 内容 | ポイント |
|------|------|---------|
| 0-10分 | 自己紹介・会社紹介 | 実績で信頼構築 |
| 10-30分 | 市場の可能性 | CAGR※の数値を使う |
| 30-50分 | ビジネスモデル説明 | 「技術不要・1名運営」を強調 |
| 50-70分 | 収支データ公開 | 12ヶ月分の月次データ |
| 70-85分 | FC条件・費用説明 | 比較表で他FCと差別化 |
| 85-100分 | Q&A・次のステップ案内 | 個別面談への誘導 |

#### 終了後
1. 録画データを保存し、ダッシュボードにアップロード
2. 参加者リストを更新
3. セミナー後フォローメールの配信を確認
4. 個別面談の日程調整を開始

### 4-3. セミナー後フォロー

| タイミング | アクション | チャネル |
|-----------|-----------|---------|
| 当日中 | お礼メッセージ + アーカイブ | LINE |
| 翌日 | 個別面談の案内 | メール |
| 3日後 | リマインド | SMS |
| 7日後 | ラストチャンス | LINE |

## 5. STEP3: 個別面談・クロージング

### 5-1. 面談前の準備
1. クライアントの情報を確認（お客様カルテの記入状態）
2. 提案書を準備（ダッシュボードの提案書セクション参照）
3. 収支シミュレーションを準備

### 5-2. 面談の進め方（約60分）

| 時間 | 内容 | ポイント |
|------|------|---------|
| 0-10分 | アイスブレイク | セミナーの感想を聞く |
| 10-25分 | ヒアリング | 動機・資金・時期・エリア |
| 25-40分 | 提案 | 収支モデルをカスタマイズ |
| 40-50分 | 質疑応答 | 不安要素を1つずつ解消 |
| 50-60分 | ネクストステップ | 契約意思の確認 |

### 5-3. クロージングの要点
- **今だけの条件**を明示（0次募集は加盟金100万円、通常は200万円）
- **投資回収期間**を具体的に（14ヶ月）
- **他のオーナーの声**を共有
- 即決できない場合は**次の具体日程**を必ず確保

## 6. STEP4: 契約・オンボーディング

### 6-1. 契約手続き
1. クラウドサインで契約書を送付
2. 入金確認（加盟金 + 初期費用）
3. 領収書の発行

### 6-2. キックオフMTG
1. ダッシュボードのURLを共有
2. ガントチャートで全体スケジュールを説明
3. 初回ヒアリング（お客様カルテの記入）

## 7. UTAGE操作ガイド

### 7-1. ログイン
1. UTAGEログインページにアクセス
2. リッツプロのアカウントでログイン
3. クライアントのワークスペースを選択

### 7-2. リード管理
1. 左メニュー「コンタクト」をクリック
2. ファネルごとのリード一覧が表示される
3. リードのステータスを確認・更新

### 7-3. ファネル管理
1. 左メニュー「ファネル」をクリック
2. LP・サンクスページの編集が可能
3. 編集後は必ず**プレビュー**で確認

### 7-4. メール配信
1. 左メニュー「メール配信」→「ステップメール」
2. シナリオを選択
3. 配信テスト（自分のアドレスに送信）を実施
4. 本番配信のスケジュールを設定

### 7-5. 注意事項
- ⚠️ 編集後は**必ず保存**ボタンをクリック
- ⚠️ ファネルの公開/非公開の切り替えに注意
- ⚠️ テスト配信は**本番配信前に必ず**実施

## 8. LINE公式アカウント運用

### 8-1. あいさつメッセージの更新
1. LINE Official Account Manager にログイン
2. 「あいさつメッセージ」→ 編集
3. テストアカウントでブロック→再追加してテスト

### 8-2. リッチメニューの更新
1. 「リッチメニュー」→ 編集
2. 6マスのボタンとアクションを設定
3. 画像のアップロード（推奨サイズ: 2500×1686px）

### 8-3. 自動応答の管理
1. 「自動応答メッセージ」→ キーワード一覧
2. キーワードとレスポンスの追加/編集
3. テスト送信で動作確認

### 8-4. 配信履歴の確認
1. 「分析」→ メッセージ配信
2. 開封率・クリック率を定期確認
3. 月次でレポートに反映

## 9. 用語集

> 詳細は [ritzpro-sales-glossary.surge.sh](https://ritzpro-sales-glossary.surge.sh/) を参照

| 用語 | 説明 |
|-----|------|
| **CAGR** | 年平均成長率。市場の成長性を示す指標 |
| **CF (キャッシュフロー)** | 会計上の利益ではなく、実際の現金の流れ |
| **PL** | 損益計算書。過去の会計上の利益を表す |
| **M&A** | 合併・買収。FC事業の出口戦略として重要 |
| **FL比** | 原価(Food) + 人件費(Labor)の売上高比率 |
| **UTAGE** | ファネル構築・メール配信・決済を一元管理するツール |
| **ステップ配信** | 登録日を起点に、日数ごとに自動送信するメール/LINE |
| **0次募集** | FC事業立ち上げ初期の特別条件での募集（加盟金優遇あり） |
| **クラウドサイン** | 電子契約サービス。FC契約書のデジタル化に使用 |
| **リッチメニュー** | LINE公式アカウントの画面下部に固定表示されるメニュー |
| **ファネル** | 見込み客を顧客に転換するための導線の仕組み |
| **デポジット** | 広告運用費の前払い預かり金 |
| **ロイヤリティ** | FC本部が加盟店から毎月受け取る対価 |
| **HQ構築** | 本部(Headquarters)の構築。FC展開の土台作り |
