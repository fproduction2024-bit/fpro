# Meta広告 出稿・運用マニュアル
**対象: 嶋岡さん（株式会社rtma）**

> このマニュアルは「アカウント開設 → ユーザー追加」が完了した後の、**実際に広告を出すための手順**です。

```
Step 1: Metaピクセルを設置する（計測タグ）
```

## Step 1: Metaピクセルを設置する ⚠️ 最重要

> **ピクセルとは？**
> MetaがLPに来た人を「誰が来たか・何をしたか」追跡するための計測タグです。
> これを設置しないと広告の効果が測れず、Metaのアルゴリズムも賢くなりません。
> **広告を出す前に必ず設置してください。**

### 1-1: ピクセルを作成する

1. [ビジネス設定](https://business.facebook.com/settings) にログイン
2. 左メニュー「**データソース**」→「**ピクセル**」
3. 「**追加**」をクリック
4. ピクセル名を入力（例：`ONサロン ピクセル`）→「作成」
5. **ピクセルID（16桁の数字）** が発行される → どこかにメモしておく

### 1-2: LPにピクセルコードを貼る

「設定を続行」→「コードを手動でインストール」を選択すると以下のコードが表示されます：

**貼る場所: LPの `<head>` タグの中（`</head>` の直前）**

| LPの種類 | 貼り方 |
|---|---|
| **ペライチ** | ページ設定 →「タグ埋め込み」→ headタグ内 |
| **UTage / LINEページ** | ページ設定 →「カスタムHTMLヘッダー」 |
| **WordPress** | 「Insert Headers and Footers」プラグインを使用 |
| **自作HTML** | `index.html` の `<head>〜</head>` 内に直接貼付 |

### 1-3: 動作確認（必須）

1. Chromeで「**Meta Pixel Helper**」拡張機能をインストール
2. ピクセルを設置したLPにアクセス
3. ブラウザ右上のアイコンをクリック
4. ✅ 緑色で「**PageView**」と表示されればOK
5. ❌ エラーが出る場合 → コードの貼り付け位置を確認

> 💡 ピクセルのデータ反映には最大20分かかる場合があります

### 1-4: コンバージョンイベントを設定する（LINE登録を計測）

LINE登録が完了した後のサンクスページに以下を追加：

```html
<script>
  fbq('track', 'Lead');
</script>
```

これでLINE登録1件 = 広告の「成果1件」として計測されます。

> コードが触れない場合は「**イベント設定ツール**」（ノーコード）でも設定できます。
> ビジネスマネージャ → イベントマネージャ → 「イベント設定ツール」

## Step 2: キャンペーンを作成する

1. [広告マネージャ](https://adsmanager.facebook.com) にアクセス
2. 「**＋作成**」ボタンをクリック
3. **キャンペーンの目的**を選択:

| 目的 | いつ使う？ |
|---|---|
| **リード獲得** | LINEフォームやメール登録を直接収集したい |
| **トラフィック** | LPへの誘導を増やしたい |
| **コンバージョン** | LP経由でLINE登録・問い合わせを増やしたい ← **rtmaの場合おすすめ** |

> **おすすめ**: ピクセルを設置してLead計測ができているなら「**コンバージョン**」目的を選択。
> ピクセルがまだ安定していない初期は「**トラフィック**」でLP誘導から始めるのも◎

4. **キャンペーン名** を入力（例：`【FC募集】ONサロン_2026年4月`）
5. **キャンペーン予算の最適化（CBO）**: はじめのうちはオフで問題なし
6. 「**次へ**」

## Step 3: 広告セット（ターゲット・予算）を設定する

### 3-1: コンバージョンの場所を設定

- 「コンバージョンの場所」→「**ウェブサイト**」を選択
- ピクセルを選択 → コンバージョンイベント「**Lead**」を選択

### 3-2: ターゲティング

**Advantage+ オーディエンス（AI任せ）がおすすめ**

はじめのうちはMetaのAIに任せる方が結果が出やすいです。以下だけ設定：

- **地域**: 日本
- **年齢**: 30〜55歳（FC加盟希望者層）
- **性別**: 指定なし（または女性メインならフィルター）

詳細ターゲティングで追加したい場合:
- 「フランチャイズ」「起業」「美容サロン経営」「エステ」などの興味関心

### 3-3: 配置（プレースメント）

- **Advantage+ 配置（推奨）**: Metaが自動で最適な場所（フィード・ストーリーズ・リール等）に配信
- 手動にしたい場合: Facebook&Instagramのフィード・ストーリーズのみに絞ることも可

### 3-4: 予算・スケジュール

| 段階 | 推奨日予算 | 期間 |
|---|---|---|
| **テスト段階** | ¥1,000〜¥3,000/日 | 最低2週間 |
| **改善段階** | ¥3,000〜¥10,000/日 | 2週間〜1ヶ月 |
| **スケール段階** | ¥10,000〜/日 | 継続 |

> ⚠️ テスト段階で急に予算を上げるとMetaの学習がリセットされます。段階的に上げてください。

- **入札戦略**: 最初は「**最小コスト（自動）**」推奨

## Step 4: 広告クリエイティブを作成する

### 4-1: フォーマット選択

| フォーマット | 特徴 | おすすめ度 |
|---|---|---|
| **シングル画像** | 作りやすい・安定して計測しやすい | ◎ まずこれから |
| **動画** | エンゲージメント高・単価が下がりやすい | ◎ 慣れたら挑戦 |
| **カルーセル** | 複数枚見せられる・商品が多いときに有効 | △ 今は不要 |

### 4-2: 画像・動画のサイズ

| 使用場所 | 推奨サイズ |
|---|---|
| フィード（正方形） | 1080 × 1080px |
| ストーリーズ・リール（縦長） | 1080 × 1920px |
| フィード（横長） | 1200 × 628px |

> 💡 迷ったら **1080×1080px（正方形）** をメインに作るのが一番効率的です

### 4-3: コピー（文章）の書き方

**メインテキスト（本文）— 最初の3行が命**
```
例）
女性オーナーが月商100万円を実現。
黄土よもぎ蒸しサロンのフランチャイズモデルを、
今なら詳しい資料でご確認いただけます。
```

- 125文字以内が推奨（それ以降は「もっと見る」で隠れる）
- 最初の1〜2行で「誰向けか」「何が得られるか」を伝える
- 数字・実績を入れると効果的（「月商100万円」「加盟後3ヶ月で黒字化」など）

**見出し（ヘッドライン）— 27文字以内**
```
例）
「よもぎ蒸し×FCで安定収益」
「初期費用200万円〜。女性に人気のサロン開業」
```

**CTA（ボタン）**
- LINE登録系 → 「詳しくはこちら」「登録する」
- 資料請求系 → 「資料を請求する」「無料で受け取る」

### 4-4: A/Bテスト（複数パターンを試す）

最低 **3パターン** のクリエイティブを用意して同時配信し、数値を見て絞り込みます。

- パターンA: 画像違い（サロン外観 vs オーナー顔写真 vs 商品アップ）
- パターンB: コピー違い（悩みフック vs 数字訴求 vs ストーリー）
- パターンC: ターゲット違い（Advantage+ vs 詳細ターゲティング）

## Step 5: 公開・審査・配信開始

### 公開前チェックリスト

- [ ] LPのURLが正しいか（実際にクリックして確認）
- [ ] ピクセルが正しく発火しているか（Pixel Helperで確認）
- [ ] クリエイティブに誤字・脱字がないか
- [ ] 予算の桁を間違えていないか（¥1,000 と ¥10,000 を見間違えないよう注意）
- [ ] クレジットカードが有効になっているか

### 審査について

- 「**公開する**」をクリックすると審査がスタート
- 通常 **24時間以内**（早ければ数時間）で審査完了
- 審査通過後、自動的に配信開始

> ⚠️ 審査で否認される場合の主な原因
> - 「保証」「確実に稼げる」などの断定表現
> - 過激なビフォー・アフター
> - 年収・投資利回りの保証文言
> → 「実績があります」「可能性があります」などの表現に置き換えてください

## Step 6: 出稿後の数値チェック

### 最初の3〜7日間は触らない！

Metaの学習フェーズ（データ蓄積期間）です。設定変更すると学習がリセットされます。
**最低でも50件のコンバージョン（Lead）が貯まるまでは手を付けないのが原則です。**

### 1週間後から確認する指標

[広告マネージャ](https://adsmanager.facebook.com) で以下の数値を確認します：

| 指標 | 意味 | 目安 |
|---|---|---|
| **リーチ** | 広告が何人に届いたか | — |
| **インプレッション** | 広告が表示された回数 | — |
| **CTR（クリック率）** | クリックされた割合 | **1%以上**なら合格ライン |
| **CPC（クリック単価）** | 1クリックのコスト | 業種によるが¥100〜300が目安 |
| **CPL（リード単価）** | 1件の登録・問い合わせのコスト | **¥1,000〜3,000以内**が目標 |
| **フリクエンシー** | 同じ人に何回広告が届いたか | **3以上**になったらクリエイティブ変え時 |

### 列の追加方法（カスタム設定）

広告マネージャ →「列」→「列をカスタマイズ」から上記の指標を追加できます。

## Step 7: 改善サイクル（PDCAを回す）

### 改善の基本フロー

```
① 配信開始（最低3〜7日は触らない）
    ↓
② 数値確認（CTR・CPL・フリクエンシーを見る）
    ↓
③ 成果の悪い広告をオフ
    ↓
④ 成果の良い広告の予算を少しずつ増額（一度に20%以内が安全）
    ↓
⑤ 新しいクリエイティブを追加（2〜4週間ごとにリフレッシュ）
    ↓
② に戻る
```

### クリエイティブの寿命

Meta広告は同じクリエイティブを使い続けると**広告疲れ（クリエイティブ疲弊）**が起きてCTRが下がります。

- フリクエンシーが **3を超えたら** 新しい画像・動画に差し替える
- 目安として **2〜4週間**ごとに新しいクリエイティブを追加

### 予算のスケールアップ方法

| タイミング | やること |
|---|---|
| CPLが目標以内で安定している | 日予算を **20%ずつ**増額（毎週） |
| CPLが悪化してきた | クリエイティブを差し替えてから再度様子見 |
| フリクエンシーが高い | 新規オーディエンス（類似オーディエンス等）を追加 |

## よくある質問（FAQ）

**Q: 広告費は毎月固定で引き落とされますか？**
A: いいえ。Metaは**使った分だけ**クレジットカードに請求されます。日予算×配信日数が実際のコストです（端数あり）。

**Q: 広告が審査で否認されました。どうすればいいですか？**
A: 「断言する表現」「保証」「誇大広告」などが原因の場合が多いです。テキストを修正して再申請してください。繰り返し否認される場合はリッツプロに相談ください。

**Q: キャンペーンを途中で止めることはできますか？**
A: はい。広告マネージャで「オン/オフ」の切り替えがいつでもできます。休止して再開することも可能です。

**Q: リッツプロが広告を管理してくれるのですか？**
A: リッツプロはパートナーとしてアカウントにアクセスし、レポート確認・設定サポートを行います。クリエイティブの制作・改善提案はリッツプロ側で実施します。

**Q: Instagramにも同時配信できますか？**
A: はい。アカウント開設マニュアルの「Step 6: Instagramアカウント連携」が完了していれば、同じキャンペーンからInstagramにも自動配信されます。

## トラブルシューティング

| 問題 | 対処法 |
|---|---|
| 広告が配信されない | 審査中 or 予算が足りない。広告マネージャの「エラー」表示を確認 |
| CTRが低い（1%未満） | クリエイティブ（画像・コピー）が刺さっていない。差し替えを検討 |
| CPLが高い（¥5,000超え） | ターゲットが広すぎる or LP自体の改善が必要。LP離脱率を確認 |
| ピクセルが発火しない | `<head>`タグ内にコードが入っているか確認。Pixel Helperで診断 |
| クレジットカードが拒否される | カード会社に「海外決済（Meta Platforms）」の許可を連絡 |
| 広告アカウントが停止された | Metaの審査基準違反の可能性。リッツプロに相談を |
