# サンクスページ → LINE導線 設計書

> リッツ・PRO CS改善施策 — 2026年3月

---

## 1. 現状と課題

### 現行フロー
```
広告クリック → FC募集LP → セミナー申込フォーム → サンクスページ（終了）
```

### 課題
- サンクスページで導線が途切れている
- LINE登録への明確なCTAがない
- セミナー前のナーチャリング（教育・関係構築）ができていない
- 申込者とのコミュニケーション手段がメールのみ

---

## 2. 改善後のフロー設計

### 全体フロー図
```
広告クリック
    ↓
FC募集LP
    ↓
セミナー申込フォーム
    ↓
サンクスページ ←【ここを改修】
    ├── ① LINE友だち追加ボタン（メインCTA）
    ├── ② QRコード表示（スマホ以外用）
    └── ③ 限定特典の訴求テキスト
         ↓
LINE友だち追加
    ↓
あいさつメッセージ（自動）
    ├── セミナー日時の確認
    ├── 限定特典の配信
    └── リッチメニュー表示
         ↓
セミナー前ステップ配信（自動）
    ├── 前日リマインド
    ├── 当日リマインド
    └── セミナーZoom URL送付
         ↓
セミナー参加
    ↓
セミナー後フォロー配信（自動）
    ├── お礼メッセージ
    ├── 個別面談の案内
    └── 決断促進メッセージ
```

## 3. サンクスページ改修仕様

### 追加要素

#### 3-1. メインCTA（LINE登録ボタン）
```
📍 配置: サンクスメッセージの直下、ファーストビュー内
📐 サイズ: 幅100%（最大480px）、高さ60px
🎨 デザイン: LINEグリーン（#06C755）、角丸12px
📝 テキスト: 「LINEで限定資料を受け取る 📩」
🔗 リンク: LINE公式アカウント友だち追加URL
```

#### 3-2. 特典訴求
```
━━━━━━━━━━━━━━━━━━━
🎁 LINE登録者 限定特典
━━━━━━━━━━━━━━━━━━━

✅ 特典①: FC加盟オーナー収支モデル（12ヶ月分の実績データ）
✅ 特典②: よもぎ蒸し市場レポート2026
✅ 特典③: セミナーで使用するスライド資料（事前配布）

※ セミナー前にLINEでお届けします
```

#### 3-3. QRコード表示
- PC閲覧者向けにLINE QRコードを表示
- スマホ表示時は非表示（CSSメディアクエリ）

#### 3-4. 緊急性の演出
```
⚠️ 本セミナーは定員制です。
LINE登録後、すぐに参加URLをお送りします。
```

### ページ構成（上から順）
1. ✅アイコン + 「お申込みありがとうございます」
2. セミナー日時・形式の確認
3. **LINE登録CTA**(NEW)
4. **特典リスト**(NEW)
5. **QRコード**(NEW / PC表示時のみ)
6. 注意事項（Zoom参加方法など）

## 5. UTAGE設定手順

### 5-1. サンクスページ編集
1. UTAGE管理画面 → ファネル → 該当サンクスページ
2. HTMLブロックを追加
3. LINE友だち追加ボタンのHTMLを挿入
4. 特典訴求テキストを追加
5. プレビューで確認

### 5-2. LINE連携設定
1. LINE Official Account Manager → 友だち追加URL取得
2. UTAGEのサンクスページにURL埋め込み
3. LINEあいさつメッセージを上記に更新
4. リッチメニューを更新
5. 自動応答キーワードを設定

### 5-3. ステップ配信設定
1. UTAGEのLINEステップ配信 → 新規シナリオ作成
2. 上記スケジュールに沿ってメッセージ登録
3. トリガー: LINE友だち追加時に自動開始
