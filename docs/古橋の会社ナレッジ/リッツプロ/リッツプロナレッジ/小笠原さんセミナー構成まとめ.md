## 第2部：スケールアップ8ステップ

### ステップ1：明確なゴール設定
- いつまでに、どれぐらいの規模を目指すか
- 企業戦略は **生存戦略** と **出口戦略** の2種類

### 会社の出口5パターン
| # | 出口 | 備考 |
|---|------|------|
| 1 | 倒産 | — |
| 2 | 清算 | — |
| 3 | 承継 | 従業員・息子等に |
| 4 | 上場（IPO） | — |
| 5 | **M&A** | 近年のトレンド、税率20% |

### M&A売却金額の算出
- **マルチプル法**：将来の営業利益 × 5〜7倍
- DCF法：上場企業向け

### ステップ2：市場調査とニーズの把握
- ゴールに対して市場が存在するか確認
- 200店舗程度までは日本市場で対応可能

### ステップ3：最短達成のための戦略設計
- 経営戦略の4層構造：**全社戦略 → 事業戦略 → 機能戦略 → 財務戦略**

### ステップ4：パッケージ化
- 接客の仕組み、集客方法、商品提供、カスタマーサクセス、経営・会計をパッケージに

### ステップ5：業務のシンプル化・効率化 ⚠️最重要
> **ここを飛ばすとほぼ短期間で衰退する**

- 教育期間の圧縮（小顔サロン例：業界平均1ヶ月 → 1週間 → **3日**）
- **品質許容の考え方**：拡大には品質をある程度許容する必要がある
  - 例：シーシャバー（フレーバーごとの細かい調整を廃止→統一マニュアル化）
  - 例：寿司郎・くら寿司 vs 職人寿司屋
- ターゲット変更の検討（品質を落としたら、満足するターゲットも変わる）
- コカコーラの変遷：「喉が乾いたら」→「リフレッシュ」→「いつでもどこでも」

### ステップ6：強力なマーケティングの実施
- **0次募集**（3〜10店舗）：マニュアル改善パートナー、割安で契約
- **1次募集**：一気に展開
- **2次募集**：さらなる拡大

### ステップ7：回収＆投資
- ROAS・CPAで費用対効果を追求
- 利益を出しながら加盟店を開拓する仕組みづくり

## 第3部：M&A売却のメリット

| メリット | 内容 |

- 月200万円の営業利益 → 年間2400万 → ×5倍 = 1.2億円バリュー

- **年商25億の会社を作るより遥かにハードルが低い**

## 第4部：FC本部構築の核心

### 本部構築の3要素

```
┌─────────────────────────┐
│   ① 社会性（共感）      │ ← MVV・ESG・SDGs
│   ② 専門性（差別化）    │ ← 何専門か？を尖らせる
│   ③ 拡大性（スケール）  │ ← 市場・ニーズ・品質許容
└─────────────────────────┘
```

> 契約に至らない原因は収益性ではなく、**専門性・社会性の不足**が大半

### 社会性の具体例
- **ESG**（投資家・経営者向け）と**SDGs**（消費者向け）の違いを理解
- 小顔サロンBUPURA：「女性の雇用」を社会テーマに（18時閉店 → 主婦が働ける）
- ライトに始めるなら**年間10万円程度の寄付**から（活動報告を自社PRに活用）

### 専門性の具体例
- **がん専門医の原理**：課題が深いほど単価が高い
- ライザップの真のターゲット：**「努力せずに痩せたい人」**
  - 高単価顧客の心理：お金・時間・労力をかけたくない
- スターバックス：コーヒーではなく**「サードプレイス（居場所）」**
- 焼肉ライク：**1人焼肉**に特化
- くら寿司：**ガチャガチャでファミリー層**を取り込み（業績20%改善）

### レッドオーシャン×ブルーオーシャン戦略
> **レッドオーシャンの業界で、ブルーオーシャンの土地に出す＝店舗ビジネス最強の勝ち方**

- 小顔サロン例：ホットペッパーで「小顔サロン」の競合がほぼゼロ
- 全店舗の集客がHPBだけで9割完結
- **加盟オーナーの半年以内2店舗目出店率：100%**

### サブスクモデルの効果
- 売上安定 → オーナーが安心して2店舗目を出店
- エリア合戦要素への対応（良い立地の早期確保）

## 第5部：拡大段階別の戦略

| 段階 | 意識すべきこと | ポイント |
|------|---------------|----------|
| **〜10店舗** | 再現性 | 本部でできても加盟店でできない施策は入れない（例：Instagram不採用） |
| **〜20店舗** | エンゲージメント | オーナーと**リアルで会う**。2ヶ月に1回以上。関係性がニーズと2店舗目出店を生む |
| **〜50店舗** | マーケティング絞り込み | 自社に合った5〜7手法に集中 |
| **〜100店舗** | オーナー出店数 | 既存オーナーの複数店舗出店率を最重要KPIに |

### 加盟店開拓の主要手法（優先順）
1. **Meta広告**（Facebook/Instagram）← 最初は必ずこれ
2. **YouTube広告** ← 動画で差別化、契約率向上
3. **資料請求型広告**
4. **プラットフォーム**（アントレ、アイデア等）← ブランド力があれば有効
5. **展示会出展**
6. **脳オーガニック戦略** ← 他社の未活用メールリストを成果報酬で活用

### ブランド力の構築
- テレビ出演（バイイング：500万〜3,000万、プレスリリース：無料）
- 企画盛り込み型：30〜50万円でタレント付き出演
- **本の出版**：自費出版5万円〜、帯にタレント起用50万円
- タレントアンバサダー起用

### マニュアルの構成要素
1. 目的と範囲（施術/接客/オープン/閉店等）

- 文字マニュアル vs 動画マニュアルの使い分け

## 第7部：サービス・料金

### リッツプロの支援モデル
- **成果報酬制**：広告費・LP制作費はリッツプロが負担
- 報酬は**加盟金からのみ**（ロイヤリティ・仕入れからは取らない）
- 月間支援先：**1社限定**
- 社内審査あり（直営店最低1店舗が条件）

### 推奨ロイヤリティ設計
- **固定型 ＋ 仕入利益**を推奨（パーセント型は計算・修正が煩雑）

### 収益シミュレーション（月5件新規加盟の場合）
| 項目 | 金額 |
|------|------|
| ロイヤリティ（固定10万/月） | 1年後：月600万円 |
| 3年契約換算の価値 | 約2.16億円 |
| 加盟金300万×20件（1年目） | 6,000万円 |
| 加盟金300万×50件（2年目） | 1.5億円 |

### 加盟店獲得コスト
| 指標 | 数値 |
|------|------|
| 申し込みCPA | 約3万円 |
| 着席率 | 約50% |
| 着席CPA | 約5〜6万円 |
| 契約率 | 10〜20%（10人中1〜2人） |
| 契約CPA | 約60万円 |
| 月間広告費目安 | 50〜100万円 |

### 実績ハイライト
| 案件 | 実績 |
|------|------|
| 小顔サロンBUPURA | 3年で56店舗（直営7+FC49）→ **13億円で売却予定** |
| 経営者コミュニティLISA&NA | 月額11万×100名突破、4大都市FC展開 |
| NBドローンスクール | 3ヶ月で11加盟獲得 → 20億円企業に成長 |
| 某美容サロン | 19店舗→148店舗 → **上場企業に売却済** |
| 某卸売代理店 | 1年で50社以上開拓 |

## 重要キーワード集

| 用語 | 意味 |
|------|------|
| マルチプル法 | 営業利益×倍率でM&A価格を算出 |
| DCF法 | 上場企業向けのM&A価格算出法 |
| ROAS | 広告費用対効果（Return On Ad Spend） |
| CPA | 顧客獲得単価（Cost Per Acquisition） |
| ESG | 投資家向けのサステナビリティ指標 |
| SDGs | 消費者向けのサステナビリティ目標 |
| 価値KPI | 顧客が本当に求めている価値の指標 |
| 脳オーガニック | 他社リストを成果報酬で活用する集客戦略 |
| 0次募集 | マニュアル改善用の初期加盟店獲得（3〜10店舗） |
