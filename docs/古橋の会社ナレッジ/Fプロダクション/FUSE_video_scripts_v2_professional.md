## 📽 第3話：なぜ、あなたの価値は「あなた」には見えないのか
**【コンセプト】** 実装の壁（面倒くささ）を認めつつ、それを突破するための「メタ認知」と「経済的合理性」を教育する。

| 構成ブロック | 映像イメージ | 脚本（ナレーション/セリフ） |
| :--- | :--- | :--- |
| **1. 実装という名の「泥沼」** | 複雑なツール設定画面や、未完成のLP原稿。 | 「自動化が大事なのは分かった。でも、いざやろうとすると絶望しませんか？ LINEの設定、動画編集、ステップメールの執筆…。本職ではないことに脳のリソースを奪われ、結局、最も大切な商品開発が止まってしまう。これはコンテンツホルダーにとって最大の悲劇です。」 |
| **2. メタ認知の科学** | 鏡を見ている人のイラスト。 | 「そもそも、あなたの商品の『真の価値』は、あなた自身には絶対に見えません。鏡なしで自分の顔が見えないのと同じです。多くの人が、自分の『当たり前』の中に眠っている1億円の原石を、ただの石ころだと思って放置しています。独自の価値を引き出し、他人に伝わる『形』にするには、客観的な『メタ認知』が不可欠なのです。」 |
| **3. 支出ではなく「節約」** | ROI比較図：自力（月300時間損失） vs FUSE導入 | 「『構築にお金がかかる』と考えるのは、今日でやめてください。非効率な集客に毎月30万円垂れ流したり、本来100万円の案件を取れるあなたが、時給数千円の作業に没頭することこそが、最大のリスクであり、損失です。FUSEを導入することは、あなたの『時給』を正しく機能させ、数千万円単位の機会損失を食い止める、最も賢い『お金の節約』なのです。」 |
| **4. 全自動の正体** | テロップ：あなたは語る、私たちは作る。 | 「あなたはただ、私にあなたの想いを語るだけでいい。後の面倒なことは、全て私たちが肩代わりします。その全貌を、次回の最終回で公開します。」 |

## 📽 第4話（VSL）：FUSE 〜あなたの自由を再定義する、フルオート・ファネル〜
**【コンセプト】** FUSEのサービス内容、価格、そして古橋氏と共に歩む未来への強いオファー。

| 構成ブロック | 映像イメージ | 脚本（ナレーション/セリフ） |
| :--- | :--- | :--- |
| **1. 運命の分岐点** | 2つの道のイメージ（現状維持 vs FUSE） | 「ここまでご覧いただき、ありがとうございます。今、あなたは分岐点にいます。今まで通り、時間を切り売りして売上の不安と戦い続けるか。それとも、仕組みを構築し、本来の価値提供に没頭できる自由を手に入れるか。その答えとして私が用意したのが、フルオート・ファネル構築サービス『FUSE（フューズ）』です。」 |
| **2. FUSEの3つの柱** | 1. メタ認知（商品企画） 2. 完全代行（実装） 3. 伴走（成果報酬） | 「FUSEは単なる制作サービスではありません。第1の柱は、私が直接あなたの『鏡』となり、1億円の価値を引き出す『商品企画』。第2の柱は、撮影、編集、構築、分析、全ての面倒を肩代わりする『完全実装』。そして第3の柱は、売上の10%という『成果報酬型』でのパートナーシップです。」 |
| **3. あなたの工数は「最小」** | 「過去の素材を活用」という図解。 | 「新しく何かを勉強する必要はありません。あなたが今までお客さんに伝えてきたメッセージ、既存の動画やテキスト。それらを私たちが整理し、最強の武器に磨き上げます。あなたの工数は、私との数回の面談と、数本の撮影。それだけで、24時間365日働き続ける『分身』が完成します。」 |
| **4. 覚悟のオファー** | 初期費用100万円 ＋ レベニューシェア10% | 「初期費用100万円。これを『高い』と感じる方は、申し訳ありませんが、私たちが力になれるフェーズではありません。これは、あなたの人生から『売上の不安』を永久に排除するための入場料です。私たちは、あなたの運命共同体として、共に売上を最大化させる覚悟を持っています。」 |
| **5. スクリーニングとクロージング** | テロップ：月間1社限定。 | 「ただし、誰でもお受けできるわけではありません。月間1社のみ。私が本気で『この人の価値を広めたい』と思える方だけを厳選します。もしあなたが、自分を信じてくれたお客さんに最高の恩返しをしたい、そのために自分の時間を買い戻したいと願うなら、下のリンクから審査面談に申し込んでください。あなたの情熱に、私の仕組みを。FUSEで、新しい景色を見に行きましょう。」 |
