# 第二話 構造化まとめ：お客様の体を確実に変えるための「ボディメイク理論」

## 1. 導入：前回の振り返りと本動画の目的
- **前回の要約**
  - 趣味の筋トレを活かしたオンライン副業＝ボディメイクコーチの提案。
  - COMPASS式メソッドで単価30万円以上でも選ばれるコーチになれる。
- **本動画の目的**
  - COMPASSメソッドの **Step 1「ボディメイク理論」** を解説。
  - お客様からお金をいただくために必要な知識レベルとその考え方を明確にする。
- **注意喚起**
  - 「NSCAなどのトレーナー資格を先に取るべきでは？」→ その前にこの動画を見てほしい。

## 2. 大前提：顧客視点の重要性
- **核心メッセージ**
  - 「お客様が求めているのは自分の体の変化であり、難しい理論ではない。」
  - 常に **顧客視点** を意識することがビジネスで稼ぐための絶対条件。
- **コーチの役割**
  - お客様の体型・健康の悩みを解決し、理想の体を手に入れるサポートをすること。

## 3. 体を変える3つの要素とゴール設定
- **3つの要素**
  - ① 食事 → 個人に合った食事プランを立てられるようになる。
  - ② 運動 → 個人に合ったトレーニングプランを立てられるようになる。
  - ③ 休養 → 正しい睡眠と休息を理解していること。
- **最重要ポイント：知識の優先順位**
  - 知識は無数にある → 断片的に学んでも「ノウハウコレクター」になるだけ。
  - **体への影響が大きい要素を体系的に学ぶ** ことが最短ルート。
  - 例：NSCA教科書の「筋収縮の仕組み（サルコメア・アクチンフィラメント）」は実践に使えない豆知識 → 後回しでOK。

## 4. ピラミッド理論①：栄養管理のピラミッド
- **構造**（下ほど重要・優先度が高い）
  - レベル1：**カロリー収支**（最重要）
  - レベル2：**3大栄養素（PFC）・食物繊維**
  - レベル3：微量栄養素・水分
  - レベル4：食事の回数・タイミング
  - レベル5：サプリメント
- **たとえ話（料理）**
  - レベル1＝味、レベル5＝見た目。味がまずい料理を綺麗に盛り付けても意味がない。
  - カロリー収支を無視してサプリメントを取るのは「味を無視してお皿選びに夢中になるようなもの」。
- **80：20の法則**
  - 土台の2つ（カロリー収支 + PFC）を管理すれば **80点** は取れる。
  - 残りの要素は100点に近づけるための20点に過ぎない。
- **食事プラン作成の6ステップ**
  - Step 1：目標摂取カロリーを設定する。
  - Step 2：3大栄養素の目標を設定する。
  - Step 3：微量栄養素が不足しない仕組みを作る。
  - Step 4：食事回数とタイミングを決める。
  - Step 5：必要であればサプリメントを選択する。
  - Step 6：食事内容を決める。

## 5. ピラミッド理論②：運動（トレーニング）のピラミッド
- **構造**（下ほど重要・優先度が高い）
  - レベル1：**継続すること**（最重要）
  - レベル2：**筋肉の動作と刺激**
  - レベル3：**ボリューム・強度・頻度**
  - レベル4：挙上成績の伸ばし方
  - レベル5：種目の選び方
  - レベル6：レスト時間
  - レベル7：挙上スピード
- **補足事項**
  - 各階層は複雑に絡み合うため、一部優先順位が入れ替わることもある。
  - ただし土台（継続・動作と刺激）が上位と入れ替わることは **絶対にない**。
- **ピラミッドの活用目的**
  - 断片的な知識を得たときに「その情報の重要度・優先度を判断する力」をつけるため。
  - 例：「重量 vs 効かせる」の迷い → 動作と刺激の観点から判断する。

## 6. ピラミッド理論③：休養のピラミッド
- **構造**（下ほど重要・優先度が高い）
  - レベル1：**睡眠**（最重要）
  - レベル2：休息期間
  - レベル3：リカバリー方法
  - レベル4：サプリメント
- **睡眠の重要性**
  - 睡眠不足がボディメイクに与える悪影響：
    - 筋肉が減りやすく、脂肪が増えやすくなる。
    - 食欲のコントロールが効かなくなる。
  - 食事・トレーニングを頑張っても停滞する場合 → まず睡眠時間を確認。
- **睡眠の質を上げる3つの行動**
  - ① **朝に日光を浴びる** → メラトニン分泌リズムが整い、夜にぐっすり眠れる。
  - ② **毎日湯船に浸かる** → 深部体温の上昇→下降で質の高い眠りに。就寝の1〜2時間前にぬるめのお湯が最適。
  - ③ **就寝時間と起床時間を固定する** → 体内時計が調整され、睡眠の質が向上。

## 7. まとめと次回予告
- **本動画のまとめ**
  - お客様の体を変えるには「食事・運動・休養」の3要素が必要。
  - 各要素には **優先順位のピラミッド** があり、土台から体系的に学ぶことが最短ルート。
  - 実践した内容をお客様に伝えれば結果は出る。
- **次回への布石**
  - ボディメイク理論だけでは **不十分**。
  - 理由：「人の本能は変わりたくない」から。
  - 体だけでなく **マインド（習慣・考え方）** もセットで変える必要がある。
  - → 次回（第三話）は「コーチングメソッド」を解説。
- **差別化の核心**
  - 脳の仕組みを理解した **本質的なサポート** ができれば、一般的なトレーナーとは完全に差別化。
  - 競合と価格比較されることなく、**高単価でも選ばれる** サービスになる。
