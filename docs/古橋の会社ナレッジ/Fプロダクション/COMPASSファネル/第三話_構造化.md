# 第三話 構造化まとめ：単価30万円でも売れる「コーチングメソッド」

## 1. 導入：前回の振り返りと本動画の目的
- **前回の要約**
  - Step 1「ボディメイク理論」を解説（食事・運動・休養の3つのピラミッド）。
  - ただし「ボディメイク理論だけでは不十分」→ **人の本能は変わりたくない** から。
- **本動画の目的**
  - COMPASSメソッドの **Step 2「コーチングスキル」** を解説。
  - 脳の仕組みに基づいた行動原理の理解 → 高単価でも選ばれるサービスの構築。
- **コーチングを学ばないと起きること**
  - 契約後にキャンセル・返金を求められる。
  - サポート終了後にお客様がリバウンドしてしまう。
  - → お互いの時間と努力が無駄になる。

## 2. コーチングとは何か
- **定義**
  - コーチングとは「マインドを書き換えること」。
  - 質問や対話を通じてお客様のマインドを変え、理想の状態に導く。
- **ボディメイク × コーチングの相性が良い理由**
  - 人の心と体は密接に連動している（運動・食事の習慣化 → メンタル改善）。
  - ボディメイクは正しく実践すれば100%結果が出る → コーチングが機能しやすい。
- **転用可能性**
  - ボディメイクで習得したコーチングスキルは、ビジネスや他領域にもそのまま応用できる。
  - → 単価50万円以上でも自信を持って販売可能。

## 3. 人間の3つの原理原則

### 原則①：人の本能は変わりたくない
- **前提**
  - 1年間ジム通いを継続できる人 = わずか **3.7%**（25人に1人以下）。
  - 続けられないのは「意志が弱い」からではなく、脳の仕組み上の正常な反応。
- **コンフォートゾーンとホメオスタシス**
  - **コンフォートゾーン** = 安心・安全な場所、自分にとっての「当たり前」。
  - **ホメオスタシス（恒常性）** = 現状を維持しようとする機能。
    - 例：サウナでの発汗、寒さでの震え（身体面）。
    - 例：腹筋が割れている人は忙しくてもジムに行く方法を考える（マインド面）。
- **コーチとしてのアクション**
  - まず自分とお客様の **コンフォートゾーンがどこにあるか** を把握する。

### 原則②：人の行動原理
- **因果の流れ**
  - **信念・アイデンティティ** → **感情** → **行動** → **結果**
- **具体例：コンビニでドーナツ vs サラダチキン**
  - Aさん（マッチョのアイデンティティ） → PFCを意識 → サラダチキン選択 → 割れた腹筋。
  - Bさん（肥満体型のアイデンティティ） → 好きなものを我慢すべきでない → ドーナツ選択 → ぽっこりお腹。
- **核心メッセージ**
  - 結果や行動を変えたければ、**根っこの信念・アイデンティティを変える** ことが重要。

### 原則③：痛みと快の法則
- **原則**
  - 人の全ての行動は「痛みを避ける」か「快楽を得る」かのどちらか。
  - **痛みを避けるエネルギーは快楽を得るエネルギーの5倍強い。**
- **具体例：二日酔いの朝**
  - 「1万円もらえる」（快楽）よりも「1万円を失う」（痛み）の方が行動を起こす動機になる。
- **コーチングへの活用**
  - 目標設定時に「得られる報酬」だけでなく、「達成しないことで受ける損失」も明確にする。

## 4. コーチングセッションのフレームワーク
- **セッションの3種類**
  - ① 体験セッション（販売時）→ 次回（第四話）で解説。
  - ② **目標設定セッション**（サポート初回）→ 今回のメイン。
  - ③ 定期セッション（サポート2回目以降）。

### 目標設定セッション：5つのステップ

#### Step 1：価値観の言語化
- **目的**: お客様が大事にしている価値観・考え方を明確にする。
- **質問例**:
  - 「○○さんにとっての自由とは何ですか？」
  - 「なぜそれが重要なのですか？」
  - 「それを感じるのはどんな時ですか？」
- **効果**: 信頼関係の構築 + 以降のセッションの質が格段に向上。

#### Step 2：目標設定
- **目的**: 心から達成したいゴールを明確にし、動機付けを強化する。
- **2つのポイント**:
  - ① **目標達成すべき理由の明確化**（痛みと快を目標に紐づける）。
    - 質問例：「達成するとどんな悩みを解決できますか？」「達成できなければどんな機会を失いますか？」
  - ② **リミティングビリーフの特定と書き換え**。
    - リミティングビリーフ = 可能性や行動を制限する固定観念。
    - 例：「自分の看板でお金を稼ぐのは無理」→ 事実ではなく解釈。
- **書き換え方法**:
  - お客様と似た（またはそれ以上に不利な）状況から成功した人のストーリーを伝える。
  - コミュニティで人が変わっていく姿をリアルタイムで共有する。

#### Step 3：KSF（Key Success Factor）と重要アクションの決定
- **KSF** = 目標達成に必ず必要な要素・状態。
  - 例：「カロリー計算が感覚でできる」「メンテナンスカロリーを把握している」「週3回の筋トレが習慣化」。
- **重要アクション** = KSFクリアにインパクトの大きい具体的行動。
  - 食事例：マイフィットネスパルに登録。
  - 運動例：エニタイムに入会、可変ダンベル購入。
  - 休養例：自分に合った枕購入、遮光カーテン購入。

#### Step 4：イフゼン（if-then）プランニング
- **定義**: 「もしAの状況になったらBをする」という最も効果的な習慣化メソッド。
- **例**: 「朝起きたら → カーテンを開ける → ベッドメイキング → 歯磨き → 白湯を飲む → 10分散歩」。
- **ポイント**:
  - イレギュラーへの対策（プランB）を事前に設定しておく。
  - 例：「雨で散歩できない → 家でスクワット10回」。
  - 小さな成功体験の積み上げ → モチベーション維持と継続。

#### Step 5：フォローアップ
- **内容**:
  - セッションの振り返り、疑問点・不安点の解消。
  - 次回セッションの日程調整。
  - コーチへのリクエスト確認。
  - 「やれる気」の醸成 → 最後にエールを送る。

## 5. コーチングの本質と差別化
- **表面 vs 本質**
  - 食事・運動だけの指導 = 一時的な結果 → サポート終了後にリバウンド。
  - 信念・アイデンティティへのアプローチ = 本質的な変化 → 自走可能。
- **差別化の核心**
  - 管理・強制ではなく、**マインドの書き換えによる自発的行動** を引き出す。
  - → 競合と比較されず、高単価でも選ばれる。
- **転用可能性**
  - このコーチングフレームワークはボディメイク以外（英語、ビジネス、恋愛等）にも転用可能。
  - 実際にCOMPASS生の中にはビジネスコーチングや英語コーチングに応用し、さらに高単価でマネタイズしている人もいる。
