## 3. 集客の方法

### SNS集客のメリットとデメリット
- **メリット**
  - 拡散性が高い（1投稿で何千・何万人にリーチ）。
  - 仕組みを構築すれば毎日更新しなくても見込み客を集められる。
- **デメリット**
  - 最初のお客様獲得までに **膨大な時間と労力** がかかる。
  - 実績なしでは商品が売れない。
  - 販売・サポート経験なしでリリースすると **一気に信頼を失うリスク** がある。
  - ゼロからなら成果が出るまで **最低3ヶ月以上**。

### 核心メッセージ：「SNSで集客したければSNSで集客するな」
- **要するに**: SNS集客の前に **まず実績を作る** べき。
- **ゴールのないマラソン問題**: 稼げる未来が見えない状態でSNSを頑張る → 挫折。
  - 目標勾配仮説：ゴールが近いほど行動が加速する。
  - 逆に、ゴールが見えなければ継続不可能。

### 実績作りのためのアウトバウンド集客
- **定義**: 見込み客に対して自分からアプローチする集客方法。
- **メリット**: SNS集客と比較して **顧客獲得までのスピードが圧倒的に早く、再現性が高い**。
- **推奨する3つの手法**:
  - ① **知人・友人への声かけ**（初心者に最もおすすめ）。
  - ② SNSでのDM。
  - ③ コミュニティの活用。

### モニターサポートの進め方
- **モニターサポートとは**: 本来価格よりも安く（場合によっては無料で）サービスを提供するお試し。
- **目的**: 収益を上げることではなく **サポート実績を作ること**。
- **具体的な手順**:
  1. 日常会話やLINEで自分の活動を伝える。
  2. 相手が興味を示したら「実績作りのためにモニター募集中。話だけでも聞いてみない？」とラフに提案。
  3. 了承を得たら日程を決めて **体験セッション（無料）** を実施。
- **ポイント**: 興味のない人に無理に提案しない。自分も「この人と一緒にやりたい」と思える人を選ぶ。

### 集客のステップまとめ
1. アウトバウンド集客（モニターサポート）で **実績と自信** を作る。
2. 実績を元に **SNS集客** に移行し、見込み客を効率よく集める。
3. フォロワーが増えたら **プロダクトローンチ** で一気に数百万円の売上も可能。
4. さらにローンチ後に **エバーグリーン導線** を構築 → SNS経由で毎月安定集客。

## 4. 販売の方法：カウンセリングセールス

### カウンセリングセールスとは
- **定義**: 質問を通して相手を深く理解し、「そのサービスが欲しい」という感情を自然に大きくする手法。
- **本質**: 「売らずに売れる」販売手法。
- **たとえ話（お医者さん）**:
  - ✕ 症状を聞かずにいきなり薬を出す → 不安。
  - ○ 痛みのレベル・周期・原因を細かく質問 → 信頼を感じる。
  - **質問の数 = 信用の大きさ**。

### 体験セッションの10ステップ
| Step | 名称 | 内容 |
|------|------|------|
| 1 | **ラポール構築** | 事前情報を元に軽い雑談、きっかけや自己紹介 |
| 2 | **プリフレーム** | 「価値を感じたら有料サポートの提案をしてもいいですか？」と事前合意 |
| 3 | **問題の確認** | 「今日はどうしましたか？」的にお客様の問題をざっくり確認 |
| 4 | **問題の拡大** | 現状放置のリスクを伝える（※脅しはNG。正確に起こりうる未来を伝える） |
| 5 | **理想の確認** | 「何のために痩せたいか」「痩せた先にやりたいこと」を深掘り |
| 6 | **仮クロージング** | 「理想の未来が手に入ったらどうですか？」→ 前向きな反応を確認 |
| 7 | **カウンセリング** | 食事・運動・睡眠の現状把握 + 軽い提案でイエスを積み上げる |
| 8 | **ロードマップ** | サポート後の具体的な流れを提示（例：1回目→自己理解ワーク → 6ヶ月後に理想の体） |
| 9 | **仮クロージング** | 理想の確認を再度行い「行動できそうですか？」でイエスを取る |
| 10 | **サービス提案** | 信頼関係が構築された状態で自信を持ってサービスを提案 |

### カウンセリングセールスの効果
- **受講生事例**: 制約率20% → カウンセリングセールス導入後 **制約率70%**（単価も16万→33万に値上げ）。
- **マインドの変化**: 「押し売り」→「お客様の相談に乗っていたら自然と売れる」感覚に。
