# 第一話 構造分析：全体像＋コアメッセージ

> **案件**: e-Harbor（3ステップセールスメソッド）
> **役割**: ファネル動画 第1話 / 全4話
> **推定尺**: 25〜30分
> **目的**: 問題認識 → 権威構築 → メソッド全体像の提示 → 次話への好奇心

---

## 全体構成マップ

```
┌─────────────────────────────────────────────────┐
│  1. フック（メリット提示＋対象者の明示）           │  ← 離脱防止
│  2. 回避できるリスクの列挙                         │  ← 痛みの喚起
│  3. 実績チラ見せ（数字）                           │  ← 信頼の種まき
│  4. 緊急性＋限定性の設定                           │  ← 視聴動機の強化
│  5. プレゼント予告                                 │  ← 最終話まで見る動機
│  6. 自己紹介＋権威付け                             │  ← 話者の信頼構築
│  7. 挫折→覚醒ストーリー                           │  ← 感情移入＋共感
│  8. 核心メッセージの提示                           │  ← 世界観のインストール
│  9. 売上の方程式で論理補強                         │  ← 納得感
│ 10. 常識の否定（集客が先は間違い）                 │  ← 気づきの付与
│ 11. 広告の前提条件                                 │  ← 伏線（第四話への布石）
│ 12. 3ステップメソッド紹介                          │  ← ロードマップ提示
│ 13. 自社実験の証明                                 │  ← 再現性の裏付け

│ 15. 理想の未来描写                                 │  ← 欲求の最大化
│ 16. 次回予告＋感想ボタンCTA                        │  ← 行動誘導
└─────────────────────────────────────────────────┘
```

## 各ブロック詳細

### ① フック：メリット提示＋対象者の明示
**テンプレート要素**:
- 「このセミナーでは〇〇ができるようになる方法をお伝えします」
- 対象者を具体的に列挙（コンサル、コーチ、講師、スクール運営者）
- 到達可能な数字を提示（30万、50万、100万以上）
- 「仕組み化・自動化」というキーワードで理想像を描く

**e-Harborでの実装**:
> 「あなたの商品がオンライン完結で、しかも高成約率で売れるようになる方法。集客からセールスまでの流れを全て最新事例をもとにお伝えします」

**再現ポイント**:
- 冒頭15秒以内に「何が手に入るか」を明言する
- 対象者を3〜4カテゴリ具体的に挙げる（自分ごと化させる）
- 数字は3段階（現実的→やや高め→理想的）で提示

---

### ② 回避できるリスクの列挙
**テンプレート要素**:
- 「逆に言うと、この動画を最後まで見ることで〇〇を回避できます」
- 3つ以上の具体的な痛みを列挙

**e-Harborでの実装**:
1. 長期間伸びないビジネスにお金と時間を奪われるリスク
2. 来月の売上が心配でお金の不安から抜けられない精神的苦痛
3. 毎日忙しく時間の切り売りから抜けられないジレンマ

**再現ポイント**:
- 「お金」「時間」「精神」の3軸で痛みを網羅
- 現状維持コストを認識させる（何もしないことのリスク）

---

### ③ 実績チラ見せ
**テンプレート要素**:
- 初心者向けの実績（ゼロから→短期間で〇〇万）
- 中級者向けの実績（年商〇〇万→〇億へ）
- あくまでチラ見せ。詳細はストーリーパートで展開

**e-Harborでの実装**:
> 「影響力0、知名度0の方でも3ヶ月を指標に100万以上の売上を作るクライアントが続出」
> 「1を10、10を100にしたい方には年商1000万から1億以上」

**再現ポイント**:
- レベル別の数字を出すことで「自分にも該当する」と思わせる
- 具体的な証拠はまだ出さず、好奇心を維持

---

### ④ 緊急性＋限定性の設定
**テンプレート要素**:
- 視聴期限の設定（=行動のデッドライン）
- 「本気の人だけに見てほしい」という選別メッセージ
- 問い合わせても対応不可という断言

**e-Harborでの実装**:
> 「このセミナー動画は3日間の限定配信。3日以上放置すると閲覧不可になり、二度と見れなくなります」

**再現ポイント**:
- 期限は「3日」が黄金バランス（短すぎず長すぎない）
- 「本気の人だけ」フレーズでスクリーニング意識を作る

---

### ⑤ プレゼント予告
**テンプレート要素**:
- 動画を最後まで見た人だけが受け取れるプレゼント
- プレゼント内容は「体験型」（診断、面談、セッション）
- 投資額を明示して価値を裏付ける

**e-Harborでの実装**:
> 「弊社の現役コンサルタントとワンオンワンであなたの売上アップ戦略を完全構築させるオーダーメイド戦略診断」
> 「2000万の事業投資から導き出した全ノウハウ」

**再現ポイント**:
- プレゼント＝実質的なバックエンドへの導線
- 「〇〇万円投資して導き出した」で価値のアンカリング

---

### ⑥ 自己紹介＋権威付け
**テンプレート要素**:
- 会社名・代表名
- 専門分野の明示
- クライアント実績の要約（数字で）
- 外部権威（メディア出演、テレビ取材等）
- チーム体制の紹介

**e-Harborでの実装**:
- 株式会社イーハーバー代表
- セールス専門のコンサルティング＋スクール事業
- 成約率80〜100%を達成するプロ集団
- 地上波テレビで「オンライン完結の自動化」として特集
- 6人のプロチーム体制

**再現ポイント**:
- 実績は「率」と「額」の両面で提示
- メディア出演はビジュアル素材があると強い
- チーム体制の明示＝「個人ではなく組織」の安心感

---

### ⑦ 挫折→覚醒ストーリー（最長ブロック）
**テンプレート構成**:

```
1. 過去の失敗（共感ポイント）
   └ 24歳で独立 → スキルなし → 情報に振り回される → 借金 → 廃業
2. どん底の描写
   └ 一文無し、サラリーマンに逆戻り、何のために独立したのか
3. 転換点（メソッドとの出会い）
   └ 飛び込み営業 → 「1冊の台本」との出会い
4. 覚醒の瞬間
   └ 台本通りに話したら150万が即決で売れた → 台本の凄さに驚愕
5. 成長の軌跡
   └ 成約率8割 → 月1000万 → 年間1億 → 30歳で再独立
```

**再現ポイント**:
- **失敗パートは具体的に**（年齢、金額、感情を入れる）
- **転換点は「1つの出会い」に集約**（メソッド/師匠/気づき）
- **覚醒は数字で証明**する（初商談で〇〇万が売れた）
- **ストーリーの起点が「今教えているメソッドの原点」になっている**

---

### ⑧ 核心メッセージの提示
**テンプレート要素**:
- 「結論、〇〇力をマスターすることです」と断言
- そのスキルがない状態で起きる問題を再列挙
- 業界の常識を否定するメッセージ

**e-Harborでの実装**:
> 「結論、高単価セールス力をマスターすることです」
> 「高単価セールス力がないまま仕組み化しようとしているから、全ての悩みが生まれる」

**再現ポイント**:
- 核心メッセージは**1フレーズに凝縮**
- 「〇〇がないから✕✕になる」という因果構造で説得力を出す

---

### ⑨ 売上の方程式（論理補強）
**テンプレート要素**:
- シンプルな数式で「なぜそのスキルが重要か」を論理的に証明
- 具体的な数字シミュレーション

**e-Harborでの実装**:
> **面談数 × 成約率 × 商品単価 ＝ 売上**
> - 50万×2件＝100万。成約率50%なら月4人集めるだけ
> - 逆算設計でやるべきことが明確になる

**再現ポイント**:
- 方程式は最大3要素に絞る
- 「たった〇人集めるだけ」と具体化して心理的ハードルを下げる

---

### ⑩ 常識の否定（パラダイムシフト）
**テンプレート要素**:
- 業界で「当たり前」とされていることを否定
- 正しい順序を提示

**e-Harborでの実装**:
> 「認知されるから売れるのではなく、**売れるから認知される**」
> 「まずSNS発信しましょう、ブランディングが大事と教えている人がいるが、**順番が逆**」
> 「商品設計→セールス→集客。**集客は最後**」

**再現ポイント**:
- 「AではなくB」という反転構文が効果的
- 多くの人が信じていることを否定するほどインパクトが大きい

---

### ⑪ 広告の前提条件（伏線）
**テンプレート要素**:
- 第四話（自動集客）への伏線を張る
- 「なぜ広告で失敗する人がいるのか」の理由をここで教育

**e-Harborでの実装**:
> 広告費15万→商品単価10万×成約率10%＝10万（赤字）
> 広告費15万→商品単価30万×成約率30%＝90万（黒字）
> **高単価＋高成約率がないと広告は回収できない**

**再現ポイント**:
- 数字シミュレーションで「先にセールスを固める理由」を補強
- 第四話への自然な導線になる

---

### ⑫ 3ステップメソッド紹介（ロードマップ提示）
**テンプレート要素**:
- メソッド名を付ける（ブランディング）
- 3ステップ以内に収める（認知負荷を下げる）
- 「シンプル」であることを強調

**e-Harborでの実装**:
> **3ステップセールスメソッド**
> 1. 売れる高単価商品を作る
> 2. セールス台本を作る
> 3. 自動集客を構築する

**再現ポイント**:
- メソッドには必ず固有名詞をつける
- 「難しく考える必要はない」「この3つがあれば成立する」と安心させる

---

### ⑬ 自社実験の証明
**テンプレート要素**:
- 「自分自身が実験台になった」というストーリー
- ゼロスタートの条件を明示
- 短期間での成果を数字で証明

**e-Harborでの実装**:
> 2021年にゼロから立ち上げ。見込み客ゼロ、影響力0、知名度0、商品なし
> → 45日で240万の売上 → 年商5000万超へ

**再現ポイント**:
- 「ゼロから」の条件を4つ以上列挙して強調
- 日数と金額のセットが説得力を生む

---

### ⑭ クライアント事例（3〜4名）
**テンプレート構成（1事例あたり）**:

| 要素 | 内容 |
|------|------|
| **Before** | 肩書き＋悩みの状況 |
| **メソッド適用** | 何をしたか（1行で） |
| **After** | 数字での成果 |

**e-Harborでの実装**:

| # | Before | After |
|---|--------|-------|
| 1 | 事務職、自分の商品なし | SNS講師として月100万超、フリーランス独立 |
| 2 | セールス苦手な女性経営者 | 商品単価30万→60万、18人中15人成約、620万達成 |
| 3 | シングルマザーのコーチ | LINE自動化で面談数爆増、1ヶ月で432万 |
| 4 | 美容サロン向け機械販売 | 単価120万→200万、成約率10%→80%、年商1.2億 |

**再現ポイント**:
- 最低3名、できれば4名以上
- 属性を分散させる（初心者/中級者/上級者、男性/女性）
- Before→Afterのギャップが大きいほど効果的

---

### ⑮ 理想の未来描写
**テンプレート要素**:
- 「一度想像してみてください」という導入
- 具体的なライフスタイルを列挙（3〜5個）
- 感情に訴えるシーン描写

**e-Harborでの実装**:
1. 好きなことに熱中できる自由
2. 家族や子供にやりたいことをやらせてあげられる
3. 場所に縛られず、自宅でも旅先でもどこでも働ける
4. 強いチームを作って社会貢献していく

**再現ポイント**:
- 「お金」「時間」「場所」「人間関係」「自己実現」の5カテゴリから選ぶ
- ターゲットのペルソナに合わせた理想像を描く

---

### ⑯ 次回予告＋感想ボタンCTA
**テンプレート要素**:
- 次回の内容を「質問形式」でティーザー
- 感想ボタン＝次話解放条件
- 3日限定のリマインド

**e-Harborでの実装**:
> 「次回はどうすれば本物の高額商品を作れるのか、クライアントの結果を出させるにはどんな仕掛けが必要なのか…」
> 「感想ボタンを送った方だけに個別で続きの動画をお送りします」
