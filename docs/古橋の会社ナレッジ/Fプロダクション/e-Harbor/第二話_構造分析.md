# 第二話 構造分析：売れる高単価商品の作り方

> **案件**: e-Harbor（3ステップセールスメソッド）
> **役割**: ファネル動画 第2話 / 全4話
> **推定尺**: 20〜25分
> **目的**: 商品設計の「正しい考え方」を教育し、「自分にもできるかも」と思わせる

---

## 全体構成マップ

```
┌─────────────────────────────────────────────────┐
│  1. 前回の振り返り（リマインド）                   │  ← 文脈の再接続
│  2. 今回の約束（メリット提示）                     │  ← 視聴動機
│  3. 回避できるリスク                               │  ← 痛みの維持
│  4. なぜ高額にする必要があるか                     │  ← 信念の書き換え
│  5. 商品設計の3つの方程式（フレームワーク提示）    │  ← 本編開始
│  6. 企画：コアコンセプトの作り方                   │  ← 教育①
│  7. リサーチの重要性                               │  ← 教育②
│  8. 設計：カリキュラム設計                         │  ← 教育③
│  9. 運営：反転学習の導入                           │  ← 教育④
│ 10. クライアント成功事例                           │  ← 社会的証明
│ 11. インタビュー動画                               │  ← 感情的証明
│ 12. 次回予告 + プレゼント告知 + 感想CTA            │  ← 行動誘導
└─────────────────────────────────────────────────┘
```

## 各ブロック詳細

### ① 前回の振り返り（リマインド）
**テンプレート要素**:
- 前回の核心メッセージを1〜2文で要約
- 「前回の動画では〇〇をお話しました」

**e-Harborでの実装**:
> 「前回の動画では、高単価セールスが絶対的に必要であり、これからの時代最もスタンダードになる売り方であることをお話ししました」

**再現ポイント**:
- 前話の核心メッセージをそのまま繰り返す
- 視聴者の記憶をリセット→再接続する

---

### ② 今回の約束（メリット提示）
**テンプレート要素**:
- 「今回は〇〇について全てお話します」
- 具体的な数字を含む約束

**e-Harborでの実装**:
> 「30万、50万、100万以上の高単価商品は一体どのように作られていくのか、その具体策を全てお話します」

**再現ポイント**:
- 「具体策を全て」という全出しの印象を与える
- 数字を3段階で出す（第一話と同じパターン）

---

### ③ 回避できるリスク
**テンプレート要素**:
- 「今日の内容を知らないと〇〇になる」
- 3つの最悪シナリオ

**e-Harborでの実装**:
1. 安売り→薄利多売で疲弊
2. 売れない商品に時間とお金を消耗
3. 商品が売れてもクライアントの成果が出ず、悪評→ビジネス存続不可

**再現ポイント**:
- 第一話とは異なるリスクを提示（今回のテーマに即した痛み）
- 「仮に売れたとしても…」と条件付きの新しいリスクを追加

---

### ④ なぜ高額にする必要があるか（信念の書き換え）
**テンプレート要素**:
- 「高い＝悪い」という思い込みを破壊
- 高額のメリットを顧客側の視点で説明

**e-Harborでの実装**:
> 「結論、顧客の実績を作りやすい。高単価の方が顧客の質が高い。本気度の高い方が集まる＝成功確率が上がる＝実績が作りやすい」
> 「安い金額だと顧客の本気度が低く、行動しない→成果が出ない→悪評→悪循環」

**再現ポイント**:
- **「高額は顧客のためでもある」**という利他的フレーム
- 逆に安い場合のデメリットを具体的に描写
- 「販売者にも顧客にもお互いにとっていいこと」と双方のメリット

---

### ⑤ 商品設計の3つの方程式（フレームワーク提示）
**テンプレート要素**:
- 独自のフレームワークを提示（3要素が鉄則）
- 「この3つが揃って初めて本物の商品」

**e-Harborでの実装**:
> **企画 × 設計 × 運営** = 本物の高単価商品
> 「多くの人はこの何かが欠けている、あるいは全ての要素が入っていない、ずれている」

**再現ポイント**:
- フレームワークは必ず3要素以内
- 「多くの人が間違えている」と暗に視聴者の問題を指摘

---

### ⑥ 企画：コアコンセプトの作り方
**テンプレート要素**:
- コンセプトの定義を1文で説明
- 自社の例を使って具体化
- 「売れない人」のパターンを提示して対比

**e-Harborでの実装**:
- **コンセプト＝「あなたのサービスを使うことで、見込み客がどんなゴールを手に入れられるか」の言語化**
- 自社例：「3ヶ月で高単価サービスが売れるようになり、年商1000万〜1億の事業を自動化し、収益と時間の自由を両立する」
- 売れない人：機能やスペック、専門用語、自分が言いたいことばかりをコンセプトにする

**再現ポイント**:
- 「結果」vs「機能」の対比が分かりやすい
- 自社コンセプトの実例が最良のお手本になる

---

### ⑦ リサーチの重要性
**テンプレート要素**:
- 「答えは市場にしかない」という原則
- 「自分の頭で考えるな、顧客の頭で考えろ」
- 独自のリサーチシートの存在を示唆
- リサーチすべき項目の列挙

**e-Harborでの実装**:
> リサーチ項目：
> - 顧客の悩み、常識、情報収集方法、使っている媒体
> - 短期的・長期的なゴール
> - 実現できていない障害や思い込み
> - 普段使う言葉、反応する言葉
> - 消費者の裏の心理（インサイト）

**再現ポイント**:
- リサーチシートの「存在」を見せるが「中身は渡さない」（特典誘導の伏線）
- 「しゃべる力・書く力がないのではなく、リサーチ力が足りないだけ」でマインドを転換
- **「商品から考える（自己都合）」vs「顧客の悩みから逆算する（顧客ファースト）」**の対比

---

### ⑧ 設計：カリキュラム設計
**テンプレート要素**:
- 「情報やノウハウをゴールにしない」→ 常識破壊
- 「顧客が結果を得られる仕組み」を作る
- 具体例（ライザップ等）で説明

**e-Harborでの実装**:
> **ライザップの例**: 特別なダイエット方法やトレーニングノウハウがあるわけではない。売っているのは「顧客が結果を得られる仕組み＝体験」
> **核心**: 「教えるか」ではなく「何をやらせるか」
> - 行動計画のプランニング＋スケジューリング
> - ステップ式の行動プラン→課題クリア→達成感→モチベーション→成果

**再現ポイント**:
- 「情報単体に価値はない」（ChatGPTの時代）という時代背景を利用
- 「教える」→「やらせる」のパラダイムシフトが最重要メッセージ
- 「結果を得られる仕組み」= 高単価にできる根拠

---

### ⑨ 運営：反転学習の導入
**テンプレート要素**:
- 運営の仕組み化＝スケール可能なモデル
- 1対1から1対Nへの移行方法
- 「自分がやらなくても回る」仕組み

**e-Harborでの実装**:
> **反転学習**:
> - 従来：講義で学習 → 自宅で復習
> - 反転：自宅で動画/テキスト予習 → 講義でアウトプット（ワーク/グループコンサル）
>
> **メリット**:
> - 受講側：インプット→アウトプットで学習定着、質問が明確化
> - 運営側：1対Nで売上青天井、同じことを繰り返し講義しなくて済む
>
> **分類**:
> - 「自分じゃないと絶対できない領域」
> - 「自分でなくてもできる領域」（外注・スタッフ）

**再現ポイント**:
- 反転学習＝東大やアメリカの教育機関で採用（権威付け）
- 「売上を青天井に最大化できる」というスケーラビリティの訴求
- **この話自体がバックエンドのセールスポイント**（受けたらこういう設計をしてもらえる）

---

### ⑩ クライアント成功事例
**テンプレート要素**:
- 商品単価の変化（Before→After）を数字で
- 3名以上の事例

**e-Harborでの実装**:
| Before | After | 倍率 |
|--------|-------|------|
| 3万円の商品 | 30万円 | 10倍 |
| 30万円 | 60万円 | 2倍 |
| 120万円 | 200万円 | 1.67倍 |

**再現ポイント**:
- 各レベル帯の事例を出す（初心者〜上級者）
- 倍率で見せるとインパクトが出る

---

### ⑪ インタビュー動画
**テンプレート構成**:

```
1. 自己紹介（何をしている人か）
2. Before（何に悩んでいたか）
3. 転換点（何がきっかけで変わったか）
4. After（具体的な成果・数字）
5. 印象に残った言葉/考え方
6. 他との違い（なぜこのプログラムを選んだか）
```

**e-Harborでの実装**:
- ハンドメイド作家→SNS講師
- Before：商品の作り方・売り方が全くわからない状態
- After：受講2ヶ月で月62万、累計644万
- キーフレーズ：「完璧主義から改善主義へ」「全てがテスト」

**再現ポイント**:
- インタビューは必ず**動画形式**（テキストより説得力が桁違い）
- 「なぜ他と違うか」を本人の口から言わせる
- 感情的なエピソード＋数字の両方が必要

---

### ⑫ 次回予告＋感想ボタンCTA
**テンプレート要素**:
- 次回のテーマを質問形式で提示
- 感想ボタン＝次話解放条件のリマインド
- 3日限定のリマインド

**e-Harborでの実装**:
> 「次回はそれを一体どういう風に売っていくのか、どんな工程を経て販売していくのか、セールスの部分を解説します」

## 第二話で使われる教育テクニック

### 信念の書き換えパターン

| 既存の信念（Before） | 新しい信念（After） |
|---------------------|-------------------|
| 高い商品は売りにくい | 高い方が顧客の質が上がり、実績が作りやすい |
| いいノウハウを教えれば売れる | 情報単体に価値はない。結果を得られる仕組みを売れ |
| 自分の強みから商品を作る | 顧客の悩みから逆算して商品を作る |
| 講義で教えるのが商品 | やらせることが商品（行動計画） |
| 1対1でないと成果は出ない | 反転学習で1対Nの方が成果も満足度も高い |
