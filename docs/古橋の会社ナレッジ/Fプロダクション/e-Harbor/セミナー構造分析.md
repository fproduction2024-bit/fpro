# e-Harbor セミナー構造分析

> **運営会社**: 株式会社イーハーバー（e-Harbor）
> **話者**: つみき（千三木 峻）
> **形式**: 全4本の動画ファネル（LINE登録 → 感想ボタンで次話解放）
> **バックエンド商品**: 高単価セールスのコンサルティング/スクール事業
> **コアメソッド**: 3ステップセールスメソッド

---

## 全体ファネル構造

```
LP（LINE登録）
  ↓
第一話：全体像＋コアメッセージ（高単価セールス力が全て）
  ↓ 感想ボタン → 次話解放
第二話：ステップ1「売れる高単価商品の作り方」
  ↓ 感想ボタン → 次話解放
第三話：ステップ2「セールス台本の構築」
  ↓ 感想ボタン → 次話解放
第四話：ステップ3「自動集客の構築」＋ オファー（1on1戦略診断）
```

**緊急性演出**: 各動画は「3日間限定配信」。放置すると閲覧不可。

## 第二話：ステップ1「売れる高単価商品の作り方」

**尺**: 約20〜25分
**役割**: 商品設計の考え方を教育し、「自分にもできるかも」と思わせる

### 構成ブロック

| # | ブロック | 内容 |
|---|---------|------|
| 1 | **前回の振り返り** | 高単価セールスが必要な理由のリマインド |
| 2 | **今回の約束** | 30万〜100万以上の高単価商品の作り方を全公開 |
| 3 | **なぜ高額にする必要があるか** | **顧客の質が上がる**。高額→本気度が高い→成果が出やすい→実績になる→好循環 |
| 4 | **商品設計の3つの方程式** | **企画 × 設計 × 運営** |
| 5 | **①企画：コアコンセプト** | 顧客がどんなゴールを手に入れられるかを言語化。機能やスペックではなく「結果」を語る |
| 6 | **顧客理解（リサーチ）の重要性** | 答えは市場にしかない。自分の頭で考えるな、顧客の頭で考えろ。オリジナルリサーチシートを使って顧客心理を丸裸にする |
| 7 | **②設計：カリキュラム設計** | 情報やノウハウをゴールにしない。**顧客が結果を得られる仕組み**を作る。ライザップの例：売っているのはノウハウではなく「結果を得られる体験」 |
| 8 | **行動計画プランニング** | 「教える」ではなく「やらせる」。ステップ式の行動プランで強制的に変化を与える→達成感→モチベーション→成果 |
| 9 | **③運営：反転学習の導入** | 従来（講義→自宅で復習）を反転（動画で予習→講義でアウトプット）。1対1→1対Nモデルへ。売上を青天井に |
| 10 | **クライアント成功事例** | 3万→30万に10倍化、30万→60万に倍増、120万→200万に引き上げ |
| 11 | **インタビュー動画** | ハンドメイド作家→SNS講師。受講2ヶ月で月62万、累計644万。「完璧主義から改善主義へ」 |
| 12 | **次回予告＋感想ボタンCTA** | 次回は「セールス台本の構築」 |

### 第二話の心理設計
1. **教育**: 商品設計の「正しい考え方」を植え付ける（情報提供≠商品）
2. **問題認識の深化**: 自分の商品が売れない原因はリサーチ不足＋情報をゴールにしているから
3. **権威強化**: オリジナルリサーチシート、反転学習など専門的フレームワークで差別化
4. **社会的証明**: 具体的なインタビュー動画で「この人たちにできたなら自分にも」

## 第三話：ステップ2「セールス台本の構築」

**尺**: 約25〜30分
**役割**: セールスの具体的な方法論を教え、台本テンプレートへの欲求を最大化

### 構成ブロック

| # | ブロック | 内容 |
|---|---------|------|
| 1 | **導入：成約率の重要性** | 10人に1人 vs 10人に7人。年間3600万の機会損失。セールスが全て |
| 2 | **セールスへの苦手意識への共感** | 自分も元々セールスが苦手。「マニュアル人間」と言われた過去 |
| 3 | **核心メッセージ** | **「成約は台本が9割」**。才能ではなく台本構築力で勝てる |
| 4 | **セミナーセールスの推奨** | Zoomオンラインセミナーで全国から集客。王道中の王道 |
| 5 | **2種類のセミナー** | ❌ **情報提供型**（ノウハウを教える→満足して終わる→売れない） vs ✅ **商品販売型**（気づきを与える→問題認識→購買動機） |
| 6 | **商品販売型の本質** | 満足させるのではなく「気づき」を与える。顧客の問題を認識させ、根本原因を発見させ、緊急性を生み出す |
| 7 | **医者と薬の比喩** | 情報提供型＝薬の成分を説明する。商品販売型＝なぜその薬が必要かを気づかせる |
| 8 | **個別面談の5ステップ** | ①アプローチ（聞かせる体制）②ヒアリング（ニーズ＝後出しジャンケン）③解決策提示（成功イメージの疑似体験）④商品説明（プレゼン）⑤クロージング（最終面接の感覚） |
| 9 | **クロージングの極意** | 「いかがですか？」はNG。主導権を持ち続ける。面接官のように顧客を選定する。スクリーニング＝売る人・売らない人の選別 |
| 10 | **台本テンプレートの告知** | 1on1戦略診断の参加特典として配布（→第四話でオファー） |
| 11 | **インタビュー動画** | ブランディング会社代表。クロージングが苦手→台本で初回60万成約→成約率100%→4ヶ月で620万 |
| 12 | **差別化の強調** | 現場で泥臭く売り続けたトップセールスが逆算設計した台本。机上の空論ではない |
| 13 | **次回予告＋感想ボタンCTA** | 次回は「自動集客の構築」＋1on1戦略診断＋5大特典の全貌 |

### 第三話の心理設計
1. **スキル教育**: 「情報提供型 vs 商品販売型」という強力なフレームで既存の思い込みを破壊
2. **欲求喚起**: 台本テンプレートが欲しくなる設計（具体策は見せず「参加特典で配布」）
3. **権威の決定打**: 「現場のトップセールスが作った台本」という差別化ポイント
4. **次話への強力なフック**: 最終話で全プレゼント＋オファーがある

## ファネル全体の設計パターン（テンプレート）

### 心理導線

```
第一話: 問題認識 → 権威構築 → 全体像の提示 → 好奇心
第二話: 教育①（商品設計） → 「自分にもできそう」
第三話: 教育②（セールス） → 「台本テンプレが欲しい」
第四話: 教育③（集客） → オファー → 緊急性 → 申込
```

### 各話共通の構造テンプレート

```
1. 前回の振り返り
2. 今回の約束（メリット提示）
3. 避けられるリスク（見ないとこうなる）
4. 本編（教育コンテンツ）
5. クライアント成功事例 / インタビュー動画
6. 次回予告 + プレゼント告知
7. 感想ボタンCTA（次話解放条件）
8. 3日限定リマインド
```

### 繰り返し登場するキーフレーズ

| フレーズ | 効果 |
|---------|------|
| 「影響力0、知名度0でも3ヶ月で100万」 | ハードル除去 |
| 「10人に話したら8人に売れる」 | 具体的な成約率のイメージ |
| 「売り込まなくても相手からお願いしますと言われる」 | セールスへの苦手意識の解消 |
| 「仕組み化・自動化」 | 労働集約型からの解放欲求 |
| 「3日間限定」「二度と見れない」 | 緊急性 |
| 「感想ボタンを送った方だけ」 | エンゲージメント＋次話への導線 |
| 「3ステップセールスメソッド」 | メソッド名のブランディング |

## オファー構造

### フロントエンド（無料）
- 4本の動画セミナー
- 1on1オーダーメイド戦略診断（通常3万円→無料）

- プロ集団による高単価セールスのコンサル/スクール
- 売上保証付き
- 優待価格（診断参加者限定）
- 少人数制・審査あり

### マネタイズの流れ
```
LINE登録（無料）
  → 動画4本で教育
    → 1on1戦略診断（無料・電話で日程調整）
      → 診断内（Zoom）でバックエンドを提案
        → 有料プログラム参加
```
