# 4本動画ファネル制作ワークフロー

> **目的**: コンテンツホルダーと協業し、4本動画ファネルを再現性高く・効率よく制作するための全体設計書
> **前提**: e-Harbor / COMPASS 等の実績ある構造をベースに横展開する

---

## 全体フロー（5フェーズ）

```
Phase 0: 事前ヒアリング（1回・60-90分）
  ↓
Phase 1: 設計（プロットシート作成）… 1-2週間
  ↓
Phase 2: 台本執筆 … 2-3週間
  ↓
Phase 3: 撮影・編集 … 1-2週間
  ↓
Phase 4: ファネル構築（LP/LINE/広告）… 1-2週間
```

**合計リードタイム目安: 5〜9週間**

---

## Phase 0: 事前ヒアリング

### 目的
コンテンツホルダーの「素材」を全て引き出す。
**ここが最も重要。素材の質＝ファネルの売上。**

### ヒアリングシート（事前に記入してもらう）

コンテンツホルダーには **録画しながら話してもらう** のが最も効率的。
文字で書くのが苦手な人が多いため、以下の質問に口頭で答えてもらい、文字起こしする。

#### A. 基本情報

| 項目 | 記入欄 |
|------|--------|
| 名前・屋号・会社名 | |
| 肩書き（どう呼ばれたいか） | |
| 事業内容（一言で） | |
| ターゲット顧客（誰に売りたいか） | |
| 現在の商品ラインナップと価格帯 | |
| バックエンド商品の価格（or 想定価格） | |
| 現在の集客方法 | |
| 月間の面談数・成約率（わかれば） | |

#### B. ストーリー素材（権威＋共感）

| 質問 | 意図 |
|------|------|
| 過去の最大の挫折・失敗経験は？ | 共感パート用 |
| そこからどうやって今の状態になった？ | 転換点のストーリー |
| 人生を変えた出会い・きっかけは？ | ドラマ性 |

| 業界の中で「自分だけが言える」ことは？ | 差別化・独自メソッド |

#### C. 顧客・実績素材

| 質問 | 意図 |
|------|------|

| 顧客がよく言う「受けてよかった理由」は？ | ベネフィット抽出 |

#### D. 商品・メソッド素材

| 質問 | 意図 |
|------|------|
| あなたのメソッドを3ステップで説明すると？ | 各話の柱になる |

| 顧客が自力では絶対にできないことは？ | バックエンドの必要性 |

#### E. オファー設計

| 質問 | 意図 |
|------|------|
| 無料プレゼントとして出せるものは？ | フロントエンド |

| 保証・返金ポリシーはあるか？ | リスクリバーサル |
| 限定性は作れるか？（人数/期間） | 緊急性 |
| 特典として出せるものは？（テンプレ/ツール等） | 特典パート |

---

### ヒアリングの進め方

```
1. 事前にシートを送付（3日前）
2. 「書けるところだけ書いて。書けないものは当日話しましょう」と伝える
3. Zoom or 対面で60-90分ヒアリング（録画必須）
4. 録画を文字起こし → Fプロ側で構造化
5. 不足がある場合は追加質問（LINEやチャットでOK）
```

> **ポイント**: コンテンツホルダーに「台本を書いてほしい」とは絶対に言わない。
> 彼らの仕事は「素材を出す」こと。構造化と台本化はFプロ側の仕事。

## プロットシートの使い方

### Fプロ側がやること

```
1. ヒアリング素材を確認
2. 上記プロットの各ブロックに、素材を割り当て
3. 「この素材で十分か？」を確認
4. 足りない場合：追加質問リストを作成
5. プロットシートをコンテンツホルダーに共有（確認用）
```

### コンテンツホルダーに見せる粒度

> [!IMPORTANT]
> プロットシートは **「全体の流れ」レベル** で見せる。
> 40ブロックの詳細を全部見せると混乱する。

**コンテンツホルダーに共有するのは「7ブロック要約版」**：

```
第一話: ①自己紹介＋失敗談 → ②問題提起 → ③解決策の全体像 → ④事例紹介
第二話: ①ステップ1の教育 → ②事例・インタビュー
第三話: ①ステップ2の教育 → ②事例・インタビュー
第四話: ①ステップ3の教育 → ②オファー → ③特典・保証
```

各話につき「あなたが話す内容のキーワード」を箇条書きで3〜5個。
**それ以上の詳細は見せない。** 台本の構造はプロに任せてもらう。

## Phase 2: 台本執筆

### 分担の考え方

| 担当 | やること |
|------|---------|
| **Fプロ** | 台本の構造設計（プロット→台本への展開） |
| **Fプロ** | 心理導線の設計（どこで何を感じさせるか） |
| **Fプロ** | CTA・緊急性・限定性の文言 |
| **コンテンツホルダー** | 専門知識パートの内容確認・修正 |
| **コンテンツホルダー** | 自分の言葉遣いへの修正（口調の調整） |
| **コンテンツホルダー** | ストーリー部分の事実確認 |

### 台本テンプレートの粒度

台本は **「そのまま読んで撮影できるレベル」** で作る。

```
❌ NG粒度:「ここで自分の失敗談を話す」（→ 何を話せばいいかわからない）
❌ NG粒度:「成約率80%の実績を語る」（→ 具体的なセリフがない）
✅ OK粒度: 実際のセリフを全文記載。ただし「※ここは自分の言葉で言い換えてOK」と注記
```

### 台本のフォーマット（推奨）

```markdown
## ブロック3: 最高の未来（1:30〜3:00）

想像してみてください。
毎月安定して100万以上の売り上げが入ってくる状態。
しかも、あなたがSNSを毎日更新しなくても、
朝起きたらLINEに「面談申し込みが入りました」と通知が届いている。

※ここは自分のクライアントの具体例に置き換えてもOK

そんな状態が、実はあと3ヶ月で作れるとしたらどうでしょうか。
```

### 確認フロー

```
1. Fプロが初稿を作成（7日以内）
2. コンテンツホルダーに共有（Google Docs or Notion）
3. コンテンツホルダーが赤入れ（3日以内）
   → 主な修正: 事実関係、口調、専門用語
4. Fプロが修正版を反映
5. 最終確認 → 撮影GO
```

## Phase 3: 撮影・編集

### 撮影前にコンテンツホルダーに伝えること

| 項目 | 内容 |
|------|------|
| 服装 | 清潔感ある普段着。4話とも同じ服はNG。話ごとに変える |
| 背景 | 白壁 or 本棚 or ブランディングに合う空間 |
| 照明 | Fプロ側で用意 or 自然光でOKの環境指定 |
| 話し方 | 台本を「読む」のではなく「語る」。ブロック単位で区切って撮影 |
| 所要時間 | 1話あたり撮影60〜90分（言い直し含む） |
| インタビュー | 顧客3名の事前手配をお願い（Zoom収録で可） |

### 編集の標準仕様

| 要素 | 仕様 |
|------|------|
| テロップ | キーワードのみ。全文字起こしは不要 |
| BGM | 話の展開に合わせて3〜4種類を使い分け |
| SE | ポイント提示時にチャイム音 |
| インサート | 実績数字、グラフ、クライアント画面、LINEスクショ |
| 尺目安 | 1話:15-25分 / 2話:20-30分 / 3話:20-30分 / 4話:40-60分 |

## 雛形の粒度：まとめ

| 誰に見せるか | 粒度 | フォーマット |
|------------|------|------------|
| **Fプロ内部** | 28〜40ブロックの詳細プロット＋心理設計メモ | Markdownファイル |
| **コンテンツホルダー** | 各話3〜5行の要約 + 「あなたが話す内容」リスト | Googleスライド（1話1ページ） |
| **台本** | 全文セリフ＋演出指示（読むだけで撮影可能） | Google Docs |
| **顧客インタビュー** | 質問リスト（5問程度） | LINEで送れる箇条書き |

### なぜこの粒度なのか

> [!WARNING]
> **コンテンツホルダーに詳細すぎるプロットを見せると3つの問題が起きる：**
> 1. 「こんなに複雑なの？自分にできるかな…」と不安になる
> 2. 構造に口を出し始めて収拾がつかなくなる
> 3. 全体の心理設計が崩れるリスクがある

> [!TIP]
> 逆に、粗すぎると：
> 1. 「何を話せばいいかわからない」と撮影で固まる
> 2. 内容の方向性がズレて、大幅な撮り直しが発生する
>
> **「自分が話す内容がイメージできる。でも細かい構成にはノータッチ」**
> このバランスが最適解。

## 品質チェックリスト（各話共通）

台本完成後、以下を確認：

- [ ] 冒頭3分以内にメリット提示があるか
- [ ] 「自分にも関係ある話だ」と思わせるフックがあるか
- [ ] 権威性の証明（数字・実績・メディア）が入っているか
- [ ] 挫折→成功のストーリーアークがあるか
- [ ] 具体的な顧客事例が最低2名入っているか
- [ ] 次話への好奇心フック（予告）があるか
- [ ] 緊急性（3日限定）のリマインドがあるか
- [ ] 感想ボタンCTAが明確か
- [ ] 専門用語を使いすぎていないか
- [ ] 1文が長すぎないか（口語で自然に聞こえるか）

### 第四話（VSL）追加チェック

- [ ] 理想の未来の描写が具体的か（感情に訴えているか）
- [ ] 反論処理（FAQ）が5つ以上あるか
- [ ] オファーの内容が明確か（何がもらえるか一目瞭然）
- [ ] リスクリバーサル（保証）があるか
- [ ] スクリーニング（来てほしくない人の明示）があるか
- [ ] 2択のクロージングになっているか
- [ ] 締切・限定性が具体的か
