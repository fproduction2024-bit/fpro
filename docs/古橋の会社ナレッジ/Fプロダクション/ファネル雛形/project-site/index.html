基本情報

事業の全体像を把握する

A-2 肩書き（動画内でどう名乗りたいか）
A-3 事業内容を一言で説明するとどうなりますか？

A-5 現在の商品ラインナップと価格帯を教えてください

A-7 現在の主な集客方法は何ですか？
A-8 月間の面談（相談）数と成約率はどのくらいですか？
B

ストーリー素材（権威＋共感）

動画の感情的な軸になるエピソードを引き出す

B-1 過去の最大の挫折・失敗経験は何ですか？ → 第一話の「共感パート」で使用
B-2 そこからどうやって今の状態になりましたか？（転換点） → 第一話の「成功ストーリー」で使用
B-3 人生を変えた出会い・きっかけは何でしたか？ → ストーリーのドラマ性を高める
B-4 今の事業を始めた本当の理由（ミッション・ビジョン）は？ → 第四話の「理念・壮大なビジョン」で使用
B-5 メディア出演・受賞・出版・資格などの実績はありますか？ → 第一話の「権威性パート」で使用
B-6 業界の中で「自分だけが言える」ことは何ですか？ → ポジショニング・差別化に使用
B-7 これまでの実績を数字で表すと？（売上・人数・年数など） → 権威付けの具体的な根拠
C

顧客・実績素材

社会的証明として使う成功事例（最低3名分が必要）

👤 成功事例①
C-1a この方のプロフィール（年齢・職業・背景）
C-1b Before（受講前の状態・悩み・数字）
C-1c After（受講後の変化・成果・数字）
👤 成功事例②
C-2a この方のプロフィール（年齢・職業・背景）
C-2b Before（受講前の状態・悩み・数字）
C-2c After（受講後の変化・成果・数字）
👤 成功事例③
C-3a この方のプロフィール（年齢・職業・背景）
C-3b Before（受講前の状態・悩み・数字）
C-3c After（受講後の変化・成果・数字）
C-4 顧客インタビュー動画は撮れますか？何名協力してもらえそうですか？
C-5 顧客がよく言う「受ける前の不安」は何ですか？ → 第四話の「反論処理」で使用
C-6 顧客がよく言う「受けてよかった理由」は何ですか？ → ベネフィット訴求に使用
D

商品・メソッド素材

動画の教育コンテンツの核になる部分

D-1 あなたのメソッドを3ステップで説明するとどうなりますか？ ⭐ 最重要 → 各話（2話・3話・4話）の柱になる
D-2 競合・他社との決定的な違いは何ですか？ → ポジショニング・差別化に使用
D-3 「これだけは絶対に間違い」と思う業界の常識はありますか？ → 第一話・第四話の「常識破壊パート」で使用
D-4 顧客に最初に教えること（最も重要な基礎概念）は？ → 第二話の教育コンテンツに使用
D-5 顧客が「自力では絶対にできない」ことは何ですか？ → バックエンド商品の必要性を語る根拠
D-6 あなたの手法の「成功の方程式」を一言で言うと？ → 第一話の「売上の方程式」パートで使用
D-7 顧客が手に入れられる「理想の未来」を具体的に描写してください → 随所の「最高の未来」描写で使用
D-8 ターゲットの「最悪の未来」（このままだとどうなるか） → 問題提起・緊急性のパートで使用
E

オファー設計

第四話のクロージングに直結する素材

E-1 無料プレゼントとして提供できるものは何ですか？ → フロントエンド＆登録の動機付けに使用
E-2 面談（個別相談）の形式と、どう呼びたいですか？ → CTA（行動喚起）の設計に使用
E-3 保証・返金ポリシーはありますか？ → 第四話の「リスクリバーサル」で使用
E-4 限定性は作れますか？（人数制限・期間限定） → 緊急性の演出に使用
E-5 特典として出せるものは何ですか？（3〜5個） → 第四話の「特典パート」で使用
E-6 「こういう人には来てほしくない」というスクリーニング基準は？ → 第四話の「審査・スクリーニング」で使用
E-7 このサービスの「他にはない優位性」を端的に言うと？ → 第四話の「この講座の優位性」で使用
