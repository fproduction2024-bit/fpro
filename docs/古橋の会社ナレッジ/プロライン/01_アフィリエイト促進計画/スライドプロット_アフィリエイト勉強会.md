# スライドプロット：プロライン アフィリエイト勉強会
## 「プロラインで月収50万を作る設計図」全20枚

> **デザイン方針**：濃紺 or 黒ベース × 白テキスト × アクセントカラー（オレンジ or ティール）  
> フォントは太め・大きめ。情報量は絞る。キーワードと図だけで伝わる設計に。

## 🔴 Part 1：なぜ稼げないのかの正体

---

### Slide 3：問いかけ

**レイアウト：大きな1行 + 小さな補足**

```
┌─────────────────────────────────────────┐
│                                         │
│                                         │
│   プロラインを紹介して                   │
│   ちゃんと稼げていますか？              │
│                                         │
│                                         │
│   ── 正直に聞かせてください ──          │
│                                         │
└─────────────────────────────────────────┘
```

**ポイント**：
- 口頭で挙手を求めるスライド
- テキストは最小限。間を大事にする
- 「正直に」という言葉で心理的安全を作る

### Slide 4：「脳死」の定義

**レイアウト：左に大きなキーワード、右に説明文**

```
┌─────────────────────────────────────────┐
│                                         │
│   「脳死」     │  考えずに同じことを    │
│                │  繰り返している状態    │
│                │                        │
│                │  能力の問題ではない    │
│                │  思考停止が問題        │
│                                         │
└─────────────────────────────────────────┘
```

**ポイント**：
- 「脳死」というワードを大きく・太く表示してインパクトを出す
- 「能力の問題ではない」は別色（オレンジ等）で強調
- 口頭で「営業40アポ・0成約の例」を話す

---

### Slide 5：脳死チェックリスト

**レイアウト：チェックボックス形式リスト**

```
┌─────────────────────────────────────────┐
│  あなたは「脳死」になっていませんか？    │
│  ─────────────────────────            │
│                                         │

│  □  数字を聞かれても即答できない        │
│  □  伸びない理由を「運」にしている      │
│  □  計画が達成できる根拠が立っていない  │
│  □  最近、戦略を変えたくなっている      │
│                                         │
│         当てはまる項目はありますか？     │
└─────────────────────────────────────────┘
```

**ポイント**：
- チェックボックスは□のまま（参加者が「自分ごと」にできるよう）
- 最後の一文を小さく下部に配置し、ゆっくり読ませる

### Slide 6：砂漠のメタファー

**レイアウト：イラスト or テキスト大きめ**

```
┌─────────────────────────────────────────┐
│                                         │
│   砂漠に水を撒いている                  │
│   気分になっていませんか？              │
│                                         │
│   🏜  ← あなた   💧💧💧 ← 毎日の投稿  │
│                                         │
│   出しても出しても…反応がない           │
│                                         │
└─────────────────────────────────────────┘
```

**ポイント**：
- 砂漠のイラストが使えるなら使う。なければ絵文字でもOK
- 参加者の「あるある」を視覚化して共感を強める
- 次のスライドで「でも本当は違う」と繋げる

## 🟠 Part 2：メディアで勝つ本当のルール

---

### Slide 7：連続成長 vs 非連続成長

**レイアウト：2つのグラフを左右に並べる**

```
┌─────────────────────────────────────────┐
│  多くの人のイメージ  │  実際の           │
│                     │  メディアの成長   │
│  フォロワー ↑       │  フォロワー ↑    │
│         /           │              ◆   │
│        /            │              |   │
│       /             │    __________|   │
│    ───────→ 日数   │  ──────────→日数 │
│    ※積み上がらない  │  ※一発で跳ねる  │
└─────────────────────────────────────────┘
```

**ポイント**：
- 左の「間違いグラフ」に✗をつける
- 右の「正解グラフ」に◎をつける
- 「ステップ関数」という言葉はあえて入れなくてOK

### Slide 8：キメ君の事例（タイムライン）

**レイアウト：横型タイムライン**

```
┌─────────────────────────────────────────┐
│  キメラ君が2ヶ月で4,000万を達成した話  │
│  ─────────────────────────────────   │
│                                         │
│  1ヶ月目            2ヶ月目            │
│     ◎ ─────────────── ◎              │
│  ブログ投稿        noteローンチ         │
│  ↓                  ↓                 │
│  有名人に紹介      AbemaTV出演         │
│                     ↓                 │
│                  売上4,000万達成       │
│                                         │
│        ※ 積み上げではなく「一発」      │
└─────────────────────────────────────────┘
```

**ポイント**：
- タイムラインは左から右へ流れる形
- 「2ヶ月以内」「4,000万」の数字を大きく・太く
- 令和の虎・リアルバリューも同じ、と口頭で補足

- ここは感覚を植え付けるスライドなので、口頭の説明が主役

## 補足：デザイントーン設定

| 要素 | 推奨 |
|------|------|
| **背景色** | 濃紺（#0D1B2A）or ほぼ黒（#111111） |
| **文字色** | 白（#FFFFFF） |
| **アクセント** | オレンジ（#FF6B2B）or ティール（#00C9B1） |
| **フォント** | 太ゴシック（Noto Sans JP Bold 推奨） |
| **1スライドの文字数** | 最大100文字以内（極力絞る） |
| **図解スタイル** | シンプルな矢印・ボックス（装飾は最小限） |
