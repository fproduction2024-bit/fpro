## 1. このマニュアルの目的

このマニュアルは、**プロラインのアフィリエイト促進プロジェクト**に参加するすべての運用者・マネージャーが共通認識を持って動けるようにするためのものです。

特に以下の3点を統一することを目的とします：

- **マインドセット**（どういう気持ちで取り組むか）
- **戦略の考え方**（何を目指してどう動くか）
- **具体的な実行フロー**（何をやるか、どの順番でやるか）

## 2. プロジェクト全体像と目標

### ゴール

| 期限 | 目標 |
|------|------|
| 2026年6月末 | 吉留さんがアフィリエイトで**月収50万円を稼げる状態**を作る |
| その後（本ローンチ） | 「吉留さんのようになりたい」人を集めた**アフィリエイター養成講座**をローンチ |

### なぜ6月末が期限なのか

- プロラインの**決算が8月末**
- 6月末までに新企画の材料（事例・データ）が揃っていると、8月末に向けた最終プッシュが機能する
- つまり「6月末 = 決算に向けた材料作りの締め切り」という位置づけ

### プロジェクトの構造

```
フェーズ1（〜6月末）
  吉留さんを成功させる
  → Xアフィリエイトで月50万の事例を作る

フェーズ2（7月〜）
  「吉留さんのようになりたい人」を集めた
  プロライン専用アフィリエイター養成講座をローンチ
  → 事例があるから集められる
```

## 3. 最重要マインドセット

> ⚠️ **全運用者に必ず伝えてください。これが抜けると絶対に伸びません。**

### 3-1. メディアは「非連続的成長」をする

SNS・メディアの成長は、コツコツ積み上げる**連続的な成長ではない**。

- ❌ 誤った認識：毎日投稿を続ければ少しずつフォロワーが増えてくる
- ✅ 正しい認識：**ある日突然、一発でドカンと跳ねる**

これを「**ステップ関数型の成長**」と呼ぶ。

> **例）キメラ君（キメ君）の事例**
> - 1ヶ月目：ブログで中学生が5万稼いだと話題化 → 池谷さんに紹介される
> - 2ヶ月目：noteをローンチ → Abema TVに出演
> - 結果：2ヶ月以内にnote売上4,000万円達成
>
> 令和の虎、リアルバリューなど大手メディアも同様。「一度ポンと伸びて終わり」の構造。

### 3-2.「棚ぼたを落とす機械を作る」感覚で動く

- ❌ 砂漠に水を撒く感覚（毎日投稿しても確実に伸びていく保証はない）
- ✅ 棚の上にある牡丹餅（ぼたもち）を**落とすきっかけを作る**感覚

**棚ぼた無限生成機を作るイメージ**。仕組みが噛み合った瞬間に一発で終わる。

### 3-3. 毎日「100点の投稿」を出すことを目指す

「100点」の定義：  
**「この投稿は、一発で伸びるきっかけになりうるか？」という問いにYesと言える投稿**

- 惰性のクオリティで出しても意味がない
- 60回の投稿機会（約2ヶ月）で60回「当てに行く」感覚

> 「数字が出なかったら、脳死でやっているか、方針が間違っているかのどちらか。  
> 方針は間違っていないので、脳死になっている可能性が高い、と疑ってほしい」（吉留）

### 3-4. 集客は難しくない

- 集客＝人を集めること
- 文化祭でも、町内会の運動会でも、マーケティングを知らない人が普通に人を集めている
- **難しいと思うから難しくなる**。本質は「人を集めるだけ」

## 4. 運用者へのマインドセット伝達方法

### 事例で伝える（非連続的成長の説明）

抽象的な説明が伝わらない相手には、以下の事例を使う：

| 事例 | 説明 |
|------|------|
| キメ君 | 2ヶ月以内に4,000万の売上。一発で伸びた |
| 令和の虎 | 初期にシーディングして一気に露出拡大 |
| リアルバリュー | プロモーション段階で集中的にシーディング |
| 雄大くんの彼女 | 恋愛系で同条件投稿から1ヶ月で600万インプレ達成 |

> **「一発で伸びる」の感覚が腹落ちしていない人には、上記事例で説明する**

### マインドセットの核心2点を必ず伝える

1. **脳死にならないこと**
2. **周りの人を脳死にさせないこと**

## 5. 実行ステップ（具体的な進め方）

### Step 1：Xアカウントの準備

- **新規アカウントは避ける**（シャドウバンのリスク・遅延が発生するため）
- **既存アカウント（ある程度投稿実績あり）を使う**
- シャドウバン歴のあるアカウントより、歴のないアカウントが望ましい
- アカウントのログイン情報を担当者（吉留さん）に共有する

### Step 2：コンセプト設計

担当者と以下3点をすり合わせる：

| 項目 | 内容 |
|------|------|
| **アカウントコンセプト** | 誰に向けた、何を発信するアカウントか |
| **シリーズ设計** | どういう投稿戦略（シリーズ）で行くか |
| **動線設計** | どのようにプロラインへ誘導するか |

### Step 3：動線設計（クッションLP方式）

```
X投稿
  ↓
クッションLP（記事LP）
  ↓
プロライン登録ページ
```

- **クッションLPを挟む**のがポイント（いきなりプロラインに飛ばさない）
- クッションLPは「記事LP」形式（読み物として自然に誘導する）

### Step 4：拡散サロン活用

- 月額22,000円の**拡散サロン**に入ることで、一定の認知・露出を確保する
- これが「変数1」：ある程度の目に触れる状態を作り出す安牌策
- 費用は古橋さん（プロライン側）が負担

### Step 5：毎日投稿の実行

- 「変数2」：運用者が毎日100点の投稿を出すこと
- 「この投稿は一発で伸びるきっかけになるか？」を自問しながら投稿する
- 2ヶ月（約60投稿機会）で当てにいく

### Step 6：バズり → 感覚習得

- 一度バズると「感覚がわかる」ようになる
- 数字を出す前は意味が理解できない部分もある → **まず一発バズらせることが最初の突破口**
- 担当者（吉留さん）がバズるパターンを習得したら、その後の再現性が上がる

## 6. マネジメントの本質

### 「脳死チェック」がマネジメントのすべて

マネジメントとは、結局のところ「**脳死になっていないかチェックすること**」。

#### 脳死になっているサインを見逃さない

| サイン | 具体例 |
|--------|--------|
| 行動に変化がない | 毎日同じクオリティの投稿を出し続けている |
| 数字を即答できない | 「今月のインプレッションは？」に答えられない |
| 戦略が立っていない | なんとなく投稿している状態 |
| 計画達成の根拠が立っていない | 「6月末に月収50万」になる道筋が見えていない |

#### マネジメントの2つのレイヤー

1. **自分のマネジメント**：自分が脳死になっていないか自己チェックする
2. **人のマネジメント**：チームメンバーが脳死になっていないか観察・介入する

> 「仕事を進める時、自分をマネジメントするか、人をマネジメントするか、この2パターンしかない」（吉留）

## 7. よくある失敗パターンと対処法

### パターン1：40アポして0成約タイプ（脳死型）

**状況**：数字が出ない → 原因は能力ではなく「脳死状態」  
**対処**：能力を疑わず、「何が脳死を引き起こしているか」を特定して改善する

### パターン2：戦略の頻繁な変更（迷走型）

**状況**：少し伸びないと「やっぱりこの戦略が違うのでは」→別の戦略に移行  
**対処**：

> 「魚屋で売れないから肉屋をやる → それでも売れないからケーキ屋」という思考パターン。  
> 本質は変わらない。**着手性と力技が足りないだけ**。

- 撤退ラインは別途設けてよいが、到達前に戦略変更しない
- 「うまくいきそうな寸前でやめる」のが最大の失敗パターン

### パターン3：大きな目標だけ追って足元が見えなくなるタイプ（灯台下暗し型）

**特徴**：遠い目標（人生の夢）にはワクワクするが、目の前のタスクに動けない  
**対処**：

- 足元を見ろ、ではなく「**目の前のマイルストーン（=直近の成果）に対してもワクワクできるフレームを作る**」
- 「Xがうまくいったらこんなことができる → それにワクワクしろ」という順番で目標を繋げる

> 「人生はロードマップ。マイルストーンをクリアしていく順番がある。  
> 目の前のマイルストーンも輝いて見えるようにしてあげることが大事」（吉留）

### パターン4：プロジェクトをまたいで動くタイプ（戦線拡大型）

**特徴**：複数のプロジェクトに手を出して、どれも中途半端になる  
**対処**：

> 「伸びている人は、全員ちっちゃい案件を極限まで大きくしている。  
> 一つのプロジェクトを着地させきったことが、次の展開を呼ぶ」（吉留）

- **まず一つを完全に着地させる**。それが次の信頼・チャンスを生む

## 8. スケジュール・期限の考え方

### 全体スケジュール（暫定）

```
2026年4月〜  プロジェクト開始
              アカウント準備・コンセプト設計・動線設計
              
2026年4月〜6月末  メイン運用期間
              拡散サロン活用 + 毎日100点投稿
              目標：バズりの感覚をつかみ、月収50万の状態を作る
              
2026年8月末  プロライン決算
              →「吉留さん月50万事例」をもとにアフィリエイター養成講座ローンチ
```

### 期限を設ける理由

- 長期決戦マインドは逆に伸びない
- **2ヶ月（60回の投稿機会）で当てにいく**のがメディア攻略の正しいアプローチ
- 期限がない = 脳死が発生しやすくなる
