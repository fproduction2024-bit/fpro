# /daily-log ワークフロー

このワークフローは、今日の日報ファイルを読み込み、
「今日やったこと」からタスクを完了に更新し、
「明日やること」から新しいタスクを追加します。

// turbo-all

## Step 1: 今日の日報ファイルを特定・読み込む

今日の日付（`date +%Y-%m-%d`）を取得し、
`/Users/hiroshi/cursor/docs/古橋の会社ナレッジ/日報/YYYY-MM-DD.md` を読み込む。

ファイルが存在しない場合は、テンプレート（`_template.md`）をコピーして
今日の日付のファイルを作成し、ユーザーに「日報ファイルを作成しました。内容を記入してから再度実行してください」と伝える。

## Step 2: 日報の内容を解析する

読み込んだ日報から以下を抽出する：

**完了タスク（✅ 今日やったこと セクション）**
- `- [x]` で始まる行 → 該当するプロジェクトのタスクを `完了（done）` にする
- プロジェクト名のマッピング：
  - 「リッツプロ」→ ritzpro関連のプロジェクトID
  - 「スキルハックス」「Fプロダクション」→ fpro
  - 「YOLO's」→ yolos-general
  - 「タングルシード」→ tangleseed
  
**新規タスク（📝 明日やること / 新規タスク セクション）**
- `- [プロジェクト名] タスク内容 (priority: xxx)` 形式の行をパース
- または `- タスク内容` の行（セクションのプロジェクト名を使用）

## Step 3: todo-dashboard/index.html のPROJECTSデータを更新する

`/Users/hiroshi/cursor/docs/古橋の会社ナレッジ/todo-dashboard/index.html` を編集し、
PROJECTSのデータを更新する（完了フラグ、新規タスク追加）。

変更前に現在の状態を確認し、変更内容をユーザーに明示して確認を求める。

## Step 4: 変更内容をサマリーとして出力する

```
📓 日報（YYYY-MM-DD）から以下を更新しました：

✅ 完了にしたタスク（N件）
  - [プロジェクト名] タスク内容

➕ 追加したタスク（N件）
  - [プロジェクト名] タスク内容（priority）

💡 メモ
  - 気づき内容
```
