# LINE配信シナリオの設計ワークフロー

ファネル動画やコンテンツ配信に使うLINEステップ配信シナリオを設計・ライティングする手順。
e-Harbor案件で実証済みのフレームワークをベースとする。

---

## 1. 締切タイプの判定

コンテンツの種類に応じて、以下3パターンから選択する。

| 条件 | 締切タイプ | ステップ数 |
|------|----------|-----------|
| **30分以下のコンテンツ視聴**を求める場合 | **2日締切** | 11ステップ |
| **30分超のコンテンツ視聴**、または**申込み等の意思決定を伴う行動**を求める場合 | **7日締切** | 16ステップ |
| **10分以下の軽い作業**（決済手続き、フォーム入力等）を求める場合 | **1日締切** | 8ステップ |

---

## 2. 各パターンのステップ構成

### パターンA: 2日締切（11ステップ）

動画視聴 → 感想送信 で次のコンテンツを解放する基本パターン。

```
01. ウェルカム＋コンテンツ配信（350字以下）
    - 目的設定、期限明示、次のプレゼント予告
    - 初回のみ自己紹介を含める
02. コンテンツ再送
    - 「見逃し防止のために視聴期限を設けています」
03. 今後の配信ロードマップ（350字以下）
    - 全コンテンツ一覧を ←今ココ！ ←次はコレ！ 形式で表示
    - 感想送信 → 次のプレゼント の条件を明示
04. 前日リマインド（350字以下）
    - [[snsnamesan]] で名前差し込み
    - お客様の声（箇条書き3つ）
    - 次のプレゼント内容を予告
    - 「見ないと残り全てのプレゼントを受け取れなくなる」
05. 最終日（350字以下）
    - プレゼントの受け取り手順を再説明
    - お客様の声（引用形式で2つ）
06. 残り4時間（250字以下）
    - 1文で内容の核心を伝える
    - 「もらい損ねて寝てしまうのはもったいない」
07. 残り2時間（150字以下）
    - 「まず3分だけ再生するつもりで」
    - 「内容には自信がある」
08. 残り1時間（50字以下）
    - 1行のみ「あと1時間でコンテンツが削除されます」
09. [先頭に戻す] 締切後の再チャンス
    - 失われるメリットを箇条書き
    - 「もう一度だけ視聴するチャンスを設けました」
10. [先頭に戻す] 最終日
    - メリット箇条書き再掲
    - 「本日中に押さないと永久に届けられなくなる」
11. [先頭に戻す] 最終告知（250字以下）
    - 「再チャンスの最後のメッセージ」
    - 「ボタンの期限はあと2時間」
```

### パターンB: 7日締切（16ステップ）

高単価商品のセールスや、意思決定を伴うCTA用。

```
01. 感想のお礼＋「準備中、1分以内に送ります」
02. 申込みページ送付＋商品概要＋追伸で限定特典
03. 【あと6日】商品メリットまとめ（350字以下）
04. 【あと5日】お客様の声・実績紹介
05. 【あと4日】リスクゼロ性の説明（返金保証等）
06. 【あと3日】Q&A（よくある質問2〜4つ）
07. 【あと2日】後押し（失われる未来、メリットの消失）
    - 朝晩連絡する旨を予告
08. 【明日終了】朝の通知＋創業者のストーリー
09. 【明日終了】夜のリマインド＋メリット箇条書き再掲
10. 【本日終了】あと16時間
11. 【本日終了】あと4時間＋限定特典の消失警告
12. 【本日終了】あと2時間（150字）＋「1秒でも過ぎたら参加不可」
13. [先頭に戻す] セールス終了・お礼
    - 「まだ迷っている方にはあと7日間延長」
14. [先頭に戻す] 最終日
15. [先頭に戻す] 最終告知
```

### パターンC: 1日締切（8ステップ）

決済手続きなど、短時間の作業完了を促すパターン。

```
01. 手続き案内＋「期限は明日24時まで」
02. 【1時間後】手続き期限リマインド
03. 【あと16時間】失われるもの一覧
04. 【あと4時間】得られるもの一覧＋後押し
05. 【あと2時間】「お忘れなだけかと思いますが」
06. [先頭に戻す] 手続き締切・再チャンス
07. [先頭に戻す] 最終日
08. [先頭に戻す] 最終告知
```

## 3. ライティングのルール

### 文字数制限（LINE公式の表示最適化）
- メイン配信: **350文字以下**（スクロールなしで読める）
- リマインド: **250文字以下**（4時間前）→ **150文字以下**（2時間前）→ **50文字以下**（1時間前）
- 文字数が減るほど緊迫感が増す設計

### 必須要素
- `[[snsnamesan]]` でLINE表示名を差し込む（ステップ4, 9等で使用）
- 全てのCTAボタンの前に `↓↓↓` を置く
- 各ステップの冒頭にステップ番号と目的を明記（運用者向け）

### トーン
- 敬語ベース（LINEは1対1の親密感が重要）
- 発信者の人格を反映（名前で名乗る：「迫です」「木村です」等）
- リマインドは回を追うごとにカジュアルに（最後は1行だけ）

### 心理テクニック
- **損失回避**: 「見ないと残り全てのプレゼントが受け取れなくなる」
- **社会的証明**: お客様の声を箇条書き（ステップ4）＋引用形式（ステップ5）で2回使う
- **段階的コミットメント**: 感想送信 → 次の動画解放 のゲート構造
- **希少性**: 「あとX時間」のカウントダウン
- **再エンゲージメント**: リセットループ（9-11）で離脱者を3回回収

## 4. ファネル全体の設計手順

// turbo-all

### Step 1: ファネル構造を確認
```
リストイン → 動画1 → 動画2 → ... → セールス動画 → セールス → 申込み → 完了
```
各ステップの「求めるアクション」を洗い出す。

### Step 2: 各ステップに締切タイプを割り当て
上記の判定表に従い、A/B/Cを割り当てる。

### Step 3: テンプレートに内容を流し込む
- 動画タイトル
- 動画の学び（箇条書き3つ）
- お客様の声（箇条書き3つ + 引用2つ）
- 次のプレゼントの内容
- 商品のメリット一覧
- 限定特典
- 創業者ストーリー（セールス用）

### Step 4: 参考ファイルの確認
e-Harbor の実例ファイル:
- `Fプロダクション/e-Harbor/木村様【1話目動画】2日締切+先頭に戻す.txt`
- `Fプロダクション/e-Harbor/木村様【2話目.動画】2日締切 .txt`
- `Fプロダクション/e-Harbor/木村様【3話目.動画】締め切り2日 .txt`
- `Fプロダクション/e-Harbor/木村様【4話目.動画】2日締切+先頭に戻す.txt`
- `Fプロダクション/e-Harbor/木村様7日「セールス」+先頭に戻す.txt`
- `Fプロダクション/e-Harbor/木村様【申込み】1日締切+先頭に戻す［9s］.txt`

スキルハックスの実例ファイル:
- `Brain/スキルハックス/LINEシナリオ/【第一話】LINEシナリオ_2日締切.txt`
- `Brain/スキルハックス/LINEシナリオ/【セールス】LINEシナリオ_7日間.txt`
- `Brain/スキルハックス/LINEシナリオ/【申込み】LINEシナリオ_1日締切.txt`

### Step 5: ライティング＆レビュー
テンプレ構造に沿ってライティングし、以下をチェック:
- [ ] 文字数制限を守っているか
- [ ] `[[snsnamesan]]` が適切に挿入されているか
- [ ] 全CTAに `↓↓↓` があるか
- [ ] お客様の声が仮のままになっていないか
- [ ] ファネル全体の遷移に矛盾がないか（前の動画タイトル等）
- [ ] リセットループ（先頭に戻す）の連番が正しいか
