## 1. ビジョン

> **コンテンツホルダーが、価値創造に集中できる世界を作る。**

ビジネスで大事なことはお金だけでなく、「作りたい世界を作り続けられていること」。
事業者が本来集中すべきは、**顧客への価値提供と、信頼残高を積み上げること**。

マーケティング・セールスが完全自動化された状態にあれば、事業者はそこに集中できる。
**その状態を、100のコンテンツホルダーに作ること**が、この計画の存在意義である。

## 2. ミッション

> **「TangleSeed状態」を、100社に届ける。**

### TangleSeed状態とは

```
LP（価値訴求）
  ↓
LINE登録（リスト獲得）
  ↓
動画コンテンツ（価値体験・信頼構築）
  ↓
自動オファー（セールス自動化）
  ↓
既存顧客への継続提供 → 信頼残高の蓄積 → 次商品即売れる状態
```

- マーケ・セールスが完全自動で回っている
- 事業者は「商品を作り、既存顧客に届ける」ことに専念できる
- 信頼残高が積み上がり、新商品ローンチのたびに爆発的に売れる

## 7. ビジネスモデルの核心思想

### 積み上がり型ビジネスへの必然性

```
❌ 単発型（ファネル作って終わり）
→ 毎月ゼロから売上を作る必要がある
→ クライアントとの関係が浅い
→ 自分の価値がスポット的にしか活かされない

✅ 積み上がり型（レベニューシェア継続）
→ クライアントが売れるほど自分の収益も増える
→ 同じ方向を向いてクライアントの成長を本気で支援できる
→ 信頼残高が積み上がり、追加施策・新商品への協力が得やすい
→ 毎月のベース収益が増え、事業が安定する
```

**全クライアントを積み上がり型にする。これが最重要。**

### 信頼残高モデル

```
クライアントが顧客に価値を届ける
　↓
顧客の信頼残高が積み上がる
　↓
次の商品が出たら即購入される
　↓
クライアントの売上が上がる
　↓
自分のレベニューシェアも上がる
```

TangleSeedの場合：既存4,000名の信頼残高 → 新商品で1,000万円即売可能。
**この状態を100社に作ることが、この計画の本質。**

## 8. リスクと対策

| リスク | 対策 |
|---|---|
| クライアントがリスト月1,000件に達しない | 伊藤さんのメディア構築・聖くんのJV・広告運用をセットで提案 |

| 100社の管理コストが増大する | CS業務（レポート等）の型化。進捗ダッシュボードによる一括管理 |
| パートナーとの世界観のズレ | パートナー用ブランドマニュアル・セールスキットの整備（新規） |
| レベニューシェアの回収が困難 | 契約時に会計処理ルールを明確化。月次レポート共有の仕組みを導入 |
