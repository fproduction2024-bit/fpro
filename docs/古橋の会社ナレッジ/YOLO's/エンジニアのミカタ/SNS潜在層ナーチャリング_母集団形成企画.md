# SNS × プロライン 潜在層ナーチャリング企画
# ── 母集団形成を「顕在層の刈り取り」から「潜在層の掘り起こし」に拡張する

> **目的**: 転職媒体だけに依存した母集団形成を、SNSからの潜在層獲得で拡張する
> **ツール**: プロラインフリー（ステップ配信 × タグ管理 × シナリオ分岐）
> **作成日**: 2026年2月21日

---

## 1. 現状の構造的な限界

### 今の採用ファネル：「顕在層の刈り取り型」

```
┌──────────────────────────────────────────────┐
│ 転職媒体（エン / マイナビ / type / doda）     │
│ ＝「今すぐ転職したい人」しかプールにいない     │
└──────────────┬───────────────────────────────┘
               ↓
           応募 459名/月
               ↓ 92.4%
           面談設定 425名
               ↓ 73.8%
           面談実施 314名
               ↓ 47.2%
           内定 148名
               ↓ 38.1%
           内定承諾 56名/月
```

**この構造の問題点**：
- 応募してくる人はすでに「転職を決めた顕在層」
- 歩留まりが高いのは「本気の人だけが来ている」から
- **逆に言えば、この母数（月459名）が天井**
- 媒体費を増やして応募数を増やしても、コストが比例して上がるだけ
- **潜在層（まだ転職を決めてない人）には一切アプローチできていない**

---

### エンジニアの転職意向ピラミッド

```
         ▲
        /  \     今すぐ転職したい（5%）← 今ここだけを取っている
       /    \    
      /      \   ちょっと考え始めた（15%）← ★ ここが取れていない
     /        \  
    /          \ いい話があれば聞く（30%）← ★ ここも取れていない
   /            \
  / まだ動く気ない \  （50%）
 /________________\
```

**今の媒体経由の採用 = ピラミッドの頂点5%だけの争い**
→ 競合（他のSES企業）も全く同じ5%を狙っている
→ 媒体費が高騰する構造的な原因

## 2. 提案：「潜在層をSNS → LINE → 面談」に引き上げるファネル

### 新しい全体設計

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【既存】転職媒体 ─── 応募 ─── 面談設定 ─── 面談 ─── 内定
           ↑ 顕在層（今すぐ転職したい人）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【新規】SNS ─── LINE登録 ─── 教育配信 ─── 温まったら面談
           ↑ 潜在層（まだ転職を決めてない人）       ↑
           │                                     │
           │      ★ この間をプロラインで自動化      │
           │        （2週間〜3ヶ月のナーチャリング）   │
           └─────────────────────────────────────┘
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**ポイント**：
- 顕在層のファネル（既存）はそのまま維持
- 潜在層のファネル（新規）を**別レーンとして追加**
- 潜在層は「教育の時間」が必要 → **ここをプロラインのステップ配信で自動化**
- 人間が介在するのは**面談だけ**

## 3. SNS集客設計

### 3-1. どのSNSから集客するか

| プラットフォーム | ターゲット層 | コンテンツ形式 | 期待効果 |
|---|---|---|---|
| **X（Twitter）** | SES現役エンジニア | テキスト + スレッド | 業界あるあるで共感を取る → LINE登録 |
| **TikTok / Reels** | 20代〜30代エンジニア | ショート動画 | 「SESのリアル」系で拡散 → LINE登録 |
| **YouTube** | キャリアに悩む中堅層 | 長尺動画 | 「SES転職の本音」系で信頼構築 → LINE登録 |
| **Qiita / Zenn** | 技術志向エンジニア | 技術記事 | 技術力アピール → 採用ページ → LINE |
| **connpass** | 勉強会参加者 | イベント | イベント参加 → LINE登録で資料配布 |

### 3-2. コンテンツ戦略（何を発信するか）

**軸となるメッセージ**：「SESの選び方で人生が変わる」

| コンテンツテーマ | 刺さる層 | 目的 |
|---|---|---|
| 「SES企業の見分け方5選」 | 転職検討手前の層 | 問題提起 → 情報収集モードに入れる |
| 「年収400万→600万になった話」 | 年収に不満がある層 | 欲求喚起 → 「自分もできるかも」 |
| 「エンジニアの1日vlog」 | 働き方に興味がある層 | イメージ形成 → 会社の雰囲気を体感 |
| 「未経験からSESエンジニアになるには」 | 異業種からの転職希望者 | 入口拡大 → 未経験層の取り込み |
| 「面接で聞くべき3つの質問」 | まだ転職活動を始めてない層 | 実用情報 → LINE登録のフック |
| 「SESで独立した先輩の話」 | キャリアに悩む層 | 将来像の提示 → 長期的な関係構築 |

| Day 4 | 「エンジニアが会社選びで後悔した3つのこと」（動画3分） | 問題意識を芽生えさせる |
| Day 7 | 「自分の市場価値を確認する方法」（記事 or 動画） | 行動のきっかけを作る |

```

| Day 21 | **アンケート配信**（簡易3問） | 温度感の測定・セグメント分け |

```

**このアンケートが最大のポイント**：
- Q2で「① 今すぐ」「② 半年以内」→ **ホットリードとしてタグ付け → シナリオAに移動**

- Q2で「④ 考えてない」→ **コールドリード → 月1配信で維持**

#### Phase 4：長期維持配信（月1回 × 最大12ヶ月）

Phase 3で面談に至らなかった人、または「まだ考えてない」人に対して：

```
月1回の配信内容（ローテーション）：
  ① 業界ニュース + ひとこと解説
  ② エンジニア向けTips（技術ネタ）
  ③ 社員の近況・プロジェクト紹介
  ④ 新しい案件情報（データ不要で見られる範囲）

★ 12ヶ月中に温度が上がったら → アンケート再配信 → シナリオ分岐
★ 12ヶ月経っても動きがなければ → 配信終了
```

**これが「人力では絶対にできない」プロラインの最大の価値**：
- 100人のリードを12ヶ月追い続ける = 人力なら専任1名が必要
- プロラインなら**月額9,680円で全自動**

## 7. 既存の施策との統合

`施策.csv`に記載されている案をSNS×LINEファネルに接続する：

| 既存施策 | SNS×LINE接続のやり方 |

## 9. まとめ：2つのファネルを並走させる
