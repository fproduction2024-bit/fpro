## 3. プロラインの思想で「足りない」5つの数字

プロラインの思想は **「媒体費 → 各中間KPI → 成果」の間にKPIを置いて改善する」** というもの。
現在のデータには**入口（媒体費・応募数）と出口（内定承諾数）はあるが、中間の行動KPIが欠落**している。

### 不足データ一覧

| # | 不足している数字 | なぜ必要か | プロラインでの活用 |
|---|---|---|---|
| **①** | **応募→初回連絡の返信率**（レスポンス率） | 応募者のうち何%が初回連絡に反応するか。メール/電話の到達率と返信率。ここが最初の離脱ポイント | LINEならメッセージ開封率（通常80%以上）で代替可能。メール返事待ちの時間がゼロに |
| **②** | **面談設定→面談実施の「不参加理由」内訳** | 26%が実施に至らない。ドタキャン/日程変更/音信不通の内訳がわからないと対策が打てない | リマインド配信（前日・当日・1時間前）で対策する内容が変わる |
| **③** | **内定→内定辞退の「辞退理由」内訳** | 62%が辞退。競合に流れた/条件不一致/教育不足の内訳がないとLINEで何を教育すべきか判断できない | 辞退理由に合わせた内定後フォロー配信の設計に直結 |
| **④** | **媒体別の一気通貫歩留まり** | 媒体ごとの応募数・入社数はあるが「エン転職応募→面談→内定→承諾」の通しデータがない | 媒体によってLINE配信内容を分岐すべきかの判断材料 |
| **⑤** | **応募→面談のリードタイム（日数）** | 応募から何日で面談に至っているか。現状の所要日数がわからない | LINEステップ配信の日数設計（5日なのか3日なのか10日なのか）に直結 |

## 4. プロラインで改善が狙える3つのボトルネック

### ボトルネック①：面談設定→面談実施（73.8%）= 26%がドタキャン

**現状の問題**：面談を設定しても4人に1人が来ない

**プロラインの打ち手**：
- 面談前日・当日のリマインド自動送信
- 面談に来るメリットを伝える動画配信（「面談ではこういう話をします」予告）
- 日程変更をLINEから簡単にできる仕組み（ドタキャンではなく「リスケ」に変換）

**改善見込み**：実施率 73.8% → **85〜90%** （月+51〜74名の面談増）

**月間インパクト**：
```
現状：面談設定425名 × 73.8% = 314名が面談実施
改善後：面談設定425名 × 87% = 370名が面談実施（+56名/月）
→ +56名 × 内定率47% × 承諾率38% = +10名の内定承諾増
```

---

### ボトルネック②：面談実施→内定（47.2%）= ミスマッチが多い

**現状の問題**：面談しても半数以上が内定に至らない（スキル不一致 or 価値観不一致）

**プロラインの打ち手**：
- 面談前にステップ配信で会社の価値観・働き方・求める人材像を教育
- 動画で「うちに合う人・合わない人」を事前に伝えてフィルタリング
- 事前アンケート（スキル・希望条件）をLINEフォームで取得 → 面談の精度向上

**改善見込み**：内定率 47.2% → **55〜65%**

**月間インパクト**：
```
現状：面談実施314名 × 47.2% = 148名が内定
改善後：面談実施314名 × 58% = 182名が内定（+34名/月）
→ +34名 × 承諾率38% = +13名の内定承諾増
```

---

### ボトルネック③：内定→内定承諾（38.1%）= 62%が辞退 ← 🚨最大の課題

**現状の問題**：内定を出しても6割以上が辞退する。これが最大のコスト損失

**プロラインの打ち手**：
- 内定通知後もLINEで「入社後のイメージ」動画を配信
- 先輩社員からの歓迎メッセージを自動送信
- 入社までの不安を払拭する定期フォロー配信
- 他社比較で迷っている人向けの「うちを選ぶ理由」コンテンツ

**改善見込み**：承諾率 38.1% → **50〜60%**

**月間インパクト**：
```
現状：内定148名 × 38.1% = 56名が承諾
改善後：内定148名 × 53% = 78名が承諾（+22名/月）
```

## 7. 補足：現在検討中の施策との関係

`施策.csv`に記載の14施策のうち、プロラインとの相乗効果が高いもの：

| 施策 | プロラインとの連動 |
|------|-----------------|
| リファラル（#1,#3,#10） | 紹介URL機能で紹介トラッキング＋特典自動配布 |
| イベント（#2） | イベント参加者→LINE登録→ステップ配信で教育 |
| Youtube広告（#4） | 動画視聴者→LINE登録の導線設計 |
| 交流会参加（#6,#8,#9） | 接点を持った人→LINE登録→長期フォロー |

**プロラインは「単体の施策」ではなく、全施策の成果を受け止める「受け皿」として機能する。**
