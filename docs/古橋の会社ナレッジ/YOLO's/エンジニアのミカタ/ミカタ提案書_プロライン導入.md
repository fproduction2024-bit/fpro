## 2. なぜこのボトルネックが起きるのか

### 仮説：エンジニアは電話が嫌い

現在の採用フローは**すべて人力（架電 + メール + Zoom）**で動いています。

```
応募 → 電話で連絡 → 電話で日程調整 → 電話でリマインド → Zoom面談 → 電話でフォロー
       ↑            ↑               ↑                              ↑
    出ない         渋々OK          忘れる/面倒                   不安のまま辞退
```

エンジニアは**非同期コミュニケーション（テキスト・チャット）を好む**職種です。
電話は「割り込まれる」「強制される」感覚が強く、以下の離脱を引き起こしていると推定：

| ステップ | 離脱数/月 | うち「電話嫌い」が原因の推定 |
|---------|-----------|--------------------------|
| 応募→面談設定 | 34名 | 20〜27名（60〜80%） |
| 面談設定→実施 | 111名 | 50〜72名（45〜65%） |
| 面談→内定 | 166名 | 25〜40名（動画教育で改善可） |
| 内定→承諾 | 92名 | 20〜30名（フォロー不足） |

**動画 + LINEで「クッション」を入れることで、電話嫌いで離脱していた層を回収できます。**

### 3-2. SNS流入動線の構築（課題①への回答）

現在は転職媒体（エン転職/マイナビ/type/doda）からの**顕在層のみ**で母集団を形成。
SNSからの**潜在層**を受け止めるLINEファネルを新設します。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【既存】転職媒体 → 応募 → 面談
              ↑ 顕在層（今すぐ転職したい5%）

  【新規】SNS → LINE登録 → 2〜4週間の教育配信 → 面談
              ↑ 潜在層（いい話あれば聞く30%）
              └ この間をプロラインで完全自動化

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

#### 潜在層ナーチャリングの4フェーズ

```
Phase 1（7日間）：価値提供 ← 売り込みゼロ
  ├── リードマグネット配布（SES企業チェックリスト等）
  ├── 業界の年収相場マップ
  └── 会社選びの失敗談動画

Phase 2（14日間）：関係構築 + アンケートでセグメント分け
  ├── エンジニア社員の1日密着動画
  ├── キャリアパス解説
  └── ★ Day21アンケート → ホット/ウォーム/コールドに自動分岐

Phase 3（14日間）：温度上昇 → 面談案内
  ├── 中途入社者インタビュー動画
  └── カジュアル面談の案内（売り込みゼロのトーン）

Phase 4（月1回 × 最大12ヶ月）：長期維持
  └── 人力では不可能な「寝かせ追客」を自動で
```

#### 潜在層ファネルの推定効果

```
SNS月間LINE登録 500名 → 内定承諾 約10名/月の純増
1人あたりコスト：3〜5万円（既存54万の1/10〜1/18）
```

## 5. 導入ステップ

### Step 1：テスト導入（仕組みの構築・稼働）

プロラインのシナリオを構築し、実際に配信が稼働する状態を作る。

- LINE公式アカウントとプロラインの連携
- ステップ配信シナリオの構築（初回連絡〜面談予約〜リマインド〜内定フォロー）
- カレンダー予約機能の実装
- リッチメニューの設計・実装
- タグ管理設計

### Step 2：数値改善（歩留まりの安定）

構築した仕組みで実際に数値を計測し、悪化していないこと（微増で安定）を確認する。

- 各ファネルの歩留まり計測
- A/Bテスト（メッセージ文面・配信タイミング）
- 配信内容の最適化
- KPIダッシュボードの整備

### Step 3：目標数値への寄せ（コンサルティング + 実装）

確認された数値をベースに、目標数値に向けて改善を重ねる。

- 個別の歩留まり改善施策の設計・実装
- SNS流入動線の構築
- 潜在層ナーチャリングシナリオの構築
- PDCAサイクルの確立

## 7. 私たちが選ばれる理由

### プロライン大規模構築の実績

| 項目 | 実績 |
|------|------|
| プロライン構築実績 | 年商1億円規模のビジネスの全自動化を構築・運用中 |
| 配信規模 | 26,000名以上への配信を管理運用中 |

| 特長 | 上流設計（事業戦略）から実装・運用まで一気通貫で対応 |

### Lステップとの違い

| 比較項目 | 一般的なLステップ構築 | 当社のプロライン構築 |
|---------|-------------------|-------------------|
| 設計思想 | 分岐を増やして細分化 → 1シナリオあたりの通過人数が減り、効果検証が困難 | **全員が同じステップを通過** → データが集まり、PDCAが回る |
| 検証可能性 | 分岐先のデータが少なく、施策効果か偶然かの判別が困難 | 母数が多いため統計的に有意な結果が出せる |
| コスト | 月額数万円〜 | プロプラン **月額9,680円** |
