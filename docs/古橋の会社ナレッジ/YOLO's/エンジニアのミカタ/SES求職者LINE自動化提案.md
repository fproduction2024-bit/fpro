# SES求職者 LINE自動化提案書
# ── 応募→面談の各数値を引き上げるプロライン活用設計

> **対象**: SES（システムエンジニアリングサービス）の求職者獲得〜面談設定
> **使用ツール**: プロラインフリー（プロプラン 月額9,680円）
> **提案者**: YOLO's（ヨロリク事業の一環）
> **作成日**: 2026年2月20日

---

## 1. 課題認識：なぜ「応募→面談」で数値が落ちるのか

### SES採用の現状フロー

```
求人媒体（Indeed / エンゲージ / Wantedly等）
  ↓
応募（エントリー）
  ↓  ← ここで大量離脱（応募したまま放置）
電話・メールで連絡
  ↓  ← ここでも離脱（電話出ない/メール未読）
日程調整
  ↓  ← ここでもドタキャン
面談実施
  ↓
内定・入社
```

### 3つの構造的問題

| # | 問題 | 原因 |
|---|------|------|
| ① | **長期フォローができない** | 人力では応募後1〜2回の連絡が限界。1週間以上経つと「もう別で決まった」 |
| ② | **価値観の教育ができない** | テキストの求人情報だけでは会社の雰囲気・文化・人が伝わらない |
| ③ | **人的コストが膨大** | 1人の採用担当が追えるのは同時20〜30名が限界。100名応募があると物理的に回らない |

### 結果として起きること

- **応募→面談率**: 20〜30%程度（7〜8割が面談前に離脱）
- **面談→採用率**: 30〜40%程度（価値観が合わず不採用 or 辞退）
- **1人あたり採用コスト**: 50〜100万円（媒体費 + 人件費）
- **採用担当のリソース**: フォロー作業で1日の大半を消費

## 2. 提案コンセプト：「教育の時間」をLINEで自動挿入する

### ロジックの核心

> **応募と面談の間に「動画 × LINE配信」の教育フェーズを入れ、
> 価値観が温まった状態の求職者とだけ面談を組む。**

### 提案フロー

```
求人媒体（Indeed / エンゲージ等）
  ↓
応募フォーム
  ↓
LINE友だち追加 ← ★ ここが起点
  ↓
【プロラインのステップ配信 5〜7日間】
  ├── 動画で会社・人・文化を教育
  ├── 求職者の不安を払拭
  └── 価値観フィルタリング
  ↓
温まった求職者だけが面談予約 ← ★ 面談の質が激変
  ↓
面談（採用担当は「面談だけ」に集中）
  ↓
内定・入社
```

### なぜこのロジックが効くか

```
従来：「応募 → 即アポ → 冷えた面談」
       ↓
  ・求職者は会社のことをほぼ知らない
  ・「とりあえず応募しただけ」の人も混在
  ・面談でゼロから説明 → 時間ロス
  ・価値観ミスマッチで不採用 → 全体の歩留まり低下

提案：「応募 → 5日間の教育配信 → 温まった面談」
       ↓
  ・動画で会社の雰囲気を体感済み
  ・「この会社いいかも」と思った人だけが面談に来る
  ・面談は確認と意思決定の場 → 短時間で決定
  ・結果：面談→採用率が大幅UP
```

## 4. 動画コンテンツ設計

### 必要な動画一覧（5本）

| # | 動画タイトル | 尺 | 主な内容 | 撮影難易度 |
|---|------------|-----|---------|-----------|
| 1 | 会社紹介ショート | 2分 | 事業内容・オフィス・雰囲気 | ★☆☆ |
| 2 | エンジニアの1日 | 3分 | 出社〜退社の密着ドキュメント | ★★☆ |
| 3 | キャリアパス解説 | 4分 | SES業界のリアル・年収推移 | ★☆☆（代表トーク） |
| 4 | 社員インタビュー | 3分 | 中途入社者2〜3名のインタビュー | ★★☆ |
| 5 | 代表メッセージ | 3分 | 「一緒に働きたい人」の価値観 | ★☆☆ |

### 動画制作のポイント

- **台本は作り込みすぎない**：リアルさが重要。ガチガチの台本はむしろ逆効果
- **スマホ撮影でOK**：高品質である必要はない。「リアルさ」が最重要
- **尺は短く**：SES求職者は忙しい。1本3分以内が理想
- **字幕必須**：通勤中・休憩中に音なしで見る人が多い

## 7. ヨロリクとの接続ロジック

### YOLO'sの採用支援サービス（ヨロリク）との整合性

```
ヨロリクの採用ファネル3変数（事業内容.mdより）：

① 母集団形成     ：SNSオーガニック + 広告配信
② 応募促進       ：LINE動線の完全自動化 ← ★ 本提案の領域
③ 内定率向上     ：LINE上で教育動画配信  ← ★ 本提案の領域
```

### ヨロリクの独自性（競合との差別化ポイント）

> 「応募辞退・内定辞退を防ぐために、LINEの動線で社長の思いを動画で送るとか、
>  実際のインタビューの声を流すとか、リストマーケティング的な活用をしている企業はいない」
> ── 石山氏

→ **この「他社がやっていないLINE活用」を、SES領域に特化して展開するのが本提案**

### 法的制約への対応

| 制約 | 対策 |
|------|------|
| 求職者DBの自社取得不可 | LINE上で教育するが、個人情報はクライアント企業のフォームで取得 |
| 面談の実施不可（免許なし） | 面談予約までをLINEで自動化。面談はクライアント企業が実施 |
| 将来的な対応 | 人材紹介免許・派遣免許の取得後、一次面談の代行まで拡張可能 |

## 10. SES特有の配信設計ポイント（補足）

SES求職者は一般的な転職者とは異なる心理を持つ。以下を配信に反映する：

### SES求職者が抱える5大不安

| 不安 | LINE配信での対処 |
|------|-----------------|
| 「案件ガチャ」が怖い | → Day 2で案件選定プロセスを透明化する動画 |
| 客先常駐で孤独じゃないか | → Day 3で帰社日や社内イベントの様子を動画で |
| スキルアップできるのか | → Day 2でキャリアパスと研修制度を具体的に |
| 年収が上がるのか | → Day 2で実際の年収推移を数字で提示 |
| ブラック企業じゃないか | → Day 1で残業時間・有給取得率をオープンに |

### 配信のトーン設計

- **嘘をつかない**: SES業界は「入ってみたら違った」が最大の離脱原因。正直に語る
- **デメリットも出す**: 「思ったより良かった」を生むために、先にデメリットを伝える
- **社員の"本音"を使う**: 広報的な綺麗事ではなく、社員のリアルな言葉で語る
- **数字で語る**: 残業時間○時間、有給取得率○%、年収モデル○万円
