## 3. プロラインで自動化できる業務の特定

| # | 業務 | 月間工数 | 自動化率 | 削減工数 |
|---|------|---------|---------|---------|
| ① | 初回架電 | 35h × 10PM = **350h** | **90%** | **315h** |
| | → LINE自動メッセージ + 動画で代替。電話不要に | | | |
| ② | 面談日程調整 | 25h × 10PM = **250h** | **85%** | **213h** |
| | → プロラインのカレンダー予約で自動化 | | | |
| ③ | リマインド架電 | 15h × 10PM = **150h** | **95%** | **143h** |
| | → 前日・当日のリマインドは完全自動化 | | | |
| ④ | 面談実施 | 40h × 10PM = **400h** | **0%** | **0h** |
| | → ★ 人間でしかできない。ここは削減しない | | | |
| ⑤ | 内定後フォロー | 20h × 10PM = **200h** | **75%** | **150h** |
| | → 動画配信で自動教育。個別対応が必要なケースのみ人力 | | | |
| ⑥ | その他 | 25h × 10PM = **250h** | **20%** | **50h** |
| | → 報告・会議は減らないが、事務作業の一部は効率化 | | | |
| | **合計** | **1,600h** | **54%** | **871h** |

### 自動化率の根拠

```
① 初回架電 → 90%自動化
  ・応募者の90%はLINEメッセージ+動画で十分
  ・電話が必要なのは「LINE未読の10%」のみ → 残り46名のうち5名だけ架電

② 日程調整 → 85%自動化
  ・プロラインのカレンダー予約機能で85%はセルフ予約
  ・残り15%は時間帯の相談等で個別対応

③ リマインド → 95%自動化
  ・前日・当日・1時間前のリマインドはすべてプロラインで自動配信
  ・人力でのリマインドは「VIP候補者」のみ

④ 面談（Zoom） → 0%（削減しない）
  ・★ ここだけは人間がやる。むしろここに集中させる

⑤ 内定後フォロー → 75%自動化
  ・動画+ステップ配信で自動教育
  ・条件交渉や個別の不安解消は人力（25%が残る）
```

### 3つのシナリオで人件費削減を試算

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

シナリオA：人員を削減する場合（コスト最小化）
──────────────────────────────────────

  PM 10名 → 5名に削減（5名分の人件費カット）

  削減額：5名 × ¥340,000 × 1.15（法定福利） = ¥1,955,000/月
  年間削減額：¥23,460,000（約2,350万円/年）

  残りの5名は「面談実施」と「例外対応」に専念
  → 面談の質が上がる（1人あたりの面談件数が減り余裕ができる）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

シナリオB：人員を維持して処理量を増やす場合（成長最大化）
──────────────────────────────────────

  PM 10名のまま維持
  空いた871h/月を「面談の実施」に振り向ける

  現状のPM面談キャパ：
    400h ÷ 10PM = 40h/人 → 1人約32件/月の面談

  追加可能な面談数：
    871h ÷ 1.25h/件（面談+記録） = 697件の追加面談が理論上可能
    → 現実的には200〜300件の面談追加が可能

  効果：
    面談実施数 314名 → 500〜600名/月（+59〜91%）
    → 母集団が同じでも面談枠の拡大で歩留まり改善
    → 潜在層ファネル（SNS経由）の面談もこのキャパで吸収できる

  人件費削減：¥0（維持するため）
  ただし、同じ人件費で1.6〜1.9倍の面談処理能力 = 実質コスト効率は向上

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

シナリオC：ハイブリッド（推奨）
──────────────────────────────────────

  PM 10名 → 7名に削減（3名分カット）
  残り7名のうち：
    ・5名：面談実施に専念
    ・2名：潜在層ファネル管理 + 例外対応

  削減額：3名 × ¥340,000 × 1.15 = ¥1,173,000/月
  年間削減額：¥14,076,000（約1,400万円/年）

  加えて：
    面談キャパも現状維持以上（5名が面談専念）
    潜在層ファネル（SNS→LINE→面談）も運用可能

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 8. 提案のキーメッセージ（先方への伝え方）

> **「プロラインを入れる = 人を減らす、ではない。
>  PMが"電話マシン"から"面談のプロ"に変わる。」**

### 3つの数字で提案する

| # | 数字 | メッセージ |
|---|------|----------|
| **①** | **月871時間の工数削減** | PMの仕事の54%を自動化。電話・日程調整・リマインドが全部なくなる |
| **②** | **年間1,400万円の人件費削減** | PM3名分の工数が不要に。もしくは同じ人数で1.6倍の面談を処理可能 |
| **③** | **採用単価▲37〜44%** | コスト削減 + 歩留まり改善の両方の効果で、1人あたり52万→29万に |

### 経営者が気にするポイントへの回答

| 経営者の懸念 | 回答 |
|---|---|
| 「人を減らせってこと？」 | 減らさなくてもOK。同じ人数で面談キャパを1.6倍にできる。採れる人が増える |
| 「LINEで採用って大丈夫？」 | エンジニアは電話嫌い。LINEの方がレスポンス率が高い。開封率80%以上 |
| 「導入に時間かかる？」 | シナリオ構築3〜5日。月額9,680円。リスクほぼゼロ |
| 「今のやり方を変えたくない」 | 面談のやり方は変えない。面談の「前後」だけを自動化する |
