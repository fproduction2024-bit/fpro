## 1. 会社のミッション・背景思想

### 1-1. ミッション

**「生きる喜びと人生の感動を感じる社会を作る」**（高木氏の人生のミッションと同義）

### 1-2. 課題認識

高木氏は日本経済の根本課題を以下のように捉えている：

- 日本の企業は**「攻め（マーケティング）」と「守り（財務）」の両方が弱い**
- 背景には「ものづくり文化」があり、マーケや財務に投資する文化が根付いていない
- 人口動態の変化も経済弱体化に大きく寄与している
- フリーランスのWeb受託市場では「ポンコツでも独立しやすい」ため、品質の低いサービスが高額で提供され、顧客が不満を抱えている（月20万→40万→60万と値上げするだけの業者）
- 従来のM&A仲介会社では、力のない経営者が「買い叩かれている」現状がある（森澤氏も同じ課題認識）

### 1-3. 解決のロジック

```
企業にマーケ×財務を最低価格で届ける
  → 企業が強くなる
    → 経済が発展する
      → 税収が上がる
        → 「生きる喜びと人生の感動を感じる社会」に直結
```

さらに：上場することで**後進の起業家を生む実績**になり、日本の起業文化そのものを育てたいという意志がある。

## 2. 事業ポートフォリオ全体像

ミーティングで議論された事業は大きく**2軸**。高木氏は「ヨロリクの勝ち筋は3つある」と述べ、フィージビリティの高いものから話した。

### 全体構造

```
【第1の事業軸：成果報酬型採用支援（ヨロリク）】
  デポジット制×成果報酬 → BPOアップセル → 資金調達 → 再投資サイクル

【第2の事業軸：フロントエンドWebマーケパッケージ（ヨロレバ）】
  月額数万円の低単価パッケージ → 採用支援へのアップセル導線

【横断軸：ビッグデータ蓄積 → AIサース量産（3年後構想）】

【最終到達点：PEファンド組成（運用総額1,000億円）+ 事業承継仲介】
```

古橋氏の評価：「50億くらいまではめちゃくちゃ解像度が高い。その先は全社戦略の話になるので調整が必要」

## 3. 第1の事業軸：ヨロリク（YOLO REC）── 成果報酬型 採用支援

### 3-1. ビジネスモデルの詳細

**既存の営業顧問会社のモデルを採用領域に転用**した設計。高木氏が現在依頼している営業顧問会社のデポジット＋成果報酬モデルを「採用側にまるっとパクる」（古橋氏の表現）。

#### デポジット（預託金）プラン

| プラン | デポジット金額 | 成果報酬率 | 特典 |
|--------|-------------|-----------|------|
| **エントリー** | 50万円 | 高い | 基本パッケージ |
| **グロース** | 100万円 | 中程度 | + 資金調達サポート |
| **プライム** | 200万円 | 低い | + 資金調達サポート |

#### 成果報酬の計算式

```
最終成果報酬 = （採用応募数 × 応募単価 + 採用内定数 × 内定単価）− デポジット金額
```

#### なぜこのモデルが強いか：5つの理由

1. **キャッシュコンバージョンサイクルが圧倒的に早い**
   - 競合：初期費用10万円 → 後入金（成果が出てから回収）
   - ヨロリク：デポジット50〜200万円が先に入金
   - 古橋氏：「毎月ショットの収益だけで1,000万くらいは作れる」
   - 高木氏：「再投資しやすい」「資本主義ゲームはスピード系」

2. **マーケティング営業がしやすい**
   - 「成果報酬」と言えるため、CPA・CPOが下がる
   - 古橋氏：「CPO下がる以前に大事なのは、顧客を選べる状態になること。採用からのグロスを考えてるから、グロスできる企業と組まないといけない」

3. **資金調達パッケージによる増幅効果**
   - グロース・プライムプランには資金調達サポートを同梱
   - 資金調達 → 広告費増 → 成果報酬の母数増 → 自社売上増
   - 高木氏：「顧客もより勝つし、うちの成果報酬も増える」

4. **クライアントの与信でビジネスする構造**
   - BPO導入で管理工数が下がった実績値 → さらなるファイナンス → 桁が上がった採用予算 → 特別デポジットプラン → この繰り返し
   - 高木氏：「つまりこれってクライアントの与信でビジネスしてるんですよ」

5. **業界別のカスタマイズ**
   - 石山氏の指摘：「営業代行なら計算式がわかりやすいが、採用単価は業界によって変数になる。マーケターの視点として見づらくないか」
   - 古橋氏の回答：「だから業界別に資料を作らないといけない」→ 認識は一致

### 3-2. サービス提供内容

**オーガニックSNS運用 ＋ 広告運用の「どっちもセット」のみ提供**（片方だけは不可）。

#### 採用ファネルの3変数とアプローチ

| 変数 | 手法 | 担当 |
|------|------|------|
| **母集団形成** | オーガニックSNS運用 + 広告配信 | 自社チーム |
| **応募促進** | LINE動線の完全自動化 | 古橋氏のLINEマーケノウハウ |
| **内定率向上** | LINE上で社長メッセージ動画・社員インタビュー配信 | リストマーケティング手法 |

#### LINE活用の独自性

石山氏の発言：
- 「応募辞退・内定辞退を防ぐために、LINEの動線で社長の思いを動画で送るとか、実際のインタビューの声を流すとか、リストマーケティング的な活用をしている企業はいない」
- 「トレプロ（競合？）のLINE見てお雑魚やんって思った。なんでこんなんで売却できてるのか不思議」
- 「LINEに関しては古橋さんの方が詳しい。古橋さんが今やってるLINEマーケの導線を、もうやるだけ」

### 3-3. 法的制約と対策

**職業安定法上の制約**（高木氏が全員に共有）：

| 制約内容 | 影響 | 対策 |
|---------|------|------|
| 求職者DBの自社取得・保管が不可 | 求職者情報を自社で取れない | LINE動線を完全自動化、求職者情報をうちで取らないファネル設計 |
| 採用面の実施調整・実施が不可 | 一次面談の代行ができない | 面談件数等で成果報酬KPIを握る |
| 免許がない | 上記の制約が解除できない | **人材紹介免許 + 派遣免許の取得**（来期〜今期のどこかで） |

**リスク**：
- 母集団はいっぱい作れるのに、採用内定がクライアント任せになる → 成果報酬のKPIをこちらで握れない
- 古橋氏：「面談件数とかで握るのか。でも向こうも『変な人ばかり来させられても困る』と言うだろうし、どう調整するか」

**免許取得後の展開**：
- 一次面談の代行が可能に → 採用内定の成果をより直接コントロールできる
- 求職者を直接契約して派遣することも可能に
- 古橋氏：「派遣業でやっていくといろいろ話が早くなる。看護師専門メディアとかを作って」
- 高木氏：「話が早すぎる」（すぐに構想を理解された反応）

### 3-4. アップセル構造（ヨロリク → ヨロガード）

```
ヨロリク導入（採用支援）
  ↓ 採用成功で売上増加
  ↓ 売上増加で管理工数が増加
ヨロガード提案（BPOパッケージ）
  ↓ 管理工数が下がる
  ↓ 導入〜BPOまでの事業計画の「実数値実績」が蓄積
さらなるファイナンス打ち出し
  ↓ 桁が上がった採用予算
  ↓ 特別デポジットプランへ
再びヨロリクへ（拡大再投資サイクル）
```

**ただし、古橋氏からの重要な指摘**：
> 「売上を伸ばすというところの蓋然性を自社プロダクトで担保しないのに、管理工数が重くなるという推論に入っている。一個浮いている」

→ この指摘を受けて、**ヨロアド（ヨロックス）**という「売上を伸ばすサービス」の必要性が議論された（後述）。

## 4. 第2の事業軸：ヨロレバ ── フロントエンドWebマーケパッケージ

### 4-1. コンセプト

**「予算がない弱者に最高品質のウェブマーケパッケージを届ける」**（高木氏）

### 4-2. 市場機会の分析

高木氏の営業資料で使っているベネフィット説明：

| これまで（掛け捨て型マーケ） | これから（積立型マーケ） |
|---|---|
| プラットフォーム依存（食べログ・ホットペッパー等） | 自社メディア資産の構築 |
| 月額掲載料を払い続ける | UGCを発信し、自社で集客・マーケ |
| メディアは「消費財」 | メディアは「不動産」のような資産 |

高木氏：
- 「ショート動画の検索欄がGoogleに載ってるし、TikTokに都道府県のUAが出てる」
- 「Threadsは地理的変数にめちゃ強いアルゴリズム。湘南の時に25アカウントで囲ってこの構想を検証してた」
- 「利益を削って第二領域（将来投資）に踏ん張ってた。湘南でビジネスモデルの検証をしきって東京に来た」

### 4-3. なぜ競合がいないか

高木氏の分析：
- 「こういうビジネスモデルを描ける人がいない」
- 「フリーランスがどんどん流行る中で、Webの受託はポンコツでも独立しやすい」
- 「そういったポンコツは大体自分の利益しか考えないから、品質悪いものを高く取って顧客を不満にさせる」

### 4-4. PMFの兆候：顧客の声

- **有限会社 大塩組の大塩会長**と話して「これやったらマジで欲しい」と言われた
- **斎藤さん**にも同じことを言われた
- この2社の先に「数百〜数千社を紹介するよ」という確約をもらっている
- 古橋氏：「30万でやってるのを3万でやったらいいとか」

### 4-5. 事業ポートフォリオ上の位置づけ

- **ここで利益を取る必要はない**（フロントエンド商品）
- フロントエンドで輝いてる会社を見つけて、ヨロリク（採用支援）の契約につなげる
- 古橋氏：「フロントエンドの50社につき1社くらい、こっち（ヨロリク）で取れたら。月300社くらいフロント打ったらね」
- プロラインを専属独占契約で全パッケージに組み込む構想

### 4-6. 「真空マーケット理論」の適用

高木氏：「最高品質のものを最低水準で届けまくる。ここでできる金額で」
- 通常なら「新規で事業部を作る」レベルの予算感のものを、月額数万円で提供
- リプレイスではなく新規市場の創造に近い

### 5-2. インフルエンサーアカウント群戦略

**参考モデル：株式会社ハド（去年リーマインドに売却）**

ハドの戦略：
- 美容セグメントを細分化（肌系、韓国美容系、成分お得系など）
- 各コンセプトで自社インフルエンサーアカウントを**20アカウント程度**作る
- 外から見たらレッドオーシャン → 蓋を開けたら**全部自社メディア**
- アカウント群でトラフィックを流せる

YOLO'sへの応用（高木氏の構想）：
- 例：施工管理市場（今めちゃくちゃ市場がある）
- 施工管理でセグメント分けしてインフルエンサー群を構築
- 自社のヨロリクサービスで労働集約的にデリバリーしつつ
- 自社メディア群からトラフィックを流してスケーラビリティを確保
- 各メディアでの成果報酬もう1案件追加可能

## 7. ヨロアド / ヨロックス ── 売上支援・マーケ人材派遣

### 7-1. 誕生の経緯

古橋氏の指摘「ヨロリク→ヨロガードの接続が1個浮いている」を受けて議論された。

古橋氏の論点：
> 「売上を伸ばすっていうところの蓋然性を自社プロダクトでは担保しません。で、その先の管理工数が重くなった世界の話をしてるから、一個浮いてるんです」

→ **「売上を伸ばす」蓋然性を自社プロダクトで担保するサービスが必要**

### 7-2. サービス設計（議論段階）

古橋氏の提案：
- 「SIerがソフトウェアを作るプロジェクト型の人材派遣だとすると、フォロワーや無形資産を構築するチーム単位でのプロジェクト派遣がヨロリク2.0」
- 古橋氏：「本気で売上を追いに行こうとしたら、マーケ人材派遣」
- 内容：営業改善、数値改善、ビジネスモデル導入、PM案件
- マッキー（牧氏）の既存クライアントへのアップセル活動の延長線上

### 7-3. ファンドへの接続に必要な1サイクル

古橋氏が整理した、PEファンド構想のために**1サイクル完走が必要な15社**の定義：

```
ヨロリク導入（採用支援）
  ↓ 採用できた → 人が増えた
ヨロアド導入（売上支援）← これがないと「1個浮く」
  ↓ 売上が伸びた → 管理工数増
ヨロガード導入（BPO・管理部門）
  ↓ 管理工数下がった → 実数値実績が蓄積
資金調達支援
  ↓ 再投資サイクルへ
```

**この1サイクルを2年間で15社完走させる**ことが、PEファンド組成のための蓋然性証明になる。

## 8. 数値計画・KPI（具体的議論の全記録）

### 8-1. PMF基準（ヨロリク）

石山氏が定義：

| 指標 | 基準値 |
|------|--------|
| **顧客数** | 最低20社 |
| **オーガニック応募単価** | 3万円以下 |
| **採用単価** | 15万円以下 |
| **達成期限** | 2026年10月 |
| **採用した人員が内定して稼働** | 必須条件 |

### 8-2. 獲得計画の逆算

議論のフロー：
1. 10月PMF → プロジェクト期間5ヶ月（5〜10月）→ **7月時点で受注完了が必要**
2. 20社のPMFのうち全部達成は無理 → 歩留まり考慮
3. 石山氏：「商談でドンピシャなのは5件中2件（約30%）」
4. → **60社獲得が必要**（20社 ÷ 30% ≒ 60社）
5. 5月末までに60社獲得 → 月20社ペース → **3月スタートで3ヶ月**

### 8-3. 広告・マーケティング実績数値

| 指標 | 数値 | 備考 |
|------|------|------|
| **CPO（顧客獲得単価）** | 約12万円（広告のみ）| 2月実績。LP制作・クリエイティブ込みだと30万程度 |
| **事業計画上のCPO** | 16万円で策定 | |
| **1月CPO** | 19万円 | 1月実数値 |
| **月間広告費（20社獲得時）** | 約320万円 | 石山氏がその場で試算 |
| **3ヶ月合計広告費** | 約960〜1,000万円 | 岩見氏：「960万くらいは3ヶ月で」 |
| **LP申込率（1月）** | 約3% | PV→申込。岩見氏：「相当高い」 |
| **LP申込率（2月）** | 1.9% | 石山氏：「1月がちょっと良すぎた」 |
| **日程予約率（1月）** | 72% | フォーム申込→自動日程調整での予約完了率 |
| **残り28%** | 架電でフォロー | 予約しなかった人のみ電話 |
| **LP スクロール率(到達率)** | 30%地点で75%残存 | 石山氏：「めっちゃいい数字」 |
| **CTAボタン** | 25%地点でフローティング | 常時表示 |

### 8-4. LP改善に関する古橋氏の洞察

- 「フォーム申込率1%上げるだけで100万くらい広告費が浮く」
- 岩見氏の重要指摘：「フォーム申込率よりも、日程予約率（=売上に近い数値）の改善の方が現実的」
- 「フォーム申込率は月によってめっちゃ変わるから」

### 8-5. クリエイティブに関する議論

岩見氏の指摘：

## 9. ファイナンス戦略・上場ロジック

### 9-1. 流動資産 vs 固定資産（石山氏の専門的解説）

**50億円→その先へのジャンプに必要な考え方**：

石山氏：
- 「AIサースを量産して売る＝ソフトウェアという**固定資産**を溜め込むアクション」
- 「未上場時期のシリーズB以降で重要なのは、**流動資産の流動性をいかに高めるか**」
- 「流動資産の流動性をハチャメチャに高めた結果でかくなった企業が**オープンハウス**」
  - PEファンド的に「安く仕入れて高値で売る」＝資産の回転率を早くする
- **アレント**（土木系SaaS・上場企業）が参考に：
  - 無料の土木系SaaSを開放しパッケージ提供
  - 受託開発型でSaaSを提供
  - 時価総額250億円（一昨年）→ 伸び続けている
  - **ソフトウェアを固定資産として抱えず、流動資産としてパッケージで売り切る**

古橋氏の反応：
- 「売り切りだとデータがコモディティ化して価値が下がる」
- 「自社のデータは全部自社で持っておいて、それによって価値が上がる企業を買って、価格を上げて売却していく方がいい」

高木氏の理解：「楽天経済圏のような構造。楽天市場で流動性を作り、旅行・銀行を買って経済圏を作り固定資産化するイメージ」

### 9-2. AIサース構想（3年後）

高木氏の構想：
- 両事業のデリバリー過程で**ビッグデータを資産として計上する前提**でセールス＆マーケティングを行う
- 3年間で蓄積した膨大なビッグデータで「核爆弾のようなAIサースを同時に100個くらい」リリース
- 3年後に仮に5,000社のクライアントだとして、**月額1〜3万円のAIツール**を全社に提供
- **今年（2026年）がAIエージェントの元年**になると予測
- 「薄っぺらい情報でそれっぽく稼ぐやつが増える。AIの本質は一次情報をどれだけ握れたか」

開発アプローチ：
- 労働集約型サービスのデリバリー過程で**MVPを無料検証**
- ヒアリング → 改善のアジャイル開発
- 今期中にアジャイルの検証を終了 → **シードラウンド**
- エクイティ・バリュエーション：30億〜100億円目標
- 来期にシリーズA/B → 3年後上場 → **ユニコーン**を目指す

### 9-3. EBITDA成長目標（PEファンドのLP営業に必要）

古橋氏が算出：

| 条件 | 数値 |
|------|------|
| LBOローン**あり**でのEBITDA成長（業界標準） | 2年で20% |
| LBOローン**なし**でのEBITDA成長（YOLO'sが示すべき） | **2年で50%**（年間25〜30%） |

→ LBOなしで50%達成できれば、LBOありのLP営業は**最強カード**になる

## 10. PEファンド構想（運用総額1,000億円）

### 10-1. ファンドの基本設計

古橋氏がPEファンド経験をもとに算出：

| 項目 | 数値 |
|------|------|
| **AUM（運用総額）目標** | 1,000億円 |
| **ファンド運営会社の売上** | AUMの10% ＝ 100億円 |
| **投資先に配分する金額** | 900億円 |
| **投資期間** | 2年で投資しきる（セオリー） |
| **投資先企業の売上総額** | 700〜800億円 |
| **1社あたり投資金額** | 約60億円（900億 ÷ 15社） |
| **ファンド人員** | メインの指揮官20名 + インターン等 |
| **支援社数** | 15社 |
| **ターゲット企業の譲渡希望価格** | 8〜20億円 → ぴったりマッチ |

### 10-2. タイムライン

古橋氏：「これだったらかなり現実的にAUM1,000億を3年以内に目指せる」

```
1〜2年目：実績づくり（ヨロリク→ヨロアド→ヨロガードの1サイクル×15社）
3年目：ファンド組成・LP営業
```

### 10-3. ファンドの独自優位性

古橋氏：「この構想をするファンドプレイヤー、いないと思う。実務が強い集団だからこそできる」

- 完全買い切り型で企業買収 → 取締役を送り込みバリューアップ支援
- ヨロリクのパッケージで採用強化 → 売上蓋然性をヨロアドで証明 → BPOで管理コスト削減
- 「モニタリングするだけで実務支援をしないファンド」（FG等）とは根本的に異なる

### 10-4. LP営業の具体的動き

- 石山氏が石山の受託を岩見氏にパスし、3ヶ月以内に経営会計に入ってもらう
- 石山氏は**ファンドの資金集め**に専念

- その実績を使い、たくみさんの人脈でYOLO's自身のLP集めに協力してもらう

### 10-5. 上場モデル

古橋氏：「**技術承継機構**みたいな上場の仕方ができるかもね」
→ 事業承継×ファンドモデルでの上場は株価が上がりやすい構造
