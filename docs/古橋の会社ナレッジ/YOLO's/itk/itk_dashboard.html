step scenario
7日間ステップ配信シナリオ

Skill Hacks式「2日締切＋先頭戻し」＋ Brain式「プレゼント段階解放」＋ SES式「5日間教育→面談」を統合

即時配信

🎉 あいさつ＋給与レポート（ダイジェスト版）

登録直後に自動送信。「itkは飲食業界専門20年」の信頼提示 + 給与レポートのダイジェスト版を即提供。全文は面談参加者に提供と予告。

価値提供

💰 「年収50万アップした人の共通点」

転職成功者の事例紹介。待遇改善にフォーカス（給与UP・土日休み取得など具体的な数字）。求職者の「自分もこうなれるかも」を刺激。

アンケート

📋 セグメントアンケート（30秒）

希望職種・エリア・重視する条件を3問で回答。回答者にはパーソナライズされた求人情報を配信。アンケート回答者は面談予約率2〜3倍（Brain実証済み）。

市場情報

📈 「飲食業界、"買い手市場"は終わった」

求人倍率・人手不足データを提示。今がチャンスの緊急性を訴求。「動かない＝損をしている」と感じさせる。

非公開求人

🔒 「非公開求人のご案内」

好条件の求人を2〜3件紹介（土日休み / 年収UP / 駅チカなど）。具体的な待遇提示で面談への動機付け。

🔥 面談CTA

📅 「無料キャリア相談のご案内」

クロージング配信。「30分・無料・無理な勧誘なし」の安心感。Skill Hacks式の締切演出：「今週の面談枠は残りわずか」。面談予約カレンダーリンク送付。

🔄 未予約者フォロー（SES式ループ配信）

Day7で予約しなかった人への長期フォローを自動化。人力では絶対にできない「寝かせてから刈り取る」戦略。

Day 14：セグメント別の厳選求人を再送｜Day 30：「新着の好条件求人」通知｜Day 60：最終リマインド

🚨

離脱防止施策（Skill Hacks式）

✅ 2日締切：給与レポートに視聴期限を設け行動を促す
✅ 先頭戻し：未反応者に「もう一度だけチャンス」を提供

✅ 感想送信で次のプレゼント解放：エンゲージメント向上

  • 認証済みアカウント：取得済み or これから申請するか

  • 送信者名の表記（「itk」で良いか）
  • 配信NGリストの有無
  • 配信可能な時間帯
  • 既存のオプトアウト対応ルール
🎯 求人コンテンツ素材 ← 最重要
  • 転職成功事例：年収UP・待遇改善した求職者のエピソード（匿名可）を3〜5件
  • よくある転職失敗パターン：求職者が陥りがちな失敗例
  • 飲食業界のトレンド変化：昔と今で求人傾向はどう変わったか（コロナ前後、人手不足、待遇改善等）
  • 職種別の給与相場感：ホール・調理・店長・料理長・SVなど主要職種の年収レンジ
  • 非公開求人の提供可否：LINEコンテンツに使える注目求人を共有可能か
  • 年収レンジの公開範囲：給与レポートに掲載OKな年収帯・職種
  • 人気の求人条件：今の求職者が一番重視する条件は？
  • itk経由のメリット：直接応募や他社エージェントとの差別化ポイント
  • 求職者からの頻出質問：面談時によく聞かれるTOP5
  • 業界の数字ファクト：有効求人倍率、離職率、平均勤続年数などの使えるデータ
👥 ターゲット像・定性データ
  • 15万リストの属性構成：年齢層・性別・職種・エリアなどの大まかな分布
  • 典型的な求職者ペルソナ：「30代・調理師・年収350万・休み少ない」など代表的な人物像
  • 転職動機のパターン：給与不満？労働環境？キャリアアップ？独立志向？
  • 過去の掘り起こし経験：以前リスト掘り起こしを試みた経験はあるか、その結果は？
  • 成約しやすい人材の特徴：過去の紹介成約データから見える「決まりやすい人」の傾向
  • 離脱しやすいポイント：面談→紹介→成約の中で離脱が多い箇所は？
  • 求職者の情報収集手段：LINE・メール・電話どれが一番反応が良いか体感値
  • 季節変動：繁忙期（4月・10月等）は転職意欲が高まるなどの傾向はあるか
⚖️ コンプライアンス
  • SMS文面の社内承認フロー（承認者は誰か）
  • トーン＆マナー（カジュアル/フォーマル・絵文字可否）
