## 1. 会社概要：ITKとは

**斎藤氏が経営する会社で、2つの事業を持つ。**

| 事業 | 内容 |
|------|------|
| **バイク事業**（足立区） | 中古バイクの販売・修理。ハーレーから現行車まで幅広く扱う。ガラスコーティングなど付加サービスも展開 |
| **飲食人材紹介事業** | 飲食業界特化の人材紹介会社。業界では**最古参レベルの知名度**を持つ。売上ナンバーワンではないが知名度は最も高いと自負 |

### 斎藤氏の人物像
- **51歳、経営歴約20年**。高卒で消費者金融からの借入で起業
- ヘッドハンター出身（飲食店に直接乗り込んで人材を引き抜くスタイル）
- 名古屋駅の飲食フロアの出入り業者を全て押さえていた実績
- 食べログの代理店を3番目に取得した過去（200店舗まで拡大するも撤退）
- **筋トレ好き**（ボディビル大会出場経験あり。プロたん・ジン等のYouTuberとも交流）
- 見た目は強面だが**ミーハー**を自称。ビジュアルやデザインにこだわりが強い
- 代理店ビジネスを「男として一番かっこ悪い」と嫌悪

## 2. 商談の目的

**YOLO's（ヨロリク）が、ITKに対してTikTok/SNSを活用した採用マーケティングサービスを提案する商談。**

### 斎藤氏側のニーズ

| ニーズ | 詳細 |
|--------|------|
| **バイク整備士の採用** | 最優先課題。経験5年以上のベテラン整備士が欲しい。若手は使えない |
| **飲食人材紹介の集客** | 求職者のSNS集客を強化したい。バイクで成功したら飲食にも展開希望 |

### バイク整備士採用が困難な理由

1. **バイク整備士の人口が極めて少ない**（車の1/500の所有率）
2. **釣り堀（求職者プール）がない** — Indeed・エン転職等に登録しない層
3. 整備士が辞めると**タクシー・運送業・ガソリンスタンド**に転職してしまう
4. 競合の人材紹介会社は**フィー45%**と高額なのに、現場のニーズを理解していない
5. バイク業界は狭いため、**応募者を不採用にすると客として来なくなる**リスクがある

### 斎藤氏が求める採用条件
- **精度の高い採用**（無駄な応募を増やしたくない）
- ターゲットは**30〜40代の経験者**。資格持ちで古いバイクもいじれる人
- 整備士の本当のニーズは「給料アップ」だけでなく、**「土日休み」「夕方に帰りたい」**などの労働環境改善
- 理念共感型の採用ではなく、**リアルな待遇提示型**の採用が刺さる

## 3. YOLO's側の提案内容

### 提案① SNS採用マーケティング（ヨロリク）

- **TikTok + Instagramを活用した採用コンテンツ制作**
- オーガニック運用と広告運用の**両方をセットで提供**
- 月1回3時間の撮影で、社長・社員のリアルな姿をコンテンツ化
- 社員エンゲージメント向上（撮影を通じた社長と社員の交流機会創出）
- 企業ブランディング効果（全国雑誌掲載・取引先への交渉力向上の実績あり）
- **不動産型の動画資産**として設計（消費財的な使い捨てではなく蓄積型）

### 提案② 飲食人材紹介の集客メディア構築

- **シンクロフード社の「グルメバイトちゃん」**をベンチマーク
  - 飲食バイトの疑似体験コンテンツ → Instagram/TikTokで集客 → 応募導線
  - 2023年2月から運用開始し、フォロワー7.9万人まで成長
- **業種セグメント別にアカウントを複数同時運用**する戦略を提案
  - 和風居酒屋コンセプト、洋風飲食コンセプトなど3〜6アカウント
  - 外から見ると独立したアカウント群 → 実は全て自社メディア（参入障壁になる）
  - **エニーマインドグループに売却した美容系企業**の事例を参考

### 提案③ TikTokライブ配信による人材紹介

- **渋谷のフリームーという人材紹介会社**：TikTokライブのみで月商6,000万円
- 中国ではキャリアアドバイザー兼ライブ配信者が存在
- YOLO'sも今期からライブコマース事業に参入決定済み

### 提案④ BPO・財務支援（バックオフィス）

- CFO代行・記帳代行・経理DX化・資金調達支援
- 採用費用をYOLO's側で資金調達して賄うことも可能
- 補助金（事業再構築補助金等）のホワイトな活用支援も実績あり

## 4. 斎藤氏の反応・フィードバック

### ポジティブな反応
- 「TikTokしかもう採用の手段がないと思っている」と自らSNS採用の必要性を実感
- バイクで成功したら**飲食の社長仲間を大量に紹介する**と明言
  - 「マジでメリットあるからね。いくらでも紹介する」
  - 「代理店ではなく、直接つないであげる」
- ライブコマースでの人材紹介に強い関心
- 補助金の正当な活用にも興味

### 厳しい指摘・注文
- **「前振りいいよ。提案からよろしく」** — 長い前置きを嫌う
- **「低層の人間の特性を分かっていないと採用はうまくいかない」** — 整備士は理念共感ではなく待遇重視
- **「ダサいのは嫌」** — ビジュアル・クリエイティブに強いこだわり
- **「丸投げしたい。でもうるさい」** — 任せたいが品質にはうるさいタイプ
- **「短期で結果が欲しい」** — 長期ブランディングより即効性を重視
- **広告手数料20%**に対して「高くないか？うちの代理店は18%で制作込みだ」と牽制
- **「年間はかけられない」** — バイク事業は儲かっておらず、意地で続けている部分がある

### 斎藤氏のSNS運用実績（自力で）
- Instagramフォロワー約**15,000人**（バイク業界では異例の多さ）
  - うち約6,000人がオーガニック、残りは広告で獲得
  - **1月に70万円**をInstagram広告に使用（無期限設定のミスで想定外の出費）
- 1投稿に**4時間**かけて自作
- YouTuberやインフルエンサーを**10人以上**呼んでコラボ済み
  - インフルエンサーコラボ → フォロワーも売上も増えない
  - YouTuber（登録者3,000人でも）→ **売上に直結**する

## 5. 業界特有の事情（斎藤氏からの共有）

### バイク業界
- **バイクは「買ったところでしか修理しない」**という慣例 → 通販のリスクが高い
- 中古バイクはインチキ品やエンジン載せ替え品がオークションに出回る
- 部品調達に体系的な卸がない（車種ごとに仕入先がバラバラ）
- **登録商標を誰もやっていない** → 斎藤氏は4つ取得見込みで将来ライセンス料を狙う

### 飲食人材紹介業界
- 斎藤氏は**ヘッドハンティング出身**で、店舗に直接乗り込むスタイル
- 「代理店はやりたくない。直接つなぐ」という信念
- インスタ無料で集客できるのにやらない飲食店が多い → チャンス
- 食べログ・ぐるなびは「金を払って待つだけ」で攻められない → SNSは攻めの手段

### 採用市場の問題
- **サイバーエージェント系の広告代理店**に任せて失敗した経験
  - 「学歴の発表会」のような営業 → 結果が出ない
  - AI学習期間と称して無駄に予算消化
- **インディードの代理店（トルー等）**も失敗
  - 予算2,300万円を消費して外国人と年寄りしか来ない
- **既存のバイク人材紹介会社**はフィー45%で保証期間なし → 足元を見た弱者ビジネス

| **追加機会** | 補助金活用、BPO（財務支援）、ライブコマースでの人材紹介 |

## 7. YOLO'sにとっての戦略的価値

このミーティングは単なる1社の商談ではなく、**YOLO'sの事業展開において極めて重要な意味を持つ**：

1. **飲食業界への大規模展開の突破口**
   - 斎藤氏は飲食人材紹介で業界最古参の知名度 → 成功事例ができれば大量の社長紹介が見込める
   - 「バズるよ、飲食業界で」と斎藤氏本人が断言

2. **ヨロリクのPMF検証に最適な案件**
   - バイク整備士＝最も採用が難しい領域 → ここで成果が出れば他業界は容易
   - 飲食業界は労働人口が桁違いに多い → スケールの余地が大きい

3. **ニッチ市場の独占可能性**
   - バイク整備士の人材紹介はほぼ競合がいない
   - 斎藤氏のリアルな現場知見をコンテンツに活かせれば圧倒的な差別化

4. **クロスセルの典型パターン**
   - 採用支援 → 飲食集客支援 → BPO（財務） → 資金調達 → 事業拡大
   - YOLO'sの事業ポートフォリオ（ヨロリク→ヨロアド→ヨロガード）の実証ケースになり得る
