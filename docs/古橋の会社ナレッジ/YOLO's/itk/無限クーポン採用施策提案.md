# ITK様向け提案書
# 「無限クーポン施策」で地域リストを構築し、採用母集団を自動形成する

> **提案者**: YOLO's
> **提案日**: 2026年2月21日
> **対象**: ITK 斎藤社長

---

## 結論：3つの数字

| 指標 | 数値 |
|------|------|
| **LINE広告でリスト1人獲得するコスト** | 100〜500円/人 |
| **飲食人材紹介の採用コスト（業界相場）** | 30〜135万円/人 |
| **無限クーポンでのリスト獲得コスト** | 実質0円（売上を出しながら獲得） |

→ **広告費をかけずに地域リストを構築し、そこから採用母集団を形成する。しかもリスト獲得の過程で飲食店の売上も上がる。**

---

## 1. 施策の全体像

### やること（3ステップ）

```
Step 1：飲食店に「無限クーポン」を導入
        → 店頭QRでLINE登録 → 来店クーポンが自動配布 → リピート促進
        → 飲食店の売上UP（来店人数 +15〜50%）

Step 2：登録者 = 「その地域で飲食店に通う人」のリストが自動蓄積
        → 1店舗あたり月100〜300人のLINE登録
        → 10店舗で月1,000〜3,000人のリスト増加

Step 3：蓄積したリストに対して採用募集を配信
        → 「この地域で飲食の仕事を探していませんか？」
        → ITKの人材紹介サービスへの導線
```

### なぜこのロジックが成立するか

```
飲食店のLINE登録者 ＝ その地域で飲食店に「日常的に通う人」

この人たちの中に必ず含まれるのが：
  ✅ 飲食業界で働いている人（ホール・キッチン・店長）
  ✅ 飲食業界で働いたことがある人
  ✅ 飲食業界に興味がある人
  ✅ 飲食業界で働く人の家族・知人

→ 飲食人材紹介の「求職者プール」として最適
```

## 2. 地域リストを持つことのビジネス上の有利さ

### 2-1. 人材紹介業界の最大の課題：「求職者が来ない」

```
飲食人材紹介の構造的な問題：

  求人企業（飲食店）   ← 斎藤社長のネットワークで無限に獲得可能 ✅
  求職者              ← ここが常にボトルネック 🚨

  → Indeed・エン転職等に予算をかけても「釣り堀（求職者プール）がない」
  → 今のSNS採用は広告費が高騰し続けている
  → 飲食業界は「転職媒体に登録しない層」が多い
```

### 2-2. リストがあれば「待ち」から「攻め」に変わる

| 従来の人材紹介 | リストを持つ人材紹介 |
|-------------|-------------------|
| 求人媒体に掲載して**待つ** | リストに直接**配信してアプローチ** |
| 応募があるかは**運任せ** | 配信すれば**確実にリーチ** |
| 1人の採用に**30〜135万円** | リストからの採用は**追加コスト0円** |
| 競合と**同じ求職者を奪い合い** | 自社リストは**独占資産** |
| 媒体を止めたら**ゼロに戻る** | リストは**永久に蓄積** |

### 2-3. 「地域」のリストが特に強い理由

```
飲食業界の特性：
  → 求職者は「自宅から通える範囲」でしか仕事を探さない
  → 全国一律の求人媒体ではミスマッチが起きやすい

地域リストの強み：
  → その地域に住んでいる/通っている人だけのリスト
  → 飲食店の所在地 ≒ 求職者の通勤圏
  → 「○○区で飲食の仕事探していませんか？」がピンポイントで刺さる
  
例：足立区の飲食店10店舗にクーポン導入
  → 足立区在住・在勤の飲食関連者リストが3,000〜10,000人規模で蓄積
  → このリストは足立区の飲食採用において独占的な価値を持つ
```

## 4. 無限クーポンなら「売上を作りながら」リストが獲得できる

### この施策の最大の強み：リスト獲得がコストではなく「収益源」になる

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
通常のリスト獲得：
  広告費 → リスト獲得（コストだけ発生）
  
無限クーポン施策：
  飲食店に導入 → 売上UP → リスト蓄積（売上も発生）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 4-1. 飲食店側のメリット（導入させやすい理由）

```
飲食店が無限クーポンを導入するメリット：

  ① 来店人数 +15〜50% UP（大阪王将実績ベース）
  ② 月額コスト 9,680円のみ（広告費ゼロ）
  ③ 作業ゼロ（全自動、POPを置くだけ）
  ④ リスクゼロ（月単位で解約可、契約縛りなし）

→ 飲食店にとって断る理由がほぼない
→ 斎藤社長の飲食ネットワークで一気に展開可能
```

### 4-2. YOLO's / ITK側の収益モデル

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1店舗あたりの収益構造
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 売上①：クーポン施策の構築・運用費
  初期構築費：●●万円（LINE構築一式）
  月額運用費：●●万円（レポート+改善）

■ 売上②：プロラインの紹介マージン
  月額9,680円 × YOLO's紹介分

■ 売上③：蓄積したリストからの人材紹介
  飲食人材紹介の成功報酬（ITKの本業）
  → 1件あたり 70〜120万円の紹介フィー

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  200人/月 × 10店舗 × 12ヶ月 = 24,000人

このリストを広告で獲得した場合のコスト：
  24,000人 × 300円（CPF中央値）= 720万円相当

  24,000人のうち飲食関連就労者 → 推定20〜30%

  うち紹介成約 → 5〜15%
  → 12〜108人の人材紹介成約

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 6. 採用母集団としてのリスト活用方法

### 6-1. LINE配信による採用アプローチ

```
蓄積したLINE登録者に対して、定期的に採用情報を配信：

配信例①：直接募集
  「○○区で飲食のお仕事を探している方へ
   時給1,200円〜、週3日からOKの求人が○件あります
   → 詳細はこちら [ITK求人ページへのリンク]」

配信例②：紹介依頼
  「お知り合いで飲食のお仕事を探している方はいませんか？
   ご紹介いただくと○○クーポンをプレゼント
   → 紹介フォームはこちら」

配信例③：キャリア相談
  「今の飲食の仕事、このまま続けていいのか不安な方へ
   無料キャリア相談を受付中（LINEで完結）
   → キャリア相談を申し込む」
```

### 6-2. リスト活用のタイムライン

```
Month 1-3：飲食店にクーポン導入 → リスト蓄積開始
  → この期間は飲食店の売上UP実績を作ることに集中
  → 成功事例ができれば斎藤社長のネットワークで横展開

Month 4-6：蓄積したリストに採用配信テスト開始
  → 反応率を計測、配信内容のABテスト
  → 求職者のLINE導線（ステップ配信）を構築

Month 7-12：本格的な採用母集団として運用
  → 定期配信による安定した求職者流入
  → リスト規模と採用実績の相関データ蓄積
  → ITKの人材紹介事業の新規チャネルとして確立
```

## 8. 提案のまとめ

### ワンフレーズ

> **「飲食店の売上を上げながら、地域の飲食関連者リストを無料で蓄積し、
>   ITKの人材紹介事業の求職者プールに変える。」**

### 3つの勝ち筋

| # | 勝ち筋 | 具体的な効果 |
|---|--------|------------|
| 1 | **リスト獲得コスト0円** | 広告で同じリストを獲得すると720万円かかるところを、売上を作りながら獲得 |
| 2 | **飲食店の売上UP** | クーポン施策自体が飲食店への価値提供。導入のハードルが極めて低い |
| 3 | **採用母集団の独占** | 地域×飲食のリストを持つのはITKだけ。競合は同じリストを持てない |

### 具体的な第一歩

```
Step 1：飲食店1〜3店舗にクーポン導入（最短3日で開始）
Step 2：2〜3ヶ月でリスト蓄積＋売上UP実績を作る
Step 3：成功事例をもとに斎藤社長のネットワークで10〜30店舗に横展開
Step 4：蓄積リストに採用配信を開始 → ITKの求職者チャネルへ
```

|------|------|------|
