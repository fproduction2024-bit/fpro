## 1. YOLOs プロダクト体系の最終決定

### 意思決定：ヨロアタック（売上構築支援）は廃止

ミーティング中に議論された結果、**3つのプロダクトから2つに集約**する方針が決定。

| プロダクト | 内容 | ステータス |
|-----------|------|-----------|
| **ヨロリク 1.0** | サブスク型の店舗採用支援パッケージ | ✅ 採用・FE商品 |
| **ヨロリク 2.0** | デポジット型・成果保証の採用支援（SNS含む） | ✅ BE商品 |
| ~~ヨロアタック~~ | ~~売上構築支援コンサル~~ | ❌ 廃止 |
| **ヨロガード** | 管理部門顧問（月額10〜15万→アップセルで60万） | ✅ 採用・FE商品 |
| **ヨロガード ネオ** | 資金調達・CFO代行を含む上位パッケージ | ✅ BE商品 |

> **廃止理由**: ヨロアタックを入れると投資戦略が特定業種に縛られる。ヨロリクで採用した人材が増えれば自然と売上も伸びる構造なので、売上支援を別商品にする必要がない。

## 2. ヨロリク 1.0 の詳細設計

### 2-1. 商品定義

> **一言で**: 数万円で店舗の採用支援ができるゲームマーケティングサービス

- 店舗の来店客向けにLINEでリスト取りの仕組みを構築
- **来店客の中から新しいスタッフを見つけるという画期的アプローチ**
  - バイト応募する人 ≒ その店に食べに来たことがある人
  - 商圏内の人口にピンポイントでリーチ可能
- プラットフォームを介在しない直接雇用 → 採用コスト激減

### 2-2. プライシング（松竹梅）

| プラン | 月額 | 内容 |
|--------|------|------|
| **梅** | 1.5万円 | プロライン無限クーポンのみ（来店頻度向上に特化） |
| **竹** | 3万円 | MEO + プロライン |
| **松** | 4.5〜5万円 | SNS運用 + MEO + プロライン（初期構築込み） |

**顧客の支払い総額**: 月額3〜3.5万円（公式LINE代5,000円は別途）

> 💡 **原価構造**: プロラインを1アカウントに集約すれば月1万/店舗も不要になり、利益率がさらに向上。1,000店舗導入で年間売上1,800万円以上。

### 2-3. 機能の切り分け

| 施策 | 役割 | 対応プラン |
|------|------|-----------|
| **プロライン（無限クーポン）** | 来店頻度向上 + LINEリスト蓄積 | 梅〜松 |
| **MEO** | 受動的新規来店獲得 | 竹〜松 |
| **SNS運用** | 能動的新規来店獲得 | 松のみ |

## 3. 無限クーポン施策の運用設計

### 3-1. 導入の仕組み

```
レジ横POP → 「今すぐLINE登録で今回のお会計から300円引き」
レジ担当  → 「300円オフクーポン要りますか？」と一声かける
来店客    → QR読み取り → LINE登録 → クーポン自動配布 → リピート促進
```

### 3-2. 利益構造の説明ロジック（提案時に必要）

飲食店オーナーの第一反応：「300円引きしたら利益なくなるだろ」

**回答ロジック**:
- 顧客単価1,300円 × 利益率20% = 利益260円 → 確かに300円引いたら赤字
- **しかし**、家賃・レイバーコスト等は固定費
- 月売上500万→550万に増えた場合、増分50万の原価は変動費（原材料費）のみ
- 原材料費30%前後なら、50万増 × 70% = **35万円の追加利益**
- つまり1杯あたりは赤字でも、**来店頻度1.3倍で月次利益は大幅プラス**

> ⚠️ **提案資料に必要**: 想定PLを作成し、導入前後のコストメリット＋売上伸長＋利益率跳ね返りを可視化すること（石山が型を作成）

### 3-3. クーポン設計のバリエーション

提案時は以下の組み合わせで12パターン程度を用意：
- 割引額: 100円 / 200円 / 300円
- クーポン有効期限: 7日 / 14日 / 30日
- 顧客の現状来店頻度をどう置くか

## 4. MEOとの連携アイデア（新規発想）

### MEOからプロラインへの導線

```
Googleマップ検索 → MEO最適化で上位表示
  → 店舗ページの「ウェブサイト」リンク
    → LP（ラーメン屋なのにLPを持つという新発想）
      → 「300円オフクーポンを受け取る」ボタン
        → LINE登録 → 無限クーポン施策に合流
```

- MEOの投稿画像にもQRコード設置可能
- マイクロコンバージョンボタンのテキスト変更も可能（「〇〇クーポンはこちら」等）
- MEO自体は自社運用推奨（主婦を時給1,500円で外注 + 社員1名が週1時間マネジメント）

## 5. ターゲット顧客の定義

### ペルソナ

| 項目 | 内容 |
|------|------|
| **年齢・性別** | 40歳・男性 |
| **属性** | 全国の店舗経営者・運営者 |
| **業種** | 飲食業界（アパレル等にも拡張可能） |
| **除外条件** | 家族経営など採用ニーズがない法人 |
| **課題** | 採用したいが採用コストをかけられない / 母集団形成コストがない |

### 市場規模

| 指標 | 数値 | 根拠 |
|------|------|------|
| 飲食店アルバイト採用市場 | 500〜600億円 | 求人情報サービス市場6,600億円 × アルバイト比率40% × 飲食絞り込み |
| アルバイト募集中の店舗数 | 約12万社 | バイトル掲載4万社 × 市場シェア30%で逆算 |
| 1店舗あたりの年間採用費 | 60〜90万円 | バイトル等の掲載費相場 |

### MVP（最小限の価値提案）

1. **商圏内の見込み求職者に対してダイレクトに採用訴求ができる**
2. **自社でリストを握れる**（二店舗目出店時の採用コストが0になる）

## 6. 営業・顧客獲得戦略

### 6-1. チャネル

| チャネル | 詳細 | 優先度 |
|---------|------|--------|
| **グルメインフルエンサー** | 武内の友達に20人程度、ローカリンク社（50名規模のインフルエンサー事務所）とも連携可能 | ★★★ |
| **代理店構築** | PayPay導入営業のようなノック商材として店舗飛び込み、1件獲得5万円など | ★★★ |
| **既存NW（リストホルダー）** | ITK斎藤社長、小島裕二（年商10〜15億のジャクソン屋社長）等 | ★★★ |
| **エンプラ営業** | 最初は大手チェーンから導入→成功事例で横展開 | ★★☆ |
| **SNS / DM** | 武内のインスタ（ストーリー閲覧率30%、2,000閲覧）等 | ★★☆ |
| **ポスティング / 地方商工会議所** | 説明商品なのでお問い合わせまでの導線 | ★☆☆ |

### 6-2. 営業上の注意点

- **説明商品**であり、VSL（ビデオセールスレター）だけでは売れない可能性が高い
- クーポン発行で利益が上がるイメージを持たせるPL感覚の醸成が鍵
- **まずエンプラ（大手チェーン）から落とす戦略が有効**
- セミナー→個別面談の導線が現実的

## 7. 横展開の可能性

### 美容室への展開

ミーティング中に複数回言及：

> 「これ絶対美容室の方が相性いいですね」（武内）
> 美容室の既存クライアントが2〜3社いるため、すぐに提案可能

**美容室の優位性**:
- 飲食よりもリピート周期が安定（1〜2ヶ月）
- 顧客単価が高い（5,000〜15,000円）
- 原材料費率が低い → クーポン施策の利益インパクトが大きい
- 商圏が明確（自宅から通える範囲）

### その他の潜在業種

ソニーのスターターダッシュツールで策定中に議論された業種：
- アパレル / 接骨院 / パーソナルジム / カーテン販売 / FCチェーン全般
