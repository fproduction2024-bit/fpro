## はじめに：なぜ今「LINE自動化」なのか

投資先企業の成長を支える上で、**顧客との接点管理**は業種を問わず最大の課題です。

多くの企業が抱える共通の構造問題：

```
❌ 人が手動で対応している → 人手不足・対応漏れ・属人化
❌ 広告に頼っている     → CPA高騰・止めたらゼロに戻る
❌ リストはあるが活用できていない → 眠っている顧客資産
```

**プロライン（プロラインフリー）** を導入することで、
LINE公式アカウントを「自動で売上を生む仕組み」に変えられます。

```
✅ 月額 9,680円 ── 導入コストが極めて低い
✅ 全業種対応   ── 店舗・EC・BtoB・人材・教育・クリニック等
✅ 完全自動化   ── 一度構築すれば人手ゼロで稼働
✅ 即効性       ── 導入初月から数値改善が出る実績あり
```

## 2. プロラインで何ができるのか

### 基本機能（業種共通）

| 機能 | 何が起きるか |
|------|------------|
| **ステップ配信** | LINE登録後に自動でメッセージ配信。教育→販売→フォローまで全自動 |
| **カレンダー予約** | LINE上から来店・面談・体験会の予約が完結。電話対応ゼロ |
| **無限クーポン** | クーポン使用→次回クーポン自動発行のループで来店頻度を自動で上げる |
| **タグ管理・セグメント配信** | 顧客属性に応じた配信で反応率を最大化 |
| **紹介URL自動発行** | 友だち毎に紹介URLを発行。紹介者への特典配布も自動 |
| **リッチメニュー** | LINE内にミニアプリのようなUI。商品一覧・予約・FAQ等を集約 |
| **アンケート・フォーム** | ヒアリングを自動化。回答に応じてシナリオを分岐 |

### 競合ツール（Lステップ等）と何が違うか

| 比較項目 | Lステップ | プロライン |
|---------|----------|----------|
| 月額 | 2.7万〜（ボリュームで増加） | **9,680円（定額）** |
| 設計思想 | 分岐を増やして細分化 → データが分散 | **全員同一ステップ** → データが集まりPDCAが回る |
| 検証可能性 | 分岐先のN数が少なく効果検証が困難 | 母数を保つ設計で統計的に有意な結果が出せる |
| 導入難易度 | 構築に専門知識が必要 | 比較的シンプル。当社で構築を一括サポート |

## 3. 業種別ユースケース：「何を押せばいいか」

**プロラインの訴求は業種ごとに変えます。**
投資先の業種に応じて、以下のどのパターンが刺さるかを見極めます。

---

### 🍽️ パターンA：店舗ビジネス（飲食・美容・整体・ジム等）

**課題**: 新規集客コストの高騰、リピート率の低さ

**打ち手**: 無限クーポン × 自動リマインド

```
来店＆LINE登録
  ↓
1stクーポン自動配布（来店動機）
  ↓
翌日：お礼メッセージ + 2ndクーポン（2週間期限）
  ↓
自動リマインド（あと1週間→あと5日→あと3日→あと2日）
  ↓
2回目来店 → 3rdクーポン → … → VIPカード（常連化完了）
```

**実績（ビールバー・蒲田）**：
- 来店人数：**2.26倍**（139名 → 312名）
- 売上：**1.81倍**（77万 → 139万）
- 広告費：**0円**
- 導入コスト：月額9,680円のみ

**刺さるポイント**：
> 「広告費ゼロで来店2倍。月1万円以下で始められます」

---

### 👩‍💼 パターンB：人材紹介・採用（SES・派遣・紹介）

**課題**: 求職者の離脱、電話対応の非効率、内定辞退

**打ち手**: 応募→面談→内定フォローの全自動LINE化

```
応募
  ↓
自動LINEメッセージ（電話不要）
  ↓
カレンダーから面談予約（セルフ）
  ↓
前日・当日・1時間前に自動リマインド
  ↓
面談実施（ここだけ人間がやる）
  ↓
内定後：動画+ステップ配信で自動フォロー
```

**推定効果**：
- PM工数：**▲54%削減**（1,600h → 729h/月）
- 内定承諾数：**+54〜71%**
- 年間人件費削減：**▲約1,400万円**

**刺さるポイント**：
> 「電話をかけなくても面談が入る。人件費を1,400万円削減しながら採用数1.5倍」

---

### 🏫 パターンC：教育・スクール・オンライン講座

**課題**: 無料体験→本申込の転換率が低い、入会後の継続率

**打ち手**: LINE登録→動画教育→体験予約→入会フォローの自動化

```
広告/SNS → LINE登録
  ↓
Phase 1（7日間）：無料コンテンツで価値提供（売り込みゼロ）
  ↓
Phase 2（7日間）：実績・受講生の声を配信（信頼構築）
  ↓
Phase 3（3日間）：体験会・無料相談の案内（限定感）
  ↓
体験参加 → 入会 → 継続フォロー配信
```

**刺さるポイント**：
> 「LINEに登録させれば、あとは自動で体験会まで連れてくる仕組み」

---

### 🏥 パターンD：クリニック・医療・治療院

**課題**: 予約管理コスト、リピート率、術後フォローの人手

**打ち手**: 予約自動化 + リマインド + 術後フォロー + 誕生日クーポン

```
① 予約自動化：LINE上でカレンダー予約 → 電話予約の80%削減
② 自動リマインド：前日・当日に自動送信 → ドタキャン率▲50%
③ 術後フォロー：「施術後の経過について」自動配信 → 問い合わせ削減
④ 誕生日クーポン：自動配布 → 再来院促進
```

**刺さるポイント**：
> 「電話予約を8割減らしながら、ドタキャンも半減」

---

### 🛒 パターンE：EC・D2C

**課題**: CPAの高騰、カゴ落ち、リピート率

**打ち手**: LINE登録→ステップ配信→購入→リピート促進の自動化

```
広告/SNS → LINE登録（クーポン付与）
  ↓
ステップ配信：商品ストーリー・製造背景・お客様の声
  ↓
初回購入促進（限定クーポン）
  ↓
購入後フォロー：使い方動画・レビュー依頼
  ↓
定期的なキャンペーン配信でリピート促進
```

**刺さるポイント**：
> 「広告で獲得した見込み客をLINEで育て、購入率を2〜3倍にする」

---

### 🏢 パターンF：BtoBサービス（SaaS・コンサル・代理店）

**課題**: リード獲得後の商談化率が低い、営業コスト

**打ち手**: リード→ナーチャリング→商談予約の自動化

```
ウェビナー/資料DL → LINE登録
  ↓
ステップ配信：業界レポート・導入事例・FAQ
  ↓
温度が上がったタイミングで商談予約案内
  ↓
カレンダー予約で自動アポ取得
  ↓
商談実施 → 受注後フォロー
```

**刺さるポイント**：
> 「営業が追いかけなくても、温まった見込み客から商談予約が入る」
