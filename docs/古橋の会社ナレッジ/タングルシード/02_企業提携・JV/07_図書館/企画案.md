# 図書館 - 提携企画案

## 1. 企画概要
知識と創造の拠点である図書館において、読書体験を補完し、集中力を高めるための「マインドフルネス・ワークショップ」を提供します。

### 導入メリット
- **「静寂」の提供**: 本を読むだけでなく、心身を静める場としての図書館の価値向上。
- **世代間交流**: 老若男女が一緒に楽しめる（バリアフリー）アートとしての親和性。
- **図書館離れ対策**: 体験型イベントによる新規来館者の創出。
- **教育的価値**: 集中力の向上、自己肯定感の育成など、生涯学習としての側面を強調。

---

## 2. 導入アプローチ
導入を成功させるための主要なアプローチステップ：

1.  **指定管理者（TRC, CCC等）への提案**:
    *   図書館を運営する大手企業（図書館流通センター、カルチュア・コンビニエンス・クラブ等）の本部へ、全国の館で横展開可能なパッケージとして提案。
2.  **「読書週間」や「夏休み」の特別企画**:
    *   10月下旬の読書週間や、子どもの自由研究に合わせた「ゼンタングルでブックマーク（しおり）作り」を提案。
3.  **しおり型体験キットの配布**:
    *   貸出カウンター等で、QRコード付きのゼンタングルしおり（未完成版）を配布。
4.  **図書館総合展への出展**:
    *   日本最大の図書館向け展示会に出展し、全国の司書や行政担当者へ認知。

---

## 3. 見積費用
（※公的機関のため、予算枠に合わせた調整が必要）

### A. 公的予算活用型ワークショップ
- **講師謝礼**: 20,000円〜50,000円 / 回（自治体・館の予算規定による）
- **教材費**: 無料、または実費程度（数百円）
- **メリット**: 図書館側の予算（生涯学習・イベント予算）で実施可能。

### B. 企業協賛型イベント
- **費用**: 協賛企業からの拠出（1回10万円〜）
- **メリット**: 図書館側の持ち出しゼロで、質の高い講師と画材を提供。

### C. 動画配信・デジタルキット提供
- **年間ライセンス**: 50,000円〜 / 館
- **メリット**: 館内のPC端末やタブレットで、いつでも動画を見ながら体験可能に。
