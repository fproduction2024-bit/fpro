# シニア向け施設・介護施設 - 提携企画案

## 1. 企画概要
高齢者の生活の質（QOL）向上、認知症予防、および手指の機能維持を目的とした、非言語・非競争のアートアクティビティとしてゼンタングルを提供します。

### 導入メリット
- **認知症予防・脳の活性化**: 集中してパターンを繰り返すことが脳トレに。
- **施設スタッフの負担軽減**: 外部講師による高品質なレクリエーション実施。
- **利用者の自己肯定感向上**: 「できた！」という成功体験を、絵心不要で提供。
- **家族へのアピール**: 「最先端の脳トレアートを導入している施設」としての差別化。

---

## 2. 導入アプローチ
導入を成功させるための主要なアプローチステップ：

1.  **レクリエーション仲介プラットフォームへの登録**:
    *   「エブリ・プラス」や「フォーセット」などの介護施設向け講師派遣サービスに登録。
2.  **大手運営会社の「本部」への提案**:
    *   各施設ごとの営業ではなく、ベネッセやSOMPOなどの本部のアクティビティ開発担当者へ一括提案。
3.  **オンライン・レクリエーションの実施**:
    *   ZOOM等を用いた全国の施設への同時配信型ワークショップの提供。
4.  **スタッフ向け研修（インストラクター化）**:
    *   施設のスタッフ自身がゼンタングルの基礎を教えられるようになるための研修パッケージを販売。

---

## 3. 見積費用
（※施設規模や頻度により調整可能）

### A. 出張ワークショップ（単発）
- **講師謝礼**: 15,000円〜30,000円 / 回（60分）
- **教材費**: 300円〜500円 / 人（画用紙・鉛筆・さっ筆等）
- **交通費**: 実費

### B. 定期開催パック（月1〜2回）
- **月額固定**: 25,000円〜50,000円（講師派遣 + 定期的なカリキュラム更新）
- **メリット**: 定期的な「楽しみ」として入居者の習慣化を促進。

### C. オンライン配信プラン
- **1接続あたり**: 5,000円〜10,000円 / 回
- **メリット**: 低コストで多くの施設・利用者に提供可能。
