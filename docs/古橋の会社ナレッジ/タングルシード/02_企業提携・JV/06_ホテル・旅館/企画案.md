# ホテル・旅館 - 提携企画案

## 1. 企画概要
宿泊客の「何もしない贅沢」をアップグレードする、旅先でのリトリート・アクティビティとしてゼンタングルを提供します。

### 導入メリット
- **宿泊体験の付加価値向上**: 景色を眺めるだけでなく、「手を動かして心を整える」能動的な癒しの提供。
- **滞在中の満足度アップ**: 雨天時でも楽しめる、室内での高品質なアクティビティとして機能。
- **旅の記念品**: 自分で描いたタイルを持ち帰ることで、宿泊の思い出が形に残る。
- **SNS/口コミ促進**: 美しい作品とホテルの空間を合わせた投稿が期待できる。

---

## 2. 導入アプローチ
導入を成功させるための主要なアプローチステップ：

1.  **「朝活/夕活ワークショップ」の提案**:
    *   朝の澄んだ空気、または夕暮れの静かな時間帯に30〜60分の体験会を実施。
2.  **客室アメニティとしての導入**:
    *   「客室で楽しむマインドフルネス・キット」として、ピグマペン、数枚のタイル、動画へのQRコードをセットにして設置。
3.  **宿泊プランオプション（リトリートプラン）**:
    *   「マインドフルネス宿泊プラン」として、専用のワークショップ、特別な画材、静かな席の確保をパッケージ化。
4.  **ウェルビーイング・ツーリズムとの連携**:
    *   外部のウェルネスサイト（Relux等）と連携した特別プランの作成。

---

## 3. 見積費用
（※施設格付けや利用人数により調整可能）

### A. 専属講師派遣プラン（定期開催）
- **講師料**: 50,000円〜100,000円 / 日（数回実施想定）
- **教材費**: 1,500円〜 / 人（高品質な素材を提供）
- **メリット**: ホテルスタッフの負担なく、プロの手による高品質な体験を提供。

### B. 常設セルフ・アクティビティプラン
- **導入サポート費**: 100,000円〜（スタッフ向け指導、案内板・什器制作）
- **キット卸価格**: 800円〜1,200円 / セット
- **メリット**: 24時間いつでも、利用者の好きなタイミングで提供可能。
