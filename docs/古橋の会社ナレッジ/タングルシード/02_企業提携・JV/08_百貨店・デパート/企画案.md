# 百貨店・デパート - 提携企画案

## 1. 企画概要
百貨店の優良顧客（外商顧客・カード会員）や、教養・美意識の高い層に向け、高品質な「マインドフルネス・アートプログラム」を提供します。

### 導入メリット
- **顧客ロイヤリティの向上**: 他の商業施設にはない、専門性の高い「癒しと芸術」の体験を提供。
- **来店頻度の向上**: 文化教室（スクール）形式での定期開催による定期的な来店。
- **高単価商材との親和性**: 画材のみならず、万年筆、ステーショナリー、インテリア額装品などの関連売上への波及。
- **ギフト需要の創出**: 「描いて贈る」文化の提案による、便箋・カード・封筒売場の活性化。

---

## 2. 導入アプローチ
導入を成功させるための主要なアプローチステップ：

1.  **百貨店内「文化教室」へのアプローチ**:
    *   伊勢丹の「OTOMANA」や三越の「三越カルチャープラザ」などの既存スクールへの講師派遣提案。
2.  **外商・VIP向けプライベートサロンイベント**:
    *   外商顧客向けの特別招待イベント（少人数制ワークショップ）として実施。
3.  **シーズナル催事との連動**:
    *   母の日、敬老の日、または「文具フェア」等の大型催事内の特設コーナーでの体験会。
4.  **「お受験・知育」文脈での提案**:
    *   子どもの集中力アップや情操教育を目的とした、親子ゼンタングル教室の開催。

---

## 3. 見積費用
（※百貨店の格付けやメニューにより調整可能）

### A. スクール形式（定期講座）
- **受講料（目安）**: 5,000円〜8,000円 / 回（材料費・お茶菓子代込）
- **百貨店手数料**: 受講料の40〜50%
- **メリット**: 百貨店側は高い手数料収入と、顧客の定期的な囲い込みが可能。

### B. 催事・イベント形式（単発）
- **運営委託費**: 100,000円〜 / 日（講師1〜2名派遣）
- **教材費**: 実費、または参加費に含まれる
- **メリット**: 短期間で多くの来客にアピールでき、フロアの活性化に寄与。
