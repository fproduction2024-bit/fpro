# カルチャーセンター・公民館 - 提携企画案

## 1. 企画概要
「新しい習い事」や「生涯学習」を求めるアクティブシニア層・主婦層に向け、定期講座としてのゼンタングル・クラスを提供します。

### 導入メリット
- **講座ラインナップの近代化**: 従来の「書道」「水彩画」に加え、「マインドフルネスアート」という新しい切り口を追加。
- **高い継続率**: ゼンタングルの段階的なカリキュラムにより、長期受講（半年〜数年）を促進。
- **集客力の活用**: カルチャーセンターが持つ既存の会員名簿や配布チラシによる効率的な募集。
- **地域貢献**: 公民館等での実施により、地域のメンタルヘルス向上・コミュニティ活性化に寄与。

---

## 2. 導入アプローチ
導入を成功させるための主要なアプローチステップ：

1.  **「一日体験講座」の企画提案**:
    *   まずは単発の体験講座（1,500円〜2,000円）を実施し、受講者の反応を見て本講座（3ヶ月〜半年）へ移行。
2.  **本部事務局への一括提案**:
    *   イオンカルチャーやNHK文化センターなどの本部へ、認定講師ネットワークを活かした全国展開を提案。
3.  **講師人材バンクへの登録**:
    *   各自治体の「生涯学習担当」へアプローチし、講師人材バンクへ登録。公民館からの依頼を待つ。
4.  **既存講座（ヨガ・瞑想等）とのコラボ**:
    *   「動のヨガ、静のゼンタングル」として、セット受講を提案。

---

## 3. 見積費用
（※施設や地域により調整可能）

### A. カルチャーセンター定期講座（3ヶ月単位）
- **受講料（目安）**: 3,000円 / 回（月2回開催、3ヶ月計18,000円）
- **施設手数料**: 受講料の30〜40%（施設側収益）
- **教材費**: 別途 2,000円〜3,000円（筆記用具・専用タイルセット）
- **メリット**: 施設側は空き教室の有効活用と安定した手数料収入。

### B. 公民館・自治体主催講座
- **講師謝礼**: 10,000円〜30,000円 / 回（自治体規定に基づく）
- **教材費**: 実費（参加者負担）
- **メリット**: 参加費を抑えられるため、新規層の獲得・認知拡大に最適。

| **5. 株式会社カルチャー** | 日本最大級のカルチャーセンター数。地方都市にも強い。 |
| **6. セブンカルチャークラブ** | イトーヨーカドー内。生活圏に近い場所での開催が可能。 |
