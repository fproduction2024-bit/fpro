# 企業福利厚生プログラム - 提携企画案

## 1. 企画概要
企業の従業員（特に女性社員や高ストレス職種）を対象に、マインドフルネスアート「ゼンタングル」を通じたメンタルヘルスケアおよび女性活躍推進を支援する福利厚生プログラムを提供します。

### 導入メリット
- **従業員満足度向上**: 「描くだけで整う」手軽なリフレッシュ体験の提供。
- **メンタルヘルス対策**: 集中状態（フロー）によるストレス低減。
- **女性活躍推進**: 女性特有のライフイベントによる不安を「整える習慣」で支える。
- **エンゲージメント強化**: 共創体験を通じた社内コミュニティの活性化。

---

## 2. 導入アプローチ
導入を成功させるための主要なアプローチステップ：

1.  **ターゲット部門特定**:
    *   人事部（採用・教育担当）
    *   健康保険組合
    *   ダイバーシティ推進室（DE&I担当）
2.  **無料体験セミナーの実施**:
    *   「15分で頭を空っぽにする方法」というタイトルで、オンラインまたはオフラインの無料デモを実施。
3.  **既存の福利厚生サービスへの導入**:
    *   「ベネフィット・ワン」や「リロクラブ」などの福利厚生代行サービスへのメニュー登録。
4.  **共創型の実証実験**:
    *   特定の部署（例：カスタマーサポートなどの高負荷部署）に1ヶ月間集中導入し、満足度データを取得して全社展開へ。

---

## 3. 見積費用
（※規模や頻度により調整可能）

### A. スポット体験会プラン（1回完結）
- **講師謝礼**: 50,000円〜100,000円
- **材料費（道具セット）**: 1,500円 / 人（ピグマペン + 練習用紙 + ガイド）
- **運営費**: 20,000円

### B. 定期開催プラン（月1回・半年契約〜）
- **月額費用**: 30,000円〜50,000円（オンライン配信、アーカイブ利用含む）
- **導入初期費用**: 50,000円（環境構築・アナウンス支援）

### C. オンライン講座アクセス権提供（サブスクリプション型）
- **ID課金型**: 300円〜500円 / 月 / ID
- **全社員開放型**: 月額固定 10万円〜（企業規模による）
