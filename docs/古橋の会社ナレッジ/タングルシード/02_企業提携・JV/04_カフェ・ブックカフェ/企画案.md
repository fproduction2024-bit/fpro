# カフェ・ブックカフェ - 提携企画案

## 1. 企画概要
「本とコーヒーとアート」の時間を楽しむ顧客層に向け、非繁忙時間帯を活用したマインドフルネス・ワークショップを提供します。

### 導入メリット
- **非繁忙時間帯の有効活用**: 平日の午前中や午後のティータイムに集客。
- **客単価の向上**: 「ドリンク＋ケーキ＋体験費」のセット販売による売上増。
- **コミュニティ形成**: 常連客同士のゆるやかな繋がりを創出し、リピート率向上。
- **ブランド体験の深化**: 「静かに自分と向き合う時間」を提供することでカフェの価値を向上。

---

## 2. 導入アプローチ
導入を成功させるための主要なアプローチステップ：

1.  **「コーヒーとゼンタングル」セットの提案**:
    *   特定のドリンクを注文すると、15分で描ける「体験コースター」とペンが付いてくるメニューの開発。
2.  **イベントスペースの活用**:
    *   店内の広いテーブルやイベントスペースを月1回貸切（または部分貸切）してワークショップを開催。
3.  **ブックカフェとの選書連動**:
    *   マインドフルネス、瞑想、自律神経、アートに関連する書籍棚の横で体験会を実施。
4.  **SNS・コミュニティへの告知協力**:
    *   店舗のInstagramやLINE公式アカウントでの告知。

---

## 3. 見積費用
（※カフェの規模や立地により調整可能）

### A. ワークショップ開催プラン（予約制）
- **参加費**: 3,000円〜4,500円 / 人（ドリンク・スイーツ代込）
- **売上配分**: カフェ側 30〜50% / タングルシード側 50〜70%
- **メリット**: 店舗側の持ち出しゼロで追加収益。

### B. 席置き「セルフ体験」プラン
- **キット販売価格**: 1,000円〜1,500円（ピグマペン1本 + 専用タイル2枚 + 描き方ガイド）
- **仕入れ価格**: 販売価格の60〜70%
- **メリット**: オペレーション負荷を最小限に抑えつつ、物販売上を確保。
