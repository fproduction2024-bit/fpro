# HP信頼性向上・提携強化のための構成案

提携先企業（資生堂・ヤクルト・地方書店等）や公的機関がアクセスした際に、「信頼に足るパートナーである」と確信を持たせるためのWebサイト構成案です。

## 1. サイト全体のキーコンセプト
**「15分の静寂で、社会を整える。日本最大級のマインドフルネス・アート・プロジェクト」**
単なる「絵画教室」ではなく、**社会的な「居場所作り」と「精神的健康（ウェルビーイング）」を支えるソーシャル・エンタープライズ**としての側面を前面に出します。

## 2. 信頼を構築する必須セクション（構成順）

### ① 圧倒的な数値実績（Social Proof）
企業の担当者が最初に確認する「数字」を配置します。
- **累計受講者数:** 40,000名突破（無料講座含む）
- **継続期間:** NPO団体での社会貢献活動 8年以上
- **満足度:** ワークショップ後の次回予約率 100%（書店提携時実績）
- **ネットワーク:** 全国の認定講師ネットワーク

### ② NPO活動・社会貢献の実績（The Roots）
「なぜこの事業をやっているのか」という大義名分を伝えます。
- **がん患者支援（カイツブリの会）:** 8年にわたり、がん患者の方々の心のケアとしてゼンタングルを提供してきた歴史。
- **居場所作り:** 高齢者や不登校の子供たちなど、社会的な繋がりを必要とする方々への貢献事例。
- **「食い扶持（経済的安定）」と「志」の両立:** 安定した経営基盤があるからこそ、純粋な社会貢献が可能であるという姿勢。

### ③ ゼンタングルの哲学（Methodology）
- **「間違いはない」:** 失敗を許容し、自己肯定感を高めるメソッドの説明。
- **誰でも描ける:** 技量に関わらず、15分で「整う」体験ができることの科学的・心理的アプローチ。

### ④ パートナーシップ・メニュー（For Partners）
提携先ごとに、具体的なメリットを明記します。
- **書店・カフェ運営者様へ:** 
    - 「手間ゼロ」運営（講師派遣・段取り・集客を全て当社が担当）。
    - 来店動機の創出、物販（ペン・専用画用紙等）の売上貢献。
- **法人・企業担当者様へ:** 
    - 福利厚生（従業員のメンタルヘルスケア）。
    - CSR/地域貢献活動としてのワークショップ共催。
    - 権威性を貸し出す「借景提携」（資生堂等、理念共鳴型ブランドとの協賛実績作り）。
- **認定講師の皆様へ:** 
    - サステナブルなライフスタイルの提供（月5〜10万稼げるお膳立て）。

### ⑤ 創業者・組織紹介（Profiles）
「誰が運営しているか」を明確にし、安心感を与えます。
- **古橋 美鳥（美鳥先生）:** 認定講師としての専門性と、8年にわたる草の根活動の想い。海外（アメリカ本家）との繋がり。
- **古橋 宏（代表/プロデューサー）:** 戦略立案・提携を支えるデジタル活用とビジネス視点。
- **運営会社:** 株式会社タングルシード（法人格としての明記）。

### ⑥ 信頼性を担保するリーガル・窓口（Footers）
- **法人専用問い合わせフォーム:** 「協業のご提案」「メディア取材」を独立させる。
- **会社概要 / 利用規約 / プライバシーポリシー / 特定商取引法に基づく表記**

## 3. 「提携戦略」を加速させるための工夫案
- **「なぞる紙（画用紙カード）」の連動:** HPから「なぞる紙」の無料サンプル請求や、設置協力者の募集ができるようにする。
- **活動レポート:** 提携実績（菊屋書店での開催風景など）を「信頼の積み上げ」として定期更新する。
- **お客様の声（アナザースカイ形式）:** 動画を通じた熱量の高いフィードバックの掲載。
