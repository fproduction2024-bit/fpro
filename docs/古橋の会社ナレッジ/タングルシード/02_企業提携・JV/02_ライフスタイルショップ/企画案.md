# ライフスタイルショップ・雑貨店 - 提携企画案

## 1. 企画概要
「丁寧な暮らし」や「心地よい日常」を提案するショップのコンセプトに合わせ、店内の文具や雑貨と連動した体験型ワークショップ「ゼンタングル体験会」を実施します。

### 導入メリット
- **店舗のメディア化**: 体験型コンテンツによる来店動機の創出。
- **滞在時間の延長**: 15〜30分のワークショップによる回遊性向上。
- **関連商品のクロスセル**: 店内で販売されている高級ペン、ノート、額縁などの同時購入。
- **SNS拡散**: 「美しい作品ができた」という達成感による店舗タグ付き投稿の促進。

---

## 2. 導入アプローチ
導入を成功させるための主要なアプローチステップ：

1.  **ショールーミング連携**:
    *   メイン通路やレジ横に、店内のペンだけで描いた美しい作品サンプルを展示。
2.  **イベントプラットフォームへの応募**:
    *   無印良品の「Open MUJI」公募や、ロフトの「文房具会議」などの定期イベントへの提案。
3.  **カレンダー・手帳シーズンとの連動**:
    *   10月〜1月の手帳シーズンに合わせ、「手帳の余白を飾るゼンタングル」として提案。
4.  **無料体験導線キットの設置**:
    *   QRコード付きの体験はがき（店内の試し書きペンで描けるもの）を什器に配置。

---

## 3. 見積費用
（※店舗規模により調整可能）

### A. 店内ミニ体験会（スタッフ派遣型）
- **参加費**: 1,500円〜2,500円 / 人（店舗とレベニューシェア）
- **講師料（弊社負担の場合）**: 売上の50%〜を店舗へ
- **什器・POP作成費**: 20,000円（初回のみ）

### B. 常設セルフ体験コーナー（什器設置型）
- **月額設置料**: 10,000円〜20,000円（什器維持・メンテナンス）
- **消耗品（体験用紙）**: 弊社提供
- **メリット**: 人員を割かずにLINEリードを獲得。
