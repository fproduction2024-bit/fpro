# ファンネル動画構成の抽象化と応用フレームワーク

## はじめに
このドキュメントは、みどりタングルサロンの5本構成の動画ファンネルを抽象化し、多様な商材やサービスにおいて「深いファン化」と「高成約率」を実現するためのフレームワークとしてまとめたものです。

---

## 1. 5ステップ・エモーショナル・ファンネル

各動画の役割を抽象化すると、以下の5段階の心理変容プロセスに分けられます。

| ステップ | 抽象化した役割 | 視聴者の心理状態 | 核心的な要素 |
| :--- | :--- | :--- | :--- |
| **Vol.1** | **共鳴と自己紹介** | 「この人は信頼できるか？」 | 弱さの開示、専門性と人柄の融合 |
| **Vol.2** | **小さな勝利（Success）** | 「自分にもできるかも？」 | 難解なことの分解、短時間での成果 |
| **Vol.3** | **深層価値の体験** | 「これは私に必要なものだ」 | 感情的メリット、フロー・癒しの疑似体験 |
| **Vol.4** | **日常への接続** | 「生活の中でどう使うか？」 | 実用例、ギフト性、社会的な広がり |
| **Vol.5** | **確信とクロージング** | 「人生を変える決断」 | 壮絶なビジョン、長期の旅の提示、圧倒的オファー |

---

## 2. 他商材への応用構成要素（フレームワーク）

### ステップ1：アイデンティティの確立（Who/Why）
- **ストーリーの源泉**: 自身がその問題を解決した「痛み」や「克服」の物語。
- **安心感の設計**: 権威性（実績）だけでなく、親しみやすさ（弱さ）をセットで提示する。
- **解決策の核心**: その手法がなぜ他と違うのかという「コンセプト」をチラ見せする。

### ステップ2：自己効力感の着火（Low Barrier to Entry）
- **マイクロ・アクション**: 道具を用意させ、その場で一つだけ完了させる。
- **スキルの民主化**: 「センス」が必要だと思われているものを、「手順」に還元して見せる。
- **無条件の肯定**: 上手い下手ではなく、取り組んだこと自体を肯定する場を作る。

### ステップ3：ベネフィットの深化（Emotional Value）
- **機能ではなく情緒**: 「何ができるか」ではなく「どう感じるか」にフォーカスする。
- **フロー体験**: 視聴中に雑念が消え、夢中になる瞬間を設計する。
- **ビジョン提示**: これを続けた先に待っている「より良い自分」をイメージさせる。

### ステップ4：社会性と実用性の提示（Contextualization）
- **TPOの具体化**: いつ、どこで、誰に対して使うのかというコンテキストを複数提示する。
- **他者への貢献**: 自分が満たされるだけでなく、周囲にポジティブな影響を与える方法を見せる（お裾分け文化）。
- **継続への自信**: 「毎日じゃなくてもいい」「放置してもいい」という継続の心理的ハードルを下げる工夫。

### ステップ5：オファーの正当化（Authority & Closing）
- **ビジョンへの招待**: 「講座を売る」のではなく「理想の未来へのコミュニティに招待する」姿勢。
- **価格の妥当性**: 個別サービス換算との対比、自身の人生をかけた投資との比較。
- **拒絶不能なオファー**: すぐに始められるスターターキットや、今だけの特典。

## 3. 応用時のチェックリスト

他の商材（例：料理教室、マーケティング支援、ヘルスケアなど）に応用する際の必須要素：

1. [ ] **「弱さ」と「強さ」の両立**: 講師は神様ではなく、先を歩く伴走者であるか？
2. [ ] **マジック・モーメントの設計**: 動画を見た直後に「え、私すごい！」と思う瞬間があるか？
3. [ ] **理屈と感情のバランス**: プライマー（理論）とインスパイア（感情）が交互に配置されているか？
4. [ ] **コミュニティの先行体験**: コメント欄やSNSでの盛り上がりを「自分も入る場所」として想起させているか？
5. [ ] **クロージングの長さ**: 最後に十分な時間をかけて、迷いを断ち切るだけの「意味」と「価値」を語り尽くしているか？
