## プロラインフリーの配信数無制限について

送信数が一定数を超えることで段階的に料金が上がる他ツールと比較して

プロラインフリーでは、どのプランでも送信数無制限でご利用いただけます、という意味です。

（プロラインフリーでは、構築するシナリオのステップ数に応じてプランを設定させていただいております。）

![送信数無制限について](https://autosns.co.jp/manual/wp-content/uploads/2023/01/Delivered01-1024x793.jpg)

LINE公式アカウント側では、送信数によってプランがありますので無料のメッセージ配信数を超える場合には、必要に応じて別途ご契約が必要になります。

補足

どのようなツールをお使いいただく場合でもMessaging API （この場合は、プロラインフリー）を通して送るメッセージは、

LINE公式アカウントの送信数としてカウントされます。

（無料の通数を超えるご利用の場合には、別途[LINE社への申し込み](#number1)が必要となります。）

## プロラインフリーで配信する際に、LINE公式アカウントにて換算される送信数について

LINE公式アカウントの送信数としてカウントされる内容については、

Messaging API (この場合プロライン)を通して送る以下のメッセージは基本的にカウントされます。

・ステップ配信メッセージ（原則１ステップ1通）

・臨時メッセージ配信

・送信完了メッセージ

・テスト送信

・チャット(プロライン経由)

他にも設定している場合には、以下のメッセージも通数に含みます。

・顧客活動通知メッセージ

・チャット受信通知メッセージ

例外として、友だちのLINE上でのアクションに対して30秒以内に反応するメッセージはカウントされません。  
（「チャット」も相手からメッセージを受信して、30秒以内にレスできれば通数にカウントされません。）

ネットワークやLINEに遅延などが発生していなければ、30秒以内に反応しますので以下のメッセージは通常は通数にカウントされません。

・応答メッセージ

・ボタン応答メッセージ

・初期登録シナリオの1通目

（※Messaging APIの仕様は、LINE社に依存している為、内容が変更になることがございます ）

補足

プロラインフリーと、ChatWorkやSlackと連携をすることで、LINE公式アカウントの月間メッセージ送信数を消費せずに管理者（複数も可能）に各種通知（顧客活動通知メッセージなど）を送る事が可能になりました。

## LINE公式アカウントに比べて送信数を節約できる部分について

プロラインではユーザーに合わせたセグメント配信や５フキダシまでを１通で送ることによって配信数をご節約していただけます。

### 1通で５つのフキダシを送ることができるとは…

５つのフキダシとは、例えば、「テキスト＋画像や画像を含むボタンなど（クリックする設定やカルーセルも可能）＋テキスト＋複数ボタン＋テキスト」のように

好きな組み合わせで５つの要素まで1通として送ることができるということです。

![フキダシとは]()

（LINE公式アカウントの場合は、1通として送ることができる内容は３フキダシまでです。）

### 反応によってシナリオ移動を変えて配信数を節約できるとは

例えば同じ１０ステップの場合であっても

全ての人に１０通目までのステップを配信した場合には、人数×１０通の送信数が必要となりますが、

プロラインフリーでは、以下の図の様にユーザーのアクションによって移動する設定が可能ですので、

![反応によってシナリオ移動が自由自在]()

すぐに回答する人は、  
「図の①→②→③→④」の４通で終わりにすることもできますし、

逆に全く反応しない人は、  
「図の①→②→③」の３通で終わりにすることもできます。（再度、ループする設定なども可能です。）

## LINE公式アカウントの無料メッセージ送信数を超えた場合にはどうすれば良いか

LINE公式アカウントの送信数上限（※）に達した場合は、プロラインフリーからも送信できなくなります。

（※公式側の契約プランがコミニュケーションプラン（フリープラン）の場合、無料メッセージ通数は、月200通です。）

そのため、LINE公式アカウントでアップグレードするためには、

プロラインフリーの管理画面上メニューの「LINE公式アカウント」をクリックして

![LINE公式アカウント]()

ログイン後、右上の該当アカウントの［設定］マークをクリックして

![設定]()

『利用と請求』＞［月額プラン］よりアップグレードしていただけたらと思います。

![月額プラン]()

※**PC版LINEの場合、動作に様々な制限がある事がございます。**  
その為、正確な動作確認をしたい場合は、スマホ版LINEアプリをご利用ください。
