# LINE公式アカウントのIDを好きなID（プレミアムID）に変更する方法

2022年1月12日

![LINE公式アカウントのIDを好きなID（プレミアムID）に変更する方法](https://autosns.co.jp/manual/wp-content/uploads/2020/08/eye_premium-id_1200×630.png)

[このページを印刷](javascript:void(0))

LINE公式アカウントのIDは、ランダムに文字列が生成されてしまいます（好きな文字列にすることができません）。

しかし、LINEが有料で提供する「プレミアムID」に申し込むことで、自分の好きな文字列に設定し直すことができます。

#### 手順1：LINE Official Account Managerにログインします

LINE Official Account Managerにログインします。  
<https://account.line.biz/login>

#### 手順2：プレミアムIDを設定したいアカウントを選択します

アカウントリストから、プレミアムIDを設定したいアカウントを選択します。

![LINE公式アカウント アカウントリスト](https://autosns.jp/manual/wp-content/uploads/2020/08/img_account_list.png)

#### 手順3：プレミアムIDを選択します

アカウントページの右側にある「歯車マークの設定」をクリックします。

![LINE公式アカウント設定]()

利用と請求より、プレミアムIDをクリックします。

![LINE公式アカウント利用と請求]()

#### 手順4：支払い方法の設定をします

支払い方法の登録をしていない場合は、「お支払い方法を登録」より、支払い方法の登録をおこないます。

支払い方法を登録後、プレミアムIDを購入の欄にプレミアムIDに設定したい文字列を入力し、「プレミアムIDを購入」をクリックして購入します。

![LINE公式アカウント プレミアムID]()

※**PC版LINEの場合、動作に様々な制限がある事がございます。**  
その為、正確な動作確認をしたい場合は、スマホ版LINEアプリをご利用ください。
