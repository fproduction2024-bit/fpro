## 🔍 重要な発見

### URLフォーマット

TanglePatterns.comは**ブログ形式**で運営されており、パターンページのURLは以下の形式：

```
https://tanglepatterns.com/YYYY/MM/how-to-draw-{pattern-name}.html
```

- `YYYY/MM`: 投稿年月
- `{pattern-name}`: パターン名（小文字、ハイフン区切り）

### Auraについて

- 公式パターンリストに **Aura単体のエントリーがない**
- **Auraknot**（ID 9番）というパターンは存在
- Auraは「オーラ技法」として、他のパターンに適用される **テクニック** である可能性が高い
- タグページや技法ページで説明されている可能性
