# タングル図鑑 改善キット — はじめにお読みください

タングルシード公式サイトの「タングル図鑑」（全154タングル）を、本番公開できる品質に仕上げるためのキットです。
内容の確認と改善を、あなたのPCとAIアシスタントで進めていただくための一式が入っています。

## 入っているもの

| ファイル | 内容 |
|---|---|
| `tangle_zukan_check.html` | **人が見るチェックシート**。ダブルクリックでブラウザが開きます |
| `AI_INSTRUCTIONS.md` | **AIアシスタントに読ませる指示書**（改善ルールと作業手順） |
| `data/patterns.ts` | 図鑑の元データ（ここを修正します） |
| `data/reference_urls.md` | 各タングルの参考ページ（TanglePatterns.com）調査結果 |
| `images/patterns/` | タングル画像の置き場所（現在3枚のみ） |
| `tools/` | チェックシートを作り直す道具（AIが使います） |
| `CHANGELOG.md` | 変更記録（AIが書き込みます） |

## 進め方（3ステップ）

1. **見てチェックする**
   `tangle_zukan_check.html` を開き、1タングルずつ内容を確認してください。
   「OK / 要修正 / 削除・統合」を選び、直してほしいことをメモ欄に書きます（例：「読みはアイソコールが正しい」「手順3は実際と違う。斜めに線を引く」）。
   画像を用意できるタングルは `images/patterns/` に入れてください（ファイル名はチェックシートの「画像なし」の下に出ている名前、例：`cadent.jpg`）。

2. **チェック結果を書き出す**
   チェックシート上部の「CSV書き出し」を押し、保存されたCSVファイルをこのフォルダの `feedback/` フォルダに入れます（無ければ作ってください）。

3. **AIに改善してもらう**
   AIアシスタント（Claude など）でこのフォルダを開き、次のように頼んでください。

   > このフォルダの AI_INSTRUCTIONS.md を読んで、その指示どおりにタングル図鑑を改善してください。

   AIが修正し終えたら、チェックシートが作り直されます。もう一度開いて確認し、1〜3を納得いくまで繰り返します。

## 終わったら

このフォルダ全体をZIPにまとめて、古橋までお送りください（`data/patterns.ts`・`images/patterns/`・`CHANGELOG.md` が反映対象です）。

※チェックの記録はブラウザ内に保存されます。別のPCやブラウザで続ける場合は「JSON書き出し」→ 先のPCで「JSON読み込み」をしてください。
