# Web-to-Markdown Crawler Tool

このツールは、指定したURLから開始してサイト内の複数のページを自動的に巡回（クロール）し、それぞれの内容をMarkdown形式で保存するための汎用スクリプトです。

## セットアップ

### 必要ライブラリのインストール
Pythonがインストールされている環境で、以下のコマンドを実行して必要なライブラリをインストールしてください。
```bash
pip install requests beautifulsoup4 markdownify
```

## 使い方

### 基本的なコマンド
```bash
python3 web_to_md_tool.py [対象URL] [保存先フォルダ]
```

### オプション引数
- `--max [数値]`: 保存する最大ページ数を指定します（デフォルト: 50）
- `--delay [秒数]`: ページ取得ごとの待機時間を秒単位で指定します（サイトへの負荷軽減のため。デフォルト: 1）
- `--strict-path`: 開始URLのディレクトリ階層以下のみをクロール対象にします。サイト全体ではなく、特定のセクションのみを抽出したい場合に有効です。

### 実行例
`https://example.com/blog/` というサイトの記事を最大100ページ分、`my_blog_markdown` というフォルダに保存する場合：
```bash
python3 web_to_md_tool.py https://example.com/blog/ my_blog_markdown --max 100 --delay 1
```

## ツールの仕組み
1. **開始URLの解析**: 指定されたURLからリンクを抽出します。
2. **ドメイン制限**: 開始URLと同じドメインかつ、同じディレクトリ階層以下のリンクのみをクロール対象とします。これにより外部サイトへの不用意な遷移を防ぎます。
3. **本文抽出**: `article`, `main`, `div.content` などのタグを探して本文を特定します。見つからない場合はメニューやヘッダーを自動で除外して本文を推定します。
4. **Markdown変換**: HTML構造を美しくMarkdown形式に変換して保存します。
